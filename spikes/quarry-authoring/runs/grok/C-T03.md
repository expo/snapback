A page `| count` is a capped fact about a bounded read, not the population total, so the dashboard uses a maintained `count applications by posting`. `postings[viewer] last 20` uses the existing `by employer, createdAt` ordering.

```
table users:
  name: text <=80

table postings:
  employer: users
  title: text <=200
  createdAt: time
  by employer, createdAt

table applications:
  posting: postings
  applicant: users
  at: time
  by posting, at
  read a <- a.applicant = viewer or postings[a.posting].employer = viewer

maintain n = count applications by posting

query dashboard():
  postings[viewer] last 20 {
    *,
    n: #n[.]
  }
```
