The public leaderboard cannot derive a population maximum from `entries[contest] last 1`: that page is baker-private and only a fact about visible rows. A declared `#` maintained max is the exact public top score.

```
table users:
  name: text <=80

table contests:
  title: text <=200
  endsAt: time

table entries:
  contest: contests
  baker: users
  score: int
  at: time
  by contest, score
  read e <- e.baker = viewer          -- private to the baker until the contest closes

maintain top = max entries of score by contest (readable: public)

query topScore(contestId: contests):
  #top[contestId]
```
