The class is a point read shaped to title and start time; instructor and the earliest 20 bookings are nested shaped joins on the existing `by class, at` order.

```
table users:
  name: text <=80

table studios:
  name: text <=100

table classes:
  studio: studios
  title: text <=200
  startsAt: time
  instructor: users
  by studio, startsAt

table bookings:
  class: classes
  user: users
  at: time
  by class, at

query classDetail(classId: classes):
  classes[classId] {
    title,
    startsAt,
    instructor: users[.instructor] {
      name
    },
    bookings: bookings[.] first 20 {
      *,
      user: users[.user] {
        name
      }
    }
  }
```
