The unread badge is a 99-row page count (`capped int`), which is exact through 99 and renders as `99+` when `.more` is set.

```
table users:
  name: text <=80

table shows:
  title: text <=200

table subs:
  user: users
  show: shows
  lastListenedAt: time
  by user, lastListenedAt

table episodes:
  show: shows
  publishedAt: time
  title: text <=200
  by show, publishedAt

query inboxBadges():
  subs[viewer] last 50 {
    show: shows[.show],
    unread: episodes[.show] after .lastListenedAt first 99 | count
  }
```
