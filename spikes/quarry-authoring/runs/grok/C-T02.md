Range reads must be bounded, so this uses the existing `by owner, createdAt` ordering with `last` for newest-first and a page cap (`.more` if there are more).

```
table users:
  name: text <=80

table recipes:
  owner: users
  title: text <=200
  createdAt: time
  by owner, createdAt

query myRecipes():
  recipes[viewer] last 50
```
