Expiry is checked against `commit` (not `now`); `now` is only stored on the redemption row.

```
table users:
  name: text <=80

table promos:
  code: text <=32
  discount: int
  expiresAt: time
  unique code

table redemptions:
  promo: promos
  user: users
  at: time
  unique promo, user

mutation redeemPromo(code: text <=32) -> redemptions:
  promo = promos[code]! else NO_PROMO
  require promo.expiresAt > commit else PROMO_EXPIRED
  require not exists redemptions[promo, viewer] else ALREADY_REDEEMED
  +redemptions { promo, user: viewer, at: now }
```
