```ts
const users = table("users");      // { id, name }
const recipes = table("recipes");  // { id, ownerId, title, createdAt }
                                   // index recipes.byOwnerCreated: (ownerId, createdAt)

export const myRecipes = query({}, ({ db, ctx }) => {
  return db.scan(recipes.byOwnerCreated, [ctx.viewer], { order: "desc" });
});
```

This query scans the recipes by the existing (ownerId, createdAt) index, pinning ownerId to the current viewer and ordering by createdAt descending for newest-first results. The index supports this access pattern directly without schema changes.
