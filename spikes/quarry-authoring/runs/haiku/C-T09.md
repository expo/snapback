Looking at this task, I need to:
1. Get the viewer's recent subscriptions (up to 50)
2. For each, count episodes published since the last listened time
3. Cap the display at 100 to show "99+" for large counts

The key insight is that asking for `first 100` episodes returns a `capped int` with `.count` (exact up to 100) and `.more` (whether there are more). The client can display "99+" whenever `.more` is true or the count reaches 100.

```
table users:
  name: text <=80

table shows:
  title: text <=200

table subs:
  user: users
  show: shows
  lastListenedAt: time
  by user, lastListenedAt

table episodes:
  show: shows
  publishedAt: time
  title: text <=200
  by show, publishedAt

query inboxBadges():
  subs[viewer] last 50 {
    show: shows[.show].title,
    unreadCount: episodes[.show] after .lastListenedAt first 100 | count
  }
```

For each subscription, this fetches up to 100 unheard episodes and reduces to a capped int. The client displays the badge by showing the exact count if under 100, or "99+" if the capped result indicates 100 or more episodes exist.
