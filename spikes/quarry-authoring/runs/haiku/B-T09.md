Looking at this task, I need to:
1. Scan up to 50 of the viewer's subscriptions
2. For each, count episodes published after `lastListenedAt`
3. Display the count capped at "99+" using the `.countCapped()` pattern from Rule 5

The key insight from the "capped display count" trap is that I can't use a `.count()` reduction to get a true total population (that would violate Rule 5). Instead, I scan with `take: 100` and use `.countCapped()` to detect overflow — if the page is full, there are 100+ episodes, so I display "99+".

When `lastListenedAt` is null (user never listened), I scan all episodes for that show.

```ts
const users = table("users");
const shows = table("shows");
const subs = table("subs");
const episodes = table("episodes");

export const inboxBadges = query({}, ({ db, ctx }) => {
  let result: any[] = [];
  
  const subs_page = db.scan(subs.byUser, [ctx.viewer], { take: 50 });
  
  for (const sub of subs_page) {
    const show = db.get(shows, sub.showId);
    
    let episodes_page: any[];
    if (sub.lastListenedAt === null) {
      episodes_page = db.scan(episodes.byShowPublished, [sub.showId], { take: 100 });
    } else {
      episodes_page = db.scan(episodes.byShowPublished, [sub.showId], 
                              { after: sub.lastListenedAt, take: 100 });
    }
    
    const { count, atCap } = episodes_page.countCapped();
    const badgeCount = atCap ? "99+" : String(count);
    
    result.push({
      showTitle: show.title,
      badgeCount
    });
  }
  
  return result;
});
```
