Looking at this problem, the key insight is the **read restriction**: entries are private until the contest closes. Yet the leaderboard needs to show the top score publicly.

The solution uses a **maintained aggregate** with a `(readable: public)` declaration. This creates a public view of the maximum score despite the visibility rules on individual entries—exactly what the "declared disclosure" mechanism is for. The query simply reads this O(1) aggregate.

```quarry
table users:
  name: text <=80

table contests:
  title: text <=200
  endsAt: time

table entries:
  contest: contests
  baker: users
  score: int
  at: time
  by contest, score
  read e <- e.baker = viewer

maintain topScore = max entries of score by contest (readable: public)

query topScore(contestId: contests) -> int:
  #topScore[contestId]
```
