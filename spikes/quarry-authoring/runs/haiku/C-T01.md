```
table users:
  name: text <=80

table studios:
  name: text <=100

table classes:
  studio: studios
  title: text <=200
  startsAt: time
  instructor: users
  by studio, startsAt

table bookings:
  class: classes
  user: users
  at: time
  by class, at

query classDetail(classId: classes):
  classId {
    title,
    startsAt,
    instructor: users[.instructor] { name },
    bookings: bookings[classId] first 20 {
      *,
      user: users[.user] { name }
    }
  }
```

The query takes a class reference, shapes it to include title and start time, reads the instructor's name via a nested read, and fetches the earliest 20 bookings (ordered by `at` ascending per the index) with each booker's name resolved.
