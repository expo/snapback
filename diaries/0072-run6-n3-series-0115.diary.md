## What the series settles

**Tokens ~2.2–2.4x is the real standing number.** Nine Snapback lanes,
three configurations, tight per-configuration token bands, agreeing
with run 5's N=1. Wall is the noisy metric — the skill lane's 2.42x
and 4.57x were the same configuration two hours apart; the 4.57x draw
spent its excess on two genuinely new framework finds, not on repeated
known friction. Run 5's 1.84x wall was a favorable draw, not the
center. Anyone quoting a single-run wall ratio in either direction is
quoting noise; LLP 0186 OQ2's instinct and diary 0066's tokens-over-
wall rule are both confirmed by measurement now.

**The zero-defect claim replicated 9/9 and got stronger.** Not one
defect-shaped framework loop in any Snapback lane; 27 first-try
codegen/typecheck passes; every refusal named its rule (the PNG-CRC
refusal quoting the exact failing chunk did it again — two lanes
hand-typed bad base64 and were each told precisely why). What remains
is knowledge-shaped and now enumerated to mechanism-level precision —
see residue.

**The control is stable and its costs are structural.** Convex's band
was 10m45s–12m50s / 94–109k under the same fleet load — its floor is
real and it is excellent at what it is. But the same three structural
facts recurred 3/3: emoji field names refused at runtime (chat's most
natural key!), offline hand-rolled and disclaimed every time, presence
rebuilt from durable primitives. Plus CLI churn 2/3 (deprecated
`--local`; hidden port flags dug out of `cli.bundle.cjs`). The
"agents don't read docs on Convex" fact held 3/3 — zero doc fetches.

**Native is the steadiest Snapback carrier.** 2.84–2.90x wall in all
three repeats, every proof on the simulator every time, zero
data-plane misbehavior; its entire cost center is Apple ceremony
(Expo Go acquisition, scheme approval, permission prompts, no
first-party headless tap, and the iOS 26.3 emoji-less simulator
runtime — third independent sighting across runs 4 and 6).

## Residue (round 4) — mechanism-precise, all ticketed

1. Cross-tab shared-leader connection makes presence read as "self" —
   two independent lanes, WS-trace + mechanism named; needs a guide
   line and possibly a per-tab identity option.
2. Supervisor child inherits `SNAPBACK_CLIENT_RQS_DIR`, takes the file
   store writer lock, and `commitReactBindingReceipt` refuses with a
   result that never names the other-process-writer cause.
3. Headless `liveQuery({transport:'stream'})` with `rqsStore:null`
   refuses `SNAPBACK_QUERY_OFFLINE_UNAVAILABLE` against a reachable
   server.
4. Retention flush latency is real (~seconds) and undocumented; a
   release web export silently prunes the baked supervisor origin —
   together they make honest offline proofs trial-and-error.
5. npm discovery: the packages ship no README to npmjs — nothing tells
   a newcomer the fastest path is `snapback new` + the shipped skill.
6. Offline image bytes are not retained while text history is — the
   gap between "offline-readable history" and user expectation; docs
   silent.

The expo-chat web-deps gap hit all six web lanes this series — the fix
is already on main (P1, this morning) and rides the next release; the
series measured 0.1.15 as published, honestly.
