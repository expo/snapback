## Commission

Charlie ratified LLP 0146's D1–D3 first tranche for implementation at
author decision sitting #2. Scope, exactly as the RFC defines the three
decisions:

1. **D1 — declaration/observation conformance**, with the sitting's OQ1
   ruling applied: **strict mode is opt-in for newly generated apps** —
   a newly generated app does not opt in by default; strict-mode
   authoring is the opt-in surface for new and legacy apps alike.
2. **D2 — `snapback verify`, the done-oracle**, as the RFC defines it
   (CLI-orchestrated; not the pinned `acceptance.run` host operation).
3. **D3 — the agent digest**, as the RFC defines it.

The sitting also ruled OQ8: the Cloudflare fan-out stays **conservative
widening** for now — no hosted claim in this tranche is gated on
recovering fan-out precision.

## Boundary — OQ7 was NOT ruled

The sitting deliberately did not rule OQ7 (the CV-14 custody trigger in
the 0062 family). Implementation of this tranche **must not claim CV-14
custody satisfaction** without the custody owner's ratification. Any
D4-adjacent digest/verify work that would imply CV-14 custody stops at
an honest nonclaim.
