# conformance: complete the LLP 0095 fixture corpus over the 0093 negative inventory

**Opened:** 2026-07-25
**Source:** LLP 0095 §2.4 / LLP 0093 D2 + Rollout P-1 (the fixture corpus
skeleton landed seeded, not complete — by design).
**Systems:** Wire Protocol, Tests, Native Clients

`schemas/live.wire-fixtures.v1.json` (generated by
`src/wire_fixtures.rs::wire_fixture_corpus()`, drift-gated through
`artifact_instances()`) seeds the durable-envelope families, the fact-2b
`durable_bytes` case, connection-wide resync, lane-P wrapper framing, the
acknowledged-batch malformed item, and the first two tolerance negatives.
The remaining classes LLP 0093 enumerates are deferred:

- **Malformed capability offers** (coordinate with P-0, which owns the
  offer matrix — these fixtures exercise `direction: client_to_server`
  refusal behavior, a direction the seeded corpus doesn't carry yet).
- **Cancelled/duplicated drains**: duplicate tolerance across the LLP 0059
  ownership cut — needs a multi-step fixture shape (drain, cancel,
  re-drain with overlapping entries), i.e. a `steps` array the v1 format
  should grow compatibly.
- **Arm-mismatch transitions**: attempting `poll/hosted`; hosted subscribe
  before socket establishment (`SNAPBACK_CONNECTION_SOCKET_REQUIRED`);
  socket loss mid-subscribe.
- **Grant-loss recovery**: `SNAPBACK_CONNECTION_TOKEN_INVALID` after local
  idle reap and after hosted grant expiry, asserting LLP 0095 §4.4's
  re-open-and-re-establish-everything semantics.
- **Wrapped/unwrapped parity** for every durable family (today only
  `live_replace` has both framings).
- **Heartbeat/freshness/backoff timing fixtures** — need a virtual-time
  notion the v1 fixture format does not define; growing the format is part
  of this ticket, additive-only (`formatVersion` bumps on any incompatible
  change).

Each addition: extend `wire_fixture_corpus()`, regenerate
(`cargo run --bin snapback-schemagen`), and extend
`tests/wire_fixtures_v1.rs`'s seeded-class census.
