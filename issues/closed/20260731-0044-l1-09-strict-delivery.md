# 0044 L1-09: private-strict delivery with ranges

**Status:** RESOLVED. **Authority:** LLP 0044 §Delivery profiles (URL
identity, private-strict), §Authorization.

The authorized delivery route over (asset, rendition) aliases — blob
keys never in URLs. Every ordinary and range request re-authorizes;
revocation/deletion denies the next request. Cache-Control: private,
no-store; trusted Content-Type/Content-Length/ETag facts; sanitized
filenames; active-content types (SVG/HTML/XML) always attachment
disposition. HTTP range support sufficient for video seek. signed/
public profiles are follow-on; a lifecycle-v1 target requires strict.

Done when: the delivery acceptance rows pass, including range
correctness, alias identity under dedup (deleting A leaves B
deliverable), and the disposition rules.
