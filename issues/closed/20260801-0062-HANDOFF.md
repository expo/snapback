## What this program is

Every Snapback app mechanically gets a command-line tool for its own
API — primarily for agents. Per the author's 2026-08-01 direction, the
post-Node distribution is **one app-bound Ibex executable**: it embeds
Ibex/Hermes, the generic trusted engine, and the app binding, and
fetches the app's API envelope dynamically. Ordinary app deploys do NOT
rebuild it. The governing doc is `llp/0062-generated-app-cli-and-code-mode.rfc.md`
(Status: Review, program recommissioned) — **read it in full first**,
especially §4 (eligibility), §5 (envelope), §6 (the one-file
direction), §7 (acceptance families).

## Rules of engagement (house method — follow exactly)

- Work in a git worktree on a fresh branch off **origin/main** (it moves
  fast — a concurrent fleet pushes constantly; `git fetch && checkout -B
  <branch> origin/main`, rebase before every push, retry ×3).
- Foreground commands with generous timeouts; ranged reads of large files
  (background/whole-file reads have stalled forks). Commit at every green
  boundary so interruptions cost nothing.
- Gates before any land: `cargo build`, full `cargo test --lib` (must be
  0 failed — it was 1621 passing at handoff), the pinned suites
  (`route_policy_v1 artifact_schemas_v0 name_keying_guard capability_v0
  host_ops_v0`), the app-cli/codegen/client package suites, the two live
  acceptance journeys, `check-generated-artifacts`, `ref-check`,
  `clippy --lib` 0 warnings. Codegen changes rotate demo artifacts
  (the inputsHash trap) — regenerate and commit them.
- Every LLP amendment uses the dated-amendment idiom + a Revised-header
  entry. New diagnostics get classified in the S5.D10 reviewed inventory
  (the gate will catch you otherwise). New public routes get a 0031 dated
  amendment + route_policy_v1 registry/probe entries.
- Close each ticket into `issues/closed/` with a resolution note citing
  the landing commit and the evidence (which test proves it).
- **Author-facing, do not decide alone:** anything that changes a frozen
  authoring spelling, the exit taxonomy, or a commercial/pricing surface
  is Charlie's call — raise it, don't pick.
