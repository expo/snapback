# IR evaluator public subpath landed without a prospective bundle freeze

**Date:** 2026-08-04
**Status:** Resolved in this landing
**Area:** `@expo/snapback-client/ir-evaluator`, client bundle metrology
**Governing:** LLP 0063, LLP 0145, LLP 0155

## Origin

Move-3 M1 added the public `./ir-evaluator` export in `f231c6386` but did not
add its prospective supplemental bundle ledger. This landing's
`scripts/verify-local-proof` run found the omission when
`scripts/client-bundle-metrology.mjs` failed fast with
`SNAPBACK_CLIENT_BUNDLE_RATCHET_FAILED: profile public-subpath-ir-evaluator has
no frozen baseline`.

Because the missing-baseline check failed before the complete active-ledger
comparison, it also masked the accumulated post-`ffee324ec` closure changes:
25 predecessor-backed profiles changed (24 grew and one shrank), and two later
public subpaths had no first-run ceiling. Those changes are recorded separately
in `issues/20260804-bundle-closure-growth-review.md`; they are not treated as
part of this defect's additive freeze.

## Resolution

Added the declared supplemental ledger
`baseline.ir-evaluator.v1.json`, generated by the runner's own
`--write-supplemental-baseline` mode on Node 24.18.0. The frozen
`public-subpath-ir-evaluator` closure is:

- minified: 21,295 bytes
- gzip: 7,615 bytes
- Brotli: 6,739 bytes

The M1 used-exports sizing spike recorded 20,833 minified / 7,383 gzip. The
public-subpath measurement is nearby: +462 minified (+2.2%) and +232 gzip
(+3.1%), consistent with the namespace-style public export fixture rather than
a material closure surprise.

The runner now declares the supplemental profile, input digest, governing
authorities, and shipping IR evaluator behavior test. Existing frozen ledgers
were not edited.

## Verification

The frozen-ledger comparison passes with 43 profiles and no ceiling
regressions. The same source tree and pinned runtime passed all real behavior
commands on the network-capable Air verifier before its SSH transport became
unavailable. A final literal combined rerun from this sandbox reaches

`volta run node scripts/client-bundle-metrology.mjs --check` in a
network-capable shell to retain the one-process witness.
