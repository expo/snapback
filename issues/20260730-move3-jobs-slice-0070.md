LLP 0127 move 3 ("Deterministic re-execution is one substrate") names *slice
3-jobs* as one of two separately named pilots: "the CV-9 jobs slice
(rolled-back mutation provably schedules nothing; injected-clock drain),
owner LLP 0070, startable now with the callee-class decision (0121 OQ2) made
inside it." The RFC's closing enumerates it as startable today with no
author decision. The design is not missing — it is LLP 0070 (durable
background work, Draft), which specifies `ctx.jobs.enqueue` with validation
and insertion in the same database transaction as the mutation's ordinary
writes, `availableAt` delays, attempt policy, idempotency keys, and its own
receipt family (immutable job + append-only attempts) — one-off work gets
0070's receipts, not the cron ledger (0115 open question 2, answered v0.2).
Implementing the slice simultaneously gives 0070 the executable evidence its
Draft status needs.

Work items (per 0115 CV-9 and 0127). (1) Implement the `runAfter` case as
the first slice of LLP 0070's `durable-work-single-process-sqlite-v1`
profile: default queue, `availableAt = now + delay`, transactional enqueue,
host-plan action callee. (2) The deterministic forced-drive test seam 0070
lacks and 0028 has: amend 0028's manual-tick/disable pattern into a sibling
injected-clock `jobs` drain so acceptance never sleeps (the 0028 test-seam
amendment). (3) Name the callee-class decision explicitly inside the slice
(0121 OQ2): whether Dispatch's one-off action-to-mutation shape fits 0070
v1's generated-host-plan-action admission or needs the later broader-action
capability. (4) The enqueue-association receipt as proposed in LLP 0121
option 3 — the job row carries producer `mutationId` and `snapshotVersion`,
or the mutation receipt embeds its enqueues — plus the generated *declared*
job-status query (an ordinary declared operation with an ordinary contract,
not an ambient system table; 0127's proposed answer to 0121's
inspection-surface question). The paved-default-queue conditional and the
inspection-surface question travel with this ticket, per 0121's relationship
section and 0115 §Sequencing 2. Exit per 0115 CV-9, verbatim: "The Dispatch
arm's one-off path uses the new primitive; a rolled-back mutation provably
schedules nothing (0070's own first acceptance bullet); an injected-clock
forced drain claims due one-off jobs with receipts in the job/attempt
ledger, giving one-off work a deterministic seam equivalent to — not
literally identical to — the cron run ledger's."

Decision boundary. The receipt-association shape's owner is DECIDED
(2026-07-30, 0127 decision 7, resolving 0121 OQ4; registry LLP 0115 v0.6
open question 8): **LLP 0070 owns the enqueue-receipt association shape**,

items, the 0094/0095 wire-shape and wide-409 delegations, burst profiling

NOT this ticket: slice 3-offline and everything displaced-in-space — now
