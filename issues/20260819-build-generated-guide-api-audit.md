# Build-generated guide API needs expansion-aware privilege proof

The privilege-surface scanner now fails closed on public-module Rust loaded
from `OUT_DIR`. `snapback-server::guide` intentionally includes
`embedded_guide.rs`, generated by `crates/snapback-server/build.rs` from the
checked guide corpus. The generated file contains the embedded byte table and
section-path constants only; it does not name a raw SQL handle, an LLP 0284
seed type, or an authority discriminator.

The temporary `generated-api` review row expires on 2026-09-19. Replace it with
an expansion-aware proof that parses the exact generated file (or a committed,
drift-checked API-shape manifest) before expiry. The proof must keep arbitrary
other `OUT_DIR` includes fail-closed.
