# Repository issues

Repository-scoped engineering follow-ups use `YYYYMMDD-slug.md` files in this
directory.

- Open working set: `issues/YYYYMMDD-slug.md`
- Completed work: `closed/` (with **Resolution:** recorded)
- Parked, not closed: [`shelved/`](./shelved/README.md)

The working set is Snapback 4. Snapback 1–3 tickets (and repo-wide follow-ups
filed against those programmes) live under `shelved/` as of 2026-09-13.

These files are local planning artifacts. Linear remains the authority for
cross-repository prioritization, assignment, and scheduling when an issue is
promoted there.
