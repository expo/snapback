# Research Room / Snapback final package confirmation diary draft

**Date:** 2026-07-29

**Outcome:** 13 PASS, 2 explicit GAP, 0 FAIL, no Stop

The most important result is that the repaired Research Room behavior survives
the actual package boundary. A clean external project installed seven staged
tarballs, imported only package exports, generated and built without the
repository, then launched and stopped the release binary through the installed
CLI. Multi-session authorization, native push, streamed settlement,
cancellation with no late patch, retry identity, cron/config, and cleanup all
worked.

What felt good:

- Package installation, code generation, production build, and runtime launch
  all worked from the immutable closure.
- The ready descriptor, exact database, binary commit, package version,
  generated-input hash, and four assigned ports gave strong target identity.
- Installed `snapback stop` retired the exact process, after which runtime and
  public roots were absent and every port was closed.
- The difficult correctness paths remained coherent across the package seam.

What remained frustrating:

- A consumer must currently call the codegen module file because the installed
  CLI exposes host operations but no `generate` subcommand.
- The sealed app still required explicit replacement of repository define,
  client, contract, harness, and lifecycle imports to become a real external
  project.
- The membership batch rule still requires decomposed setup operations.
- The session client's `inspect()` composition still needs a direct public
  inspect request with the exact protocol offer.
- Effect receiver destinations are source literals, so isolated ports require
  an application-source transformation.
- Asset bytes and native semantic retrieval remain product GAPs.

Snapback should make the successful path ordinary: scaffold a package-only app,
expose package-level generate/build/start/stop commands, generate membership
setup shapes that obey runtime cardinality, make official client inspection
session-aware, and make external effect destinations runtime-configurable.

The original first-arm friction and Stage 4 remediation attempts remain
separate retained evidence. This confirmation adds package-bound confidence;
it does not erase earlier authoring cost.
