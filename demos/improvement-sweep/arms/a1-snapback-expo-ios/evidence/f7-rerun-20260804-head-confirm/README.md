## Gate

This bundle is the standing regression gate for the ~2s reconnect loop:
a future rerun executes `../f7-rerun-20260803/harness/f7-run-ios.mjs`
against the then-current tip and compares its `f7-evidence.json` against
this one — the gate holds while `hold.lostDuringHold.totalLost` is 0 over a
≥120s idle hold with both queries' rows intact at hold end. Any `lost`
transition now arrives with the full loss-detail signature
(`ed8ee8764`), so a recurrence names its close code directly.
