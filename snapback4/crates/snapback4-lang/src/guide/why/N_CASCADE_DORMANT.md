# N_CASCADE_DORMANT

N_CASCADE_DORMANT: This unbounded cascade or set-null edge has no declared source that can delete its parent. No cap is required yet. Adding an admitting delete rule, authored delete, expiry or reachable cascade rechecks the full action graph. If that deletion is needed, choose a product limit with `cap N by reference`; the engine maximum is a ceiling, not a suggested product limit. Operator and externally supplied deletes still need a complete prepaid reservation. guide writes.
