# E_QUARRY_IMMUTABLE

E_QUARRY_IMMUTABLE: An immutable patch provably changes a stored value or supplies a fresh clock/id. Omit it from the patch; insert it when creating the row. A literal or constant expression differing from a pinned key or the exact row just inserted is refused. Distinct fresh id captures differ too. A fresh clock on an immutable time column cannot preserve its original timestamp on later conflicts. Exact target keys, current exact snapshots and proven equal values from an unconditional insert stay quiet. Intervening writes or uncertain control flow prevent snapshot proof; uncertainty receives N_IMMUTABLE_PATCH instead of a refusal. Source writers elsewhere do not constrain historical, seeded or adopted values. External IR keeps the established privacy exception: an unreadable target ignores immutable patch fields without comparing hidden values. guide writes.
