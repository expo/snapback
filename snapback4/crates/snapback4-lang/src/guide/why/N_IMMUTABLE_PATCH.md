# N_IMMUTABLE_PATCH

N_IMMUTABLE_PATCH: On readable targets, an immutable patch succeeds only when its value equals the stored value. For example, `upsert responses[key] { teacher: viewer, body }` succeeds for the original teacher; a different teacher's conflict is refused at runtime. Keep it when that equality guard is intended. Omit the column from the patch if another value may update this row; branch on a readable point and insert initial immutable values only when absent. Update obeys the same law. A value equal to the target key or a current exact snapshot stays quiet. Spreads and captured values receive the same analysis. Private read policies receive this note even for a known mismatch: a hidden target may accept the mutable remainder while ignoring immutable fields. Unknown values, stale snapshots and other source writers' literals do not establish a mismatch. An unreadable target keeps the hidden-target exception: immutable patch fields are ignored without comparing stored values. guide writes.
