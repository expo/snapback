# N_SYNC_EMPTY

N_SYNC_EMPTY means a cursorless device page filters a public, unbounded synced table by a reference, such as
notices for one sailing. There is no bounded acquisition boundary for that
subdivision. If the empty partition stays loading, bound the public sync and
read the window unfiltered, then filter in the client. For server history,
call through app.online.query or useOnline().query. This advice does not mean every empty read stalls;
whole acquisition can establish coverage. A pinned owner/member sync group,
an unfiltered public page, a cursor traversal, a bounded window and a server-planned query do not
get this note. `guide sync` explains acquisition and window order.
