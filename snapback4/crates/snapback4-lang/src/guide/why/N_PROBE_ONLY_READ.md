# N_PROBE_ONLY_READ

A rule probe sees every row: `read <- exists applications[.application]` admits every signed-in caller while the application exists, even one who cannot read it. `check` notes N_PROBE_ONLY_READ for a read-rule disjunct that probes a private table through the row's reference and names no caller (unless the probe's own tests make that row public): write `read through .application` to admit exactly the application's readers, or name the caller in the probe (`exists applications[.application, applicant = viewer]`). Keep the probe only when every caller may read the child rows while the parent exists. `check` stays silent when the probe's own tests make the parent row public (`exists decks[.deck, isPublic = true]` under a deck rule that admits public decks).
