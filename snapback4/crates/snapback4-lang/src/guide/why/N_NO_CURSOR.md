# Reads — N_NO_CURSOR

N_NO_CURSOR: a returned page cannot continue. If the screen pages,
declare `c: cursor ?` and page with `after c`, preserving its predicate and order.

Filling `first N` or `last N` is complete without `next`. Composed fields
omit this note. Meter cuts, undecided authorization and missing device
coverage still apply (`guide reads`).
