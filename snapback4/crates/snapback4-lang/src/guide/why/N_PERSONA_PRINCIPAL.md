# N_PERSONA_PRINCIPAL

N_PERSONA_PRINCIPAL means a principal column literal is a bare declared persona name. alice is a cast
name; dev:alice is its development principal. Write 'dev:alice' for development
relationships or use the authenticated account principal for production.
Dev refuses bare persona principal arguments with E_INPUT and the same repair.
The static advisory can remain when deliberately modeling that literal principal;
it never changes a value or grants authority. `guide personas` explains the cast
and `guide deploy` carries the complete production transition recipe.
