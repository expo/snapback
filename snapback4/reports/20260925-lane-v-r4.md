```ts
  setItem: (key, value) => localStorage.setItem("work:" + key, value),
  removeItem: key => localStorage.removeItem("work:" + key),

```

Engineering decisions and deviations where the brief was silent:

- A mirror-only legacy session requires another sign-in. Importing it into IDB
  would reintroduce the rejected stale-authority assumption. Pre-IDB unadmitted
  stamps are cancelled; committed outbox entries retain their existing custody.
- Custom mirror adapters require an explicit stable namespace. Inferring a
  prefix from arbitrary functions is impossible; sharing one default record
  would mix independent accounts. Builtin calls, explicit global localStorage,
  and copies of their returned stores preserve their usual opening form.
- Authority records and revocation metadata use the existing `SessionStore`
  interface. No bearer persistence is added to the default memory store or a
  native store. Async-only custom stores without a recognized authority reader
  fail closed for unadmitted browser journals.
- Session mirroring precedes the IDB commit so a full localStorage cannot produce
  a committed operation reported as failed. A crash can leave a speculative
  mirror, which is harmless to locked IDB admission; later IDB reads repair it.
- The startup gate also covers ordinary sends, as Grok's completed review
  requires. Native startup keeps its existing coordination. No row buckets,
  acquisition page sizes, engine meters, disclosure checks or wasm budget change.
- No new acquisition benchmark was requested or run this round. Prior round-2
  measurements remain 13.298 / **15.825** / 18.703 seconds for bounded buckets,
  versus 70.716 seconds per-row: median **4.47×**, 65,180 rows retained after
  offline reopen. These are prior measurements, not new round-4 numbers.
