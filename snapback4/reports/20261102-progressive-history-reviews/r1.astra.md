3. **[P2] Continuous stream backlog starves acquisition and queued interactive work.**  
   [local-acquisition.ts:127](/Users/ccheever/projects/snapback-ph-20261102/snapback4/packages/snapback4/src/local-acquisition.ts:127) keeps `streamDue` true whenever an ordinary page has `more:true`.    **Fix:** bound ordinary-drain turns, release the network owner, and allow acquisition to advance between turns when no deferred publication or authority fence requires further draining.

4. **[P2] Tier-1 materialization exceeds the delivery heap budget before checking it.**  
   [acquire.rs:122](/Users/ccheever/projects/snapback-ph-20261102/snapback4/crates/snapback4-core/src/partition/acquire.rs:122) first materializes the entire horizonless page through `snapshot::walk`; only afterward does it call `budget.push`.    **Fix:** pass the shared delivery budget into the tier-1 walk and admit bounded decode batches before materialization, as `expand_group` already does.
