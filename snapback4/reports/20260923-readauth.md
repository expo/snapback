`evaluate_read_rule` remains unconditional on provenance for F3's not-yet-written
image. It propagates runtime errors and records unknown coverage, which prevents
successful prediction; only definite denial skips an owned copy without that
condition. No wire, stored-row, or outbox format changed. The current execution's
write set and the existing engine-owned `pending` marker still identify images.

The device uses the same server rule truth values for raw witnesses. Consequently
`checks.read <- exists notes[...]` can authorize a check using this device's
pending note even when the note's own rule denies the reader. The tests now
require that check to remain visible and complete. This is the supervisor's
explicit rule, not an exception or a recursion shortcut.

The aggregate investigation distinguishes two paths. Live expiring aggregates
rescan their sources; filtering those sources must agree with visible rows and
must not emit a partially known total. Non-expiring aggregates use the server's
delivered value plus this device's own write deltas. Schema validation already
requires a synced aggregate's recipients to receive every source contribution
(`schema.rs::validate_maintain`); there is no broader foreign-source disclosure
introduced by those own-write deltas. The both-store live-maintain regression
keeps a hidden source physically present while requiring aggregate point and
scan results to exclude it, and requires the visible source's value to be one.

### The nested-read ladder's changed cost

Astra's fixture first reads an expiring provisional membership, then repeatedly
reads a delivered note authorized by that membership. Removing recursive witness
ACL evaluation necessarily removes its charges: the membership and each note now
cost **one** probe, rather than reauthorizing the membership under every note.
Under the unchanged default 8,192-probe ceiling, 4,094, 4,095 and 4,096 note reads
all return the note complete; the 8,192-note rung cuts, with no unknown.

The requested 4,094 / 4,095 / 4,096 cut ladder is additionally exercised with a
4,095-probe ceiling appropriate to the raw-witness cost: note/complete at 4,094,
then null/meter cuts at 4,095 and 4,096, never unknown. Meter totals are 4,095,
4,096 and 4,097 respectively (each later point still attempts its prepaid charge).
No fictitious recursive charge is retained to preserve the old boundary.
