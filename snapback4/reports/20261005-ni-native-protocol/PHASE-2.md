Owner: the next assigned instrument lane, after NI's driver qualification review.
Earliest scheduling: after the Phase-1 code/evidence is accepted; no pilot date
or execution is implied by this plan. Scored use remains disabled until this
pilot, its fixes and affected reruns are complete under LLP 0201 D7.

1. Cut an immutable `0.4.0-native.1` packet from the qualified local commit and
   inventory. Record source commit, manifest/inventory, exact base web component,
   helper bytes and complete toolchain. Give both builders the same new prompt,
   native contract, revised kit/helper, brief and aid disclosures before their
   first edit. Preserve the old calibration series separately.
2. Start two independent fresh builder sessions, one Snapback 4 and one Convex,
   serially on the same authoring machine with the same model/effort and recorded
   caps. Use pinned published backend packages and their public docs. Neither
   builder sees NI's reference app or the other's source. Charge native helper
   integration, stable IDs, fixture seed and oracle mapping inside authoring
   time; preserve transcript-native metering. These are unscored builds, not
   calibrations or comparative score samples.
3. Use a locally runnable Convex deployment whose foreground backend can be
   stopped and restarted with the same data directory. Preflight that property
   before admitting the builder. A hosted deployment or client offline toggle
   is not an equivalent protocol. If local ownership cannot be established,
   publish the setup limitation as unmeasured and return for an owner ruling;
   do not substitute networking semantics mid-pilot.
4. Build each own Release application on the Apartment mini using isolated
   `/tmp` directories and **only** simulator
   `3D325BD4-FD16-4A94-AA74-9F5CF1F8E48B`. Never use the black M5 or office M1.
   Preserve source/dependency/native/Hermes hashes and operator timings. Use the
   generic driver, source-audited read-only oracle, normal Alice sign-in and
   browser Bob. Run M6 and M8 separately, preserving every failed attempt.
5. Validate the artifacts independently, inspect the actual image frames/video,
   verify native row/receipt accessibility including recycled offscreen rows,
   and audit that hooks are passive. Repeat the listed negative controls against
   the qualified instrument where app wiring differs materially. Publish the
   matrix, all setup/product/instrument failures and their evidence without O4
   or overall scores. M7 and M8 web convergence remain separately unrun unless
   independently commissioned; native evidence cannot grant them a pass.
6. Permit one retained setup rerun after a documented repair. Do not rerun a
   product failure until green. A material prompt/kit/helper/driver change cuts
   new candidate bytes and reruns affected pilot milestones before caps freeze.
   Owner review then decides scored admission, operator budgets and any version
   increment. Every subsequent trend plot declares the series break.

recorded pilot safety limits (LLP 0201 D7: 4 h/2M tokens per milestone; this is a

per app** as an estimate, not a measured NI attention figure. Phase 1's actual
