# Wave 12 affected host validation

`receipt.json` binds each isolated command to its exact pass count and compressed log hash. Cargo used `/tmp/lang-affected-target`, twelve jobs, incremental compilation disabled, and debug data disabled for development and test profiles.

The batch covers memory and SQLite devices, the SQLite-backed CLI, simulation controls, and Postgres compilation. The reservation controls additionally ran against the final wasm device: authentic caller-supplied IDs remain server-custodied, old semantic backends refuse before execution, and explicit adoption of the current backend preserves the old outbox.
