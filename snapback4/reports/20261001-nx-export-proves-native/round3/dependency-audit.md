# Round 3 dependency audit

Fresh npm installs differ from the round-2 snapshots only at the paths in dependency-delta.json. The snapback4-expo change is this round's export wrapper, outside native plugin code. Other byte changes are license/readme/package metadata, a ws-tunnel TypeScript declaration, and sdk-runtime-versions' SDK-prefix string helpers, tests and maps. The latter's installed implementation only formats/parses the exposdk version string; it reads no application JS or native resource. No stock native writer or template changed. The package-tree pin is updated for the wrapper and the two complete installed snapshots are pinned. All previous stock mod audit inputs remain applicable, now with URI refusal and EXPO_IMAGE_UTILS_NO_SHARP=1 in evaluation/build. The installed snapshots, rather than a declared version alone, remain required.

Resolution-level auditing also reaches two stock plugins with no registered iOS mods in the default config: expo-dev-menu is an identity function (no-op since SDK 44); expo-status-bar returns config untouched absent explicit props, or maps hidden/style to static plist values when supplied. Neither reads app source. Their whole shipped package trees are now pinned independently of stack registration, with the full dependency snapshot still required.
