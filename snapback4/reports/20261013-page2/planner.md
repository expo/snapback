# PAGE2 planner lane report

## Result

PAGE2 now admits exact owner/grant-or-membership pages when membership discovery has a total unique point or a genuinely applicable cap. A unique `(parent, principal)` proves at most one witness for a target/caller pair; it does not bound the viewer's total membership count. Uncapped inversion therefore uses the existing metered all-or-nothing discovery fence. Read-meter cuts (including discovery `steps`) return an empty incomplete page without a cursor; heap exhaustion remains `E_BOUND`. The implementation also supports a target's intrinsic `.id` and readable parent-owner points such as `exists offers[.offer, baker = viewer]`. Diagnostics suggest an exact cap only when it repairs the shape, and the guide states that such a cap is a hard write/adoption limit.

Set-null cap disposition: Quarry rejects a cap grouped by a `set null` reference with `E_REFERENCE_ACTION` before Lean membership classification. `lean_emit::set_null_cap_cannot_admit_membership_discovery_to_the_model` records that boundary; the emitter does not need a second cap-exemption model.
