Engineering decisions and review qualifications:

- Transport is deferred until the critical section completes. `storeLock`
  remains non-reentrant: a runtime-wide depth flag could accidentally let an
  unrelated async operation bypass the session lock.
- The existing exit callback returns `void`; the transport mutant did not
  wedge peer logout permanently in this reproduction. It did enter transport
  under the held lock, and the new test rejects that behavior directly.
- Removing only `logoutEpoch` does not admit the exact minimal tombstone,
  because that value also lacks a matching principal. The explicit logout
  guard matters for a recognized same-epoch tombstone retaining session fields.
  The test includes both shapes and kills that specific mutant without
  weakening the independent principal check.
- Raw `DeviceOpener.open()` now returns before journal/orphan recovery so an
  app can attach its owner first. The first core call performs recovery for
  direct device consumers; local-client construction attaches authority and
  awaits device calls before exposing its client. Three existing raw-device
  cases were adjusted to that deliberate boundary change.
- Chromium headless tests synthesize the hidden visibility event at a controlled
  point during the real IndexedDB admission, rather than relying on an OS tab
  switch. Hard navigation uses actual `location.assign` and a fresh document.
- Bounded bucket storage is unchanged in this round. No page-size ceiling,
  durability mode, disclosure rule or engine meter was loosened.
