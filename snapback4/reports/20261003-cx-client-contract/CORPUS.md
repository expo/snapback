## Reproduce the arithmetic

Run this from the repository root. It uses only the retained dataset and standard Python; the source quotation/span audit is described in [VALIDATION](./VALIDATION.md).

```python
import json
from pathlib import Path
d = json.loads(Path("snapback4/reports/20261003-cx-client-contract/measurements.json").read_text())
rows = [r for r in d["records"] if r["series"] == "Astra" and r["calibration"] >= 16]
xb = sum(r["calibration"] for r in rows) / len(rows)
for category in rows[0]["scores"]:
    mean = sum(r["scores"][category] for r in rows) / len(rows)
    slope = sum((r["calibration"]-xb)*(r["scores"][category]-mean) for r in rows) / sum((r["calibration"]-xb)**2 for r in rows)
    print(category, len(rows), round(mean, 4), round(slope, 4))
for cost in "ABRFL":
    hits = {q["calibration"] for q in d["quotes"] if q["cost"] == cost and isinstance(q["calibration"], int) and q["calibration"] >= 16}
    print(cost, len(hits), sorted(hits))
```
