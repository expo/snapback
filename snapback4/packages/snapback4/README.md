# Snapback 4

Run `npx snapback4 guide start`, then `npx snapback4 guide workflow`.
Install with `npm i snapback4`; Node 24.x is required.
Run `npm run verify` for the starter proof loop after wiring app assertions.
Build from those guides. Long references: `guide package-reference <topic>`.
This app's calls and exact signatures: `guide api react|client|auth|proof|generated`.
Version notes: `guide changes`.
Editors: [Quarry highlighting and compiler diagnostics](https://github.com/expo/snapback/tree/main/snapback4/editors).
