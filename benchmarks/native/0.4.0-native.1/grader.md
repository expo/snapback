# Native evidence grading — 0.4.0-native.1

This is a new series under LLP 0201.000, not an amendment to a historical
packet. Scored use is disabled until Phase 2 is complete. Driver qualification
is unscored and does not qualify Snapback 4, Convex, or the rest of Clique.

Validate the entire directory using `driver/validate.py` before reading assertion
receipts. Transport every bound file. Invalid, missing, truncated, unbound or
incomplete evidence is **unmeasured** (`pass:null`), with its reason; a correctly
recorded executed product failure is `pass:false`. Downstream blocked assertions
stay not-run, never inferred failures. A single successful app callback is not
an assertion. Inspect helper wiring and the read-only oracle against source;
verify that no hook changes caching, auth, outbox persistence, retry or receipts.
Inspect ordinary-media fixture pixels and cold screenshot/video together. Inspect
view-once prime/close and cold refusal, including absence of residual image pixels;
this is observable refusal, not forensic proof of byte erasure from every device.

Use the existing `supplementalExternal`, `requiredForGreen:false` representation.
Native evidence never changes web milestone green. Map only M6 a01–a07 and M8
a17/a18. M7's nine day-two assertions and M8's web multi-device assertions remain
separate. Bob is a real browser client, not a second native device.

O4 remains eligible only with M6 green. Eligible but unmeasured native evidence
means `O4:null`, reason `native-unmeasured`. Report the missing dimension and
profile. Do not manufacture a low score from absence, normalize the other weights,
or publish a comparable overall/holistic number with the missing dimension.

The published O4 anchors are unchanged: observed broken native cold launch can
support 30; demonstrated reads with lost/misordered writes or incorrect receipts
can support 60; demonstrated native reads/search/ordered writes/final receipts
can support 90 only with M8's restart evidence when full-run scope applies.
Interpolation is grader judgment, citing exact assertion IDs, events, frames and
video timestamps. A build or Hermes hash supplies provenance, never behavior.
Do not compute any score for this qualification program or the Phase-2 pilot.

Every trend plot and cost comparison must show the **0.4.0-native.1 series break**.
O4, overall scores, native coverage and authoring costs across the break are not
like-for-like; unchanged assertions may be named descriptive subsets only.
