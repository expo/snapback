## M1 — 2026-09-15T14:07:05.264Z
Built password signup/login, persistent local sessions, public profiles, unique handles, editing and avatars using the frozen kit. The Quarry declarations and built-in identity were straightforward. The hardest work so far was instrument packaging: missing relative-import dependencies and read-only copied directories. One application bug copied extra profile fields into mutation arguments; the precise E_INPUT diagnostic made the fix immediate. Prior React and Expo familiarity saved navigation and form work; no previous Snapback implementation was consulted. The README was unusually comprehensive but lengthy. Compared with Convex, auth and media policy came together in less separate configuration; compared with Supabase, no storage policy SQL was needed. The live replica hook passed actual two-client edits. This is web evidence plus a Hermes export, not simulator evidence.

## M2 — 2026-09-15T14:12:30.897Z
Built feeds, text/image/video posts, follow counts, idempotent likes and reposts, direct reply threads, and 20-entry pagination. Declaring maintains and shaped queries felt direct. Media ownership was clear: every upload belongs to one row, so fixture reuse uploads bytes again. The kit required actual video posters; web canvas supplied them. The harness assumed tabs remained available on profiles, which forced broader navigation chrome. React knowledge saved component wiring; the exact Snapback surface was learned from the README and guide. A wide-merge diagnostic identified a future scaling concern before measurement. Compared with Supabase realtime, the local live query avoids explicit channel invalidation. Compared with Convex, it adds partition-completeness decisions that matter for offline reads. Suite and all choreography checks passed; scale viability is not claimed yet.

## M3 — 2026-09-15T14:19:58.557Z

Against Supabase, authorization and sync audience are expressed together rather than separately. All required web choreography passed, and the iOS Hermes export is retained.

The final suite, choreography, web export, Hermes export, digest restart proof, and persisted replica proof passed; full final-snapshot scale verification continues on its separate clock.
