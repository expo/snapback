Receipt state is reduced across the current roster, excluding the author; message acknowledgements are monotone.
Conservatively classified digestPeriods as a work table because only digest reads/writes this durable period-emission ledger. The only stored counter, likeCounts, is world-readable because it counts public likes on public posts, and ranking needs those counts; no private chat counter is world-readable. No auxiliary operation exists: profile/post/follow/createChat/addMember are ordinary authorized domain mutations used by seed, and helpers are inline Quarry expressions.
