# Clique diary

## M1 boundary

Built from the Expo Chat template and retained its explicit Snapback schema/functions and supervised web lifecycle. The explicit profile made generated binding ownership clear, but the available time did not permit a faithful mapping of the entire canonical social schema. The missing diagnostic was an end-to-end migration recipe for this benchmark's many relational tables.

## M2–M6 and M8 boundaries

The retained template demonstrated sessions, generated live queries, mutation commands, upload intent, typing presence, and an outbox-aware message screen. It did not become Clique: feeds, graph, media post rules, moderation windows, group administration, offline convergence, analytics, and scheduled digest remain absent. Static contract smoke checks were useful for catching missing IDs, but they are not behavioral acceptance. Explicit authoring saved ambiguity about generated files and runtime identity; it cost time because every additional product relation needs a new schema/function design rather than a quick generic endpoint. The missing diagnostic was a concise capability map for server schedules, durable web custody, and the benchmark's aggregate/read-model needs.
