# Clique / Convex build diary

## 1787854398 — M1 green

Built bcrypt-password signup/login, expiring server-revocable sessions, unique email/handle enforcement, the exact profile model, avatar data handling, and live profile queries in the Expo Router shell. The data declarations, indexes, and reactive profile update felt direct. Anonymous local startup was pleasantly self-contained once the package source revealed the mode and hidden port controls. What fought me was integration rather than data: npm initially tried to mutate the read-only UI-kit dependency, React Native 0.87 disagreed with the frozen kit's 0.86.2 types, and the first logout/relogin choreography uncovered both a stale-auth-query race and a route-landing assumption. Prior familiarity with React session races and index-backed uniqueness made both fixes small. Missing documentation was the exact anonymous CLI/noninteractive setup path; the installed 1.45.0 package source was more useful than the public-doc browser response, which returned no body.
## 1787855308 — M2 green

Built text/image/video posts, the Following and Global projections, follow state, like/repost set-state writes, direct-reply threads, profile-to-feed navigation, and live two-client updates. Convex's reactive query path made remote counts and new posts feel easy; the write model stayed compact and idempotent. The fight was the boundary between the frozen React Native kit and React Native Web 0.21: roleless nodes lost `accessibilityValue`, and `Image` became a CSS-background `div` even though the frozen browser contract required semantic values and loaded image elements. I kept the kit contracts intact and supplied the missing web semantics in the application wrapper. Prior familiarity with DOM accessibility inspection, browser automation, and projection modeling quickly separated those UI misses from the correctly updating backend. The missing capability was a documented kit/runtime compatibility profile that would have made this web-rendering difference explicit.

## 1787856094 — M3 green

Built deduplicated direct conversations, group membership and admin authority, reactive message timelines, typing expiry, delivery/read aggregation, retained-history cutoff, quoted replies, and stable chat-list identities. Realtime message and receipt projections felt natural on Convex, and server-side membership checks were straightforward. The difficult part was navigation durability and post-removal behavior: an immediate hard navigation could abandon a WebSocket mutation, the active chat disappeared from the directory projection, and an unrelated typing subscription could mask the valid retained-history query. A keepalive HTTP mutation using the published 1.45.0 envelope plus a retained conversation identity fixed the full lifecycle. Familiarity with independent reactive subscriptions and authorization-cutoff models helped reveal that “removed” must mean no new data without erasing old data. Missing docs were concrete guarantees around mutation survival on document unload and recommended patterns for this browser boundary.
## 1787856151 — M4 green

Built image and video messages, the modal media viewer, set-state reaction aggregates, sender-only edit/delete controls, server-derived edit/delete windows, and durable tombstones. This milestone felt easy: the schema and indexed message lookup already carried the needed authority, and Convex propagated each mutation to the second client without extra subscription machinery. Nothing materially fought the implementation during the frozen run; the earlier web media decisions also carried over cleanly. Prior familiarity with immutable message identity and tombstone modeling saved rework. The only missing backend convenience was a first-class media storage path in this local benchmark setup, so fixture bytes remained data URLs by design.

## 1787860231 — M5 green; O5 scale degradation failure

Built disappearance settings and server-authoritative expiry, view-once media with one-time authorization, background selection, cached offline reads/search, an ordered durable browser write queue, and reconnection receipts. The product suite and two-client web choreography were green. Convex made timer-independent expiry checks and live post-reconnect convergence straightforward; keeping queue intent in local storage also fit the web boundary cleanly. The scale run fought harder: deploying a second anonymous local instance required package-source discovery, two self-authored verifier bugs confused canonical key order and omitted optional media with semantic null, and the first final-probe error path failed to persist its sample. Prior familiarity with deterministic replay and invariant accounting let me preserve the valid fresh 167,157-action run instead of replaying blindly. The final evidence is candid: all invariants conformed, replay used 11.4% of its four-hour cap, and eight of nine degradation rules passed, but Trending's 50% p95 sat above its linear midpoint ceiling, fixing O5 at band 30. Missing from the published instrument were the promised P3 absolute latency ceilings, while Convex's public CLI surface also did not expose the isolated local-deploy path documented by its package source.

## 1787860282 — M6 green

Built and exercised a backend-neutral custom-client surface, push-registration and delivery seams, replay-mode suppression, deterministic sample-log replay through the real auth and mutation path, and the web offline queue proof. The custom client and replay adapter felt pleasantly thin because Convex functions are directly addressable from a headless client and share the application's validation and authorization. The only meaningful friction had already been paid in M5's queue and scale work, so both the suite and frozen two-client segment passed on their first M6 attempt. Familiarity with transport-independent API design helped keep the adapter from becoming a privileged import path. The unavailable capability is environmental rather than product-shaped: this Linux host cannot run Xcode, iOS Simulator, or a Hermes export, so the native artifact is recorded as environment-null rather than inferred from web behavior.

## 1787860716 — M8 green

Built the full Insights totals and daily series, bounded server-side Trending, same-account live state, cross-device read clearing, and dual offline queues that reconcile independently and converge exactly once. Aggregate queries and second-context live updates felt easy on Convex; the suite passed immediately, and the durable two-client flow worked without backend changes. What fought me was again React Native Web semantics: the frozen controls held the right state but omitted observable `aria-selected` and chat identity attributes, while Metro briefly served the stale lazy module after the wrapper correction. Explicit web semantics plus a cache-clearing restart fixed the two choreography misses. Prior familiarity with DOM mutation ordering kept this a presentation correction rather than an unnecessary data-model rewrite. The missing docs/capability remained a pinned kit-to-web semantic compatibility contract; the native M8 simulator/Hermes proof is environment-null on this Linux lane.
