# Building Clique on the explicit Snapback path

Clique ended up being a useful test of the boundary between a pleasant reactive programming model and the unglamorous projection work that a social product actually needs. The successful path was to treat Snapback as the authority for identity, server time, mutation idempotency, and live state, while keeping the Expo client deliberately thin. Profiles, feed edges, inbox rows, per-recipient message views, receipts, notifications, and insights are all explicit data products rather than client-side guesses.

The strongest part of the authoring experience was the build-bound feedback loop. Structured generation refusals caught unsupported handler syntax, ambient time, implicit authentication, and unadmitted writes before they became runtime mysteries. The served Guide was enough to repair the documented refusals without reading package source. Exact generated references also made the headless client and browser app exercise the same operations.

The hardest part was recipient fan-out. A sender mutation needs to author feed or message projections for people other than the authenticated actor. The default ownership posture refused that composition, and the served diagnostic did not provide a supported server-owned projection policy. The implemented compromise uses public-readable storage tables while every exported owner-scoped query authenticates and filters by the caller. That preserves the intended application behavior but weakens defense in depth: table visibility is broader than the query surface suggests. It is a real trust gap, not something the green browser receipts erase.

The browser proof also exposed an important distinction between rendered appearance and machine-observable semantics. React Native Web dropped or transformed some accessibility values the frozen choreography expected. A small semantic bridge restores those values on the frozen `sm-*` elements without changing the instrument. Navigation needed similar care: history-preserved screens created multiple hidden selector trees, so product routes now replace rather than stack for the tested shell. These repairs improved observability and determinism without weakening an assertion.

Offline messaging was the most product-shaped client problem. The Snapback client reconnects, but the benchmark requires visible pending state and ordered replay. Clique therefore keeps an explicit local queue, renders pending messages immediately, and flushes sequentially on reconnection. The live message projection also retains the newest observed version so a stale cache emission cannot visually roll a sent message backward. This is intentionally a client protocol layered on server-idempotent message identifiers.

The view-once and disappearing flows reached the required visible behavior, including cross-client consumption and relaunch disappearance, but they expose two remaining production gaps. Media is represented by compact fixture references rather than a first-party upload/revocation pipeline, and disappearance is filtered from the user-visible projection rather than proven as physical server purge. The benchmark's long wait is represented with a shortened development TTL, so this build should not be read as a production retention policy.

The final application is strongest where evidence crosses boundaries: committed fixture actions went through authenticated mutations, a documented headless client used the generated protocol, and independent browser contexts proved live collaboration and reconnection. It is weaker where platform capabilities were not admitted by the available explicit authoring path: scheduled weekly digest execution and durable asset revocation remain capability gaps. M7 is deliberately absent because the lane contract marks it environment-null.

The main lesson is that a green reactive demo is much easier than an auditable social system. The valuable work was making ownership, projection, time, retry, observability, and evidence explicit—and recording the places where the implementation could not honestly claim the production property.
