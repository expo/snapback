The native Hermes export passed. The replica owned queue ordering and persistence, which was pleasantly little client code. Scale execution remains on its separate clock after M8, against a fresh instance; native runtime behavior is not claimed from a bundle export.

## M8
Built six maintained Insights totals, seven server UTC-day buckets, an expiring like-ranked Trending index, a scheduled digest job through the push seam, and same-account offline/read-state convergence. The existing replica made multi-device message and receipt propagation almost free. A real browser-process restart preserved queued writes, though the required native output remains an export rather than simulator evidence. Aggregate declarations were compact and made the screen independent of corpus size. Ranking needed a small explicit read model, and existing rows needed an idempotent backfill. The digest was the most backend-shaped work: a resumable profile sweep computes period counters, a time-indexed message sweep accumulates authorized unread activity, and a final sweep emits once per user-period. Its two-minute fixture schedule passed across a backend restart, including a quiet following period. The schedule would not resolve a module-local job and rejected a dotted target; moving the job and schedule to the root file worked, an awkward undocumented namespace corner. The frozen harness assumes chat rows on home, so a recent-chats section now exposes the same subscribed data there. One later dual-offline harness attempt timed out; an unchanged retry and an independent three-client probe passed. That transient is unresolved and must remain visible in the reliability assessment. Prior aggregate/outbox experience helped, but no prior Snapback source was used. Compared with Convex, these operations trade TypeScript freedom for declarative maintenance and resumable sweeps. Compared with Supabase, no SQL triggers, publication wiring or custom offline reconciler were required. Scale performance is the remaining empirical question, not something these small-data greens establish.
