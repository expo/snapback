## Production transformation

Call site is unchanged: `mergeOfflineProtocolDeclarations()` runs once after declaration emit and copy into `dist/` (`input/source/snapback2/packages/snapback2/build.mjs:153`). The declaration emit Program still uses `skipLibCheck: true` and still runs **before** the merge (`build.mjs:109-153`). That is the pre-existing hole named by `issues/20260907-snapback2-published-declaration-ambient-modifiers.md`; this candidate does not close it inside `build.mjs`. It closes it with registered consumers of the merged output.

The changed function (`build.mjs:299-314`):

```
const ambientDeclarations = offlineDeclarations.trim().replace(/^export declare /gm, "export ");
```

Only the string inserted inside the ambient module is rewritten. `dist/offline-protocol.d.ts` is not written by this function.

`compiler/lib.d.ts` is a single `declare module "snapback2" { ... }` (`lib.d.ts:1` … `:183`). Column-0 `}` occurs once, at the module close. `lastIndexOf("\n}")` therefore targets that unique boundary on the pre-merge copy (the same heuristic as the parent). Nested braces in `lib.d.ts` are indented and do not match.

Actual standalone emit (`candidate-package/dist/offline-protocol.d.ts`) uses:

- `export type` / `export interface` for types (no `declare`)
- exactly eleven line-leading `export declare class` / `export declare function` forms (class `DeliveryEnvelopeDecodeError` plus ten functions, lines 153–184)

No indented `export declare`, no `export declare type` / `interface`, no `declare` without `export`. `/^export declare /gm` is therefore exact for this emit: it cannot eat types, comments, or signatures, and it cannot drop an export. If a future emit indented those lines, the replace would miss and TS1038 would return; that is fail-closed, not silent omission.

Mechanical reconstruction (source `lib.d.ts` + standalone text with only that replace, inserted at `lastIndexOf("\n}")`) is **byte-identical** to built `dist/index.d.ts` (17657 bytes, sha256 `9421f44dba3885530a95327c7192d26ad0c37228ca1787e29b1dbe2ccc00fa48`). Inventories before/after are 153 leaves and equal.

In the merged root, the eleven historical TS1038 sites are now `export class` / `export function` without `declare` at the same line numbers the 0.0.16 counterfactual reported (336, 340, 342–344, 346, 359, 361, 363, 365, 367).
