No new severity-rated finding requires a fix in this delta. The following inherited findings remain material; neither should be represented as covered by a universal “failed admission changes nothing” or “duplicates work” claim.

1. **P2, inherited — duplicate absence entries can leave owner removal half-applied.** At [coverage.ts:113](../packet/source/snapback2/packages/evaluator/src/coverage.ts#L113), removal walks `old.absences`, while lines 120–122 append every occurrence but count ownership in a `Set`. Give one owner two identical `messages/byId/missing` absences, then remove it: the first iteration deletes the last map entry; the second dereferences undefined and throws `TypeError`. The absence is already gone, while owner deletion and subsequent invalidation do not complete. Replacing that owner has the same failing removal path. Parent [coverage.ts:112](../packet/before/snapback2/packages/evaluator/src/coverage.ts#L112) has the identical defect. The probe also confirms that two distinct owners sharing one absence preserve it until the final owner leaves. **Scoped fix:** deduplicate the per-owner absence identities before installation/removal and add same-owner duplicate replacement/removal controls. The constructed duplicate wire envelope passes the real `decodeDeliveryEnvelope` and `tagReceipt` functions; this proves decoder admission, not that a native owner emits duplicates or that an end-to-end native delivery was exercised.

2. **P2, inherited — malformed standalone rehydrate destroys prior state before refusal.** At [store.ts:72](../packet/source/snapback2/packages/evaluator/src/store.ts#L72), rows are removed/replaced and coverage is reset before `setReceipt` validates the incoming proof. Start with one row and a valid absence, then rehydrate with no rows and a nonboolean verdict: `E_INPUT` is thrown, but the old row and absence have already disappeared. Parent [store.ts:67](../packet/before/snapback2/packages/evaluator/src/store.ts#L67) behaves identically. **Scoped fix:** prepare and validate the replacement rows and coverage before publishing the replacement, or make this operation transactional; add a regression asserting prior rows, proofs, and directory state survive refusal. This probe deliberately exercises the standalone API with malformed private input. It is not a public/native authorization bypass; public verdict decoding checks booleans.
