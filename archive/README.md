# Archive

This directory holds retired or historical material that is no longer part of
Snapback's active authoring surface but remains useful as evidence or design
context. Archived content is kept in git, is not a current implementation
authority, and should not be used as a starting point for new work.

- `docs/` preserves the former internal-engineering shelf, including historical
  Contract/Exact integration guidance and implementation plans whose context is
  still useful when reading the changes they motivated.
- `notes-archive/` preserves superseded planning and review notes that retain
  provenance value after the LLP corpus and `llp/reviews/` became authoritative.
- `spike-isolated-node-action/` preserves the completed isolated Node action
  experiment, its fixtures, draft schemas, and result records because open LLP
  0249 follow-ups still use them as design inputs.
