# LLP 3000.027: A top-N answer is complete

**Type:** RFC
**Status:** Implemented
**Systems:** Snapback 4 bounded reads, composition, device coverage, diagnostics and client guides
**Author:** Claude (supervisor decision) / GPT-6 Astra (implementation)
**Date:** 2026-09-27
**Revised:** 2026-09-27
**Related:** [LLP 3000](./3000-snapback4.explainer.md), [LLP 3000.007](./3000.007-relaxed-quarry-and-explicit-residency.rfc.md), [LLP 3000.001](./3000.001-durable-replica-and-write-lifecycle.research.md)

## 1. Decision

Calibration #23 added an optional cursor solely to make a top-ten answer
complete. `first N` and `last N` define the answer: holding that bound does
not make it incomplete. This records the supervisor's 0.4.6 lane CQ decision,
superseding cursorless-overflow completeness in LLP 3000.007.

`complete` means the query answered its declared request within known coverage
and execution limits. A cursorless top-N answer has no `next`; a cursor page
may be complete with `next`. Composition preserves this rule, including a
`last 1` preview. A declared bound is not lost coverage.

## 2. Invariants

Meter cuts, undecided read-rule prefixes and device horizons keep their current
behavior. Rules apply per source table and row before projection, counting or
ordering. All work remains metered. Incomplete lane discovery stays incomplete.
A collector interrupted over a cursor page stays incomplete: its continuation
would skip the input rows it did not consume. A cursorless loop that breaks
has no continuation to lose: the program's return value is the answer,
computed over complete inputs. This preserves the existing collector behavior;
meter cuts, undecided prefixes and horizons still make those inputs incomplete.

A plain cursorless query scan stops at its declared bound without examining or
charging an overflow row. That lookahead existed only to decide the removed
overflow bit and must not cut an already full answer. Cursor pages retain
lookahead to establish `next`. Merge inputs retain lookahead for ordered lane
opening/refill and exhaustion; distinct lane discovery retains it to detect
unopened lanes. Device horizon scans retain their boundary proof and lookahead:
a full page must not certify unknown coverage beyond the acquired floor.
Meter-bounded domains, streaming aggregates and job traversal retain their
existing consumption rules: the meter is not a declared answer bound.
Aborting mutation scans retain their admission charge and lookahead; this
change concerns query completeness, not mutation admission or abort limits.
`value_source_incomplete` directly vetoes completeness on every host as well as
continuation; its component overflow marker records the same discovery loss.

Ordinary device fallback still asks the server only for missing knowledge or
unknown presence. A held top-N answer is one the server would repeat; a meter
cut or a declared page bound does not request fallback. Certificates continue
to classify authorization and coverage rather than promise unbounded results.

## 3. Diagnostics and documentation

`N_NO_CURSOR` remains advice for a returned page that cannot continue: declare
`c: cursor ?` and use `after c` if the screen pages. A composed field's declared
`first N` or `last N` is its whole intent and emits no such note. The reads,
bounds, search and client guides use the definition in §1 and remove rewrites
whose only purpose was completeness.

## 4. Implementation and validation

Implementation sites: `snapback4-core/src/engine/{read,word_merge,view_merge}.rs`
and component coverage; `snapback4-lang/src/bind/mod.rs` and page provenance;
the existing device/local outcome, certificate and CLI test paths are audited.
Paths here are relative to `snapback4/crates/`.

Prove on the server and both device stores: cursorless `last 10` over 1,000
matches is complete; meter cuts, undecided prefixes and horizons stay
incomplete; a composed `last 1` preview is complete. Cover continuation advice,
client fallback and CLI reporting. Run the entire guide test and
`snapback4/scripts/test.sh`; measure wasm against the unchanged budget.
Search membership planning belongs to lane GS; only obsolete completeness
assertions and explanatory text change here.
