## Transition questions

Source guards and actual typed writes identify a bounded transition question;
operation names and enum declaration order do not establish product authority.
Two supported shapes are:

- A literal writer accepts either A or B and writes C, while a sibling explicitly
  requires A before writing B. Replay the actual A to C edge and ask whether B
  is a prerequisite (030's measured to reported path).
- A caller selects an enum value. Existing guards are executed rather than
  treated as evidence that a transition is safe. A
  sibling requires one of those values before changing another enum state.
  Replay the declared default directly to that required value, and ask whether
  the intermediate declared values require explicit transitions (035). The enum
  list is a domain, never an inferred sequential order or automatic gate.

The bounded lane requires direct typed target references, straight-line writes
and a unique write to the questioned enum per operation. Anchors are simple
single-resource mutations with no additional caller arguments, branching,
loops, early returns or preceding writes. Prefix bindings may read only the
exact target row; authored targets and fields are checked before helper
reduction. Auxiliary asserted reads, assertions/helpers inside guards,
computed anchor write fields and unreduced object spreads remain uncovered. Unmapped conditions stay
uncovered.
The existing terminal-workflow inference also treats unreduced parent or child
spreads as unresolved: an unknown parent update can reopen a state, so an
incomplete graph cannot establish terminality or commission a production gate.
Unmapped or source-unrestricted parent state writes likewise leave terminality
unresolved; absence of an old-state guard is not evidence of no outgoing edge.
All other stored prerequisites remain applicability conditions, including
global populations with no target-row reference. Only a positive unique-roster
actor probe (and combinations of such probes) is exempted from applicability;
all of its source qualifiers remain in the basis. Global actor
checks remain part of the complete source basis without assuming that the
publisher and prerequisite actor are the same person. Every full normalized
anchor guard and the types of every field in both typed writes bind the
hypothesis identity, together with the actual reduced applicability predicate.
Guard-read dependency types and operation argument types
are retained too, so identical zero-value JSON cannot hide a change of units
outside the written fields. This binding follows the typed reference closure
without source coordinates or unrelated program bodies, including
qualifiers omitted from the short question. Source coordinates select the
executed write privately; comments and line movement do not define meaning.

A card needs an admitted authored mutation, exact old/next values at its actual
write, and the target column still present with that value after commit.
No-op, reverted, deleted or expired observations are insufficient. The public
candidate is a question, with a separate complete hypothesis; its private deny
collector is not product intent. The actual bypassing operation and caller,
source anchor and observed edge remain visible. Generated initial worlds retain
their fixture provenance; they are not claimed reachable from an empty app.

These questions are advisory, absent from production augmentation, and share
the existing deterministic 8,192-work question campaign. The list of codes eligible to gate,
the 3,072 gate budget, runtime admission and deploy/review scheduling do not change.
018's already-witnessed approval-path question remains the sibling receipt
case from LLP 3000.036.004.006; it is preserved without double coverage credit.
An author can enforce explicit named old/next update rules or program guards,
and state independent intent, rather than treating a guessed enum order as law.

New transition cards use one factual default line and share the assignment
tier's positive deployment-summary placement; verdicts, gates, refusals and
test status remain visible. Expanded review/JSON retains the whole replay.

A syntactic guard cannot hide an admitted edge: a no-change guard, redundant
conjunction, or partial old-state restriction still receives the same bounded
bad-edge replay. A proper ordered guard removes that witness, even when its
private question hypothesis remains available for later regressions.

## Parent-window correction

The full affected unit run exposed an overbroad uncertainty guard: a known-target
parent state writer without an old-state requirement made completion terminality
unknown, and also accidentally erased the separate parent-window contract. The
existing `parent_window_coupling_requires_the_exact_changed_parent` test is
retained unchanged. Its ten cases distinguish the related parent from an
incidental parent write and distinguish real changes from no-ops.

Source-unrestricted known-target writers now prevent terminal completion inference
after the independent window contract is emitted. Unmapped targets and unreduced
spreads remain uncovered before either inference. This preserves the earlier
reopening precision corrections without letting an unrelated write erase a
known window. The six guarded/unguarded reopening cases remain required.
