## Summary

Snapback 4 removes substantial work around authorization, local data, durable
writes and asset lifetime. The September 18–20 Clique diaries still show a
recurring cost: ordinary application work requires considerable knowledge of
Quarry's execution, completeness, residency and resource model. Correct
refusals protect the application, but recovering from them remains work.

Charlie requested this document, six problem children corresponding to the
preceding assessment, and an improvement proposal beneath each problem.
This is that thirteen-document family. The initial commission was to document and
propose. The subsequent author instruction in §6 authorizes review, directional
selection, implementation, npm publication and a Clique rerun. The initial
Drafts changed no existing limits; §7 records the delegated selection and the
child RFCs now distinguish implemented work from pending qualification.

The distinct contribution is a dated account of the residual experience on
0.2.29–0.2.31, with independently discussable proposed remedies. Existing
mechanisms retain their owning LLPs. In particular, this family does not
reopen the implemented increment of LLP 3000.008 or duplicate the maintained
columns implementation commissioned under LLP 3000.007.001.

## 5. How to judge the proposed improvements

Measure application responsibilities removed: authored bridges, marker and
reconciliation code, duplicated state machines, diagnostic corrections and
manual lifecycle sequencing. Generated code still counts toward maintenance,
runtime work and failure cases; hiding it is not removing its cost.

Keep correctness and costs beside that result: authority, complete domains,
durability, acquisition bytes, peak memory, scans, writes, restart behavior
and supported package/host identities. Preserve failed attempts and unrun
cases. Use the existing suites, witnesses and run records, with no new global
registry or blocking battery. Fresh builders should receive equivalent tasks
and only their installed package's public guidance. A small pilot yields
descriptive evidence, not a statistically established improvement.

The six RFCs were candidates for the delegated directional decision in §6;
§7 records the resulting selection. Start with reproductions and the smallest change that removes a demonstrated
responsibility. A proposal that merely relocates complexity, weakens the
contract or cannot improve its stated workload should be revised or withdrawn.
