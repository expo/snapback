**Findings**

1. **High — An unused malformed helper can panic the compiler.**  
   [aggregate_provenance.rs:314](snapback4/crates/snapback4-lang/src/bind/aggregate_provenance.rs:314), also lines 316 and 322.

   ```quarry
   fn unused(): at()
   query ok():
     return 0
   ```

   Uncalled helper bodies are not typechecked by ordinary program binding. The new pass explicitly visits them at lines 83–86, reaches `at`, and indexes an empty `values` vector. `slice()` and insufficient-argument `group()` have equivalent paths. Thus `diagnostics.is_empty()` does not establish these indexing preconditions.

   **Smallest fix:** validate builtin arity inside this pass and return `UNKNOWN` for unsupported/malformed calls. Add a no-panic regression for unused helpers; do not change admission merely to protect diagnostic analysis.

2. **High — Joining identical nested objects performs exponential work.**  
   [aggregate_provenance.rs:39](snapback4/crates/snapback4-lang/src/bind/aggregate_provenance.rs:39), triggered by the unconditional environment joins at line 169.

   Bind `x` to an object with 30 nested single-field `a` objects, then execute an unrelated `if flag: ignored = 1` before returning `x`. Each common field appears twice in `self.fields.keys().chain(other.fields.keys())`. Both occurrences recursively compute the same merge before the second insertion replaces the first. Joining this unchanged object therefore requires more than a billion recursive calls.

   **Smallest fix:** traverse each distinct field once, and skip joins for unchanged bindings. Whole-environment cloning and uncached helper interpretation also prevent the requested proportional-work claim; add a scaling regression covering those paths.

3. **Medium — `slice` loses argument influence when an element is extracted, producing a false positive.**  
   [aggregate_provenance.rs:313](snapback4/crates/snapback4-lang/src/bind/aggregate_provenance.rs:313).

   With the public `posts.score` schema and literal initialization used by `INCREMENT`:

   ```quarry
   mutation choose(postId: posts, offset: int):
     p = posts[postId] ! else NOT_FOUND
     delta = first(slice([1, -1], offset, offset + 1)) ! else BAD_OFFSET
     update posts[p.id] { score: p.score + delta }
   ```

   The caller selects increment or decrement. `slice` puts `ARGUMENT` only in the container’s `bits`; `first` returns its untainted item. Consequently `delta` becomes ambient and the write becomes read-derived, emitting the note. This is equivalent to the argument-selected conditional that correctly disqualifies cal10. It is not the documented exception for selecting a table read.

   **Smallest fix:** propagate slice-bound influence into its element provenance, including nested fields—for example through `influenced`—and add this silent regression.

4. **Medium — A loop-carried count of table rows is missed.**  
   [aggregate_provenance.rs:183](snapback4/crates/snapback4-lang/src/bind/aggregate_provenance.rs:183), applied at line 200.

   ```quarry
   total = 0
   for row in posts[] first 5 by byId:
     total = total + 1
   update posts[postId] { score: total }
   ```

   Every stored value is a count over a table read, with no value argument. However, loop-cardinality influence retains only `ARGUMENT | UNKNOWN`; it drops `READ`. `total` stays ambient and disqualifies the column. The existing accumulator test adds `row.score`, so it cannot detect this omission.

   **Smallest fix:** propagate read-derived iteration-count influence into changed carried bindings, alongside argument/unknown influence. Add the positive count-loop regression.

5. **Low — Two promised silence controls are missing.**  
   [aggregate_copies.rs:70](snapback4/crates/snapback4-lang/tests/aggregate_copies.rs:70), [479](snapback4/crates/snapback4-lang/tests/aggregate_copies.rs:479).

   There is no append-only derived-copy control. The recursive-shape test returns the widened object from a query and asserts the unrelated `INCREMENT` note remains; it would still pass if widening incorrectly supplied read evidence to a written column.

   **Smallest fix:** add an otherwise qualifying append-only insertion and a public write of the widened value, both asserting silence.
