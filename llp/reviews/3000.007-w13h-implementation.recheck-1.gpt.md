**High — Conditional value joins can still rewind a returned raw page.**

Location: [pages.rs:261](/Users/ccheever/projects/snapback-w13-review-f/repo/snapback4/crates/snapback4-core/src/engine/pages.rs:261), with [record-field filtering:161](/Users/ccheever/projects/snapback-w13-review-f/repo/snapback4/crates/snapback4-core/src/engine/pages.rs:161) and [publication:360](/Users/ccheever/projects/snapback-w13-review-f/repo/snapback4/crates/snapback4-core/src/engine/runner.rs:360).

Use the existing `auxiliary_return` fixture, replacing its return form with:

```quarry
  selected = page if q = 'raw' else ignored
  return { page: selected, shaped: ignored }
```

The compiler lowers the conditional to two assignments to one temporary. [Lowering:116](/Users/ccheever/projects/snapback-w13-review-f/repo/snapback4/crates/snapback4-lang/src/bind/program/expr.rs:116). The branches have the same source page but different shape lineages. `origins` retains only exactly equal bindings, so it drops the temporary’s provenance and subsequently `selected`’s provenance. Record analysis silently omits that field and sees only `ignored`.

With `q = 'raw'`, the returned record therefore contains raw `[a]`, yet publication selects `ignored`’s inclusive rewind to `a`. Following it returns `[a]` again. This is a source-derived counterexample to the required raw-page precedence.

The same join also introduces a regression without exhaustion: `return page if q = 'raw' else ignored` loses its owner entirely, returning no continuation for a nonfinal page. Before shape lineage entered `Origin` equality, those branches retained their common page origin.

**Smallest correct change:** retain the common page identity through conditional assignments and resolve the selected shape lineage using the executed branch. A potentially page-carrying field cannot silently disappear when deciding raw-page precedence. Add this record control and the standalone conditional-value control, exercising both arms on all three hosts. Simply unioning lineages would still rewind the raw arm.
