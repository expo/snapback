All references below are at IMPL_COMMIT `0abb5b7e25da60d62cb17f21f9ef03f5b6bd11cb`. Three fixes are sound; the absence matcher has one Low-precision defect.

1. **FIXED — Unicode canary.** U+0307 has canonical combining class 230 and U+0323 class 220, so `d U+0307 U+0323` is genuinely unordered (`UnicodeData.txt:776,804`). NFC reorders them, and the decomposition mappings confirm `d + U+0323 → U+1E0D` while U+0307 remains (`UnicodeData.txt:6914,6916`). The native oracle computes `input.nfc()` through `unicode_normalization`, rather than trusting literals alone (`snapback4/crates/snapback4-core/tests/unicode_fold.rs:6,14-16`). The web guard uses the corrected input (`snapback4/crates/snapback4-device/src/web.rs:29`). The stub performs adjacent pair substitutions across its input rather than returning a canary-specific constant; it produces U+1E0B U+0323 without reordering, so the corrected guard refuses it while the old ordered guard admitted it (`snapback4/packages/snapback4/test/unicode.test.mjs:30-38`).

2. **FIXED — composed `since`.** `lastSyncAt` is captured immediately before calling the server and that captured value is used in the sole composed-result formatter (`snapback4/packages/snapback4/src/local.ts:889-907`). Direct queries and watches both enter that same path (`local.ts:1094-1107,937-952`), including the watch observations before and after reconnect in the existing test (`retained-history.test.mjs:411-433`). The new test records the pre-query sync timestamp, holds `/q/both`, completes another sync, proves its timestamp advanced, then releases the reply and requires the older value (`retained-history.test.mjs:152-178,376-395`). The old code would return the advanced mutable `lastSyncAt`, so it would fail this assertion.

3. **PARTLY — Unicode-table absence rule.** The substring check catches both ordinary and hash-mounted Twiggy forms, and its synthetic rows call the exported production `checkAbsent` directly (`snapback4/scripts/attribute-wasm.mjs:123-136`; `snapback4/packages/snapback4/test/wasm-absent.test.mjs:3,10-13`). It does not satisfy “and nothing else”: `includes('unicode_normalization')` also matches unrelated symbol names containing that substring.

4. **FIXED — boundary and documentation.** The guard runs only from the constructor (`snapback4/crates/snapback4-device/src/web.rs:21-43`). Every later non-ASCII fold invokes the live host method; the web build has no Rust NFC fallback (`snapback4/crates/snapback4-core/src/words.rs:10-15,33-40`). Thus deletion, a non-callable replacement, or a throw produces a JavaScript exception, while a callable wrong implementation supplies wrong folded keys. The LLP states this limitation and preserves `word_fold` as the witness (`llp/3000.002-end-to-end-resource-bounds.research.md:414`; `web.rs:57-60`). README’s browser-open statement remains consistent with the search card (`snapback4/packages/snapback4/README.md:1015`; `snapback4/crates/snapback4-lang/src/guide/search.rs:60`). README and the sync card use identical pre-request timestamp wording (`README.md:1424-1427`; `guide/sync.rs:162-165`), enforced by the exact-paragraph comparison at `snapback4/crates/snapback4-lang/tests/guide.rs:1065-1073`.
