Findings:

- **Medium — `snapback4/packages/snapback4/test/wasm-codec-census.mjs:141-160`.** Macro bodies are scanned only when a derive name is already in the resolved Deserialize set. A macro emitting `#[derive(crate::prelude::Deserialize)] #[serde(untagged)] enum E { X }`, where `prelude` re-exports serde’s derive, produces no census error. Smallest fix: apply the ordinary-item unknown-derive rule to macro bodies; any buffered macro representation must be provably Serialize-only or explicitly allowlisted. Add qualified-re-export and macro-parameter regressions.

- **Medium — `snapback4/packages/snapback4/test/wasm-codec-census.mjs:110-124,141-160`.** Alias sets are global rather than file/scope-specific. Concrete evasion: one file imports `serde::Serialize as D`; another re-exports `serde::Deserialize as De`; a third imports `crate::prelude::De as D` and derives `D` on an untagged enum. The global Serialize alias whitelists the third file’s Deserialize derive. Conversely, an indirect Serialize-only re-export such as `S0 as S` is falsely refused. Smallest fix: resolve aliases per file/scope with a fixpoint for re-exports, treating ambiguity as refusal; add both three-file cases.

- **Low — `llp/3000.002-end-to-end-resource-bounds.research.md:434`.** The LLP calls the symbol-family check the procedural-macro “backstop,” but the instrument only classifies surviving symbols and explicitly permits fully inlined helpers to have no family entry (`scripts/attribute-wasm.mjs:75-79,189-190`). A procedural macro whose small content decoder is fully inlined can escape both checks; only the report-only total-byte budget remains. Smallest fix: qualify the claim as a surviving-symbol check and name the byte measurement as the final, non-blocking fallback.
