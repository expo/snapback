The exact completion rule is:

- Collect the current readable selected keys actually emitted between the acquisition markers.
- If fewer than N historical rows were selected, publish `whole`, including when all selected rows subsequently disappear.
- Otherwise, begin with the smallest delivered key K. Examine the descending unselected historical rows at or above K. A row blocks K only if its current image exists, is readable, remains in this group, and has exactly its historical key.
- Publish the smallest delivered key strictly above the greatest blocker, or omit completion if none exists. With no blocker, publish K.

This performs point reads against the retained unselected list, not a current-index walk. The rule is conservative for coverage, but that conservatism is observably history-dependent.
