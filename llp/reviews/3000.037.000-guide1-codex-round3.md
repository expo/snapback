  232 on: cached answers were consumed). A planted cached-hit-to-miss fault is caught
  233 by the random corpus (LLP 3000.035 §5.1; the closed
  234 [coverage ticket](../issues/closed/20261007-quarry-store-oracle-prefetch-coverage-gap.md)).
  235 Heap is charged identically on every store and the device (LLP 3000.007
  236 §20.24.5); any disagreement is a ticket candidate, never normalized into a pass.
  237 The cluster regression asserts it finds no signature and refuses any new one.

  239 `run-stores --seconds N` stops each worker between cases after N seconds; a case
  240 and any shrinking already underway finish. `cases` remains the requested count,
  241 `generated` is actual completed generation, and `time_limited_workers` reports
  242 the early stop. Slowest-case timing includes generation, comparisons, shrinking
  243 and artifact saving. It does not silently claim the requested million. The scheduled
  244 runner rejects incomplete reports; its own `--hours` option instead chooses a
  245 case count from a 256-case calibration of both campaigns, with 20% headroom and
  246 a million-case cap. This is a sizing estimate, not a hard deadline.

  248 Generator widening (`src/widen.rs`, LLP 3000.035 §5.1): from a stream
  249 independent of the base generator (`generate::base`; a seed it leaves alone is
  250 the base case byte for byte), cases gain prefetch-reachable reads, mutation
  251 blocks (lets, `require`, `if`, several writes to `key` and `k2`, reads after
  252 writes), a prelude of mutations `prep0..` run in order on the same store before
  253 `run` (`Case::steps`, sometimes as the other viewer; `observe` then reads both
  254 keys), and expiry (`expire at .until`, a clock advancing from `seeded_at`
  255 through each step to `clock`, sweeps, `until: now + ttl`). Every oracle runs the
  256 prelude (`execute::world`) and compares its outcomes (`prelude-*` fields;
  257 `store-postgres-prelude`); a device acquires at the seed clock and catches up by
  258 one sync round after the server's prelude. The prelude is emitted first so no
  259 rewrite moves its sites. `lean::generate` narrows half the cases outside the
  260 model (projections, expiry) back into its fragment; the rest stay named
  261 unsupported (`shape`, `loop`, `table-expiry`). The report's `coverage` counts

  199 /// The contents of every ```quarry block in a card or a README.
  200 pub fn quarry(text: &str) -> Vec<String> {
  201     let mut blocks = Vec::new();
  202     let mut current: Option<String> = None;
  203     for line in text.lines() {
  204         match &mut current {
  205             Some(block) if line.trim_end() == "```" => {
  206                 blocks.push(std::mem::take(block));
  207                 current = None;
  208             }
  209             Some(block) => {
  210                 block.push_str(line);
  211                 block.push('\n');
  212             }
  213             None if line.trim_end() == "```quarry" => current = Some(String::new()),
  214             None => {}
  215         }
  216     }
  217     blocks
  218 }

   53 fn distance(a: &str, b: &str) -> usize {
   54     let b: Vec<char> = b.chars().collect();
   55     let mut row: Vec<usize> = (0..=b.len()).collect();
   56     for (i, a) in a.chars().enumerate() {
   57         let mut diagonal = row[0];
   58         row[0] = i + 1;
   59         for (j, b) in b.iter().enumerate() {
   60             let old = row[j + 1];
   61             row[j + 1] = (diagonal + usize::from(a != *b)).min(row[j] + 1).min(old + 1);
   62             diagonal = old;
   63         }
   64     }
   65     row[b.len()]
   66 }

  422 /// A word as written, and its singular (`loops` finds "loop", `queries` "query").

  430 // @ref LLP 3000.007#20.1 — `--find a b` is every word on one line; `a|b` and `a OR b` are either.
  431 /// Line numbers (0-based) whose text holds an alternative: its phrase, or
  432 /// every one of its words (each as written or singular).
  433 fn mentions(card: &str, words: &str) -> Vec<usize> {
  434     let lines: Vec<String> = card.lines().map(str::to_lowercase).collect();
  435     let mut found = Vec::new();
  436     for alternative in alternatives(words) {
  437         let phrase = alternative.to_lowercase();
  438         let each: Vec<Vec<String>> = words_of(&phrase).split_whitespace().map(forms).collect();
  439         found.extend((0..lines.len()).filter(|&i| {
  440             if lines[i].contains(&phrase) { return true; }
  441             let line = words_of(&lines[i]);
  442             !each.is_empty() && each.iter().all(|forms| forms.iter().any(|w| line.contains(w.as_str())))
  443         }));
  444     }
  445     found.sort_unstable();
  446     found.dedup();
  447     found
  448 }

  459 /// `guide <card> --section <words>`: the title line and one section, found by
  460 /// its number in the index (`0` or `opening` for the text before the first
  461 /// heading), its heading (any case, punctuation ignored), a unique prefix, a
  462 /// unique substring, or headings holding every word. When no heading matches
  463 /// but the words occur, the section holding most of their mentions prints, or
  464 /// every mention when they spread; only words no line mentions refuse, naming
  465 /// the nearest heading by spelling.
  466 pub fn section(name: &str, card: &str, words: &str) -> Result<String, String> {
  467     let found = sections(card);
  468     let lines: Vec<&str> = card.lines().collect();
  469     let title = lines.first().filter(|line| line.starts_with("# ")).map(|line| format!("{line}\n\n")).unwrap_or_default();
  470     let wanted = words_of(words);
  471     let print = |start: usize, end: usize| format!("{title}{}", lines[start..end].join("\n").trim_end());
  472     let opening = opening_end(card, &found);
  473     if matches!(wanted.as_str(), "0" | "opening" | "intro" | "introduction") {
  474         if let Some((_,heading,start,end))=found.first() {
  475             if heading == "Opening" {return Ok(print(*start,*end));}
  476         }
  477         return Ok(lines[..opening].join("\n").trim_end().to_owned());
  478     }
  479     if let Ok(n) = wanted.parse::<usize>() {
  480         return match found.get(n.wrapping_sub(1)) {
  481             Some((_, _, start, end)) => Ok(print(*start, *end)),
  482             // `1000` is an alias of the bounds card, not its thousandth section.
  483             None => alias_inside(name, card, words).ok_or_else(|| format!("guide {name} has no section {n}\n{}", section_index(name, card))),
  484         };
  485     }
  486     // An alias that names a section of this card lands there (`subpaths` would match two headings).
  487     if super::alias_section(words).is_some_and(|(target, _)| target == name) {
  488         if let Some(landing) = alias_inside(name, card, words) { return Ok(landing); }
  489     }
  490     let numbered: Vec<(usize, &(usize, String, usize, usize), String)> = found.iter().enumerate().map(|(n, s)| (n + 1, s, words_of(&s.1))).collect();
  491     let stages: [&dyn Fn(&str) -> bool; 4] = [
  492         &|heading| heading == wanted,
  493         &|heading| heading.starts_with(&wanted),
  494         &|heading| heading.contains(&wanted),
  495         &|heading| wanted.split(' ').all(|w| heading.split(' ').any(|h| h.starts_with(w))),
  496     ];
  497     for stage in stages {
  498         if wanted.is_empty() { break; }
  499         let matches: Vec<_> = numbered.iter().filter(|(_, _, heading)| stage(heading)).collect();
  500         match matches.as_slice() {
  501             [] => continue,
  502             [(_, (_, _, start, end), _)] => return Ok(print(*start, *end)),
  503             many => return Err(format!("{words:?} matches {} sections of guide {name}: {}; pick one by number: snapback4 guide {name} --section {}", many.len(), many.iter().map(|(n, s, _)| format!("{n}. {}", s.1)).collect::<Vec<_>>().join(" · "), many[0].0)),
  504         }
  505     }
  506     // No heading matches. A curated alias naming a section of another card
  507     // lands there, saying so (`guide wire --section acceptance`).
  508     // @ref LLP 3000.007#20.1 — acceptance under wire, statements under language, loops under writes.
  509     let hits = mentions(card, words);
  510     if let Some((target, _)) = super::alias_section(words).filter(|(target, _)| *target != name) {
  511         if let Some(landing) = super::card(target).and_then(|text| alias_landing(words, target, text)) {
  512             let here = match hits.len() {
  513                 0 => String::new(),
  514                 1 => format!(" (one line of guide {name} mentions it: --find {words:?})"),
  515                 n => format!(" ({n} lines of guide {name} mention it: --find {words:?})"),
  516             };
  517             return Ok(format!("No heading of guide {name} is named {words:?}; it is a section of guide {target}{here}:\n\n{landing}"));
  518         }
  519     }
  520     // When the words occur, print the section holding most of their mentions
  521     // (a strict plurality), or every mention when sections tie for the most.
  522     // @ref LLP 3000.007#20.1 — a topic word (audience, React, Reference) prints what it names instead of failing.
  523     if !hits.is_empty() {
  524         let mut counts: Vec<(usize, usize)> = Vec::new();
  525         for &i in &hits {
  526             let (n, _) = section_of(&found, i);
  527             match counts.iter_mut().find(|(section, _)| *section == n) { Some(entry) => entry.1 += 1, None => counts.push((n, 1)) }
  528         }
  529         let &(best, count) = counts.iter().max_by_key(|(n, count)| (*count, std::cmp::Reverse(*n))).expect("a hit has a section");
  530         // @ref LLP 3000.007#20.1 — a plurality lands (`client --section react` listed 4 sections); only a tie lists mentions.
  531         if counts.iter().filter(|(_, other)| *other == count).count() == 1 {
  532             let (heading, start, end) = if best == 0 { ("Opening", 0, opening) } else { let s = &found[best - 1]; (s.1.as_str(), s.2, s.3) };
  533             let share = match (hits.len(), count == hits.len()) {
  534                 (1, _) => "the one line that mentions it".to_owned(),
  535                 (total, true) => format!("all {total} lines that mention it"),
  536                 (total, false) => {
  537                     let mut others: Vec<(usize, usize)> = counts.iter().copied().filter(|(n, _)| *n != best).collect();
  538                     others.sort_by_key(|&(n, count)| (std::cmp::Reverse(count), n));
  539                     let others = others.iter().take(3).map(|&(n, count)| format!("{n}. {} ({count})", if n == 0 { "Opening" } else { found[n - 1].1.as_str() })).collect::<Vec<_>>().join(", ");
  540                     format!("{count} of the {total} lines that mention it; also {others} (--find {words:?} prints them all)")
  541                 }
  542             };
  543             let note = format!("guide {name}: keyword {words:?} opens {best}. {heading} ({share}).");
  544             let body = if best == 0 { lines[start..end].join("\n").trim_end().to_owned() } else { print(start, end) };
  545             return Ok(format!("{note}\n\n{body}"));
  546         }
  547         let note = format!("guide {name}: keyword {words:?} appears in {} sections; matching lines:\n", counts.len());
  548         return find(name, card, words).map(|lines| format!("{note}{lines}"));
  549     }
  550     // A whole-card alias no line mentions prints the card's opening.
  551     if let Some(opening) = alias_inside(name, card, words) { return Ok(opening); }
  552     // A miss: the nearest heading by spelling (a typo), and the index.
  553     let mut out = format!("no section of guide {name} is named {words:?}, and no line mentions it");
  554     let mut near: Vec<(usize, usize, &str)> = numbered.iter().map(|(n, s, heading)| {
  555         let best = heading.split(' ').map(|h| distance(&wanted, h)).chain([distance(&wanted, heading)]).min().unwrap_or(usize::MAX);
  556         (best, *n, s.1.as_str())
  557     }).collect();
  558     near.sort();
  559     if let Some(&(_, n, heading)) = near.first().filter(|(best, _, _)| *best <= wanted.chars().count().div_ceil(2)) {
  560         out.push_str(&format!("; nearest heading: {n}. {heading}"));
  561     }
  562     Err(format!("{out}\n{}", section_index(name, card)))
  563 }

  566 const FIND_LINES: usize = 80;

  568 /// `guide <card> --find <words>`: every line holding the words (the phrase, or
  569 /// each word on one line; `a|b` either), with a line of context, under its
  570 /// section's number and heading. When no line holds every word, the lines
  571 /// holding any of them print and the result is still an error (exit 1).
  572 pub fn find(name: &str, card: &str, words: &str) -> Result<String, String> {
  573     let found = sections(card);
  574     let lines: Vec<&str> = card.lines().collect();
  575     let mut hits = mentions(card, words);
  576     // No line holds every word: print the lines holding any of them, still exiting 1.
  577     let mut any = false;
  578     if hits.is_empty() {
  579         // An alias of this card no line holds: the section it names, or the opening.
  580         if let Some(landing) = alias_inside(name, card, words) { return Ok(landing); }
  581         hits = any_mentions(card, words);
  582         if hits.is_empty() { return Err(format!("no line of guide {name} mentions {words:?}\n{}", section_index(name, card))); }
  583         any = true;
  584     }
  585     // Merge each hit's one line of context into ranges.
  586     let mut ranges: Vec<(usize, usize)> = Vec::new();
  587     for &i in &hits {
  588         let (start, end) = (i.saturating_sub(1), (i + 2).min(lines.len()));
  589         match ranges.last_mut() { Some(last) if start <= last.1 => last.1 = end, _ => ranges.push((start, end)) }
  590     }
  591     let mut out = if any {
  592         format!("no line of guide {name} mentions all of {words:?}; {} {} one of them (a|b searches for either; words with spaces must share a line)\n", hits.len(), if hits.len() == 1 { "line mentions" } else { "lines mention" })
  593     } else { format!("guide {name}: {} {} {words:?}\n", hits.len(), if hits.len() == 1 { "line mentions" } else { "lines mention" }) };
  594     let (mut printed, mut shown, mut current) = (0, 0, usize::MAX);
  595     for (start, end) in ranges {
  596         if printed >= FIND_LINES { break; }
  597         let (n, heading) = section_of(&found, start.max(hits.iter().copied().find(|&h| h >= start).unwrap_or(start)));
  598         if n != current { out.push_str(&format!("{n}. {heading}\n")); current = n; } else { out.push_str("  …\n"); }
  599         for (i, line) in lines.iter().enumerate().take(end).skip(start) {
  600             let hit = hits.binary_search(&i).is_ok();
  601             out.push_str(&format!("{:>5}{} {line}\n", i + 1, if hit { ':' } else { ' ' }));
  602             printed += 1;
  603             shown += usize::from(hit);
  604         }
  605     }
  606     if shown < hits.len() { out.push_str(&format!("… {} more; narrow the words or read one section with --section <number>\n", hits.len() - shown)); }
  607     out.push_str(&format!("Whole sections: snapback4 guide {name} --section <number>"));
  608     // Search rows are numbered excerpts, not executable fences. Keep the query
  609     // and the first actual matches when a dense result exceeds the read budget;
  610     // paragraph-only bounding would discard the entire result as one block.
  611     if out.len() > FULL_BYTES {
  612         let tail=format!("\n… more matching context; narrow the words or read snapback4 guide {name} --section <number>");
  613         let room=FULL_BYTES.saturating_sub(tail.len());
  614         let end=out[..out.floor_char_boundary(room)].rfind('\n').unwrap_or_else(||out.floor_char_boundary(room));
  615         out.truncate(end);out.push_str(&tail);
  616     }
  617     if any { Err(out) } else { Ok(out) }
  618 }

  621 /// Paragraphs and complete fences are the units of reading and project deltas.
  622 // @ref LLP 3000.037.000#8 — never cut a runnable fence in half.
  623 pub fn reading_blocks(text: &str) -> Vec<String> {
  624     let mut blocks = Vec::new(); let mut block = String::new(); let mut fenced = false;
  625     for line in text.lines() {
  626         if line.trim_start().starts_with("```") { fenced = !fenced; }
  627         if line.is_empty() && !fenced {
  628             if !block.is_empty() { blocks.push(std::mem::take(&mut block)); }
  629         } else { block.push_str(line); block.push('\n'); }
  630     }
  631     if !block.is_empty() { blocks.push(block); } blocks
  632 }

  639 fn bounded(name: &str, text: &str, limit: usize) -> String {

  646     }
  647     out.push_str(&hint); out
