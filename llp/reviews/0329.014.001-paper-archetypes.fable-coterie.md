# Paper archetype: coterie in the v0 language (LLP 0329.014.000)

Source: `demos/coterie/snapback/schema.mjs`, `functions.mjs` and acceptance tests M1–M3. Author: Claude Fable 5. No repository file was modified; features the spec lacks are not used in corrected forms — they go to §6 and the operation stays `refused`.

Two design moves recur: (a) `conversationMembers` + `conversationCurrentMembers` become `seats` (one row per principal × conversation: `active`, `removedSequence` cutoff) plus an `incarnations` history; the former-member cutoff becomes the **read rule** on `messages`. (b) The receipt watermark becomes a bounded per-receipt patch (K3) so every displayed count is a maintained aggregate. Both are argued in §5 and §8.

Prediction legend: *closed* = every read is a shape-keyed row the predicting client necessarily holds; *conditional* = a row/absence it may not hold, or a `cap`/`unique` it cannot evaluate; *partial* = a site it cannot replay (asset slot, other members' receipts).

### 2. Schema in v0

```ts
import { table, id, text, int, bool, time, ref, unique, cap, immutable, maintain, viewer, public, never, channel } from 'backend'   // principal(), .optional(), asset(), list(), key() are [inferred] spellings
const activeSeat = c => db.exists(seats.byOwnerConvActiveRole, [viewer, c, true])          // rule helpers: inlined, one probe each
const adminSeat  = c => db.exists(seats.byOwnerConvActiveRole, [viewer, c, true, 'admin'])
const anySeat    = c => db.exists(seats.byOwnerConv, [viewer, c])
const ownsProfile = p => db.get(profiles, p)?.ownerId === viewer, ownsPost = p => db.get(posts, p)?.ownerId === viewer
const bootstrapOrAdmin = r => (r.joinedSequence === 0 && db.get(conversations, r.conversationId)?.creatorId === viewer) || adminSeat(r.conversationId)
const OPT = n => text({ max: n }).optional()
const FX = { fixtureId: OPT(128), fixtureDigest: OPT(64) }, FXM = { clientMutationId: OPT(128), fixtureMutationId: OPT(128), fixtureDigest: OPT(64) }

export const profiles = table({ id: id(), ownerId: principal(), fixtureId: OPT(128), handle: text({ max: 20 }), displayName: text({ max: 50 }), bio: text({ max: 200 }),
    location: text({ max: 50 }), link: text({ max: 2048 }), avatar: asset('avatarUpload').optional(), avatarSourceDigest: OPT(64) })
  .unique('byOwner', ['ownerId']).unique('byHandle', ['handle']).unique('byFixture', ['fixtureId']).index('byHandleOrder', ['handle'])   // nullable unique: §6 #6
  .rules({ read: public('handles resolve for signed-out visitors'), insert: p => p.ownerId === viewer, update: p => p.ownerId === viewer, delete: never })
  .constraints(immutable(['ownerId']))

export const posts = table({ id: id(), ownerId: principal(), authorProfileId: ref(profiles), ...FX, kind: text({ max: 6 }), body: text({ max: 500 }), parentId: ref(posts).optional(), isReply: bool(), createdAt: time() })
  .index('byAuthorReplyTime', ['authorProfileId', 'isReply', 'createdAt', 'id']).index('byParentTime', ['parentId', 'createdAt', 'id']).unique('byFixture', ['fixtureId'])
  .rules({ read: public('posts are public'), insert: p => p.ownerId === viewer && ownsProfile(p.authorProfileId), update: p => p.ownerId === viewer, delete: never })
  .constraints(immutable(['ownerId', 'authorProfileId', 'parentId', 'isReply', 'createdAt']), cap({ by: ['parentId'], where: p => p.isReply, max: 1023 }))   // §6 #3; P4

export const postImages = table({ id: id(), postId: ref(posts), position: int(), asset: asset('postImageUpload'), sourceDigest: OPT(64) })
  .unique('byPostPosition', ['postId', 'position']).constraints(cap({ by: ['postId'], max: 4 }))
  .rules({ read: public('post media is public'), insert: i => ownsPost(i.postId), update: i => ownsPost(i.postId), delete: i => ownsPost(i.postId) })
export const postVideos = table({ id: id(), postId: ref(posts), asset: asset('postVideoUpload'), sourceDigest: OPT(64) }).unique('byPost', ['postId']).rules({ /* as postImages */ })

export const feedEvents = table({ id: id(), kind: text({ max: 6 }), sourceId: id(), postId: ref(posts), actorProfileId: ref(profiles), createdAt: time() })
  .unique('bySource', ['kind', 'sourceId']).index('byTime', ['createdAt', 'id']).index('byActorTime', ['actorProfileId', 'createdAt', 'id'])
  .rules({ read: public('the global feed is public'), insert: e => ownsProfile(e.actorProfileId), update: never, delete: e => ownsProfile(e.actorProfileId) })

export const follows = table({ id: id(), followerId: principal(), followerProfileId: ref(profiles), followedProfileId: ref(profiles), createdAt: time(), ...FXM })
  .unique('byPair', ['followerProfileId', 'followedProfileId']).index('byFollower', ['followerProfileId']).index('byFollowed', ['followedProfileId'])
  .rules({ read: public('the social graph is public'), insert: f => f.followerId === viewer, update: f => f.followerId === viewer, delete: f => f.followerId === viewer })
  .constraints(immutable(['followerId', 'followerProfileId', 'followedProfileId']), cap({ by: ['followerProfileId'], max: 1024 }))   // its code needs §6 #2
export const likes = table({ id: id(), ownerId: principal(), ownerProfileId: ref(profiles), postId: ref(posts), createdAt: time(), ...FXM })
  .unique('byOwnerPost', ['ownerProfileId', 'postId']).index('byPost', ['postId'])
  .rules({ read: public('likes are public'), insert: l => l.ownerId === viewer, update: l => l.ownerId === viewer, delete: l => l.ownerId === viewer })
export const reposts = table({ /* as likes */ }).unique('byOwnerPost', ['ownerProfileId', 'postId']).rules({ /* as likes */ })

maintain.count(likes,   { by: ['postId'], as: likeCount, overflow: 'refuse' });  maintain.count(reposts, { by: ['postId'], as: repostCount })
maintain.count(posts,   { by: ['parentId'], where: p => p.isReply, as: replyCount })
maintain.count(follows, { by: ['followedProfileId'], as: followerCount });       maintain.count(follows, { by: ['followerProfileId'], as: followingCount })   // public sources ⇒ no `readable`

export const conversations = table({ id: id(), creatorId: principal(), creatorProfileId: ref(profiles), kind: text({ max: 5 }), dmLow: ref(profiles).optional(), dmHigh: ref(profiles).optional(), ...FX,
    groupName: OPT(50), groupDescription: OPT(200), nextSequence: int(), lastMessageId: ref(messages).optional(), lastMessageAt: time(), createdAt: time() })
  .unique('byDmPair', ['dmLow', 'dmHigh']).unique('byFixture', ['fixtureId'])
  .rules({ read: c => anySeat(c.id), insert: c => c.creatorId === viewer, update: c => activeSeat(c.id), delete: never })
  .constraints(immutable(['creatorId', 'creatorProfileId', 'kind', 'dmLow', 'dmHigh', 'createdAt']))

// One row per principal × conversation. `active` is current authority; `removedSequence` is the read cutoff.
export const seats = table({ id: id(), ownerId: principal(), conversationId: ref(conversations), profileId: ref(profiles), role: text({ max: 6 }), active: bool(), joinedSequence: int(), removedSequence: int().optional(), lastActivityAt: time() })
  .unique('byOwnerConv', ['ownerId', 'conversationId']).index('byOwnerConvActiveRole', ['ownerId', 'conversationId', 'active', 'role']).index('byConvActive', ['conversationId', 'active']).index('byOwnerActivity', ['ownerId', 'lastActivityAt', 'conversationId'])
  .rules({ read: s => s.ownerId === viewer || anySeat(s.conversationId), insert: bootstrapOrAdmin, update: s => s.ownerId === viewer || adminSeat(s.conversationId), delete: never })
  .constraints(immutable(['ownerId', 'conversationId', 'profileId']), cap({ by: ['ownerId'], max: 1000 }), cap({ by: ['conversationId'], where: s => s.active, max: 50 }))   // the two chat envelopes; `where` is §6 #3

export const incarnations = table({ id: id(), seatId: ref(seats), conversationId: ref(conversations), profileId: ref(profiles), joinedAt: time(), joinedSequence: int(), removedAt: time().optional(), removedSequence: int().optional(), fixtureMutationId: OPT(128), fixtureDigest: OPT(64) })
  .unique('byFixtureMutation', ['fixtureMutationId']).index('bySeat', ['seatId', 'joinedSequence'])
  .rules({ /* read, insert as seats */ update: i => db.get(seats, i.seatId)?.ownerId === viewer || adminSeat(i.conversationId), delete: never }).constraints(immutable(['seatId', 'conversationId', 'profileId', 'joinedSequence']))

export const messages = table({ id: id(), ownerId: principal(), conversationId: ref(conversations), senderProfileId: ref(profiles), ...FX, body: text({ max: 2000 }), quotedMessageId: ref(messages).optional(), recipientCount: int(), sequence: int(), createdAt: time() })
  .unique('byConvSeq', ['conversationId', 'sequence']).unique('byFixture', ['fixtureId'])
  .rules({ read: m => activeSeat(m.conversationId) || (db.get(seats.byOwnerConv, [viewer, m.conversationId])?.removedSequence ?? -1) > m.sequence,   // rejoined: full history; former: strictly before the cutoff
           insert: m => m.ownerId === viewer && activeSeat(m.conversationId), update: m => m.ownerId === viewer, delete: never })
  .constraints(immutable(['ownerId', 'conversationId', 'senderProfileId', 'sequence', 'recipientCount', 'createdAt']), cap({ by: ['conversationId'], max: 1024 }))   // MESSAGE_ENVELOPE_EXCEEDED

export const receipts = table({ id: id(), ownerId: principal(), conversationId: ref(conversations), messageId: ref(messages), sequence: int(), recipientSeatId: ref(seats), recipientProfileId: ref(profiles),
    required: bool(), rank: int() /* 0 sent, 1 delivered, 2 read */, deliveredAt: time().optional(), readAt: time().optional() })
  .unique('byMessageRecipient', ['messageId', 'recipientProfileId']).index('bySeatRequiredRank', ['recipientSeatId', 'required', 'rank'])
  .rules({ read: r => activeSeat(r.conversationId) || (db.get(seats.byOwnerConv, [viewer, r.conversationId])?.removedSequence ?? -1) > r.sequence,   // the messages rule retyped; §6 #4 wants inherits(messages, 'messageId')
           insert: r => activeSeat(r.conversationId), update: r => r.ownerId === viewer || adminSeat(r.conversationId), delete: never })
  .constraints(immutable(['ownerId', 'conversationId', 'messageId', 'sequence', 'recipientSeatId', 'recipientProfileId']))

maintain.count(receipts, { by: ['recipientSeatId'], where: r => r.required && r.rank < 2, as: unreadCount });  maintain.count(receipts, { by: ['recipientSeatId'], where: r => r.required, as: seatRequiredCount })   // about the caller
maintain.count(receipts, { by: ['messageId'], where: r => r.required, as: requiredCount })                     // K2: readable ⇔ message readable — §6 #4, else a declared `readable`
maintain.count(receipts, { by: ['messageId'], where: r => r.required && r.rank >= 1, as: deliveredCount });   maintain.count(receipts, { by: ['messageId'], where: r => r.required && r.rank >= 2, as: readCount })

export const typing = channel({ conversationId: id(conversations) }, { publish: a => activeSeat(a.conversationId), subscribe: a => activeSeat(a.conversationId), ttlMs: 5000 })
// not expressible: typing's value type, 256 B, 5 Hz / burst 10, latest@100 ms, connection key (§6 #9); the three upload policies — media types, 10/50 MB, EXIF strip, variants (§6 #10)
```

No `interval`, `tree`, or `schedule`: coterie's "membership at a time" is a cutoff on a per-conversation sequence — one `get` and one comparison. Thirteen tables replace fourteen.

### 8. Where the design is wrong

1. **K2's "the compiler proves readability or refuses" gives a false positive whenever readability is inherited through a foreign key.** Receipts, post media and feed events are readable exactly when their parent is, but the receipt rule is a *retyped* copy over denormalised columns and the compiler cannot know `r.sequence === m.sequence`. So `maintain.count(receipts, { by: ['messageId'] })` is refused, or admitted only with a declared `readable` — an `E_DISCLOSURE` security item naming `receipts` for a number that discloses nothing — a K2-class wrong answer. *Confirm:* run `check` on §2's `requiredCount`; it must emit `E_DISCLOSURE` or refuse, while with `inherits` (§6 #4) it emits nothing and the count is identical.
2. **The bound calculus has no fan-in shape, so the archetypal social read is certified at 10× its cost and the language pushes toward the wrong product change.** followingFeed is admitted at 21,785 examined; a k-way merge is 2,330. Under `G.examined = 10⁴` it is refused, and the only in-language rewrite is fan-out-on-write into per-follower inboxes — unbounded, because followers are uncapped, hence `E_FANOUT`. The escape the diagnostic then offers is capping followers: changing the product to protect the model, exactly the cheat boundary 0329.015.003 draws. *Confirm:* compile §3's followingFeed under `G.examined = 10,000` and read the rewrite `E_BOUND` proposes.
3. **K6 and prediction are told half the story: constraints are code-less and invisible to the certificate.** Seventeen of 25 mutations are gated by a `cap`/`unique` the client cannot evaluate, and §1 marks them `closed` because §11's modes are defined by key provenance alone. Meanwhile the acceptance suite's contract is operation-exact codes, which `E_CONSTRAINT` cannot carry — so an author who wants `CHAT_ENVELOPE_EXCEEDED` must pre-read the invitee's seat count, which is precisely the read K2 refuses. The spec's two amendments collide on coterie's most-tested behaviour. *Confirm:* `openDm`'s certificate says `closed` with no `disclosures[]`; drive Bob to 1,000 chats and open a DM from Alice — the server refuses with a sealed `E_CONSTRAINT`, the local prediction had succeeded, and no in-spec program can emit the product's code without violating `E_STRUCTURAL_COUNT`.
