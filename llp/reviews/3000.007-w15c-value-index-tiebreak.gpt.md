Maintained identity is the canonical complete group tuple ([schema.rs:1283](snapback4/crates/snapback4-core/src/schema.rs:1283)). Inserts and score changes use complete before/after keys; zero deletion removes those keys ([store.rs:412](snapback4/crates/snapback4-core/src/store.rs:412)). Aggregate rebuilds reconstruct rows, and index-only adoption regenerates indexes from existing rows ([maintains.rs:71](snapback4/crates/snapback4-core/src/engine/maintains.rs:71), [activation.rs:98](snapback4/crates/snapback4-core/src/store/activation.rs:98)).

An uncovered tie shape is a maintain grouped by `room, tag, postId`, indexed as `room, value, tag, id`, with several groups sharing score `2` and nullable `tag = null`, both within and across rooms. Here the omitted `postId` makes maintained `id` essential. The code compares and resumes using `(2, null, id)` in every lane. Ascending bounds exclude the complete position through its upper bound; descending bounds exclude it directly, so neither direction loses another tied row ([rows.rs:114](snapback4/crates/snapback4-core/src/rows.rs:114)). The new recipe fixture does not exercise this case because its trailing `postId` already distinguishes posts.
