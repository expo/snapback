## Findings

### High

**H1. The drafts treat 3000.007 as open design. It is not.**  
3000.007 is Accepted (every §14 question, including 16–18). Status still says “implementation in flight,” but §18.7 records 0.2.12 published: ceremony 3/3 with **zero** Snapback-attributed loops; Astra 7/7 green, holistic 86, independent grade 101 pass / 0 fail / 18 not-run. 3000.008.000 §4 still says “amend 3000.007 with the chosen forms.” Those forms are already on the language card (`else if`, `continue`, reassignment, `text +`, `/` `%`, `where`, seeks, `group`, `fn` bodies, job preludes). Implementing 3000.008 as a second syntax program would fight the accepted RFC.

**H2. 3000.008.000 re-opens settled filtering and ranking.**  
§3: “Reads inside a predicate remain a later decision.” 3000.007 ruling 4 is **yes from the start**; the reads card and `where_filters_after_rules_and_meters_lazy_predicate_reads` already admit and meter them.  
Acceptance example 5 asks an exact Trending hit outside the first 200 candidates. 3000.007 §5.3 / feeds card already chose: rank the examined trailing-day set, `complete: false` past the ceiling, maintained `ranked` when the day outgrows it. The 0.2.12 Astra essay used that materialized ranking. Building “exact top-ten of an unbounded day” in Quarry would be a new ranking engine, which NOT-DOING still refuses.

**H3. The actual remaining language defect is not in 3000.008.000’s agenda.**  
`issues/20260914-snapback4-helper-early-return-drops-page-cursor.md` (P1): a shape calling a helper that `return`s early yields `next: null`, `complete: true`. Reproduced on the 0.2.12 binary (12 rows). `runner.rs` `Stmt::Return` still does `self.page = self.page_plan.get(&site)…`, which clears the outer page. The programs card already claims “A helper return exits only the helper.” 3000.007 §19.2 is the commissioned fix. This snapshot has **not** landed N1–N3: `connected` is still always `SiteClass::Server` in `bind/residency.rs`; `==` is still a generic syntax error.

**H4. 3000.008.002’s predicted-result recommendation contradicts ruling 8.**  
The child still floats exposing a predicted value. 3000.007 ruling 8: **`result` on `sent` only**; prediction is pending rows. `contract.ts` already matches. Do not add a second result channel.

### Medium

**M1. Evidence is frozen at 0.2.6 / `94e7ece`.**  
Umbrella §2 still cites 21.446 s full-corpus browser startup, incomplete Grok, pending grades, and the video ticket path. Current Clique pin: 167,243 settled actions, 634 ms cold 100-conversation replica, independent grade in. The video ticket file the child links is gone; the behavior is closed in `client-seams.test.mjs` (“id-only video predicts after offline reopen”). Counting those as open defects would re-fix shipped work.

**M2. 3000.008.001 still offers 3000.006’s mandatory `online only` as a live alternative.**  
3000.007 ruling 7: optional now. Ruling 12: 3000.006 stays **Superseded**. Optional spelling plus `check --residency` is what shipped (`parser.rs`, `bind/residency.rs`, `sim/tests/residency.rs`). Offline non-value is already `E_OFFLINE`, not a new `unavailable` word (§6.5 / ruling).

**M3. Static eligibility vs runtime coverage is already the product model; one contradiction remains.**  
`Op.runs` / `Op.predicts` and horizon-site comments are emitted (`emit.rs`). The remaining builder loop is presence: the card says devices treat everyone as connected; the binder marks every `connected[...]` as `predicts: never`. Ruling 18 option C is the fix: presence may decide **emits only**. That is 3000.007 §19.1, not a new residency vocabulary.

**M4. Mutation replay is a real client-contract hole, not a new Write design.**  
Security decision (3000.007 §17): replay returns identity + `replayed: true`, **no** historical `result`. README already says so. `contract.ts` still requires `result: R` on every `sent`; `client.ts` `send()` copies `json.result` and drops `replayed`, so a lost-ack retry can resolve as `undefined` under `R` (`issues/20260914-snapback4-write-result-type-omits-replay-state.md`, P2). Narrow card repair. Do not restore cached results.

**M5. Pending-on-shape is delivered more mechanically than 3000.008.002 wants.**  
Shapes card: a row-based shape keeps `pending?: boolean`. `ty_ts(RowShape)` appends it to every shaped object. Chat apps render `message.pending`. Device tests keep the mark across reopen. The child’s “joined author’s pending is not the message’s” case is still only typed, not proven by a misattribution regression. Do not build a provenance algebra unless a fixture shows the wrong row’s flag.

**M6. Performance work is being asked to outrun its current measurement.**  
0.2.6 startup and 0.2.8 vs 0.2.5 HTTP medians are historical. The live P1 is membership-feed cost on **0.2.10** Office source, with the ticket itself saying current-source measurement is pending because 0.2.12 changed those paths. 3000.008.003’s six-journey table is fine as reporting hygiene; it is not a reason to create budgets LLP 3000 §3 left descriptive. Wasm diet (`~314 KB gzip`, mostly serde) is real and already ticketed; it is not the Clique-builder loop.

**M7. 3000.008.004’s “complete Clique grading” target is stale, and its next-app/ops slice is scope growth.**  
0.2.12 independent grade exists; nine iOS assertions are `not-run` for lack of a simulator artifact in **both** 0.2.9 and 0.2.12 — grader class, not a new backend fail. M7 was not run by design. Interview is still Draft. No backup/restore command exists (the child correctly refuses to invent one). Six composed journeys are mostly already covered by `client-lifecycle`, `client-seams`, retained-history, write-authority, and witnesses. A new evidence matrix without a product change is the failure mode the prompt warned against.

**M8. Authorization/disclosure: do not let 3000.008 reopen 3000.007 write-authority.**  
§8.7 / §5.9 / rulings 15–17 are governing, reviewed, and landed (paired hidden/absent meters, replay-shaped `_ops`, uniform mutation pages). 3000.008.000’s “keep conservative cursor behavior until settled” is behind the code: filled `next` is last **returned** row; cut `next` is last **rule-visible** examined row; never a hidden key (reads card).
