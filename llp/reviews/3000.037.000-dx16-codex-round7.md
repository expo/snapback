# llp-orient

<!-- @ref https://github.com/ccheever/llp/blob/v0.5.2/llp/0008-distributed-agent-skills.rfc.md#the-skills--core-five-plus-flags — skill contract -->

Load the design rationale governing the area you're about to touch, before touching it. This is the consumption side of LLP — orienting first is what turns `@ref` from a possibility into a habit.

Invoke as `/llp-orient <path-or-task>` (file, directory, subsystem, or task description). With no argument, use the current change scope (`git diff --name-only`).

## Trigger

Start of a coding task that touches an area with documented design. The orient-first *rule* lives in the repo's always-loaded `AGENTS.md`; this skill is the detailed form that rule routes to for non-trivial work — don't rely on ambient description-match alone.

## Invariants

- MUST be read-only: never edit code or LLP documents.
- MUST scope to the task: pull the constraints that bind this change, not a corpus summary.
- MUST cite, not restate: reference policy as `LLP NNNN#anchor` rather than paraphrasing sections.
- MUST NOT invent constraints. If something isn't documented, say so.
- MUST NOT guess the rationale behind a broken `@ref` — report it and hand off to `llp-maintain`.

## Workflow

> **Recipe (advisory)** — corpus root = nearest `llp/` walking up from the path in scope (LLP 0001 §Unit of adoption); "no corpus" is an empty walk, not cwd-relative absence. Read `llp/foundation/` first (the kernel; the root LLP is there once `Active` — on a fresh adoption it is still `Draft` and sits in `current/`), then skim `llp/current/` (the declared working set); both hold relative links — symlinks, or small files containing the relative path — so `ls` answers and either form resolves. Then the root LLP's systems vocabulary. `Grep '@ref'` over the files in scope and `Read` each target — these are the highest-signal context. `Grep` the `**Systems:**` headers across `llp/` for LLPs governing the subsystems touched; read the governing ones (Spec, Decision, Principles, relevant RFCs). Follow `Related:` and nearby `@ref` targets one hop out; stop there unless something is clearly load-bearing. Stale-pin nudge (skip offline): read the installed tag from the skills receipt (or a `source:` pin), compare `git ls-remote --tags <origin>` — if upstream is newer, say so in one line ("skills at v0.3.0, upstream v0.5.2 — run /llp-adopt update") and move on; never update from here.

## Artifact

A context pack with these sections, faster to read than the documents it points at:

- **Scope** — files / subsystems queried
- **Governing LLPs** — numbered list, one-line gloss each; mark which are in `foundation/` and which are in `current/` (in-flight — its guidance may still move)
- **Active constraints** — bullets, each citing `LLP NNNN#anchor`
- **Relevant rationale** — the *why*, same citation form
- **Open questions / risks** for this area
- **Likely doc updates** if the change lands
- **Hand-off** — one of `none | llp-adopt | llp-create | llp-review | llp-maintain`

## Hand-offs

- No corpus (no `llp/` walking up from the path in scope) → `llp-adopt`.
- The task needs a decision no LLP covers → `llp-create` (or `llp-review` if proposal-shaped).
- An `@ref` target or anchor doesn't resolve → `llp-maintain`.

converts a driver error to a refusal; it never changes the traffic.

twice on SQLite, and compare up to eight seeded positions per dimension on

counters are in `store_stats`; each selected position runs prefetch on and off.
Physical prefetch counters are separate from the exact public outcome record.

projecting `tags[.tag]` and `tags[name = .label]` (a `Get` and a unique

/// Adapt adds missing proof infrastructure, preserving files and script names
/// already owned by the application. It never runs a package manager.
pub(super) fn plan(dir: &std::path::Path, own: &super::OwnSchema, enable_day2: bool, refresh_default_frontend: bool) -> std::io::Result<Vec<(&'static str, String)>> {
    let web = dir.join("src/App.tsx").is_file();
    let router = dir.join("app/_layout.tsx").is_file();
    if !web && !dir.join("App.tsx").is_file() && !router { return Ok(Vec::new()); }
    let shape = super::starter::Shape { title: super::title(dir), password: own.identity.is_some_and(|(p, g)| p && !g),
        personas: own.identity.is_none().then(|| own.personas.clone()).filter(|p| !p.is_empty()),
        body: if super::adapt::fits_todos(own) { super::starter::Body::Todos } else { super::starter::Body::Home(None) }, offline: own.offline.clone() };
    let path = dir.join("package.json");
    let text = std::fs::read_to_string(&path)?;
    let mut package: Value = serde_json::from_str(&text).map_err(std::io::Error::other)?;
    let router = router && !web && package["main"] == "expo-router/entry";
    if !web && !dir.join("App.tsx").is_file() && !router { return Ok(Vec::new()); }
    let original = package.clone();
    let day2_text = std::fs::read_to_string(dir.join("scripts/day2-proof.mjs")).ok();
    let referenced_day2 = package["scripts"].as_object().is_some_and(|scripts| scripts.values().any(|v| v.as_str().is_some_and(|s| s.contains("scripts/day2-proof.mjs"))));
    let missing_managed_day2 = day2_text.is_none() && matches!(package["scripts"]["day2:proof"].as_str(),
        Some("node scripts/day2-proof.mjs" | "node scripts/day2-proof.mjs versions/v1.q versions/v2.q" | "node scripts/day2-proof.mjs versions/v1 versions/v2"));
    let managed_day2 = day2_text.as_deref().is_some_and(super::proof_advice::known_day2) || missing_managed_day2;
    let day2 = enable_day2 || referenced_day2 || package.pointer("/snapback4/starter/day2") != Some(&json!(false)) && managed_day2;
    // Deleting both the command and file records a durable opt-out on apply.
    // Preview/check never write the inferred choice. Explicit --day2 opts in again.
    if (package["snapback4"].is_null() || package["snapback4"].is_object()) && (package["snapback4"]["starter"].is_null() || package["snapback4"]["starter"].is_object()) {
        package["snapback4"]["starter"]["day2"] = json!(day2);
    }
    let backend = package["scripts"]["backend"].as_str().and_then(|s| s.strip_prefix("snapback4 dev --port ")).and_then(|s| s.parse::<u16>().ok())
.or_else(|| launcher_port(dir, "backend")).unwrap_or(4400);
    let frontend = launcher_port(dir, "frontend").or_else(|| package["scripts"][if web { "dev" } else { "start" }].as_str()
        .and_then(|s| s.split_once("--port ")).and_then(|(_, rest)| rest.split_whitespace().next()).and_then(|n| n.parse::<u16>().ok())
        .or_else(|| std::fs::read_to_string(dir.join("vite.config.mts")).ok().and_then(|s| s.split_once("server: { port: ").and_then(|(_, rest)| rest.split(|c: char| !c.is_ascii_digit()).next()).and_then(|n| n.parse::<u16>().ok())))
        ).unwrap_or(if backend != 4400 { backend.saturating_add(1) } else if web { 5173 } else { 8081 });
    let mut generated = vec![("package.json", pretty(&package))];
    let mut flags = std::collections::BTreeMap::new();
    if router { flags.insert("template".into(), "social".into()); }
    else if let Some(Some(template)) = previous_frontend(dir, web) { flags.insert("template".into(), template.into()); }
    if day2 { flags.insert("day2".into(), String::new()); }
    let default_todos = shape.body == super::starter::Body::Todos && !flags.contains_key("template");
    files(&mut generated, &Options { positionals: vec![dir.to_string_lossy().into_owned()], flags, json: false }, backend, frontend, web, &shape)?;
    // A saved version is immutable application evidence. Never fill its missing
    // fixture files from today's working release during an adaptation.
    generated.retain(|(name, _)| !name.starts_with("versions/") || {
        let version = name.split('/').nth(1).unwrap();
        !dir.join("versions").join(version).exists()
    });
    // New directories capture the current source and contemporary fixtures. Flat
    // legacy snapshots remain untouched evidence; they are never propagated.
    // Custom proofs own their saved source layout; do not manufacture snapshots.
    if !managed_day2 && !enable_day2 { generated.retain(|(name,_)| !name.starts_with("versions/")); }
    let wanted: Value = serde_json::from_str(&generated[0].1).unwrap();
    for group in ["scripts", "devDependencies"] {
        if !package[group].is_object() { package[group] = json!({}); }
        for (key, value) in wanted[group].as_object().unwrap() {
            let old = package[group].get(key).and_then(Value::as_str);
            let managed = group == "scripts" && old.is_some_and(|old| match key.as_str() {
                "day2:proof" => managed_day2 && matches!(old, "node scripts/day2-proof.mjs" | "node scripts/day2-proof.mjs versions/v1.q versions/v2.q"),
                "backend" => old.strip_prefix("snapback4 dev --port ").is_some_and(|n| n.parse::<u16>().is_ok()),
                "dev" | "preview" => old.strip_prefix(if key == "dev" { "vite --port " } else { "vite preview --port " }).and_then(|s| s.strip_suffix(" --strictPort")).is_some_and(|n| n.parse::<u16>().is_ok()),
                "start" | "web" => old.strip_prefix(if key == "start" { "expo start --port " } else { "expo start --web --port " }).is_some_and(|n| n.parse::<u16>().is_ok()),
                _ => false,
            });
            if managed || ((key == "day2:proof" && enable_day2 || key == "frontend:proof" && super::proof_advice::known_frontend(dir) || key == "playwright-core" && (super::proof_advice::known_frontend(dir) || super::proof_advice::referenced(dir, "scripts/frontend-proof.mjs"))) && old.is_none()) { package[group][key] = value.clone(); }
        }
    }
    let mut config_changes = Vec::new();
    if web {
        if let Ok(current) = std::fs::read_to_string(dir.join("vite.config.mts")) {
            // Replace only the exact initializer forms, allowing their port literals.
            let numbers = current.split("port: ").skip(1).filter_map(|s| s.split(|c: char| !c.is_ascii_digit()).next()?.parse::<u16>().ok()).collect::<Vec<_>>();
            let mut normalized = current.clone();
            for number in &numbers { normalized = normalized.replace(&format!("port: {number}"), "port: 5173"); }
            let reference = include_str!("starter/web/vite.config.mts").replace("port: 4173", "port: 5173");
            if normalized == reference { config_changes.push(("vite.config.mts", runtime_vite(&current, backend, numbers.first().copied().unwrap_or(5173)))); }
        }
    }
    let inherited_frontend = previous_frontend(dir, web).filter(|template| template.is_some()
        || super::adapt::fits_todos(own) && refresh_default_frontend);
    if let Some(template) = inherited_frontend {
        if let Some((_, text)) = generated.iter_mut().find(|(name, _)| *name == "scripts/frontend-proof.mjs") {
            *text = frontend_proof(include_str!("frontend-proof.mjs"), template, web);
        }
    }
    let referenced_after = |path: &str| package["scripts"].as_object().is_some_and(|scripts| scripts.values().any(|v|v.as_str().is_some_and(|s|s.contains(path))));
    let mut additions: Vec<_> = generated.into_iter().skip(1)
        .filter(|(name, text)| {
            if *name == "scripts/frontend-proof.mjs" {
                return (!default_todos || refresh_default_frontend)
                    && (inherited_frontend.is_some() || !dir.join(name).exists() && referenced_after(name));
            }
            if *name == "scripts/day2-proof.mjs" { return day2 && (managed_day2 || !dir.join(name).exists() && (enable_day2 || referenced_day2))
                && std::fs::read_to_string(dir.join(name)).ok().as_deref()!=Some(text.as_str()); }
            if !dir.join(name).exists() {
                return name.starts_with("versions/") || name.starts_with("v1/") || referenced_after(name)
                    || shape.password && *name=="scripts/staging.mjs";
            }
            false
        }).collect();
    additions.extend(config_changes);
    if package != original { additions.push(("package.json", pretty(&package))); }
    Ok(additions)
}

fn launcher_port(dir: &std::path::Path, name: &str) -> Option<u16> {
    let text = std::fs::read_to_string(dir.join("scripts/launch.mjs")).ok()?;
    // Recognize the generated fallback expression, not client application code.
    let marker = if name == "backend" { "low === null ? " } else { ": low === null ? " };
    text.split_once(marker)?.1.split_whitespace().next()?.parse().ok()
}


pub(super) fn apply(dir: &std::path::Path, additions: &[(&str, String)]) -> std::io::Result<()> {
    let frozen:Vec<_>=additions.iter().filter(|(name,_)|name.starts_with("v1/")).collect();
    if !frozen.is_empty() {
        if dir.join("v1").symlink_metadata().is_ok() {return Err(std::io::Error::other("v1 already exists; no historical source replaced"));}
        let nonce=std::time::SystemTime::now().duration_since(std::time::UNIX_EPOCH).unwrap_or_default().as_nanos();
        let stage=dir.join(format!(".snapback4-frozen-{}-{nonce}",std::process::id()));
        std::fs::create_dir(&stage)?;
        let result=(|| -> std::io::Result<()> {
            for (name,body) in &frozen {
                let relative=std::path::Path::new(name.strip_prefix("v1/").unwrap());
                if relative.components().any(|c|!matches!(c,std::path::Component::Normal(_))) {return Err(std::io::Error::other("frozen destination escapes v1"));}
                let path=stage.join(relative);
                std::fs::create_dir_all(path.parent().unwrap())?;
                std::fs::write(path,body)?;
            }
            if dir.join("v1").symlink_metadata().is_ok() {return Err(std::io::Error::other("v1 appeared during capture; no historical source replaced"));}
            std::fs::rename(&stage,dir.join("v1"))
        })();
        if result.is_err() {let _=std::fs::remove_dir_all(&stage);}
        result?;
    }
    for (name, body) in additions {
        if name.starts_with("v1/") {continue;}
        let path = dir.join(name);
        std::fs::create_dir_all(path.parent().unwrap())?;
        if *name == "package.json" || *name == "vite.config.mts" || *name == "scripts/frontend-proof.mjs" || *name == "scripts/day2-proof.mjs" { super::replace_file(&path, body)?; }
        else {
            use std::io::Write;
            let mut file = std::fs::OpenOptions::new().write(true).create_new(true).open(&path)?;
            file.write_all(body.as_bytes())?;
        }
    }
    Ok(())
}

/// Environment is evaluated whenever Vite loads the config, never at init time.
pub(super) fn runtime_vite(text: &str, backend: u16, frontend: u16) -> String {
    if text.contains("const proofRange") { return text.to_owned(); }
    let header = format!(r#"const proofRange = [process.env.PORT_LO, process.env.PORT_HI];
if (proofRange.some(v => v !== undefined) && (!proofRange.every(v => v && /^\d+$/.test(v)) || Number(proofRange[0]) < 1 || Number(proofRange[1]) > 65535 || Number(proofRange[0]) >= Number(proofRange[1]))) throw Error("PORT_LO/PORT_HI must provide at least two valid ports");
const backendPort = proofRange[0] === undefined ? {backend} : Number(proofRange[0]);
const frontendPort = proofRange[0] === undefined ? {frontend} : backendPort + 1;
process.env.VITE_SNAPBACK_URL ??= `http://127.0.0.1:${{backendPort}}`;
"#);
    let mut result = text.to_owned();
    // All generated configurations have literal ports; preserve unrelated config.
    for port in [frontend, 5173, 4173] { result = result.replace(&format!("port: {port}"), "port: frontendPort"); }
    format!("{header}{result}")
}

//! A day-one headless client must keep its own handles and module boundary.
// @ref LLP 3000.037.000#9 — capture before editing; never overwrite historical evidence.
use std::{path::Path, io};
use serde_json::json;

pub(super) fn files(dir: &Path, sources: &[(String, String)]) -> io::Result<Vec<(&'static str, String)>> {
    if dir.join("v1").symlink_metadata().is_ok() { return Ok(Vec::new()); }
    let bound = snapback4_lang::compile(sources);
    if !bound.diagnostics.is_empty() { return Err(io::Error::new(io::ErrorKind::InvalidData,"cannot freeze an unchecked v1 client; fix current schema first")); }
    let mut files = Vec::new();
    fn push(files: &mut Vec<(&'static str,String)>, path: String, text: String) {
        if let Some((_,body))=files.iter_mut().find(|(name,_)|*name==path) { *body=text; }
        else { files.push((Box::leak(path.into_boxed_str()),text)); }
    }
    fn walk(root: &Path, relative: &Path, files: &mut Vec<(&'static str,String)>) -> io::Result<()> {
        let path = root.join(relative);
        if !path.exists() { return Ok(()); }
        if path.symlink_metadata()?.file_type().is_symlink() { return Err(io::Error::other(format!("frozen client refuses symlink {}", path.display()))); }
        let root_path=root.canonicalize()?;
        let canonical=path.canonicalize()?;
        let relative=canonical.strip_prefix(&root_path).map_err(|_|io::Error::other("frozen script entry escapes the app; keep client modules inside the project"))?;
        if path.is_dir() {
            if matches!(path.file_name().and_then(|n|n.to_str()),Some("node_modules"|"dist"|"target"|".git")) { return Ok(()); }
            for entry in std::fs::read_dir(path)? { walk(root, &relative.join(entry?.file_name()),files)?; }
        } else if matches!(path.extension().and_then(|s|s.to_str()), Some("mjs"|"cjs"|"js"|"ts"|"mts"|"cts"|"tsx"|"jsx")) || path.file_name().is_some_and(|n|n=="package.json") {
            push(files,format!("v1/{}",relative.display()),std::fs::read_to_string(path)?);
        }
        Ok(())
    }
    // Freeze executable application script entries and their imports. UI build
    // assets, node_modules, stores and credentials are outside this capture.
    let package: serde_json::Value = std::fs::read(dir.join("package.json")).ok().and_then(|b|serde_json::from_slice(&b).ok()).unwrap_or_else(||json!({}));
    // Script entries can live outside scripts/src/app (for example tools/calls.mjs).
    if let Some(scripts)=package["scripts"].as_object() {
        for command in scripts.values().filter_map(|v|v.as_str()) {
            for word in command_words(command)? {
                let path=Path::new(&word);
                if path.is_absolute() {continue;}
                if matches!(path.extension().and_then(|s|s.to_str()),Some("mjs"|"cjs"|"js"|"ts"|"mts"|"cts"|"tsx"|"jsx")) && dir.join(path).is_file() {
                    walk(dir,path,&mut files)?;
                }
            }
        }
    }
    // Follow literal relative module imports beyond conventional source directories.
    // Runtime-computed paths remain application responsibilities, as in Node itself.
    let canonical_root=dir.canonicalize().unwrap_or_else(|_| std::env::current_dir().unwrap_or_default().join(dir));
    let mut index=0;
    while index<files.len() {
        let (saved,text)=&files[index];
        let source=dir.join(saved.strip_prefix("v1/").unwrap());
        let imports=if source.extension().and_then(|e|e.to_str()).is_some_and(|e|matches!(e,"mjs"|"cjs"|"js"|"ts"|"mts"|"cts"|"tsx"|"jsx")) {
            crate::worker_graph::imports(text,&source).map_err(std::io::Error::other)?
        } else {Vec::new()};
        // Node owns import/require resolution, including CJS package main/index
        // and package scope metadata. Resolution reads files; it executes no imports.
        let output=std::process::Command::new(crate::project::node())
            .args(["--experimental-import-meta-resolve","--input-type=module","-e",include_str!("../../worker_graph.mjs")])
            .arg(&canonical_root).arg(source.canonicalize()?)
            .args(imports.iter().map(|item|serde_json::to_string(item).unwrap()))
            .env_remove("NODE_OPTIONS").env_remove("NODE_PATH").output()?;
        if !output.status.success() {return Err(io::Error::other(format!("frozen client dependency resolution: {}",String::from_utf8_lossy(&output.stderr))));}
        let graph:serde_json::Value=serde_json::from_slice(&output.stdout).map_err(io::Error::other)?;
        for path in graph["files"].as_array().ok_or_else(||io::Error::other("frozen module resolver returned no files"))?.iter().filter_map(|p|p.as_str()) {
            let path=Path::new(path);let canonical=path.canonicalize()?;
            let relative=canonical.strip_prefix(&canonical_root).map_err(|_|io::Error::other("frozen relative import escapes the app"))?;
            let saved=format!("v1/{}",relative.display());
            if files.iter().any(|(name,_)|*name==saved) {continue;}
            if path.symlink_metadata()?.file_type().is_symlink() {return Err(io::Error::other("frozen module imports must not use symlinks"));}
            if path.is_file() {push(&mut files,saved,std::fs::read_to_string(path)?);}
        }
        index+=1;
    }
    for (name,text) in sources { push(&mut files,format!("v1/snapback/{name}"),text.clone()); }
    push(&mut files,"v1/snapback/generated/api.ts".into(),snapback4_lang::emit::typescript(&bound));
    push(&mut files,"v1/snapback/generated/package.json".into(),"{\"type\":\"module\"}\n".into());
    let command=package["scripts"]["client:calls"].as_str();
    // The outer packet is ESM. Preserve a non-ESM application's original root
    // package scope too, so ordinary .js require helpers keep their Node meaning.
    let original_scope=command.is_some() && package["type"] != "module";
    if original_scope {
        for (name,_) in &mut files {
            *name=Box::leak(format!("v1/.source/{}",name.strip_prefix("v1/").unwrap()).into_boxed_str());
        }
        push(&mut files,"v1/.source/package.json".into(),super::pretty(&package));
        push(&mut files,"v1/snapback/generated/api.ts".into(),snapback4_lang::emit::typescript(&bound));
        push(&mut files,"v1/snapback/generated/package.json".into(),"{\"type\":\"module\"}\n".into());
    }
    let mut frozen=package.clone();
    frozen["private"]=json!(true);frozen["type"]=json!("module");
    if !frozen["scripts"].is_object() {frozen["scripts"]=json!({});}
    if original_scope { frozen["scripts"]=json!({}); }
    else if package["scripts"].is_object() { frozen["scripts"]=package["scripts"].clone(); }
    frozen["scripts"]["client:calls"]=json!("node .snapback4-frozen-run.mjs");
    if let Some(command)=command { frozen["scripts"]["client:calls:frozen"]=json!(if original_scope { "npm --prefix .source run --silent client:calls" } else { command }); }
    for group in ["dependencies","devDependencies"] { if package[group].is_object() { frozen[group]=package[group].clone(); } }
    push(&mut files,"v1/package.json".into(),super::pretty(&frozen));
    push(&mut files,"v1/.snapback4-frozen-run.mjs".into(),include_str!("frozen-run.mjs").into());
    Ok(files)
}

/// Shell words are inspected, never executed; quoted paths keep their spaces.
fn command_words(command: &str) -> io::Result<Vec<String>> {
    let mut words=Vec::new();let mut word=String::new();let mut quote=None;let mut chars=command.chars();
    while let Some(ch)=chars.next() {
        match (quote,ch) {
            (Some('\''),'\'')|(Some('"'),'"')=>quote=None,
            (None,'\''| '"')=>quote=Some(ch),
            (Some('\''),_)=>word.push(ch),
            (_, '\\')=>{if let Some(next)=chars.next(){word.push(next);}},
            (None,c) if c.is_whitespace() || matches!(c,';'|'&'|'|')=>{if !word.is_empty(){words.push(std::mem::take(&mut word));}},
            _=>word.push(ch),
        }
    }
    if quote.is_some() {return Err(io::Error::other("cannot freeze malformed quoted package script"));}
    if !word.is_empty(){words.push(word);}Ok(words)
}

# What Snapback 4 Does Not Do

Longer than the doing-list on purpose. Moving something off it means writing one
line naming what it unblocks and taking something off the doing-list in the same
change. Nothing comes off during slice one (LLP 3000 §3: the clock is four weeks).

## The bars

The bakeoff gates in [LLP 3000 §3](../llp/3000-snapback4.explainer.md) are the
bars: the loop bar, hub acquisition within 2× the measured floor, client bytes
under the competitor-anchored budgets, the six scenarios green in the simulator
on the hub fixture. Everything not required to pass them does not exist yet.

## Not building

- **A second authoring language.** Quarry, one spelling, copied from Snapback 2 (LLP 1004, LLP 1007 §4b). TypeScript is for seeds, journeys, effect bodies and the client.
- **Byte- and step-priced certification.** No closure, heap, output or step ceilings at `check`; the certificate certifies shape, uniformity, completeness class and prediction eligibility. Resources are metered at runtime (LLP 2000.000 §6).
- **A device per-query result cache.** No range receipts, halos, absence evidence, coverage spans, extent facts, held directories, fact integrity or swap journals. The client replicates declared partitions with one watermark each (LLP 2000.000 §7). The server's narrow Postgres revision-equality cache and explicitly clock-qualified G6 read grant are the exceptions below; cross-revision promotion remains excluded.
- **Engine-minted ids for client inserts, grants, ID slices.** Ids are client-minted, time-ordered, 128-bit; the engine mints for its own writes.
- **The `drain` protocol, follower-tab inbox rows, `defineItems`, `withHistory`, `mutationTarget`, `receipt.source`, `local.caughtUp`, `partial` reason codes.** The card (`packages/snapback4/src/contract.ts`) is the whole client vocabulary; `why` carries the rest.
- **`retain` as a receipt rule.** `until-revoked` and `delivered-history` survive as the client's leave policy on a scope tombstone.
- **JavaScript in the data plane.** Queries and mutations run in the Rust interpreter inside the SQLite transaction, and in the same interpreter on the client (host decided at week 3 by measurement, LLP 2000.000 §9). A *job* may be the app's own Rust, hosted as wasm through the interpreter's operations under the job's meter (LLP 3000.005, the Moves line below); a query or mutation may not.
- **An embedded JS engine for effects.** The data plane never calls out. `emit` writes the effect durably in the mutation's commit and an external worker holding a service token claims, performs and settles it over the wire (`snapback4/worker`); the four reference effects run on the builder's Node (LLP 2000.000 §10, decided 2026-09-13).
- **Committed generated code; an auth mode; a supervised bundler.** As Snapback 2 (`rules/NOT-DOING.md`): types by inference, personas not modes, `SNAPBACK_URL` is the client contract.
- **A TypeScript twin of the interpreter.** Retired by the author's ruling of 2026-09-13 (LLP 3000 §7): one implementation, in Rust, on every host — the core's SQLite under the native module, memory under wasm on the web with the host persisting each commit's changes. The web pays 312,924 B gzip before the diet where the twin's tier paid 16,842; the conformance obligation between two interpreters ends. Expo Go runs the online tier.
- **More than one hosted target, an admin console, media transcoding or thumbnails, push delivery itself (a worker's), cron syntax beyond `every N at HH:MM`, vector or relevance-ranked search (word-prefix search is in: `words(..)` and `matching`), federation, multi-region, device-to-device sync, at-rest encryption claims.** After the clock, on evidence.
- **General observability beyond `why`, `trace`, `logs`, `data`, `sql`, server operation latency, and bounded client subscription inspection.** The `sql` verb is read-only inspection of the developer's own store (LLP 3000.007 §8.8), never an application surface. Separately declared application SQL reads are admitted for increment D (LLP 3000.009 §6.2, §14.4; the 2026-09-16 Moves line below), not implemented by this inspection verb.
- **A guide corpus.** The compiler's facts, one language card and keyword cards, as Snapback 2; no freshness dates. Every card's Quarry is compiled by the suite and the language card is run, so a card cannot promise a form the parser refuses.

- **Partial union delivery, two group audiences, a public branch.** A union syncs principal-column branches and at most one group branch, each a whole disjunct of the read rule (LLP 3000.036.000.000); a branch with an extra condition, a second group or a `public` branch is refused with the rewrite, never partially delivered; service grants add no device audience (LLP 3000.007 §20.6). A union does not combine with delivered history, read-through children, synced or row-keyed views, owner keys, timelines, private field owners, acquisition windows or direct/inherited expiry on content or membership scopes.
- **Exact horizon maintenance.** The horizon bounds acquisition (a snapshot, a bootstrap); the log never evicts or back-fills to hold a device's group at exactly N rows. A local read past the acquired horizon by key says `complete: false`.

- **Clock expressions in rules.** A read rule compares with `=` and `!=` only; `.expiresAt > now` remains a mutation `require`. Stored lifetimes use `not before .col` for server-controlled opening and `expire at .col` for expiry. The engine publishes opening commits; devices receive no unopened payload. The supported compositions and explicit exclusions are in LLP 3000.036.003.
- **A jobs framework.** No priorities, worker pools or dead letters: one FIFO of runs, one chunk at a time, a refused chunk parked with its refusal. Actions, effects and scheduled actions carry per-operation retries, deadlines and cancellation, and a record per external step (LLP 3000.009 §5.2; the Moves line below). Missed period boundaries while a server is down fire once on return, not once per missed period.
- **Asset processing.** No transcoding, thumbnails, rungs or HEIC: the bytes are served as uploaded; JPEG, PNG, WebP and MP4 only; image dimensions and optional MP4 duration read from the header; MP4 dimensions are not extracted.
- **Search beyond word prefixes.** One tokenizer (NFC, lowercase, alphanumeric words), one index shape (`scope, words(cols), order.., id`), one read (`matching`): every term a prefix of some word, the first term's words merged as lanes, bounded by the meter in a uniform scope, at most 32 words in an admitted non-uniform scope. No stemming, no ranking by relevance, no phrase or mid-word matching, no per-language folding, no intersection index for the second term (it filters the page).
- **An identity provider.** Guests, password accounts, service seats, and sessions a service mints for accounts the application authenticated itself. No phone, OAuth, magic links or MFA in the engine: an application's worker verifies those and mints the session.
- **No multi-server presence, no presence history or last-seen storage, no broadcast event stream, no connection-bound rows.** `connected[p]` stays server-wide, counting held polls and their 35 s grace; a live query that may read it re-runs in the background about every 5 seconds to stay current (LLP 3000.018). Typing and viewing use short-lived, authorized ephemeral tables in one server process (LLP 3000.017); they never sync or decide durable invariants. A device does not know presence and says so.

pre-registered comparison on one clock.

## 1. Summary

LLP 2000 is right that the whole application is the unit of design, right
that ownership comes before abstraction, and right to ask for deterministic
simulation and an early real deployment. Its weakness is that it treats the
two structural choices that produced Snapback 2's costs as open research
questions, and then proposes a first experiment at exactly the scale where
those costs are invisible. This document takes a position on both, names
what to keep from Snapback 2 verbatim, and rewrites the first slice so it
can fail for the right reasons.

The position, in one paragraph. Snapback 2's *core* is excellent and should
be copied: the rule language and its uniformity analysis, the structural-fact
family, one data language, typed states with no silence, refusals that paste
a rewrite, personas, the successor classifier, the derived per-recipient
log, the loop verbs and their sub-second budgets. Two *substrates* under
that core are where the record shows the hours went, and both should be
flipped rather than re-investigated: (1) the static certificate should keep
certifying **authorization and shape** and stop pricing **bytes and steps**,
which move to a deterministic runtime meter with honest `capped`/abort
outcomes; and (2) the client should hold **a replica of the viewer's declared
partition** — the local-first shape every shipped sync engine and Snapback
2's own `deliver` log converge on — instead of a per-query result cache
proven by receipts. Those two flips dissolve most of the machinery that
leaked into the application (receipts, coverage, halos, validators, grants,
ID slices, drains, `withHistory`, follower inboxes, per-table retention
words) and turn the 28-second acquisition into a bulk stream whose floor is
the device's write speed. The first slice should be built on the **hub
fixture** (1,000 memberships, 500 follows, 100,000 messages), with the
day-two change designed before the day-one screen, a native client in the
first slice, and a deterministic simulator as the primary test harness.

Three claims this document makes that LLP 2000 does not:

1. **The costs have two named causes, and both are decisions, not
   mysteries.** Byte-priced static certification and the receipt-proven
   result cache account for every ergonomic residual in LLP 1018.008.009
   except documentation. §2 shows the mapping.
2. **The first experiment must include the hub.** Snapback 2 was "elegant on
   day one and hostile on day two" (LLP 1020) and broke at 1,000 memberships
   (LLPs 1023, 1024, 1025). A two-principal slice will pass and teach nothing.
3. **The process is part of the product.** Seventy-one LLPs, over two
   thousand commits, and seven ceiling raises in fourteen days produced a
   sound system nobody can hold in their head. Snapback 3 needs one owner on
   the core, a simulator instead of a test matrix, and budgets anchored to
   competitors so that raising one means admitting a loss.

## 8. Wave-32 builder reading and waiting (TOK1)

The start card replaces the introductory card tour with one complete compiling
customer/staff/evidence/deadline/approval schema and on-demand feature sections.
Its first read fits 8,000 UTF-8 bytes, a conservative 8,000 byte-token ceiling.
Default card output has the same hard byte budget; references remain available
with --full or an explicit section. Repeated project-local reads show only new
paragraphs or complete code fences; --repeat forces selected content and --full
forces the reference. The cache contains content hashes only, is disposable,
and never affects check, security or execution. Changed content is shown again.

Build-time declaration digests for proof/client/auth derive from dist declarations,
with a generated API operation index derived from the bound schema. Digests are
bounded, identify omitted declarations, and are checked for declaration drift.
Every starter script points to the relevant digest. Init prints start before
starting an asynchronous frontend install with private progress/status files,
a join/status command and normal npm exit status. A request identity is published
before spawning, so delayed startup cannot join an earlier success. An IPC-owned
worker group stops npm and its process-group descendants if the installer is killed; progress
and custody files are private. A compact file custody map
and the generated API index reduce starter rereads.

Probe scripts announce their indefinite lifetime before deployment. A project
receipt records a held run's lifetime and request activity without credentials;
a previously terminated run held over 60 seconds with zero requests refuses
before deployment unless --hold or SNAPBACK4_PROBE_HOLD=1 is supplied.
Unattended foreground first runs also stop after a 60-second idle grace, with
bounded host cleanup and the probe:check recipe. Check-owned serveCheck runs set the hold override because their uptime is
already bounded by the checker. Explicit hold preserves the
harness's indefinite lifetime contract; the external bakeoff harness must pass that opt-in (SNAPBACK4_PROBE_HOLD=1).
This is a developer-wait safeguard, never an authorization or deployment gate.

Asset placement retains one home per asset (including distinct columns of the
same row), and placement by the uploader. E_ASSET_PLACED includes a concrete
same-bytes upload-per-column recipe. The uploads card demonstrates that recipe
and distinguishes shared references from separate placements. No security binder
or client contract changes are required. Evidence and independent reviews are
recorded with the workstream report; no publication or version bump is made.

        if let Err(error) = proof::files(&mut files, options, port.unwrap_or(4400), web_port.unwrap_or(if web { 5173 } else { 8081 }), web, &shape) {eprintln!("init proof capture: {error}");return 2;}
    }
    for (name, text) in &mut files {
        if name.starts_with("scripts/") && (name.ends_with(".mjs") || name.ends_with(".ts")) && !text.contains("API signatures:") {
            let header = "// API signatures: snapback4 guide api proof | client | auth | generated\n";
            if text.starts_with("#!") { if let Some(at) = text.find('\n') { text.insert_str(at + 1, header); } }
            else { text.insert_str(0, header); }
        }
    }
    let mut conflicts = Vec::new();
    // A project's existing introduction is unrelated to the starter. Keep it
    // and place our setup instructions beside it, still without overwriting.
    if dir.join("README.md").symlink_metadata().is_ok() {
        for (name, _) in &mut files {
            if *name == "README.md" { *name = "README.snapback.md"; }
        }
    }
    // @ref LLP 3000.007#20.2 — installed packages can receive a starter; only conflicting required entries refuse.
    let mut pinned = Vec::new();
    let mut kept_scripts = Vec::new();
    for (name, text) in &mut files {
        if *name == "package.json" && dir.join(*name).exists() {
            match merge_package(&dir.join(*name), text, &mut pinned, &mut kept_scripts) {
                Ok(merged) => *text = merged,
                Err(error) => conflicts.push(error),
            }
        } else if *name == "package.json" && dir.is_dir() {
            match inherited_package_type(dir) {
                // A directory with no package above it and no scripts of its
                // own keeps the starter's module type (Vite expects ESM).
                Ok(None) if !has_scripts(dir, 0) => {},

    if expo && files.iter().any(|(name, text)| *name == "package.json" && serde_json::from_str::<Value>(text).unwrap()["type"] == "module") {

        }
    }
    // @ref LLP 3000.007#20.2 — scope generated ESM to its artifacts, preserving existing application scripts' module interpretation.
    files.push(("snapback/generated/package.json", GENERATED_PACKAGE.into()));
    // Check every destination before writing any starter file. An existing
    // file is a conflict, or with --skip-existing is kept exactly as it is.
    let mut existing = Vec::new();
    for (name, _) in &files {
        if let Err(error) = preflight_parents(&dir.join(name)) { conflicts.push(error); }
        let alternate = match *name { "metro.config.cjs" => Some("metro.config.js"), "babel.config.cjs" => Some("babel.config.js"), "metro.config.js" => Some("metro.config.cjs"), "babel.config.js" => Some("babel.config.cjs"), _ => None };
        let mut present = Vec::new();
        if let Some(alternate) = alternate.filter(|name| dir.join(name).symlink_metadata().is_ok()) {
            present.push(format!("{} already exists", dir.join(alternate).display()));
        }
        // `check` and `dev` write snapback/generated/ and rewrite it on every
        // run: an existing file there is init's to replace, never a conflict.
        // @ref LLP 3000.011.003.000#7.4 — schema-first init after `check` (wave 4: E_INIT_CONFLICT on check's own package.json).
        if regenerable(name) && dir.join(name).symlink_metadata().is_ok_and(|metadata| !metadata.is_file()) {
            conflicts.push(format!("{} is not a regular generated file", dir.join(name).display()));
        }
        if *name != "package.json" && !regenerable(name) {
            match dir.join(*name).symlink_metadata() {
                Ok(_) => present.push(format!("{} already exists", dir.join(*name).display())),
                Err(error) if error.kind() == std::io::ErrorKind::NotFound => {},
                Err(error) => conflicts.push(format!("{}: {error}", dir.join(*name).display())),
            }
        }
        if present.is_empty() { continue; }
        if skip_existing { kept.push((*name).to_owned()); } else { existing.extend(present); }
    }
    files.retain(|(name, _)| !kept.iter().any(|kept| kept == name));
    let skippable = !existing.is_empty();
    conflicts.extend(existing);
    if let Err(error) = preflight_parents(&dir.join(".gitignore")) { conflicts.push(error); }
    for name in ["package.json", ".gitignore"] {
        if name == "package.json" && !files.iter().any(|(file, _)| *file == name) { continue; }
        if dir.join(name).symlink_metadata().is_ok_and(|m| !m.is_file()) {
            conflicts.push(format!("{} is not a regular file", dir.join(name).display()));
        }
    }
    if !conflicts.is_empty() {
        conflicts.sort(); conflicts.dedup();
        let recipe = if skippable { "rerun with --skip-existing to keep every existing file as it is and write only the missing ones (snapback/*.q is never overwritten), or rename the listed files and rerun; " } else { "" };
        // A second init over the first one's starter: --adapt is what fits it to the schema.
        let refit = skippable && !adapt::leftovers(dir).0.is_empty();
        let recipe = if refit { format!("{recipe}to fit the starter already here to your snapback/*.q, run `snapback4 init --adapt` instead; ") } else { recipe.to_owned() };
        let first = if refit { "; the starter is already here: `snapback4 init --adapt` fits it to your snapback/*.q" }
            else if skippable { "; rerun with --skip-existing to keep your files and write the rest" } else { "" };
        eprintln!("E_INIT_CONFLICT: no files written{first}\n  {}\n  rewrite: {recipe}reconcile any listed package.json entries first. Do not init into another directory and copy it over: that overwrites your files", conflicts.join("\n  "));
        return 1;
    }
    if options.flags.contains_key("dry-run") {
        println!("init: preview only; {} files in {}", files.len(), dir.display());
        for (name, _) in &files { println!("  {name}"); }
        println!("No files written; rerun without --dry-run to create this starter.");
        return 0;
    }
    let readme = files.iter().find(|(name, _)| name.starts_with("README.")).map(|(name, _)| *name);
    let mut overwritten = Vec::new();
    for name in files.iter().filter(|(name, _)| *name == "package.json" || regenerable(name)).map(|(name, _)| *name).chain([".gitignore"]) {
        let path = dir.join(name);
        if path.is_file() {
            match std::fs::read_to_string(&path) {
                Ok(original) => overwritten.push((path, original)),
                Err(error) => { eprintln!("init: could not preserve {}: {error}; no files written", path.display()); return 2; }
            }
        }
    }
    let mut created = Vec::new();
    let mut write = || -> std::io::Result<()> {
        for (name, text) in &files {
            let path = dir.join(*name);
            std::fs::create_dir_all(path.parent().unwrap())?;
            if *name == "package.json" || regenerable(name) {
                let existed = path.symlink_metadata().is_ok();
                replace_file(&path, text)?;
                if !existed { created.push(path); }
            } else {
                let mut file = std::fs::OpenOptions::new().write(true).create_new(true).open(&path)?;
                created.push(path);
                file.write_all(text.as_bytes())?;
            }
        }
        let gitignore = dir.join(".gitignore");
        let existing = match std::fs::read_to_string(&gitignore) { Ok(text) => text, Err(e) if e.kind() == std::io::ErrorKind::NotFound => String::new(), Err(e) => return Err(e) };
        let original = existing.clone();
        let existing = starter_gitignore(&existing);
        let ignores = format!("{GITIGNORE}{}{}", if expo || web { "dist/\n" } else { "" }, if expo { ".snapback4-witness/\nartifacts/native-smoke/\n" } else { "" });
        let missing = ignores.lines().filter(|line| !existing.lines().any(|old| old == *line)).collect::<Vec<_>>().join("\n");
        if !missing.is_empty() || existing != original { replace_file(&gitignore, &format!("{existing}{}{missing}\n", if existing.is_empty() || existing.ends_with('\n') { "" } else { "\n" }))?; }
        Ok(())
    };
    if let Err(error) = write() {
        eprintln!("init: {error}");
        for path in created.iter().rev() {
            if let Err(error) = std::fs::remove_file(path) { eprintln!("init: could not remove {}: {error}", path.display()); }
        }
        for (path, original) in overwritten.iter().rev() {
            if std::fs::read_to_string(path).ok().as_ref() != Some(original) {
                if let Err(error) = replace_file(path, original) { eprintln!("init: could not restore {}: {error}", path.display()); }
            }
        }
        return 2;
    }
    println!("{}", crate::guide_seen::render_in(dir, "start", snapback4_lang::guide::card("start").unwrap(), false));
    let _ = std::io::stdout().flush();
    // A starter that wrote package.json dependencies needs them installed before
    // its typecheck, build or `npm start` can run.
    let install = if web || expo { "`node scripts/install.mjs --wait`, then " } else if files.iter().any(|(name, _)| *name == "package.json") { "`npm install`, then " } else { "" };
    let dev = port.map(|port| format!("snapback4 dev --port {port}")).unwrap_or_else(|| "snapback4 dev".into());
    let kind = if password_starter {"password app, online reads and journaled writes"} else if social { "Expo Router social app" } else if chat && expo { "Expo chat app" } else if chat { "Vite chat app" }
        else if expo && home { &format!("Expo app: sign-in and a Home screen for your snapback/*.q, native when available, online in Expo Go{}", shape.offline.summary()) }
        else if expo { "Expo todos: native when available, online in Expo Go" }
        else if online_web { "Vite + React app, online reads and journaled writes (no device)" }
        else if web && home { &format!("Vite + React app: sign-in and a Home screen for your snapback/*.q{}", shape.offline.summary()) } else if web { "Vite + React todos, offline-capable" }
        else if online { "online-only" } else { "local-first" };
    println!("init: wrote {} files in {} — {kind} — next: {install}`snapback4 check`, then `{dev}`{}", files.len(), dir.display(), readme.map(|name| format!("; see {name}")).unwrap_or_default());
    println!("init: files: {}", written_files(&files.iter().map(|(name, _)| *name).collect::<Vec<_>>()));
    // @ref LLP 3000.011.003.000#7.4 — the advisories are read before the install that reports them, not after.
    if expo && files.iter().any(|(name, _)| *name == "package.json") {
        println!("init: Expo dependencies are pinned; next: `node scripts/install.mjs`, then `npx snapback4 check`. Adapter-first installs constrain React Native 0.86.3 and compatible React 19; this starter pins React/React DOM 19.2.3 and supplies the app/scripts.");
        println!("init: `npm install` takes a few minutes; Expo code signing uses patched node-forge 1.4.1. Qualification audits development dependencies too (README)");
    }
    if web {
        let page = web_port.unwrap_or(5173);
        // @ref LLP 3000.011.003.000#7.6 — wave 7 (11 lanes): `--port N` already moved both; the line named only --web-port.
        let flags = if port.is_some() { "" } else { "; `init --web --port N` sets the backend to N and the page to N+1 together" };
        println!("init: the backend is http://127.0.0.1:{}; `npm run dev` serves the page on http://localhost:{page}{flags}", port.unwrap_or(4400));
    } else if expo {
        println!("init: the backend is http://127.0.0.1:{}; `npm run web` serves http://localhost:{}; `--port N` sets the client's backend URL and the README and launchers together", port.unwrap_or(4400), web_port.unwrap_or(8081));
    }
    if (web || expo) && (std::env::var_os("PORT_LO").is_some() || std::env::var_os("PORT_HI").is_some()) { println!("init: PORT_LO/PORT_HI set at init are baked into these defaults; a later runtime pair overrides them through `npm run backend` and the frontend launcher (`npm run dev`/`npm run web`)"); }
    if !pinned.is_empty() {
        println!("init: pinned package.json {} (the starter's exact versions)", pinned.join(", "));
    }
    if !kept_scripts.is_empty() {
        println!("init: kept your package.json {}", kept_scripts.join(", "));
    }
    if !kept.is_empty() {
        println!("init: kept {} existing file{} unchanged: {}", kept.len(), if kept.len() == 1 { "" } else { "s" }, kept.join(", "));
    }
    if !skipped.is_empty() {
        println!("init: skipped the todo starter's {}: they test its todos schema, not yours", skipped.join(" and "));
    }
    // Files an earlier init wrote, kept above, may not fit the schema written since.
    let stale = if own.is_some() { adapt::leftovers(dir).0 } else { Vec::new() };
    if !stale.is_empty() {
        println!("init: kept starter files that do not fit your snapback/*.q: {}; `snapback4 init --adapt` fits them", stale.iter().map(|leftover| leftover.path).collect::<Vec<_>>().join(", "));
    }
    let screens = files.iter().any(|(name, _)| name.starts_with("src/") || name.starts_with("App."));
    if let Some(own) = own.as_ref().filter(|_| screens && (web || expo) && !chat && !social) {
        if matches!(shape.body, starter::Body::Home(_)) {
            println!("init: your snapback/*.q was kept; it has no todo starter operations, so the screen behind the sign-in is a Home that compiles against any schema (the signed-in viewer, your operations and your first query without required arguments) — run `snapback4 check` to write snapback/generated/api.ts, then replace Home with your own screens");
        } else {
            println!("init: your snapback/*.q was kept; the starter screens call the todo starter's operations (list, add, toggle, remove) — adapt them to your schema after `snapback4 check`");
        }
        match own.identity {
            None if shape.personas.is_some() => println!("init: your schema declares `use personas` and no `use identity`, so the screen picks a persona instead of signing in (development only; `snapback4 guide personas`)"),
            None => println!("init: your schema declares no `use identity`: add `use identity` for the starter's guest sign-in (`snapback4 guide personas`)"),
            Some((_, false)) => println!("init: your schema declares `use identity password`, which has no guests: the starter uses `auth.signup`/`auth.login` (`snapback4 guide personas`)"),
            Some(_) => {},
        }
    }
    if web || expo {
        println!("init: verify with `npm run probe:check` (password previews); `npm run frontend:proof` checks the screen. `probe:serve` stays up until SIGTERM.");
        if !options.flags.contains_key("no-install") && std::env::var("SNAPBACK4_INIT_INSTALL").as_deref() != Ok("0") {
            if let Err(error) = background_install(dir) { eprintln!("init: frontend install could not start: {error}; run node scripts/install.mjs"); }
        } else { println!("init: frontend install deferred; run node scripts/install.mjs"); }
    }
    0
}

/// Files under `snapback/generated/`, which `check` and `dev` rewrite.
fn regenerable(name: &str) -> bool { name.starts_with("snapback/generated/") }

/// The project's own schema: every `snapback/*.q` already in the directory.
/// `reads`: the `api` paths of the queries a starter Home may read with
/// `useQuery(api.x, {})` (no required arguments), in declaration order;
/// empty when the schema does not compile.
struct OwnSchema { files: Vec<String>, identity: Option<(bool, bool)>, personas: Vec<String>, tables: Vec<String>, operations: Vec<String>, reads: Vec<String>, offline: starter::Offline }

fn own_schema(dir: &Path) -> Result<Option<OwnSchema>, String> {
    let folder = dir.join("snapback");
    let entries = match std::fs::read_dir(&folder) {
        Ok(entries) => entries,
        Err(error) if matches!(error.kind(), std::io::ErrorKind::NotFound | std::io::ErrorKind::NotADirectory) => return Ok(None),
        Err(error) => return Err(format!("{}: {error}", folder.display())),
    };
    let mut own = OwnSchema { files: Vec::new(), identity: None, personas: Vec::new(), tables: Vec::new(), operations: Vec::new(), reads: Vec::new(), offline: starter::Offline::Unknown };
    let mut sources = Vec::new();
    for entry in entries.flatten() {
        let name = entry.file_name().to_string_lossy().into_owned();
        if !name.ends_with(".q") { continue; }
        // An unreadable or unparsable file still counts as the project's; its
        // declarations are whatever parsed.
        let source = std::fs::read_to_string(entry.path()).unwrap_or_default();
        let (document, _) = snapback4_lang::parse_document(&name, &source);
        own.identity = own.identity.or(document.identity);
        own.personas.extend(document.personas);
        own.tables.extend(document.tables.into_iter().map(|table| table.name));
        own.operations.extend(document.programs.into_iter().map(|program| program.name));
        own.files.push(name.clone());
        sources.push((name, source));
    }
    own.files.sort();
    sources.sort();
    let bound = snapback4_lang::compile(&sources);
    if bound.diagnostics.is_empty() {
        own.reads = snapback4_lang::emit::argument_free_reads(&bound);
        let schema = &bound.schema;
        let tables = || schema.visible_tables().filter(|(name, _)| schema.maintain_for(name).is_none());
        own.offline = starter::Offline::Tables {
            synced: tables().filter(|(_, table)| table.sync.is_some()).map(|(name, _)| name.to_string()).collect(),
            total: tables().count(),
        };
    }
    Ok((!own.files.is_empty()).then_some(own))
}

/// The page and app name: the directory's, as words ("bake-sale" → "Bake Sale").
/// A starter file with init's ports: the backend's (`--port`) and the Vite
/// page's (`--web-port`). A README's `npx snapback4 dev` names the port too.
// @ref LLP 3000.011.003.000#7.4 — wave 6 (042): the README said plain `snapback4 dev` beside a client on another port.
pub(super) fn localize(name: &str, text: &str, port: Option<u16>, web_port: Option<u16>) -> String {
    let mut text = text.to_owned();
    if let Some(port) = port {
        text = text.replace("127.0.0.1:4400", &format!("127.0.0.1:{port}")).replace("localhost:4400", &format!("localhost:{port}"));
        if name.starts_with("README") { text = text.replace("npx snapback4 dev  ", &format!("npx snapback4 dev --port {port}  ")); }
    }
    if let Some(web_port) = web_port {
        text = text.replace("port: 5173", &format!("port: {web_port}")).replace("port: 4173", &format!("port: {web_port}")).replace("localhost:5173", &format!("localhost:{web_port}"));
    }
    text
}

pub(super) fn title(dir: &Path) -> String {
    let path = std::fs::canonicalize(dir).unwrap_or_else(|_| std::path::absolute(dir).unwrap_or_else(|_| dir.to_path_buf()));
    let name = path.file_name().map(|name| name.to_string_lossy().into_owned()).unwrap_or_default();
    let words: Vec<String> = name.split(|c: char| c == '-' || c == '_' || c == '.' || c.is_whitespace()).filter(|word| !word.is_empty())
        .map(|word| { let mut chars = word.chars(); chars.next().map(|first| first.to_uppercase().chain(chars).collect()).unwrap_or_default() }).collect();
    if words.is_empty() { "My app".into() } else { words.join(" ") }
}

/// Vite's config is `vite.config.mts`, so the reference tsconfig names that.
// @ref LLP 3000.037.000#3-password-online-starters — Expo examples retain strict optional and indexed access checks.
fn strict_expo_config(text: &str) -> String {
    let mut config: Value = serde_json::from_str(text).unwrap();
    config["compilerOptions"]["exactOptionalPropertyTypes"] = json!(true);
    config["compilerOptions"]["noUncheckedIndexedAccess"] = json!(true);
    pretty(&config)
}

fn esm_vite_config(tsconfig: &str) -> String { tsconfig.replace("\"vite.config.ts\"", "\"vite.config.mts\"").replace("\"types\": []", "\"types\": [\"node\"]") }

/// npm scripts compare as commands: the same program and subcommand, then the
/// same options in any order ("tsc --noEmit -p x" is "tsc -p x --noEmit").
/// Spellings that run the same thing are the same command: a leading `npx`
/// (npm scripts already find `node_modules/.bin`), and tsc's default project
/// (`tsc --noEmit` is `tsc -p tsconfig.json --noEmit`).
// @ref LLP 3000.011.003.000#7.4 — wave 4 (094): `tsc --noEmit` refused against the starter's `-p tsconfig.json`.
fn same_command(left: &str, right: &str) -> bool {
    fn shape(script: &str) -> Vec<(Vec<&str>, Vec<Vec<&str>>)> {
        script.split("&&").map(|step| {
            let mut head = Vec::new();
            let mut options: Vec<Vec<&str>> = Vec::new();
            for word in step.split_whitespace() {
                if word.starts_with('-') { options.push(vec![word]); }
                else if let Some(option) = options.last_mut() { option.push(word); }
                else { head.push(word); }
            }
            if head.first() == Some(&"npx") { head.remove(0); }
            if head == ["tsc"] {
                options.retain(|option| !matches!(option.as_slice(), ["-p" | "--project", "tsconfig.json" | "./tsconfig.json" | "." | "./"]));
            }
            options.sort();
            (head, options)
        }).collect()
    }
    shape(left) == shape(right)
}

fn preflight_parents(path: &Path) -> Result<(), String> {
    let ancestors = path.ancestors().skip(1).filter(|p| !p.as_os_str().is_empty()).collect::<Vec<_>>();
    for parent in ancestors.into_iter().rev() {
        match std::fs::metadata(parent) {
            Ok(metadata) if metadata.is_dir() => {},
            Ok(_) => return Err(format!("{} is not a directory; rename it or choose another init directory", parent.display())),
            Err(error) if error.kind() == std::io::ErrorKind::NotFound && parent.symlink_metadata().is_err() => {},
            Err(error) => return Err(format!("{}: {error}", parent.display())),
        }
    }
    Ok(())
}

// A new package boundary in an existing directory inherits the nearest
// package's type, including its absence, rather than reinterpreting scripts.
fn inherited_package_type(dir: &Path) -> Result<Option<Option<Value>>, String> {
    let absolute = std::fs::canonicalize(dir).map_err(|e| e.to_string())?;
    for ancestor in absolute.ancestors().skip(1) {
        let path = ancestor.join("package.json");
        let text = match std::fs::read_to_string(&path) {
            Ok(text) => text,
            Err(error) if error.kind() == std::io::ErrorKind::NotFound => continue,
            Err(error) => return Err(format!("{}: {error}", path.display())),
        };
        let package: Value = serde_json::from_str(&text).map_err(|e| format!("{}: {e}", path.display()))?;
        return Ok(Some(package.get("type").cloned()));
    }
    Ok(None)
}

// Existing JavaScript keeps its module interpretation: only a directory
// without scripts can take the starter's `"type"`.
fn has_scripts(dir: &Path, depth: usize) -> bool {
    let Ok(entries) = std::fs::read_dir(dir) else { return false };
    entries.flatten().any(|entry| {
        let name = entry.file_name();
        let name = name.to_string_lossy();
        let path = entry.path();
        if path.is_dir() { depth < 4 && name != "node_modules" && !name.starts_with('.') && has_scripts(&path, depth + 1) }
        else { name.ends_with(".js") }
    })
}

/// A starter is the user's code: keep each comment's explanation and drop the
/// annotation pointing into this repository's design records.
// @ref LLP 3000.007#20.1 — wave 3: agents guessed `vite.config.ts` and `metro.config.cjs`; init names what it wrote.
/// The files init wrote, compactly: top-level names, then each directory's
/// files in braces (a directory of more than twelve shows its count).
fn written_files(names: &[&str]) -> String {
    let mut groups: Vec<(&str, Vec<&str>)> = Vec::new();
    for name in names {
        let (dir, rest) = name.split_once('/').unwrap_or(("", name));
        match groups.iter_mut().find(|(group, _)| *group == dir) {
            Some((_, members)) => members.push(rest),
            None => groups.push((dir, vec![rest])),
        }
    }
    groups.sort_by_key(|(dir, _)| !dir.is_empty());
    groups.iter().map(|(dir, members)| match (*dir, members.len()) {
        ("", _) => members.join(", "),
        (dir, 1) => format!("{dir}/{}", members[0]),
        (dir, n) if n > 12 => format!("{dir}/ ({n} files)"),
        (dir, _) => format!("{dir}/{{{}}}", members.join(", ")),
    }).collect::<Vec<_>>().join(", ")
}

pub(crate) fn without_design_references(text: &str) -> String {
    const POINTER: &str = concat!("@", "ref LLP ");
    text.split_inclusive('\n').map(|line| {
        let Some(start) = line.find(POINTER) else { return line.to_owned() };
        let rest = &line[start..];
        match rest.find(" — ") {
            Some(gloss) => format!("{}{}", &line[..start], &rest[gloss + " — ".len()..]),
            None => line.to_owned(),
        }
    }).collect()
}

// @ref LLP 3000.007#20.2 — merge an installed package without losing it on a partial write.
fn replace_file(path: &Path, text: &str) -> std::io::Result<()> {
    use std::{fs::OpenOptions, io::Write, sync::atomic::{AtomicU64, Ordering}};
    static SERIAL: AtomicU64 = AtomicU64::new(0);
    let (temporary, mut file) = loop {
        let temporary = path.with_file_name(format!(".{}.{}.{}.tmp", path.file_name().unwrap().to_string_lossy(), std::process::id(), SERIAL.fetch_add(1, Ordering::Relaxed)));
        match OpenOptions::new().write(true).create_new(true).open(&temporary) {
            Ok(file) => break (temporary, file),
            Err(error) if error.kind() == std::io::ErrorKind::AlreadyExists => continue,
            Err(error) => return Err(error),
        }
    };
    let result = (|| {
        if let Ok(metadata) = std::fs::metadata(path) { file.set_permissions(metadata.permissions())?; }
        file.write_all(text.as_bytes())?;
        file.sync_all()?;
        std::fs::rename(&temporary, path)
    })();
    if result.is_err() { let _ = std::fs::remove_file(&temporary); }
    result
}

fn merge_package(path: &Path, starter: &str, pinned: &mut Vec<String>, kept_scripts: &mut Vec<String>) -> Result<String, String> {
    let text = std::fs::read_to_string(path).map_err(|e| format!("{}: {e}", path.display()))?;
    let mut existing: Value = serde_json::from_str(&text).map_err(|e| format!("{}: {e}", path.display()))?;
    let object = existing.as_object_mut().ok_or("package.json must be an object")?;
    let required: Value = serde_json::from_str(starter).unwrap();
    let mut conflicts = Vec::new();
    for (key, value) in required.as_object().unwrap() {
        if matches!(key.as_str(), "dependencies" | "devDependencies" | "scripts") {
            let Some(group) = object.entry(key.clone()).or_insert_with(|| json!({})).as_object_mut() else {
                conflicts.push(format!("package.json {key} must be an object"));
                continue;
            };
            for (name, needed) in value.as_object().unwrap() {
                let equivalent = |old: &Value| key == "scripts" && old.as_str().zip(needed.as_str()).is_some_and(|(old, needed)| same_command(old, needed));
                // `npm i snapback4` saves "^0.4.17"; the starter pins the exact
                // version its binary and client were built together at.
                let admits = |old: &Value| key != "scripts" && old.as_str().zip(needed.as_str()).is_some_and(|(old, needed)| old.strip_prefix(['^', '~']) == Some(needed));
                match group.get(name) {
                    Some(old) if old != needed && equivalent(old) => kept_scripts.push(format!("{key}.{name} {old} (the same command as the starter's {needed})")),
                    Some(old) if admits(old) => {
                        pinned.push(format!("{key}.{name} {old} → \"{}\"", needed.as_str().unwrap()));
                        group.insert(name.clone(), needed.clone());
                    }
                    Some(old) if old != needed && !equivalent(old) => conflicts.push(format!("package.json conflict at {key}.{name}: existing {old}, required {needed}")),
                    Some(_) => {},
                    None => { group.insert(name.clone(), needed.clone()); }
                }
            }
        } else if key == "main" && object.get(key).is_some_and(|old| old != value) {
            conflicts.push(format!("package.json conflict at {key}: existing {}, required {value}", object[key]));
        } else if key != "type" {
            // An absent type is itself the existing package's module policy.
            object.entry(key.clone()).or_insert_with(|| value.clone());
        }
    }
    if conflicts.is_empty() { Ok(pretty(&existing)) } else { Err(conflicts.join("\n  ")) }
}

// Derive from parsed declarations and logical lines, so work clauses, comments,
// whitespace and multiline argument lists cannot leave half an invitation behind.
fn core_expo_schema(source: &str) -> String {
    use snapback4_lang::lexer::{Kind, lex};
    let (document, errors) = snapback4_lang::parse_document("schema.q", source);
    assert!(errors.is_empty(), "the embedded Expo schema must parse: {errors:?}");
    let starts: std::collections::BTreeSet<_> = document.actions.iter().filter(|action| action.name == "invite").map(|action| action.site.line)
        .chain(document.schedules.iter().filter(|schedule| schedule.target == "invite").map(|schedule| schedule.site.line)).collect();
    let (tokens, _) = lex("schema.q", source);
    let mut removed = std::collections::BTreeSet::new();
    for (index, token) in tokens.iter().enumerate() {
        if starts.contains(&token.site.line) || (token.value == "use" && tokens.get(index + 1).is_some_and(|next| next.value == "server")) {
            let end = tokens[index..].iter().find(|next| matches!(next.kind, Kind::Newline | Kind::Eof)).unwrap().site.line;
            removed.extend(token.site.line..=end);
        }
    }
    source.lines().enumerate().filter(|(index, _)| !removed.contains(&(*index as u32 + 1)))
        .map(|(_, line)| format!("{line}\n")).collect()
}

fn background_install(dir: &Path) -> std::io::Result<()> {
    use std::process::{Command, Stdio};
    let logs = dir.join(".snapback4"); std::fs::create_dir_all(&logs)?;
    #[cfg(unix)] { use std::os::unix::fs::PermissionsExt; std::fs::set_permissions(&logs, std::fs::Permissions::from_mode(0o700))?; }
    let mut log_options = std::fs::OpenOptions::new(); log_options.create(true).append(true);
    #[cfg(unix)] { use std::os::unix::fs::OpenOptionsExt; log_options.mode(0o600); }
    let log = log_options.open(logs.join("install.log"))?;
    #[cfg(unix)] { use std::os::unix::fs::PermissionsExt; log.set_permissions(std::fs::Permissions::from_mode(0o600))?; }
    // Publish request identity BEFORE spawning: an immediate --wait cannot
    // mistake an older successful receipt for this install, even on slow Node startup.
    let request = format!("{}-{}", std::process::id(), std::time::SystemTime::now().duration_since(std::time::UNIX_EPOCH).unwrap_or_default().as_nanos());
    let mut request_options = std::fs::OpenOptions::new(); request_options.create(true).write(true).truncate(true);
    #[cfg(unix)] { use std::os::unix::fs::OpenOptionsExt; request_options.mode(0o600); }
    let mut pending = request_options.open(logs.join("install-request.json"))?;
    pending.write_all(serde_json::to_string(&json!({"id":request})).unwrap().as_bytes())?;
    Command::new("node").arg("scripts/install.mjs").arg("--background").env("SNAPBACK4_INSTALL_REQUEST", &request).current_dir(dir)
        .stdin(Stdio::null()).stdout(Stdio::from(log.try_clone()?)).stderr(Stdio::from(log)).spawn()?;
    println!("init: frontend install running in background; read/edit now. Progress: node scripts/install.mjs --status; join once: node scripts/install.mjs --wait; log .snapback4/install.log");
    Ok(())
}

            if matches!(path.file_name().and_then(|n|n.to_str()),Some("node_modules"|"dist"|"target"|".git")) { return Ok(()); }

                }
            }
        }
    }
    // Follow literal relative module imports beyond conventional source directories.
    // Runtime-computed paths remain application responsibilities, as in Node itself.
    let canonical_root=dir.canonicalize().unwrap_or_else(|_| std::env::current_dir().unwrap_or_default().join(dir));

    // package scope too, so ordinary .js require helpers keep their Node meaning.

    if original_scope {
        for (name,_) in &mut files {
            *name=Box::leak(format!("v1/.source/{}",name.strip_prefix("v1/").unwrap()).into_boxed_str());
        }
        push(&mut files,"v1/.source/package.json".into(),super::pretty(&package));
        push(&mut files,"v1/snapback/generated/api.ts".into(),snapback4_lang::emit::typescript(&bound));
        push(&mut files,"v1/snapback/generated/package.json".into(),"{\"type\":\"module\"}\n".into());
    }
    let mut frozen=package.clone();
    frozen["private"]=json!(true);frozen["type"]=json!("module");
    if !frozen["scripts"].is_object() {frozen["scripts"]=json!({});}
    if original_scope { frozen["scripts"]=json!({}); }
    else if package["scripts"].is_object() { frozen["scripts"]=package["scripts"].clone(); }

    push(&mut files,"v1/.snapback4-frozen-run.mjs".into(),include_str!("frozen-run.mjs").into());
    Ok(files)
}

/// Shell words are inspected, never executed; quoted paths keep their spaces.
fn command_words(command: &str) -> io::Result<Vec<String>> {
    let mut words=Vec::new();let mut word=String::new();let mut quote=None;let mut chars=command.chars();
    while let Some(ch)=chars.next() {
        match (quote,ch) {
            (Some('\''),'\'')|(Some('"'),'"')=>quote=None,
            (None,'\''| '"')=>quote=Some(ch),
            (Some('\''),_)=>word.push(ch),
            (_, '\\')=>{if let Some(next)=chars.next(){word.push(next);}},
            (None,c) if c.is_whitespace() || matches!(c,';'|'&'|'|')=>{if !word.is_empty(){words.push(std::mem::take(&mut word));}},
            _=>word.push(ch),
        }
    }
    if quote.is_some() {return Err(io::Error::other("cannot freeze malformed quoted package script"));}
    if !word.is_empty(){words.push(word);}Ok(words)
}

        std::fs::create_dir(&stage)?;
        let result=(|| -> std::io::Result<()> {
            for (name,body) in &frozen {
                let relative=std::path::Path::new(name.strip_prefix("v1/").unwrap());
                if relative.components().any(|c|!matches!(c,std::path::Component::Normal(_))) {return Err(std::io::Error::other("frozen destination escapes v1"));}
                let path=stage.join(relative);
                std::fs::create_dir_all(path.parent().unwrap())?;
                std::fs::write(path,body)?;
            }
            if dir.join("v1").symlink_metadata().is_ok() {return Err(std::io::Error::other("v1 appeared during capture; no historical source replaced"));}
            std::fs::rename(&stage,dir.join("v1"))
        })();
        if result.is_err() {let _=std::fs::remove_dir_all(&stage);}
        result?;
    }
    for (name, body) in additions {
        if name.starts_with("v1/") {continue;}
        let path = dir.join(name);
        std::fs::create_dir_all(path.parent().unwrap())?;
        if *name == "package.json" || *name == "vite.config.mts" || *name == "scripts/frontend-proof.mjs" || *name == "scripts/day2-proof.mjs" { super::replace_file(&path, body)?; }
        else {
            use std::io::Write;
            let mut file = std::fs::OpenOptions::new().write(true).create_new(true).open(&path)?;
            file.write_all(body.as_bytes())?;
        }
    }
    Ok(())
}
