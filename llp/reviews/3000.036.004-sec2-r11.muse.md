## Findings

- Framing claim holds. `framed` requires exact `Content-Length` match, rejects duplicate/invalid lengths, rejects any `Transfer-Encoding` other than exactly `chunked`, and rejects conflicting `Length + chunked`. The unit test covers the truncated-yet-valid-JSON prefix, duplicates, and conflict. Split is bytes-before-UTF8 (boundary scan on bytes, UTF-8 only on headers, `serde_json::from_slice` on raw bytes). `chunks` is strict: hex parse, CRLF checks, trailer rejection, overflow guard, outer 1 MiB cap.
- Rotation-before-revocation claim holds. Code confirms live `/schema` 200, rotates via `/auth/refresh`, requires distinct token with equal `principal`, confirms successor 200, then requires old-token 401/`E_AUTH` before `POST /auth/logout-all` (and requires `ok` plus nonzero `revoked`). Mass revocation cannot mask broken rotation.
- Door coverage matches the claim: both retired bearers at `GET /schema`, `GET /changes?since=0&wait=0`, `POST /sync`, `POST /probe`, `POST /auth/refresh`, plus every authored `/q/` and `/m/`. Server checks auth before body parsing on all of these, so the generic probe bodies cannot false-pass as 400s. Error paths fail closed (`?`/`return Err`), never counted as refusals.
- Credential hygiene holds. Tokens never printed. The one error string that echoes a bearer uses `Bearer [REDACTED]`. Ephemeral guest/password is loopback-only against a scratch host.
- Scope exclusions are explicit everywhere they matter: no-identity schemas and native/action/effect apps report missing coverage; offline retained bytes and current-role freshness without a sync round are disclaimed in code print, guide, and RFC.
- Snapshot/cleanup holds. Linux copies `/proc/self/exe` (stable inode across Cargo replacement); RAII `Scratch`/`Process` cleans up on all returns with `drop(host)` before `drop(scratch)`.

## Concrete fixes (hardening, not blocking)

1. `framed`, no-framing acceptance: a response with neither `Content-Length` nor `Transfer-Encoding: chunked` is currently accepted as-is. `tiny_http` always frames these doors, so this is latent. Still, require presence: fail qualification when `length.is_none()` and not chunked.
2. `framed`, header-name whitespace: `Content-Length : 5` (space before colon) is silently ignored rather than rejected. Trim or reject malformed names so a smuggled length can never be skipped.
3. Optional coverage: retired tokens are not replayed at `POST /assets` or `/following/` for schemas that have them. The claim does not cover those doors, so this is a scope note, not a false claim. Consider adding them to the loop if those features are in scope for revocation.
