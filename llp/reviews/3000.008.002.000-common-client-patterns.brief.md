   viewer lifetime) going to create a correctness or disclosure problem
   worse than the one it fixes? If you think the RFC is aimed at the wrong
   thing, say what the right thing is.
5. **What should the implementation build first?** Give a ranked list of the
   concrete changes that would most improve Snapback 4 for this class of
   application — each with where it goes (files), roughly how big it is, and
   how to verify it. Mark anything in the RFC that should *not* be built.

Severity: **High** = the RFC misreads the evidence or the code in a way that
would send the implementation in the wrong direction, or proposes something
that would break an existing law (authority, disclosure, durability,
at-most-once). **Medium** = a real correction the implementation must fold.
**Low** = minor. Do not pad; three real findings beat twelve speculative
ones. DIRECTIONALLY RIGHT means: implement as written. RIGHT WITH CORRECTIONS
means: fold these and implement. MISJUDGED means: the implementation would be
aimed at the wrong problem — say what the right problem is.
