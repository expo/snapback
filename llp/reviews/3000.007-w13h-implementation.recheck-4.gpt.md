**High — Record-preserving joins can prevent the planner from terminating.**

Location: [pages.rs:168](/Users/ccheever/projects/snapback-w13-review-f/repo/snapback4/crates/snapback4-core/src/engine/pages.rs:168), interacting with the unbounded fixpoint at **431–450**.

Using the existing `msgs` fixture:

```quarry
fn wrap(previous: json <=4000 ?, payload: json <=4000):
  return { previous, payload }

query feed(c: cursor ?):
  page = msgs[0] after c first 1 by byLane
  wrapped = null
  for i in range(0, 1):
    wrapped = wrap(wrapped, page)
  return { page, wrapped }
```

This executes one finite wrapping operation. The helper’s declared JSON parameters keep its inferred result type finite: argument checking accepts these values, while lowering preserves them as ordinary variable bindings ([types.rs:185](/Users/ccheever/projects/snapback-w13-review-f/repo/snapback4/crates/snapback4-lang/src/types.rs:185), [control.rs:419](/Users/ccheever/projects/snapback-w13-review-f/repo/snapback4/crates/snapback4-lang/src/bind/program/control.rs:419)). Consequently, the binder’s recursive-*type* guard does not prevent this origin-analysis problem.

Let `P` be the page’s ambiguous origin. The loop-header origin of `wrapped` grows as follows:

```text
Empty
{ payload: P, previous: Empty }
{ payload: P, previous: { payload: P, previous: Empty } }
...
```

The new record/empty arm preserves each newly nested record. Record/record joins recurse into `previous`, so `next == entry` never becomes true. The analysis ignores the literal loop’s one-iteration bound and has no widening rule.

On `31ec7136e1`, the first record/empty join instead became `Unknown`, which stabilized. This is therefore introduced by fix 4. It affects compiler page-site analysis ([bind/mod.rs:231](/Users/ccheever/projects/snapback-w13-review-f/repo/snapback4/crates/snapback4-lang/src/bind/mod.rs:231)) and runtime planning before metered execution ([runner.rs:179](/Users/ccheever/projects/snapback-w13-review-f/repo/snapback4/crates/snapback4-core/src/engine/runner.rs:179)).

**Smallest correct change:** add conservative widening for recursively growing record origins at loop backedges. Preserve possible page content and any provable unique owner, with ambiguous lineage and trimming disabled; retain the new fieldwise record/empty rule for ordinary joins. Add this finite helper composition as a termination regression for compilation and all three hosts.
