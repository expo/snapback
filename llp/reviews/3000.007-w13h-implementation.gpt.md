Findings, derived from source inspection:

1. **High — Auxiliary results can rewind a returned raw page.**  
   [pages.rs:49](/Users/ccheever/projects/snapback-w13-review-f/repo/snapback4/crates/snapback4-core/src/engine/pages.rs:49), [shaping.rs:45](/Users/ccheever/projects/snapback-w13-review-f/repo/snapback4/crates/snapback4-core/src/engine/shaping.rs:45).

   Extend the ownership fixture to return `{ page, n: count(ignored) }`. The raw `page` still contains `a`. Backward flow now marks `ignored` relevant, and its source site matches the raw page’s site, so its starved shape rewinds their shared position inclusively to `a`. Following `next` repeats a row already returned. A conditional return selecting raw versus shaped output has the same underlying problem.

   **Smallest correct change:** track which collector actually transports the selected returned page, separately from auxiliary dependencies. Associate the adjusted position with that collector’s output; do not mutate the raw source page’s shared position. Add the used-summary and conditional-return controls on all three hosts.

2. **Medium — An inherited cap can leave an eager-merge shape falsely “finished.”**  
   [shaping.rs:31](/Users/ccheever/projects/snapback-w13-review-f/repo/snapback4/crates/snapback4-core/src/engine/shaping.rs:31), [read.rs:859](/Users/ccheever/projects/snapback-w13-review-f/repo/snapback4/crates/snapback4-core/src/engine/read.rs:859).

   Materialize an owning page, exhaust the meter with subsequent work, then shape its rows using a helper containing an eager merge whose lanes come from a list or range—for example, a non-unique index without an ending `id`. `charge_lane` returns `false` directly when `capped_at` is set. Every lane can therefore be skipped without incrementing `read_cuts`. The eager merge returns `[]`; `shape_starved` sees successful execution and an unchanged counter, retains the row, and leaves `next` past its missing preview.

   **Smallest correct change:** report this inherited-cap stop through `read_capped()` or equivalent starvation accounting. Add an eager range/list preview regression under an already-cut meter.

   [RFC:539](/Users/ccheever/projects/snapback-w13-review-f/repo/llp/3000.007-relaxed-quarry-and-explicit-residency.rfc.md:539), [README.md:615](/Users/ccheever/projects/snapback-w13-review-f/repo/snapback4/packages/snapback4/README.md:615).
