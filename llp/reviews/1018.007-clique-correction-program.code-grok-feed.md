### Disjoint maintain-group ranges (`maintained-coherence.ts` 51–59, `range-store.ts` 1379–1390)

Authority evictions still visit every owner of a range on the **maintain target** table (`rangeTables`). Previously any such visit stripped **all** ranges on that table and partialized the whole answer (`next` dropped). That is the Astra sibling case: `replyCounts` / `repostCounts` unique-get ranges on the feed receipt, while a source row in another group (`parent = null` vs post id, `repost false` vs `true`) invalidates a different target key.

`disjoint` keeps a range only when some **aligned** prefix slot is a `Column` equal to `maintain.by[i]` and `totalCompare` of the prepared prefix `Scalar` vs the contribution group value is non-zero. Same group and unmapped `byId` (prefix is the target id, not a `by` column) stay conservative: `disjoint` is false, the range is removed, the answer goes `partial` / `missing-authority`. Warm/cold regression in `overlay-retirement.test.ts` 168–205 matches that matrix.

`invalidations()` still skips `0n` via bigint truthiness. Source `transition` only runs when the row body actually changed (`range-store.ts` 1167–1173), so equal-image same-seq conflicts remain errors. `RangeReceipt.get(range, true)` is the in-memory prepared object: `CarrierIndex.set` / `receipt()` re-own ranges on load and on delivery.

### Owner-page fallback keyed by `{through, order}` (`offline.ts` 1148–1160)

`store.answer` attaches `ItemCapture.inputs().selection` from the stored capped page (`range-store.ts` 635–645, `freshItemSelection` = `{ through: seq, order }`). Twin evaluate of the **same** op/args uses the same stored selection. A successor install bumps store-wide `local.seq` without changing the head’s membership observation. The old `local.seq === held.seq` (or seq 0) guard was the causal miss; it is gone.

Still blocking: missing `order` on either side, different `order`, `held`/`denied`, non-`computed-key` partial, predicted outbox entries, `maintained-coherence` held pages (`held.state === "capped"` is required), `preserveOwner` false (drains). Fallback publishes the **whole** held capped answer with its own `next`; it does not attach that cursor to a different local body. A newer complete local with a **different** `{through, order}` wins (`offline-owner-custody.test.ts` 59–75).
