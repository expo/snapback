## Question 1 — provenance rule

From `record` and `notes`: a column qualifies when it has at least one write whose value carries `READ`, **no** write carries `ARGUMENT` or `UNKNOWN`, and **no** write is ambient-only except a **literal insert** (or omitted literal/null default). Mixed read+ambient is allowed. Inserts of `score: 0` do not disqualify once another writer is read-derived (`record`, 388–392). `notes` then applies today’s gates: public or uniformly readable, `truth(rule) == Some(true)` on insert or update, not immutable, not `append only`, not a maintain target (396–407). A native job makes the all-writers proof empty (67–69).

That is the brief’s rule. Extras that are conservative, not contradictory: upsert keys are writers (336–351); uncalled helpers are analyzed with fictitious `ARGUMENT` inputs (81–88); `UNKNOWN` silences.

**False positive a careful builder would call caller-set.** The suite taints an argument `break` *before* the accumulator (`aggregate_copies.rs` 467). This program is the same idea with the `break` after the add, and there is no test for it:

```quarry
mutation like(postId: posts, choice: bool):
  p = posts[postId] ! else NOT_FOUND
  delta = 0
  for row in posts[] first 5 by byId:
    delta = delta + row.score
    if choice:
      break
  update posts[p.id] { score: p.score + delta }
```

`carried_control` only influences *later* statements in that body (`aggregate_provenance.rs` 175–179, 147–150). The loop join taints assigned names with the domain’s argument bits (200), not with a body’s argument-dependent exit. `choice` never touches `delta`, so the column still looks derived under `allow`.

**Misses of the calibration footgun.** `p.score + 1` next to a like insert fires (`aggregate_copies.rs` 257–266). Helpers, shapes, aliases, `count`/`sum`, and a loop-carried total without an argument fire (335–351, 412). `rank.score + (1 if value else -1)` is silent because `value` is an argument (365) — that is P5, not an escape. Selectors on a table/maintain read do not taint (`read()` evaluates keys/seeks and discards them, 215–219), which is the stated rule, not a hole.

**Presence.** `connected` is a builtin, not a table (`program/expr.rs` 173–177). Unknown tables are `AMBIENT` (219). The seven corpus hits were `n: connected[p]`, `count([0] + [connected[p]])`, and `n = 1` selected by `exists connected[p]` — live session state, not an engine aggregate. No name list. Principled.

**Widening.** Growing a scalar into fields/items becomes `self.all() | other.all() | UNKNOWN` (35–37). `UNKNOWN` disqualifies (388). Recursive functions and named shapes cut at the current stack (129, 250). The `For` loop stops when the env’s `Value`s are `Eq` (204). The lattice is finite because field names come from the program and depth collapses. The 5s test (479–487) is the hang they found; unknown-or-read still silences rather than noting.

## Findings

### Medium — argument-dependent `break` after a loop-carried add still looks derived

**Where:** `snapback4/crates/snapback4-lang/src/bind/aggregate_provenance.rs` 175–179 and 197–201.

**Failing scenario:** The program in Q1 (`delta = delta + row.score` then `if choice: break`) under `insert/update <- allow`. A builder would call that caller-set. The classifier notes it. The suite only covers break *before* the assign (`aggregate_copies.rs` 467).

**Smallest fix:** Thread the body’s `carried_control` (or `exits_path` plus those if-conditions’ bits) out of `body()`, and in the `For` join do what `count_arguments` already does: `joined.influenced(break_bits)` on assigned names. Same principle they used for argument-selected constants.

**Where:** `aggregate_provenance.rs` 406–407; `tests/aggregate_copies.rs` 70–86 and 375–405 (no `append only`).
