**Failure scenario**

1. Drain requests `batch: 16` from cursor `null`.
2. Page 0 is a legal complete/capped frame whose `next` is `c1`. Page 1’s `next` is also `c1` (required repeated-cursor control).
3. Owner responds `{ pages: [page0], more: false, error: { code: "E_OFFLINE_RESUME", ... } }`.
