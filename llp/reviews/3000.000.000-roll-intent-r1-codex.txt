The invariant path can retain current actions/effects and operations while the generated release contains only Quarry sources and metadata. A worker introduced after the predecessor is neither retained nor rejected. This breaks the promised complete execution closure.

2. **A predecessor export alias can lose its current guard.** The selective path visits predecessor program declarations, not each predecessor exported alias. With a schema widening and no invariant declaration, the generated view retains `oldRead = base`, bypassing the current guard. Table-authority equality does not detect this endpoint change.
