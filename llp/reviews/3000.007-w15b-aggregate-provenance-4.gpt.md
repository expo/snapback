**Finding — Medium: shaping an argument list manufactures READ evidence for its caller-supplied count.**

Location: [aggregate_provenance.rs:346](snapback4/crates/snapback4-lang/src/bind/aggregate_provenance.rs:346), interacting with [count handling at :477](snapback4/crates/snapback4-lang/src/bind/aggregate_provenance.rs:477).

Concrete scenario:

```quarry
table source:
  n: int
  public 'source'

table copies:
  n: int
  public 'copies'
  insert <- allow

mutation copy(xs: [int] <=10):
  p = source['seed'] ! else MISSING
  mapped = xs { ignored: p.n }
  insert copies { n: count(mapped) }
```

Given the source row, the written value is **exactly `count(xs)`**, independent of `p.n`. The caller supplies the collection whose length is stored. The projected read value is discarded; it neither supplies nor selects the stored number.

The pass nevertheless emits the note:

- [Arguments at :78](snapback4/crates/snapback4-lang/src/bind/aggregate_provenance.rs:78) represent `xs` as scalar ARGUMENT, without a list item.
- Shaping constructs an object containing the READ field and preserves ARGUMENT only as control. Because `base.item` is absent, it loses the fact that this is a collection with argument-derived cardinality.
- `count` consequently takes its opaque-input fallback and unions the projected field’s READ bits. The final verdict sees READ plus AMBIENT, with no ARGUMENT.

This is an accepted language shape: [list projection lowering](snapback4/crates/snapback4-lang/src/bind/program.rs:595) pushes one object per input element; [runtime count](snapback4/crates/snapback4-core/src/engine/runner.rs:914) reads only array length. Replacing `count(mapped)` with `count(xs)` or `sum(mapped, 1)` stays silent under the current pass despite computing the same value.

**Smallest fix:** preserve argument-derived collection cardinality through shapes so `count` cannot substitute projected-field provenance. Where the abstract source cannot distinguish a collection from an object, retain ARGUMENT or conservatively return UNKNOWN instead of granting a READ proof. Add the example and equivalent direct-count/projected-sum controls, including a helper/cache variant.

This is a behavior finding, not a wording-only request.

Verdict: NOT READY
