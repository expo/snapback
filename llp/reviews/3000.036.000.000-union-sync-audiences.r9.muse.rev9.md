2. Low — `partition.rs:101` `group_of()`. It returns only `sync.audience`'s (first arm's) group, which is wrong for a union table, and it now has no callers anywhere in the tree (all live paths use `partitions()` / `arm_group()`). A future caller reaching for "the row's group" would silently get arm-one-of-N. Proposed change: delete it, or document that it is first-arm-only and must not be used for union tables.
