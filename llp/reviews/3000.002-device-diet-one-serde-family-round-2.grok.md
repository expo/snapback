## Shared envelope and route probe

`PageArgument` (`call.rs:175–181`): `page: StreamPage` (required), `first: Json` with `#[serde(default)]`. Missing `page` fails `from_text`, falls through to `call()`, which still does `arg(..., "page")` (`call.rs:80`) — same missing-page diagnostic as BASELINE. `first` missing or `null` → `Null` → `as_bool() == None` → `false`, same as BASELINE `get("first").and_then(as_bool).unwrap_or(false)`. Unknown fields ignored (no `deny_unknown_fields`). Duplicate struct keys fail `from_text` and take the owned last-key-wins path (`route.rs:10` `"watermark":99,` plus the duplicate-key case in `codec.rs:161`).

`ROUTE` / `thread_local!` / `#[path]` are all `#[cfg(test)]` (`call.rs:161–168, 189–196`). They compile out of non-test and integration-test rlibs. Setting the cell does not change `page_call`. No leak into a shipped build.
