## 1. The provenance rule

A column is derived in fact when it has evidence of a **read** write and is not `disqualified`:

```418:425:snapback4/crates/snapback4-lang/src/bind/aggregate_provenance.rs
    fn record(&mut self, table: &str, name: &str, value: &Value, insert: bool, expression: &str, maintain: Option<String>) {
        let column = self.columns.entry((table.into(), name.into())).or_default();
        let bits = value.all();
        if bits & (ARGUMENT | UNKNOWN) != 0 || (bits & READ == 0 && !(insert && value.literal)) { column.disqualified = true; }
        if bits & READ != 0 {
            column.evidence.get_or_insert_with(|| (expression.into(), self.owner.clone()));
```

That is exactly: every writer’s value is read-derived (table/maintain read, `count`/`sum` over one, or prior-image arithmetic), possibly mixed with ambient, and **no** writer is argument, unknown, or ambient-only — except a **literal insert** (or omitted literal/null default) which does not disqualify when some other write is read. `notes()` then applies the old gates: public or uniformly readable, `truth(rule) == Some(true)` on insert or update, not immutable, not `AppendOnly`, not a maintain target, not a native job (`85–88`, `441–452`).

**False positive I tried.** Caller-chosen `first(slice([1,-1], offset, offset+1))` is now silent because `slice` **influences** the container, its `item`, and nested fields (`54–63`, `347–349`, test `583–597`). Argument `if choice: break` after `delta = delta + row.score` taints carried values via `loop_exit` (`222–227`, `612–620`). Presence (`connected`, `exists connected`) is `AMBIENT` because `read` only tags catalog tables (`244`). I do not have a careful, published-shape program that still notes and a builder would call legitimately caller-set.

**Missed footguns.** `score: p.score + 1` next to a like-style update notes (`271–280`). Helpers, shapes, aliases, `count`/`sum`/`group`, jobs, and uncalled helpers note (`349–365`). `total = 0; for row in posts[]: total = total + 1` notes because loop cardinality now includes `READ` (`203`, `600–608`). Copied counts through helpers/shapes are in that same suite.

**Presence is principled.** `connected` is not in `catalog.tables`, so it is session/ambient, not a durable aggregate. The seven corpus hits were `connected[p]` / `count(ns)` of that (`JOURNAL.md:41089–41102`). That is a catalog boundary, not a column-name suppression list.

**Widening.** Recursive growth hits `32–37`: if the left summary is a scalar and the right has fields/items, the result is `self.all() | other.all() | UNKNOWN` — **unknown**, which `record` disqualifies even when `READ` bits are present. Quarry `if` scopes match the binder’s lexical scopes (`control.rs:8–26`), so F2’s scoped maps do not drop reassigned parent bindings.
