1. **High — SQLite’s preflight allocates the payload before its allowance.**  
   [store.rs:809](/Users/ccheever/projects/snapback-w13-review/repo/snapback4/crates/snapback4-core/src/store.rs:809)

   `length(CAST(r.data AS BLOB))` does not obtain a payload-free stored length. In the pinned SQLite implementation, the length optimization applies to a direct column argument; the intervening cast evaluates the column normally before casting it ([SQLite compiler:118114](/Users/ccheever/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/libsqlite3-sys-0.38.2/sqlite3/sqlite3.c:118114)). Thus line 812 can materialize the JSON before line 815 reserves its native payload scratch.

   The existing 4,000-byte-row/500-byte-ceiling probe already supplies a concrete scenario. Its assertion only counts executions of the **subsequent** payload statement, so it misses payload allocation inside the size statement ([word_heap test:123](/Users/ccheever/projects/snapback-w13-review/repo/snapback4/crates/snapback4-core/tests/word_heap.rs:123)). These temporary column buffers are precisely the scratch the ledger promises to charge, not merely shared database pages.

   **Smallest correction:** use a direct byte-length operation that retains SQLite’s column optimization, such as the pinned implementation’s `octet_length(r.data)`, and verify the preflight itself does not load oversized payloads before the allowance. Extend the probe beyond the later statement’s run count.

2. **High — Shared retained-state propagation excludes horizon-free and positive-existence word reads.**  
   [read.rs:432](/Users/ccheever/projects/snapback-w13-review/repo/snapback4/crates/snapback4-core/src/engine/read.rs:432)

   `retained_group` is now called only inside the non-existence, horizon-bearing branch. Generated word scans subsequently reuse `word.retained` instead of performing their previous lookup ([read.rs:672](/Users/ccheever/projects/snapback-w13-review/repo/snapback4/crates/snapback4-core/src/engine/read.rs:672)). Delivered-history retention itself has no horizon requirement ([history.rs:50](/Users/ccheever/projects/snapback-w13-review/repo/snapback4/crates/snapback4-device/src/device/history.rs:50)).

   A legitimate horizon-free retained group can therefore return its local matching rows without marking its component retained. Combine that component with another component requiring server knowledge: client composition requires a retained component, so it can fall back to the whole server answer and lose the left group’s delivered history ([local.ts:1050](/Users/ccheever/projects/snapback-w13-review/repo/snapback4/packages/snapback4/src/local.ts:1050)). The current component fixture uses a horizon and misses this branch.

   **Smallest correction:** compute and precharge the retained verdict once for every relevant device matching scope, independently of horizon and existence coverage; then share it. Add legitimate acquire/leave tests for horizon-free matching and positive existence, including mixed-component routing.

3. **Medium — Inclusive predicate retry can return the same empty page indefinitely.**  
   [read.rs:796](/Users/ccheever/projects/snapback-w13-review/repo/snapback4/crates/snapback4-core/src/engine/read.rs:796), [read.rs:863](/Users/ccheever/projects/snapback-w13-review/repo/snapback4/crates/snapback4-core/src/engine/read.rs:863)

   Retrying the interrupted membership fixes the new three-group fixture, but there is no corresponding no-progress handling for predicates. The existing refusal requires a recorded returned-shape position; an ordinary filtered page has none.

   For example, let the first public room have more than 8,192 unswept expired rows under a normal prefix index. A page filtered by `exists messages[.id]` spends its fresh examined allowance proving no witness, returns no rooms, and positions inclusively at that same room. Following the cursor repeats the same work and token forever, preventing later rooms from being reached. This affects non-word reads too.

   **Smallest correction:** retain the necessary inclusive retry, but detect a failed retry at the same input position with no emitted progress and stop advertising continuation. Add a no-progress predicate regression without a returned shape; keep the final-answer veto unchanged.
