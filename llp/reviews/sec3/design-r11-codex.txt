## 12. SEC3 day-two amendment

Implementer: SEC3, 2026-10-19. Commission: day-two fix list 3/4/5/8.
REL5 owns release transitions and compatibility; MIG owns backfills and staging
clock control. This amendment changes security analysis, not runtime authority.

### 12.1 Column read intent

`invariant table.column read only P` protects the value, computations over it,
value-dependent counts/existence/refusals, copied values, assets and delivery.
It does not forbid observing an otherwise public row's existence independently
of the protected value. Binding validates the column and preserves its identity
in every verdict and audit. Effective payload authority is row read AND any
owner-private field gate. Pure projections excluding the field may eliminate
that payload path; predicates, group/order keys, derived values and copied
fields remain observations. Unknown flow stays unproved. A synthetic whole-row
read cannot refute a projection-only column policy: column counterexamples
execute an authored observer in two schema-valid worlds differing only in that
column, with policy false in both. Outputs must differ reproducibly. Maintained
values are recomputed; column-sensitive counts/existence are included. Separate
obligations name unresolved raw-probe, wire, device and opaque flows. A direct
column theorem never silently clears those obligations. Per-column audit
reports effective audience plus operation/derived observers, not only its type.

### 12.2 Reproducible campaigns and reachability

Generated seed ingress contains only authored base rows/fields. Never re-seed
maintained targets or engine-recorded fields. Generated lifetime samples are
live at the campaign clock; principal fields vary independently. Rejected
snapshots are recorded as unsupported, not successful attempts. Existing
fixture histories instead fork the complete SQLite store and asset ledger into
owned isolated memory stores; captures, deadlines, maintained values, lifetimes
and actual media identities survive unchanged. No source store is modified.
Temporary asset directories belong to Store and disappear on drop.

Actors include all principal values in fixtures. Required/optional references
range over fixture rows, not only the first. Short histories visit first steps
breadth first before extending them under a reported work cap. Read and row
assertions are checked after each step. Write/operation assertions judge only
actual committed changes, correct insert/update/delete arms and pre-write
policy state; ambiguous multiple writes, implicit effects or unstable policy
need executed-effect tracing and remain unsupported. A finite trace is never
an induction proof for always or arbitrary histories.

Every counterexample has a machine-readable origin: authored trace from trusted
fixture, trusted-seed-only, or synthetic operation. Only the first establishes
application reachability from the recorded trusted starting state and fails
normal check/test. Seed/synthetic witnesses remain refutations of all-snapshot
claims, visible with --all and JSON, without failing acceptance. Unproved
reachability is never asserted unreachable as a mathematical theorem. Check
loads the same fixture base for reachable histories as test, without HTTP or
business-case execution. A stronger witness must replace a synthetic witness
for the same declaration. --all exposes all witnesses and never changes which
ones fail. No unreachable refutation may print pass/ok beside exit 1.

### 12.3 Actionable authority advice

N_PRIVILEGE_ESCALATION identifies authored caller operations that write role
or group grants trusted by later rules while the effective admission does not
establish independent authority to confer that particular grant. Include
self-signup roles and transitions where a caller can confer a role they lack.
A trusted service seat or an independently authorized administrator may appoint
other roles; holding an unrelated ordinary role does not establish delegation.
Advice names the operation, grant and gate and points to guide staging's
operator first-admin recipe. It is advice, never an implicit runtime refusal
or a proof of malicious intent. Legitimate open enrollment can be intentional.

N_GRANT_OUTLIVES_ROLE requires an actually mutable/revocable current-role
population and a retained principal/grant branch lacking that role recheck;
cover read AND write branches. Immutable/static role populations do not fire.
N_EXISTENCE_ORACLE excludes public populations and caller-owned role lookups;
only an absent/hidden distinction crossing a narrower private audience warrants
advice. Every security note has a real source location and contributes to the
reported note count. Rule printing preserves connective precedence. Identity
429 responses include a conservative retry delay covering the rate window;
the existing limits and authentication semantics are unchanged.

### 12.6 Disclosure and clock clarifications

A column observer mutation is declined if it can change the protected image,
policy dependency or an unresolved implicit writer before disclosure. A
pre-operation false policy cannot refute an authorized post-transfer return.
Column observers also run after committed history steps, preserving the
trusted initial fixture and authored prefix. All reference and principal
arguments use the same bounded fixture Cartesian cases; truncation of read
observer cases at 32 is named. Clock-only whole-row probes exclude columns.
Column tick coverage beyond the recorded campaign clock remains named.

All security fixture loading, probes, writes, paired deletions and policy
judgments use the same explicit campaign clock. Business tests keep their own
existing clock and store; security reloads trusted fixture files independently.
Raw policy probes respect both not-before and expire-at bounds. Direct delete
assertions judge removed pre-images against the stable pre-write state, never
surviving rows alone; ambiguous implicit removals remain unsupported.

Fixture forks copy already activated engine state without re-adopting a schema.
They use fresh entropy/minter and private assets, never shared live connections.
Ephemeral-hub fixtures require a separate isolated snapshot and are declined.
Structural privilege advice combines dominating safe operation requirements
with the actual insert/update/upsert gate and applicable owned-field patch gate.
A mutable roster alone is not enough for lifetime advice: require independent
current-role intent or a retained recipient column tied to a role literal
(judge, inspector, host, contractor, engineer; ordinary author attribution alone
is not a current-role contract). Deletion revokes even an immutable role field.

### 12.7 Stable judgments and direct payload witnesses

Unknown bound policy dependencies never authorize a mutation observer: such
column mutations require disclosure-boundary tracing. Pre-write assertions use
a transitive closure of maintained and cascade/set-null writes; a policy
dependency or target that may change implicitly makes the assertion unsupported.
The same rule covers insert, update, upsert and delete. Looped/opaque net images
cannot stand in for executed write events. Effective inserted authority includes
a defaulted role even when omitted from the source write.

An authored complete query returning a compiler-typed Row/Table or Page/Table
containing the protected row id is a direct payload witness at that query's
snapshot. Nested typed row returns retain their source-table identity. This
avoids inventing an invalid absent world by deleting a referenced parent.
Projected scalar/aggregate/refusal observations still require validated paired
worlds; a matching untyped id or value alone cannot attribute an exposure.

Check prioritizes actual fixture histories and column observers before searching
remaining synthetic counterexamples. It does not repeat the test-only operation
exploration matrix, which judges no additional policy. That matrix shares an
8192-call budget across every operation (1–512 calls per operation), reports
truncation, and preserves enum/reference/principal alternatives within that cap.
Required image/file operation arguments are actual uploads owned by the acting
principal, with ledger/scratch custody in the isolated engine. Unsupported video
and uncoupled column-world media identities remain named.

For escalation advice, a role-protected appointer is an explicit delegation
boundary; conferring a different role is not by itself evidence of escalation.
Independent role-value intent may restrict that boundary (for example a producer
must not confer legal). Ordinary role casts make service-seat equality false,
including inside operation requirements. Fixed literals still undergo the privilege comparison; ordinary enrollment
whose rules add no role-specific authority is not advised. Analyze caller-chosen
roles, defaulted inserted authority and owner-field upgrades; respect the
argument's actual enum choices. A fixed bootstrap that can appoint further
roles remains an actionable first-admin risk. Notes remain advisory; absence
of independent intent is not proof that a delegation matches the specification.

### 12.8 Runtime intent and independent worlds

Reference-hop intent is judged by the engine's own authorized RuleProbe and
three-valued verdict on an isolated actual snapshot. Hidden/missing references
remain Unknown, never false; snapshot-only evaluators decline those terms.
Temporal reference policies require a per-tick authorized replay and remain
explicitly unsupported until that path runs. Referenced immutable-column worlds
use fresh stores with copied verified asset ledgers and all authored base rows,
then ordinary seed validation/recomputed maintenance. They do not require a
legal delete transition. Every non-protected base field, capture, row identity
and row population must match before comparing observations.

Implicit stability includes source and member writes to row-keyed views,
maintained owner columns, through-parent effects and transitive cascade/set-null.
Only an actual direct delete can refute delete authority; commit-end expiry is
not relabeled a deletion by the caller. Defaulted upsert roles are analyzed on
the insert arm only; omitted fields are preserved on update. Revocability advice
requires an expanded write to a mutable role field or an admitted deletion,
not an unrelated display-name update.

For a write history, a stable necessary policy component may establish a
violation despite another changing conjunct. Replace unstable atoms (or an
entire unstable negation) by Allow, retaining And/Or composition; separately
verify `original => weakened` with the existing exhaustive kernel. Denial of
that weakened condition establishes denial of the original, never its proof.
Stability includes transitive read-authority dependencies of referenced rows.
Do not use this reduction when implicit writes can change the target image or
executed arm. This catches a demoted recorder whose role stays false even when
another statement updates an unrelated field on its parent. No new axiom is
introduced. Id-column presence/count intent shares the row identity observer
path; arbitrary untyped matching ids do not establish a payload witness.

Independent intent binds authorized reference operands without installing a
runtime read gate; live-hop restrictions on executable read rules do not remove

history state rechecks row assertions, including unchanged rows whose related
policy rows changed; pre-existing unchanged seed violations stay supplemental.
Role advice expands helpers with lexical argument substitution and dominating
requirements, retaining the actual write source site. Constant defaults and
literal assignments use the same authority comparison. Optional-column pairs
vary both values and null presence to observe value-existence aggregates.

Mutation column observers include transitive read-authority dependencies and
implicit targets when establishing policy stability. Role probes normalize
unique-key components and extra equalities identically. Argument-domain
narrowing follows the resolved argument expression, never a coincidentally
same-named argument beside a literal assignment. An unconditional helper call
exports its guaranteed requirement prefix to subsequent caller writes;
conditional/loop-local requirements do not become caller assumptions.

Column observers first judge authorized intent on the validated primary world
once per actor. They share a 16384-call campaign budget (including repeatability
and declined worlds), with explicit remaining-world coverage when exhausted.
The budget cannot discharge an obligation or turn an unproved path into proof.

principal column after a role does not. Lifetime advice therefore requires an
independent current-role invariant as well as an authored revocation writer.
The missing-intent note covers schemas without that specification. Global role
advice requires a principal/role unique roster; per-resource context keys need
a separate delegation reduction. Delegation guards constrain the actual role

For fixed ordinary enrollment, row-scoped permissions alone do not warrant
escalation advice. Without contrary independent intent, a fixed assignment
requires new unconditional read/delete or roster authority to emit the note;
caller-chosen roles retain the broader effect comparison. This advisory is not
an all-operation reachability theorem; scoped-resource delegation and fixed

The report keeps the shortest reachable witness. Campaigns can also retain

History read observers first select compiler-typed row-return candidates or the

Fixed-role comparison retains any additional probe context as an opaque

pub(super) fn bind(catalog: &Catalog, diagnostics: &mut Vec<Diagnostic>) -> Vec<Invariant> {
    let mut out=Vec::new();
    for decl in catalog.documents.iter().flat_map(|d| &d.invariants) {
        let Some(info)=catalog.tables.get(&decl.table) else {
            diagnostics.push(Diagnostic::new(&decl.site,"E_SECURITY_TARGET",format!("invariant names unknown table {}",decl.table),"declare the table or correct its name").guide("security")); continue;
        };
        let named_operation=operation::resolve(catalog,decl);
        if (!matches!(decl.target.as_str(),"read"|"insert"|"update"|"delete"|"write"|"always") && named_operation.is_none())
            || decl.column.as_ref().is_some_and(|c|c!="id"&&!info.columns.contains_key(c)) {
            diagnostics.push(Diagnostic::new(&decl.site,"E_SECURITY_TARGET","invariant needs a declared column or table effect","use invariant table.read only <policy>, table.column write only <policy>, or table always <predicate>").guide("security")); continue;
        }
        let effect=match decl.target.as_str(){"insert"=>ast::Effect::Insert,"update"|"write"=>ast::Effect::Update,"delete"=>ast::Effect::Delete,_=>ast::Effect::Read};
        // Independent intent may use authorized reference operands even when a
        // runtime read gate must use captured authority. It never installs a gate.
        let effect=if effect==ast::Effect::Read{ast::Effect::Insert}else{effect};
        let rule=ast::RuleDecl{effect,bindings:Vec::new(),value:decl.value.clone(),site:decl.site.clone()};
        let (policy,unsupported)=match super::schema::bind_rule(catalog,info,&rule) {
            Ok(rule)=>(Some(rule),None),Err(error)=>match temporal::bind(catalog,info,&decl.value) {
                Some(rule) if decl.target=="read" => (Some(rule),None),
                _ => (None,Some(format!("policy outside rule proof fragment: {} ({})",error.message,error.code))),
            },
        };
        let requirements=named_operation.as_ref().map(|(_,p)| operation::requirements(catalog,info,p)).unwrap_or_default();
        out.push(Invariant{operation:named_operation.map(|(name,_)|name),requirements,syntax:Some(decl.value.clone()),table:decl.table.clone(),target:decl.target.clone(),column:decl.column.clone(),predicate:crate::print::expression(&decl.value),site:decl.site.clone(),policy,unsupported});
    }
    out
}

            // including seed/adoption, with no assumption about a writer.

            };

                // immutable local fields have the equal-image substitution;
                // owner-field and implicit writers remain separate blockers.
            }
        }

        verdicts.push(Verdict{invariant:inv.clone(),status,direct_rule:direct,paths,reasons,counterexample:None,obligations});

    let missing=adoption::missing(bound);
    if !missing.is_empty() {notes.push(Diagnostic::new(&Site::default(),"N_SECURITY_INTENT",format!("{} tables have access rules and no security invariants: {}; declare the spec's privacy rules as invariants (`guide security`)",missing.len(),missing.join(", ")),"review snapback/generated/security-invariants.q.draft against the spec; candidates are never auto-accepted").guide("security"));}
    let roles=audit::roles(&exposures);
    let uncovered=adoption::uncovered(bound,&exposures);
    Report{format:1,scope:"logical row/authority intent; all database snapshots; ordinary authenticated viewers including service seats; explicit unproved paths".into(),

}
fn blockers(bound:&Bound,inv:&Invariant)->Vec<String> {

    }

//! Equal-image substitution only for engine-enforced immutable local fields.
// @ref LLP 3000.036.004#111-avoid-duplicate-concrete-searches — no reference or mutable-field equality is assumed.
use super::*;
use snapback4_core::schema::{Table,Constraint};

pub(super) fn stable(table:&Table,rule:&RuleExpr)->RuleExpr{
    fn term(table:&Table,value:&mut RuleTerm){
        if let RuleTerm::OldField(field)=value && (field=="id"||table.constraints.iter().any(|c|matches!(c,Constraint::Immutable{fields} if fields.contains(field)))) {
            *value=RuleTerm::Field(field.clone());
        }
    }
    fn walk(table:&Table,rule:&mut RuleExpr){match rule{
        RuleExpr::Eq(a,b)|RuleExpr::Ne(a,b)|RuleExpr::Compare(_,a,b)=>{term(table,a);term(table,b);},
        RuleExpr::Exists{key,equalities,..}|RuleExpr::Created{key,equalities,..}=>{
            for value in key.iter_mut().chain(equalities.iter_mut().map(|(_,t)|t)){term(table,value);}
        },
        RuleExpr::And(xs)|RuleExpr::Or(xs)=>for rule in xs{walk(table,rule)},
        RuleExpr::Not(rule)=>walk(table,rule),
        RuleExpr::Allow|RuleExpr::Deny|RuleExpr::Public{..}=>{},
    }}
    let mut out=rule.clone();walk(table,&mut out);out
}
pub(super) fn update(table:&Table,policy:&RuleExpr)->Result<bool,String>{
    kernel::implies(&stable(table,&table.update_rule_judged()),&stable(table,&policy.old_and_next()))
}
//! Finite three-valued implication, deliberately independent of database facts.
// @ref LLP 3000.036.004#3-sound-proof-boundary — impossible valuations overapproximate all snapshots.
use snapback4_core::schema::{RuleExpr as R, RuleTerm as T};
use std::collections::BTreeSet;

pub const MAX_ATOMS: usize = 10;
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Truth { Yes, No, Unknown }
impl Truth {
    fn not(self) -> Self { match self { Self::Yes => Self::No, Self::No => Self::Yes, Self::Unknown => Self::Unknown } }
    fn combine(self, other: Self, and: bool) -> Self {
        let decisive = if and { Self::No } else { Self::Yes };
        if self == decisive || other == decisive { decisive }
        else if self == Self::Unknown || other == Self::Unknown { Self::Unknown }
        else { decisive.not() }
    }
}
#[derive(Clone, Debug)]
enum Formula { Constant(Truth), Atom(usize), Not(Box<Self>), And(Vec<Self>), Or(Vec<Self>) }
impl Formula {
    fn eval(&self, values: &[Truth]) -> Truth {
        match self {
            Self::Constant(v) => *v, Self::Atom(n) => values[*n], Self::Not(x) => x.eval(values).not(),
            Self::And(xs) => xs.iter().fold(Truth::Yes, |v, x| v.combine(x.eval(values), true)),
            Self::Or(xs) => xs.iter().fold(Truth::No, |v, x| v.combine(x.eval(values), false)),
        }
    }
}
fn term(t: &T) -> T { match t { T::NextField(f) => T::Field(f.clone()), other => other.clone() } }
fn atom(rule: &R) -> String {
    let mut r = rule.clone();
    match &mut r {
        R::Eq(a,b) | R::Compare(_,a,b) => { *a=term(a); *b=term(b); }
        R::Exists { key, equalities, .. } | R::Created { key, equalities, .. } => {
            for t in key { *t=term(t); }
            for (_,t) in equalities.iter_mut() { *t=term(t); }
            equalities.sort_by(|a,b| a.0.cmp(&b.0));
        }
        _ => {}
    }
    if let R::Eq(a,b)=&mut r && serde_json::to_string(a).unwrap()>serde_json::to_string(b).unwrap() { std::mem::swap(a,b); }
    let mut json=serde_json::to_value(&r).unwrap();
    // Provenance controls planning, not rule evaluation. Remove only this
    // leaf's metadata, never a similarly named literal-object field.
    for name in ["Exists","Created"] { if let Some(body)=json.get_mut(name).and_then(serde_json::Value::as_object_mut) { body.remove("provenance"); } }
    json.to_string()
}
fn formula(rule: &R, atoms: &mut Vec<String>, nodes: &mut usize) -> Result<Formula, String> {
    *nodes+=1; if *nodes>1024 { return Err("formula exceeds 1024 nodes".into()); }
    Ok(match rule {
        R::Allow | R::Public {..} => Formula::Constant(Truth::Yes), R::Deny => Formula::Constant(Truth::No),
        R::And(xs) => Formula::And(xs.iter().map(|r| formula(r,atoms,nodes)).collect::<Result<_,_>>()?),
        R::Or(xs) => Formula::Or(xs.iter().map(|r| formula(r,atoms,nodes)).collect::<Result<_,_>>()?),
        R::Not(x) => Formula::Not(Box::new(formula(x,atoms,nodes)?)),
        R::Ne(a,b) => Formula::Not(Box::new(formula(&R::Eq(a.clone(),b.clone()),atoms,nodes)?)),
        R::Eq(T::Literal(a),T::Literal(b)) => Formula::Constant(if a==b {Truth::Yes}else{Truth::No}),
        R::Eq(T::Viewer,T::Viewer) => Formula::Constant(Truth::Yes),
        other => { let key=atom(other); let n=atoms.iter().position(|a| a==&key).unwrap_or_else(|| {atoms.push(key);atoms.len()-1});
            if atoms.len()>MAX_ATOMS {return Err(format!("more than {MAX_ATOMS} independent predicates"));} Formula::Atom(n) }
    })
}
/// `Ok(true)` is a proof; `Ok(false)` is only an abstract countermodel.
/// Neither limit exhaustion nor a countermodel is a concrete refutation.
pub fn implies(admission: &R, policy: &R) -> Result<bool,String> {
    let (mut atoms,mut nodes)=(Vec::new(),0);
    let a=formula(admission,&mut atoms,&mut nodes)?;
    let p=formula(policy,&mut atoms,&mut nodes)?;
    let mut values=vec![Truth::Unknown;atoms.len()];
    for mut n in 0..3usize.pow(atoms.len() as u32) {
        for v in &mut values { *v=match n%3 {0=>Truth::Yes,1=>Truth::No,_=>Truth::Unknown}; n/=3; }
        if a.eval(&values)==Truth::Yes && p.eval(&values)!=Truth::Yes { return Ok(false); }
    }
    Ok(true)
}
pub fn dependencies(rule: &R) -> BTreeSet<String> {
    let mut out=BTreeSet::new();
    match rule {
        R::Exists{table,key,equalities,..}|R::Created{table,key,equalities,..} => {out.insert(table.clone());for term in key.iter().chain(equalities.iter().map(|(_,t)|t)){for (table,_) in term.references(){out.insert(table.into());}}}
        R::And(xs)|R::Or(xs) => for x in xs {out.extend(dependencies(x));}, R::Not(x) => out.extend(dependencies(x)),
        R::Eq(a,b)|R::Ne(a,b)|R::Compare(_,a,b) => for t in [a,b] { for (table,_) in t.references() {out.insert(table.into());} },
        _=>{}
    }
    out
}

pub(super) fn prove(bound:&Bound,inv:&Invariant)->Result<bool,String>{
    let p=bound.programs.iter().find(|p|Some(&p.program.name)==inv.operation.as_ref()).ok_or("operation did not bind")?;

    let writes=snapback4_core::ir::write_tables(&p.program);
    if !writes.iter().any(|(t,_)|t==&inv.table){return Err("operation has no direct write to the named table; implicit effects require a reduction".into());}
    let dependencies=inv.requirements.iter().flat_map(kernel::dependencies).collect::<BTreeSet<_>>();
    if writes.iter().any(|(t,_)|dependencies.contains(t)) {return Err("require dependency can be changed by this operation, including its target write".into());}

    // Source helpers/control flow may hide write sets or viewer changes.
    let json=serde_json::to_value(&p.program).unwrap();
    fn opaque(v:&serde_json::Value)->bool{match v{serde_json::Value::Object(m)=>m.keys().any(|k|matches!(k.as_str(),"For"|"If"|"JobAs"|"JobQuery"|"Emit"))||m.values().any(opaque),serde_json::Value::Array(xs)=>xs.iter().any(opaque),_=>false}}

    let admission=RuleExpr::And(inv.requirements.clone());
    // Table-rule gates can only further restrict a dominating stable require;
    // using the require alone overapproximates effective owner-field gates.
    kernel::implies(&admission,inv.policy.as_ref().unwrap())
}

//! Paired logical observations, replayed independently in memory.
// @ref LLP 3000.036.004#101-separate-observer-obligations — two valid worlds and repeatable observations are required.
use super::*;

#[derive(Clone,Debug,Serialize)]
pub struct Observations {
    pub present: serde_json::Value,
    pub absent: serde_json::Value,
    pub absent_rows: BTreeMap<String,Vec<Value>>,
}

pub(super) fn observe(engine:&mut Engine,p:&Program,viewer:&str,args:BTreeMap<String,Value>)->Result<serde_json::Value,String>{
    let context=Context::new(viewer,args).at(NOW);
    if p.kind==ProgramKind::Query {
        match engine.query(&p.name,context) {
            Ok(q) if q.unavailable || !q.complete => Err("incomplete/metered query is outside logical payload comparison".into()),
            Ok(q)=>serde_json::to_value(&q.data).map_err(|e|e.to_string()),
            Err(e)=>Err(format!("query error is not an admitted observation: {e}")),
        }
    }else{
        match engine.mutate(&p.name,None,context).map_err(|e|e.to_string())?.state {
            snapback4_core::WriteState::Sent{result,..}=>Ok(serde_json::json!({"sent":result})),
            snapback4_core::WriteState::Failed{why,current}=>{
                // E_RULE can also mask authorization-budget exhaustion. Only
                // an authored require/constraint carries this rule marker;
                // bound/storage/schema/ambiguous engine refusals cannot be a
                // logical counterexample in our resource-excluding contract.
                if why.rule.is_none()||!matches!(why.family.as_str(),"rule"|"constraint") {
                    return Err(format!("resource/engine or ambiguous mutation refusal {} is outside paired logical comparison",why.code));
                }
                Ok(serde_json::json!({"refusal":{"code":why.code,"message":why.message},"current":current}))
            },
        }
    }
}

                        // committed world, before any operation can change roles.
                        let focal=actual.get(&inv.table).into_iter().flatten().find(|r|r.field("id").ok()==row.field("id").ok()).cloned().unwrap_or_else(||row.clone());
                        if policy_in(bound,inv,&actual,viewer,None,&focal,&mut e)!=Ok(false){return Err("paired policy is not definitely false in both worlds".into());}
                        observe(&mut e,p,viewer,args.clone()).map(|value|(value,actual))
                    };
                    let ((a,rows),(b,absent_rows))=match (execute(&present),execute(&absent)) {
                        (Ok(a),Ok(b))=>(a,b),
                        (Err(e),_)|(_,Err(e))=>{

                            continue;
                        },
                    };

                    if a==b {continue;}
                    // The query order is engine-defined. Recreate both worlds
                    // to decline store-scoped cursors or unstable outputs.
                    if !matches!((execute(&present),execute(&absent)),(Ok((aa,_)),Ok((bb,_))) if aa==a&&bb==b){
                        out.unsupported.insert(format!("{}: paired observation is not repeatable",p.name));continue;
                    }
                    out.violations.push(Counterexample {reachability:Reachability::SyntheticOperation,history:Vec::new(),invariant_site:inv.site.to_string(),args:args.clone(),viewer:viewer.into(),
                        operation:p.name.clone(),effect:"read observation".into(),row:row.clone(),old:None,supporting_rows:rows,
                        rule_path:"paired present/absent engine executions differ while the declared privacy policy is false in both".into(),
                        scope:"schema-valid seed-ingress paired worlds; authenticated logical data/refusal only; no application reachability claim".into(),
                        observations:Some(Observations{present:a,absent:b,absent_rows})});
                    break;
                }
                if out.violations.iter().any(|v|v.invariant_site==inv.site.to_string()&&v.observations.is_some()){break;}
            }
            if out.violations.iter().any(|v|v.invariant_site==inv.site.to_string()&&v.observations.is_some()){break;}
        }
    }
    out.unsupported.insert("paired observations exclude wire sequences/receipts, physical timing and resource/meter differences; HTTP and device histories require separate qualification".into());
}

            }

    }
}

fn role_candidates<'a>(bound:&Bound,p:&'a Program,initial:&BTreeMap<String,Vec<Value>>,actors:&[String],cases:&[BTreeMap<String,Value>],fixture:&Engine)->Vec<(&'a Program,String,BTreeMap<String,Value>)>{

    for (table,_) in ir::write_tables(p){
        let columns=super::super::privilege::role_columns(bound,&table);
        if !columns.iter().any(|c|json.contains(&format!("\"{c}\":"))){continue;}
        let t=&bound.schema.tables[&table];
        for row in initial.get(&table).into_iter().flatten(){
            let principal=t.columns.iter().find_map(|(c,k)|matches!(k.required(),C::Principal).then(||row.field(c).ok()).flatten());
            let Some(principal)=principal else{continue;};
            let mut targets=Vec::new();
            for case in cases{
                let mut args=case.clone();
                for (name,kind) in &p.args{match kind{
                    ir::ArgType::Principal=>{args.insert(name.clone(),principal.clone());},
                    ir::ArgType::Ref{table:target} if target==&table=>{if let Ok(id)=row.field("id"){args.insert(name.clone(),id.clone());}},_=>{}
                }}
                if !targets.contains(&args){targets.push(args);}
            }
            let mut row_cases=Vec::new();
            for actor in actors{
                let owner=columns.iter().filter_map(|c|t.written_by.get(c)).any(|a|row.field(&a.owner).ok()==Some(&Value::Id(actor.clone())));
                let gate=judge.fixture_policy(&t.update_rule_judged(),actor,Some(row),row,NOW).ok();
                if !owner&&gate!=Some(rules::Verdict::Readable){continue;}
                for args in &targets{row_cases.push((p,actor.clone(),args.clone()));}
            }
            groups.push(row_cases);
        }
    }
    for n in 0..groups.iter().map(Vec::len).max().unwrap_or(0){for g in &groups{if let Some(case)=g.get(n){out.push(case.clone());}}}
    out
}
pub(super) fn run(bound:&Bound,fixture:&Engine,out:&mut Campaign){
    if bound.invariants.is_empty(){return;}
    let initial=match readback(fixture){Ok(r)=>r,Err(e)=>{out.unsupported.insert(e);return;}};
    if initial.values().all(Vec::is_empty){out.unsupported.insert("history needs a trusted fixture; generated snapshots have separate reachability labels".into());return;}
    if initial.values().map(Vec::len).sum::<usize>()>1000{out.unsupported.insert("history fixture exceeds 1000 rows".into());return;}
    let actors=actors(bound,&initial);
    let probes=Vec::new();
    let mut groups=Vec::new();
    for bp in bound.programs.iter().filter(|p|p.program.kind==ProgramKind::Mutation&&!p.program.native){
        let cases=fixture_cases(&bp.program.args,&initial,&actors,out);
        let mut group=role_candidates(bound,&bp.program,&initial,&actors,&cases,fixture);
        // Diagonal order gives both actors and argument values an early turn.
        for shift in 0..actors.len(){for n in 0..cases.len().max(actors.len()){
            if cases.is_empty(){break;}
            group.push((&bp.program,actors[(n+shift)%actors.len()].clone(),cases[n%cases.len()].clone()));
        }}
        if !group.is_empty(){groups.push(group);}
    }
    let mut candidates=Vec::new();
    for n in 0..groups.iter().map(Vec::len).max().unwrap_or(0){for g in &groups{if let Some(c)=g.get(n){candidates.push(c.clone());}}}
    let mut base=match fork(bound,fixture,probes.clone()){Ok(e)=>e,Err(e)=>{out.unsupported.insert(e);return;}};
    for inv in bound.invariants.iter().filter(|i|i.target=="always"){
        for row in initial.get(&inv.table).into_iter().flatten(){for viewer in &actors{
            if policy_in(bound,inv,&initial,viewer,None,row,&mut base)!=Ok(false){continue;}
            let mut witness=Campaign::default();violation(&mut witness,inv,&[],viewer,row,None,&initial,"always");
            if let Some(mut v)=witness.violations.pop(){v.reachability=Reachability::TrustedSeedOnly;v.operation="$fixture.assertion".into();v.rule_path="initial trusted fixture assertion; no authored mutation".into();v.scope="definite violation in trusted seed; no authored transition claimed; non-failing supplemental evidence".into();out.violations.push(v);}break;
        }}
    }
    observe(bound,&mut base,&initial,&initial,&actors,&[],out);
    // Breadth first, then diagonal pairs: no first step monopolizes the cap.
    let singles=candidates.len().min(LIMIT);
    for n in 0..singles+LIMIT {
        let indices=if n<singles{vec![n]}else if candidates.is_empty(){break;}else{let k=n-singles;vec![k%candidates.len(),(k/candidates.len()+k+1)%candidates.len()]};
        let mut engine=match fork(bound,fixture,probes.clone()){Ok(e)=>e,Err(e)=>{out.unsupported.insert(e);break;}};
        out.sequences+=1;let mut steps=Vec::new();
        for i in indices{
            let (p,viewer,args)=&candidates[i];let before=match readback(&engine){Ok(r)=>r,Err(e)=>{out.unsupported.insert(e);break;}};
            let args=match materialize_arguments(&mut engine,&p.args,args,viewer){Ok(a)=>a,Err(why)=>{out.unsupported.insert(format!("{}: history asset arguments: {why}",p.name));break;}};
            let mut prior=if bound.invariants.iter().any(|i|i.target!="read"&&i.policy.as_ref().is_some_and(RuleExpr::has_reference)){match fork(bound,&engine,Vec::new()){Ok(e)=>Some(e),Err(why)=>{out.unsupported.insert(why);None}}}else{None};
            out.attempted+=1;*out.operations.entry(p.name.clone()).or_default()+=1;
            match engine.mutate(&p.name,None,Context::new(viewer,args.clone()).at(NOW)){
                Ok(result)=>{
                    let sent=matches!(result.state,snapback4_core::WriteState::Sent{..});
                    steps.push(Step{operation:p.name.clone(),viewer:viewer.clone(),args:args.clone(),result:serde_json::to_value(&result.state).unwrap()});
                    let after=match readback(&engine){Ok(r)=>r,Err(e)=>{out.unsupported.insert(e);break;}};
                    if sent{changed(bound,p,&before,&after,&initial,viewer,&steps,&mut prior,&mut engine,out);}else{out.refused+=1;}
                    if sent&&before!=after{observe(bound,&mut engine,&after,&initial,&actors,&steps,out);column_reads::after_history(bound,&engine,&initial,&steps,out);}
                },Err(e)=>{out.unsupported.insert(format!("{}: history engine error {e}",p.name));break;}
            }
        }
    }
    out.unsupported.insert("history breadth/pairs bounded to 512; unvisited and longer traces remain uncovered".into());
}

    }
    Ok((true,next))
}

        for m in &bound.schema.maintains{if affected.contains(&m.source)||m.row_key.as_ref().is_some_and(|r|affected.contains(&r.table)){
            if bound.schema.table(&m.target).is_some(){implicit.insert(m.target.clone());affected.insert(m.target.clone());}
            if let Some(owner)=&m.private{implicit.insert(owner.table.clone());affected.insert(owner.table.clone());}
        }}
        for (name,t) in &bound.schema.tables{
            if t.through.as_ref().is_some_and(|edge|edge.live.is_some()&&affected.contains(&edge.parent)){implicit.insert(name.clone());affected.insert(name.clone());}
            for (column,action) in &t.on_delete{
            if action.writes()&&let Some(C::Ref{table})=t.columns.get(column).map(C::required)&&affected.contains(table){implicit.insert(name.clone());affected.insert(name.clone());}
        }}
        if before==affected.len(){break;}
    }implicit
}

pub(super) fn dependencies(bound:&Bound,rule:&RuleExpr)->BTreeSet<String>{
    let mut deps=kernel::dependencies(rule);
    loop{let before=deps.len();for name in deps.clone(){if let Some(t)=bound.schema.table(&name){deps.extend(kernel::dependencies(&t.rules.read));if let Some(edge)=&t.through{deps.insert(edge.parent.clone());}}}if before==deps.len(){return deps;}}
}
/// A stable necessary condition may refute an intent even when another
/// conjunct changes. Dropping a requirement never proves the full policy.
pub(super) fn necessary(bound:&Bound,p:&Program,inv:&Invariant)->Option<Invariant>{
    let policy=inv.policy.as_ref()?;let implicit=implicit(bound,p);
    if implicit.contains(&inv.table){return None;}
    let mut changed=implicit;
    changed.extend(ir::write_tables(p).into_iter().filter(|(t,_)|t!=&inv.table).map(|(t,_)|t));
    fn weak(bound:&Bound,r:&RuleExpr,changed:&BTreeSet<String>)->RuleExpr{
        match r{
            RuleExpr::And(xs)=>RuleExpr::And(xs.iter().map(|r|weak(bound,r,changed)).collect()),
            RuleExpr::Or(xs)=>RuleExpr::Or(xs.iter().map(|r|weak(bound,r,changed)).collect()),
            _ if dependencies(bound,r).iter().any(|d|changed.contains(d))=>RuleExpr::Allow,
            _=>r.clone(),
        }
    }
    let weaker=weak(bound,policy,&changed);
    if kernel::implies(policy,&weaker)!=Ok(true){return None;}
    let mut judged=inv.clone();judged.policy=Some(weaker);Some(judged)
}
//! A campaign fork retains activated semantics without running adoption again.
use super::*;
impl Engine {
    // @ref LLP 3000.036.004#122-reproducible-campaigns-and-reachability — isolation includes entropy, assets and ephemeral ownership.
    pub fn fork_fixture(&self) -> Result<Self, RuntimeError> {
        if self.schema.tables.values().any(|t|t.ephemeral.is_some()) {
            return Err(RuntimeError::Schema("fixture fork needs an isolated ephemeral-hub snapshot".into()));
        }
        if self.presence.is_some(){return Err(RuntimeError::Schema("fixture fork needs an isolated external presence snapshot".into()));}
        let store=self.store.fork_memory()?;
        let identity=store.meta("store_id")?.ok_or_else(||RuntimeError::Store("fixture store has no identity".into()))?;
        Ok(Self {
            timeline_schedule:timeline::Schedule::default(),
            ephemeral:std::sync::Arc::new(ephemeral::Hub::new(identity,self.generation,&self.schema)),
            store,schema:self.schema.clone(),programs:self.programs.clone(),ceilings:self.ceilings,
            entropy:crate::ids::seed(),minter:crate::ids::Mint::default(),generation:self.generation,
            expiry_after:self.expiry_after.clone(),dev_effects:self.dev_effects,
            #[cfg(feature="native")] native:self.native.clone(),
            #[cfg(feature="native")] native_logs:native::Logs::default(),presence:None,
        })
    }
}

impl Engine {
    /// Judge independent fixture intent with the engine's authorized rule hops.
    pub fn fixture_policy(&mut self,rule:&crate::schema::RuleExpr,viewer:&str,old:Option<&Value>,next:&Value,now:i64)->Result<rules::Verdict,RuntimeError>{
        let tx=self.store.read_transaction()?;
        let context=if viewer==crate::SYSTEM_PRINCIPAL{Context::system()}else{Context::new(viewer,BTreeMap::new())};
        let mut runner=Runner::new(&tx,&self.schema,context.at(now),Meter::new(Ceilings::unbounded(),Cut::Abort),0);
        let bytes=runner.rule_scratch(rule);
        runner.authorized_scratch(bytes,&[],|runner,allowance|{
            let mut probe=read::RuleProbe{runner,allowance};
            rules::evaluate_verdict(rule,viewer,old,next,false,&mut probe)
        })
    }
}
//! Isolated complete fixtures, including captured authority and asset ownership.
use super::*;
impl Store {
    // @ref LLP 3000.036.004#122-reproducible-campaigns-and-reachability — fork committed state, never reinterpret stored rows as new seed input.
    pub fn fork_memory(&self) -> Result<Self, RuntimeError> {
        let mut fork = Self::memory()?;
        {
            let backup = rusqlite::backup::Backup::new(&self.conn, &mut fork.conn)?;
            backup.run_to_completion(256, std::time::Duration::ZERO, None)?;
        }
        fork.catalog = self.catalog.clone();
        fork.identity = self.identity.clone();
        fork.server = self.server;
        if self.assets_dir.exists() {
            std::fs::create_dir_all(&fork.assets_dir).map_err(io)?;
            for entry in std::fs::read_dir(&self.assets_dir).map_err(io)? {
                let entry = entry.map_err(io)?;
                if !entry.file_type().map_err(io)?.is_file() {
                    return Err(RuntimeError::Store("fixture asset ledger contains a non-file".into()));
                }
                std::fs::copy(entry.path(), fork.assets_dir.join(entry.file_name())).map_err(io)?;
            }
        }
        Ok(fork)
    }
}

fn io(e:std::io::Error)->RuntimeError {RuntimeError::Store(e.to_string())}

impl Store {
    /// Independent valid worlds share verified bytes, never source row state.
    pub fn empty_with_asset_ledger(&self)->Result<Self,RuntimeError>{
        let fresh=Self::memory()?;
        let ids=self.conn.prepare("SELECT id FROM _assets")?.query_map([],|r|r.get::<_,String>(0))?.collect::<Result<Vec<_>,_>>()?;
        for id in ids{
            let mut asset=self.asset(&id)?.ok_or_else(||RuntimeError::Store("fixture asset disappeared".into()))?;
            asset.home=None;asset.released_at=None;
            fresh.record_asset(&asset)?;
        }
        if self.assets_dir.exists(){
            std::fs::create_dir_all(&fresh.assets_dir).map_err(io)?;
            for entry in std::fs::read_dir(&self.assets_dir).map_err(io)?{
                let entry=entry.map_err(io)?;
                if !entry.file_type().map_err(io)?.is_file(){return Err(RuntimeError::Store("fixture asset is not a regular file".into()));}
                std::fs::copy(entry.path(),fresh.assets_dir.join(entry.file_name())).map_err(io)?;
            }
        }
        Ok(fresh)
    }
}

    let text = std::fs::read_to_string(path).map_err(|error| format!("cannot read {}: {error}", path.display()))?;

            // from the data: a reference is a row of its table, preferring

            if candidates.is_empty() {

                    for (arg, kind) in &program.program.args {
                        match sample_arg(&engine, kind, &principal, at) {
                            Some(value) => { args.insert(arg.clone(), value); }

                            None => {}
                        }
                    }
                    if !missing.is_empty() { break; }
                    candidates.push((args, None));
                }
            }

            }
            // The first answer with rows wins; else the first answer; else the first refusal.
            let mut chosen: Option<(usize, BTreeMap<String, snapback4_core::Value>, Option<&str>, Result<snapback4_core::QueryOutcome, snapback4_core::Refusal>, f64)> = None;
            let tried = candidates.len();
            for (args, source) in candidates {
                let started = Instant::now();
                let result = engine.query(name, Context::new(principal.clone(), args.clone()).at(fixture_now));
                let ms = started.elapsed().as_secs_f64() * 1000.0;
                let rank = match &result { Ok(outcome) if !empty_answer(&outcome.data) => 0, Ok(_) => 1, Err(_) => 2 };
                if chosen.as_ref().is_none_or(|(best, ..)| rank < *best) { chosen = Some((rank, args, source, result, ms)); }
                if rank == 0 || source.is_some() { break; }
            }
            let Some((rank, args, source, result, ms)) = chosen else { continue };
            let shown = if args.is_empty() { String::new() } else { format!(" {}", serde_json::to_string(&args.iter().map(|(k, v)| (k.clone(), wire::to_json(v))).collect::<serde_json::Map<_, _>>()).unwrap_or_default()) };

            let shown = match source { Some(at) => format!("{shown} (from {at})"), None => shown };
            let derived = !args.is_empty() && source.is_none();
            let label = format!("{name} ({persona})");
            match result {
                Ok(outcome) => {
                    let m = outcome.metered;
                    let state = if outcome.complete { "complete" } else { "capped" };
                    if outcome.complete { complete += 1 } else { capped += 1 }
                    // @ref LLP 3000.007#20.22.1 — report approach to a ceiling on the fixture, separately from actual cuts.
                    if outcome.capped_at.is_none() && outcome.word_cut_at.is_none() {
                        if let Some(cost) = crate::serve::read_cost::near_ceiling(m, ceilings) { near.push(format!("{label} {cost}")); }

fn expression(catalog:&Catalog,p:&ProgramDecl,expr:&Expr,env:&Env,guards:&[Stmt],depth:usize,out:&mut Vec<(Expr,ProgramDecl)>){

        Expr::Write{..}=>{let mut context=p.clone();context.prelude=Vec::new();context.body=guards.to_vec();out.push((e.clone(),context));},

// Only an unconditional direct call exports a helper's guaranteed prefix.
// Conditional/loop-local requirements never become caller assumptions.
fn helper_guards(catalog:&Catalog,expr:&Expr,env:&Env,depth:usize)->Vec<Stmt>{
    if depth>=32{return Vec::new();}
    let Expr::Call{name,args,..}=resolve(expr,env)else{return Vec::new();};
    let Some(f)=catalog.functions.get(&name)else{return Vec::new();};
    let mut locals=f.args.iter().zip(args).map(|(a,v)|(a.name.clone(),v)).collect::<Env>();
    let FunctionBody::Block(body)=&f.body else{return if let FunctionBody::Expression(value)=&f.body{helper_guards(catalog,value,&locals,depth+1)}else{Vec::new()};};
    let mut out=Vec::new();
    for s in body{match s{
        Stmt::Require{condition,code,message,site}=>out.push(Stmt::Require{condition:resolve(condition,&locals),code:code.clone(),message:message.clone(),site:site.clone()}),
        Stmt::Bind{names,value,..}=>{out.extend(helper_guards(catalog,value,&locals,depth+1));if names.len()==1{locals.insert(names[0].clone(),resolve(value,&locals));}},
        Stmt::Expr{value,..}=>out.extend(helper_guards(catalog,value,&locals,depth+1)),
        Stmt::Return{value,..}=>{out.extend(helper_guards(catalog,value,&locals,depth+1));break;},_=>break,
    }}out
}
fn statements(catalog:&Catalog,p:&ProgramDecl,body:&[Stmt],env:&mut Env,guards:&mut Vec<Stmt>,depth:usize,out:&mut Vec<(Expr,ProgramDecl)>){
    for s in body{match s{
        Stmt::Bind{names,value,..}=>{expression(catalog,p,value,env,guards,depth,out);guards.extend(helper_guards(catalog,value,env,0));if names.len()==1{env.insert(names[0].clone(),resolve(value,env));}},
        Stmt::Require{condition,code,message,site}=>{
            expression(catalog,p,condition,env,guards,depth,out);
            guards.push(Stmt::Require{condition:resolve(condition,env),code:code.clone(),message:message.clone(),site:site.clone()});
        },
        Stmt::Return{value,..}=>{expression(catalog,p,value,env,guards,depth,out);break;},
        Stmt::Expr{value,..}=>{expression(catalog,p,value,env,guards,depth,out);guards.extend(helper_guards(catalog,value,env,0));},
        Stmt::If{condition,then_body,else_body,..}=>{
            expression(catalog,p,condition,env,guards,depth,out);
            statements(catalog,p,then_body,&mut env.clone(),&mut guards.clone(),depth,out);
            statements(catalog,p,else_body,&mut env.clone(),&mut guards.clone(),depth,out);
        },
        Stmt::For{domain,name,body,..}=>{expression(catalog,p,domain,env,guards,depth,out);let mut local=env.clone();local.remove(name);statements(catalog,p,body,&mut local,&mut guards.clone(),depth,out);},
        Stmt::As{body,..}=>statements(catalog,p,body,&mut env.clone(),&mut guards.clone(),depth,out),_=>{}
    }}
}

                    let target=if tag=="DeleteTarget"{body.get("target").and_then(|v|v.get("table"))}else{body.get("table")};
                    if delete&&target.and_then(serde_json::Value::as_str)==Some(name){return true;}
                }}
                xs.values().any(|v|writes(v,name,roles,update,delete))
            },serde_json::Value::Array(xs)=>xs.iter().any(|v|writes(v,name,roles,update,delete)),_=>false,
        }
    }
    bound.programs.iter().any(|p|{
        let system=p.program.kind==snapback4_core::ir::ProgramKind::Job;
        let update=mutable&&(system||!matches!(t.rules.update,RuleExpr::Deny)||roles.iter().any(|c|t.written_by.contains_key(c)));
        let delete=system||!matches!(t.rules.delete,RuleExpr::Deny);
        writes(&serde_json::to_value(&p.program).unwrap(),name,&roles,update,delete)
    })
}
fn recipient_role(bound:&Bound,name:&str,branch:&RuleExpr,grant:Option<&str>,roster:&str,effect:&str)->bool{
    if bound.invariants.iter().any(|i|i.table==*name&&(i.target==effect||i.target=="write"&&matches!(effect,"insert"|"update"))&&i.policy.as_ref().is_some_and(|p|kernel::dependencies(p).contains(roster)&&role_test(bound,p)&&kernel::implies(branch,p)!=Ok(true))){return true;}
    let _=(branch,grant,roster);
    // Field names cannot establish a current-role contract. The missing-intent
    // note asks for that independent specification before lifetime advice.
    false
}
pub(super) fn notes(bound:&Bound,exposures:&[Exposure])->Vec<Diagnostic>{
    let mut notes=Vec::new();
    for (name,t) in bound.schema.visible_tables(){
        if t.rules.read.is_uniformly_readable(){note(&mut notes,&Site::default(),"N_BROAD_READ",format!("{name} is readable by every signed-in user: {}",t.rules.read.quarry()),"confirm the spec permits these columns and declare read intent; snapback4 audit lists inherited grants and their writers");}
        if let RuleExpr::Exists{table:roster,key,equalities,..}=&t.rules.read
            && equalities.is_empty()&&key.iter().any(|k|matches!(k,RuleTerm::Viewer)) {
            note(&mut notes,&Site::default(),"N_BROAD_READ",format!("{name} is readable by any signed-in user with a matching {roster} row; no particular role or row ownership is required"),"confirm that every roster member should see all these columns; declare intent from the privacy spec and inspect audit");
        }
        for (column,kind) in &t.columns {
            use snapback4_core::schema::ColumnType as C;
            if kind.contains_asset() && (kind.is_optional() || matches!(kind.required(),C::List{..}|C::ListRange{min:0,..})) {
                note(&mut notes,&Site::default(),"N_OPTIONAL_EVIDENCE",format!("{name}.{column} permits omitted or empty media evidence"),"if the spec requires evidence, declare a required image/file or [image] 1..N; otherwise retain optionality deliberately (guide security)");
            }
        }
        for leaf in rule_parts(&t.rules.insert) {
            if let RuleExpr::Created {table:parent,..}=leaf
                && bound.schema.table(parent).is_some_and(|p| p.rules.insert.disjuncts().iter().any(|r| matches!(r,RuleExpr::Allow|RuleExpr::Eq(RuleTerm::Field(_),RuleTerm::Viewer)|RuleExpr::Eq(RuleTerm::Viewer,RuleTerm::Field(_)))))
                && bound.schema.tables.values().any(|other| [&other.rules.read,&other.rules.insert,&other.rules.update,&other.rules.delete].iter().any(|r| rule_parts(r).iter().any(|r|matches!(r,RuleExpr::Exists{table,key,equalities,..} if table==name&&matches!(key.as_slice(),[RuleTerm::Viewer])&&equalities.is_empty())))) {
                note(&mut notes,&Site::default(),"N_VACUOUS_RULE",format!("{name}: `created {parent}` can bootstrap authority trusted globally by a viewer-only probe; a caller may create their own global administrator grant"),"provision global authority only through an operator/service seat or existing authorized admin; group creation must scope every later grant to that group (guide deploy, first-admin setup)");
            }
        }
        for (effect,rule) in [("read",&t.rules.read),("insert",&t.rules.insert),("update",&t.rules.update),("delete",&t.rules.delete)] {
          for branch in rule.disjuncts(){
            for dep in kernel::dependencies(branch){if let Some(g)=bound.schema.table(&dep) {
                let rosters=[&g.rules.insert,&g.rules.update].into_iter().flat_map(kernel::dependencies).filter(|r|r!=&dep&&mutable_role(bound,r)).collect::<BTreeSet<_>>();
                if rosters.iter().any(|r|recipient_role(bound,name,branch,Some(&dep),r,effect))&&(role_test(bound,&g.rules.insert)||role_test(bound,&g.rules.update)){
                    note(&mut notes,&Site::default(),"N_GRANT_OUTLIVES_ROLE",format!("{name}.{effect}: `{}` trusts retained {dep} grants while current role in {} can change",branch.quarry(),rosters.into_iter().collect::<Vec<_>>().join(", ")),"recheck the current role in this branch or revoke every derived grant transactionally on role changes; guide security");
                }
            }}
            let declared=bound.invariants.iter().filter(|i|i.table==*name&&(i.target==effect||i.target=="write"&&matches!(effect,"insert"|"update"))).filter_map(|i|i.policy.as_ref()).flat_map(kernel::dependencies).filter(|r|mutable_role(bound,r)).collect::<BTreeSet<_>>();
            if !reader_columns(branch).is_empty()&&declared.iter().any(|r|recipient_role(bound,name,branch,None,r,effect)) {
                note(&mut notes,&Site::default(),"N_GRANT_OUTLIVES_ROLE",format!("{name}.{effect}: principal branch `{}` does not recheck the declared mutable current role",branch.quarry()),"recheck the current role as well as principal attribution; guide security");
            }
          }
        }
    }
    // Inspect original syntax for argument flow and distinct authored codes.
    // Keeping lints outside Bound.notes preserves the compiler's existing
    // diagnostic contract; check/audit expose this security advice separately.
    let _=exposures;
    let mut retained=BTreeSet::new();
    notes.retain(|n|n.code!="N_GRANT_OUTLIVES_ROLE"||retained.insert(n.message.split(':').next().unwrap_or("").to_string()));
    notes
}

                    }

            let mut codes=Vec::new();refusals(&p.body,bound,&mut None,&mut codes);
            for (site,why) in codes.into_iter().take(1){note(&mut out,&site,"N_EXISTENCE_ORACLE",format!("{}: {why}; row readership is broader than declared private-existence intent",p.name),"use the same absence/denial code and message for private existence, or tighten the row audience");}
            if p.kind==ProgramKind::Job {
                fn guards(body:&[Stmt],out:&mut Vec<Expr>){for s in body {match s{
                    Stmt::Require{condition,..}=>out.push(condition.clone()),
                    Stmt::If{condition,then_body,else_body,..}=>{out.push(condition.clone());guards(then_body,out);guards(else_body,out);},
                    Stmt::For{body,..}|Stmt::As{body,..}=>guards(body,out),_=>{}
                }}}
                let mut job_guards=Vec::new();guards(&p.body,&mut job_guards);
                let clock=job_guards.iter().any(|g|{let mut g=g.clone();let mut found=false;super::super::intent_walk::expression(&mut g,&mut |e|if matches!(e,Expr::Name{name,..} if name=="now"){found=true;});found});

                for table in writes {for m in doc.programs.iter().filter(|m|m.kind==ProgramKind::Mutation){
                    let mut aliases=BTreeSet::new();
                    for s in &m.body{if let Stmt::Bind{names,value,..}=s{
                        let v=if let Expr::Assert{value,..}=value{value.as_ref()}else{value};
                        if matches!(v,Expr::Read(r) if r.table==table){aliases.extend(names.clone());}
                    }}
                    let mut checks=Vec::new();guards(&m.body,&mut checks);let(mut status,mut now)=(false,false);
                    for mut c in checks{super::super::intent_walk::expression(&mut c,&mut |e|match e{
                        Expr::Name{name,..} if name=="now"=>now=true,
                        Expr::Member{base,name,..} if name=="status"&&matches!(base.as_ref(),Expr::Name{name,..} if aliases.contains(name))=>status=true,_=>{}
                    });}
                    let module = std::path::Path::new(&doc.file).file_stem().and_then(|s| s.to_str()).unwrap_or("schema");
                    let job_name = if module == "schema" { p.name.clone() } else { format!("{module}.{}", p.name) };
                    let already_named = bound.notes.iter().any(|n| n.code == "N_SWEEP_DEADLINE" && n.site == m.site
                        && n.message.contains(&format!("column {table}.status)"))
                        && n.message.contains(&format!("scheduled job {job_name} ")));
                    if status&&!now&&!already_named{note(&mut out,&m.site,"N_SWEEP_ONLY_DEADLINE",format!("{} gates on {table}.status while clock job {} changes that status; writes can run between the deadline and sweep",m.name,p.name),"enforce the deadline against server now in the mutation too; a sweep cleans up state but does not enforce an exact deadline");}
                }}
            }
        }
    }
    out
}

//! Logical observer obligations, separate from the whole declaration verdict.
// @ref LLP 3000.036.004#101-separate-observer-obligations — pull group authority back to each contributor.
use super::*;

#[derive(Clone, Debug, Serialize)]
pub struct Obligation {
    pub path: String,
    pub status: Status,
    pub reason: String,
    pub repair: Option<String>,
}
impl Obligation {
    fn implication(path: String, admission: Result<RuleExpr, String>, policy: &RuleExpr) -> Self {
        let result = admission.and_then(|a| kernel::implies(&a, policy));
        let (status, reason, repair) = match result {
            Ok(true) => (Status::Proved, "every admitted logical contributor satisfies this policy".into(), None),
            Ok(false) => (Status::Unproved, "observer authority does not imply the source policy".into(),
                Some("retain the privacy fields as bare group keys and apply the source privacy policy to this observer".into())),
            Err(why) => (Status::Unproved, why, Some("use ordinary group keys and a read rule over those keys; keep opaque/temporal derivations private".into())),
        };
        Self { path, status, reason, repair }
    }
}

pub(super) fn obligations(bound: &Bound, inv: &Invariant) -> Vec<Obligation> {
    if inv.target != "read" { return Vec::new(); }
    let Some(policy) = &inv.policy else { return Vec::new(); };
    let table = &bound.schema.tables[&inv.table];
    let mut out = vec![Obligation::implication(
        "server point/scan/planned view/count/sum/exists payload".into(),
        Ok(super::columns::admission(table,inv.column.as_deref())), policy)];
    for m in bound.schema.maintains.iter().filter(|m| m.source == inv.table) {
        let admission = (|| {
            if m.row_key.is_some() || m.parent_key.is_some() || m.private.is_some()
                || !m.aliases.is_empty() || !m.computed.is_empty() || m.own_keys.is_some()
                || table.read_lifetime_sensitive()
            { return Err(format!("{} -> {}: captured/private/computed/temporal maintenance needs a contributor reduction", m.source, m.target)); }
            let target = bound.schema.table(&m.target).ok_or_else(|| format!("{}: maintained-column observer needs its owning table/field authority", m.target))?;
            if m.by.iter().any(|key|key.contains('.')||key.starts_with('$')||table.recorded.contains_key(key)
                || table.columns.get(key).is_none() || table.columns.get(key)!=target.columns.get(key)) {
                return Err(format!("{} -> {}: group keys are not bare identically typed source/target columns",m.source,m.target));
            }
            if target.through.is_some() || target.read_lifetime_sensitive() {
                return Err(format!("{}: derived observer has inherited/temporal authority", m.target));
            }
            // A target group field equals that field on every contributing
            // source row. Its id/value and all lost fields have no such law.
            pullback(&target.rules.read, &m.by)
        })();
        out.push(Obligation::implication(format!("maintained {:?}: {} -> {}", m.kind, m.source, m.target), admission, policy));
        for next in bound.schema.maintains.iter().filter(|n| n.source == m.target) {
            out.push(Obligation { path: format!("derived chain {} -> {} -> {}", inv.table, m.target, next.target),
                status: Status::Unproved, reason: "downstream contributor substitution is not implemented".into(),
                repair: Some("query the directly protected aggregate, or declare and verify privacy on each derived observer".into()) });
        }
    }
    out
}

fn pullback(rule: &RuleExpr, keys: &[String]) -> Result<RuleExpr, String> {
    fn term(t: &RuleTerm, keys: &[String]) -> Result<RuleTerm, String> {
        match t {
            RuleTerm::Viewer | RuleTerm::Literal(_) => Ok(t.clone()),
            RuleTerm::Field(f) if keys.contains(f) => Ok(t.clone()),
            _ => Err("derived rule reads a value/id/lost group field or a reference without a contributor identity".into()),
        }
    }
    Ok(match rule {
        RuleExpr::Allow | RuleExpr::Deny | RuleExpr::Public {..} => rule.clone(),
        RuleExpr::Eq(a,b) => RuleExpr::Eq(term(a,keys)?,term(b,keys)?),
        RuleExpr::Ne(a,b) => RuleExpr::Ne(term(a,keys)?,term(b,keys)?),
        RuleExpr::Compare(op,a,b) => RuleExpr::Compare(*op,term(a,keys)?,term(b,keys)?),
        RuleExpr::And(xs) => RuleExpr::And(xs.iter().map(|r|pullback(r,keys)).collect::<Result<_,_>>()?),
        RuleExpr::Or(xs) => RuleExpr::Or(xs.iter().map(|r|pullback(r,keys)).collect::<Result<_,_>>()?),
        RuleExpr::Not(x) => RuleExpr::Not(Box::new(pullback(x,keys)?)),
        RuleExpr::Exists {table,index,key,provenance,equalities} => RuleExpr::Exists {table:table.clone(),index:index.clone(),
            key:key.iter().map(|t|term(t,keys)).collect::<Result<_,_>>()?,provenance:*provenance,
            equalities:equalities.iter().map(|(n,t)|Ok((n.clone(),term(t,keys)?))).collect::<Result<_,String>>()?},
        RuleExpr::Created {..} => return Err("created probe has no derived read contributor reduction".into()),
    })
}
//! Typed server-clock facts used only by the proof abstraction, never runtime rules.
// @ref LLP 3000.036.004#102-temporal-intent — lifetime is independent of physical sweep lag.
use super::*;
use snapback4_core::{Value, ir::BinaryOp as Op, schema::{Table, ColumnType}};
// Quarry identifiers cannot contain ':'. No authored field aliases this atom.
const CLOCK: &str = "$security:server-clock";
pub(super) fn clock() -> RuleTerm { RuleTerm::Field(CLOCK.into()) }
pub(super) fn has_clock(rule: &RuleExpr) -> bool {
    rule.any_term(&|t| matches!(t, RuleTerm::Field(f) if f == CLOCK))
}
pub(super) fn comparison(op: Op, a: RuleTerm, b: RuleTerm) -> RuleExpr {
    match op {
        Op::Gt => RuleExpr::Compare(Op::Lt,b,a), Op::Gte => RuleExpr::Compare(Op::Lte,b,a),
        Op::Eq => RuleExpr::Eq(a,b), Op::Ne => RuleExpr::Ne(a,b),
        _ => RuleExpr::Compare(op,a,b),
    }
}
pub(super) fn admission(table: &Table) -> RuleExpr {
    let mut facts = vec![table.rules.read.clone()];
    for (column,op) in table.not_before.iter().map(|f|(f,Op::Lte)).chain(table.expire.iter().map(|f|(f,Op::Gt))) {
        let field=RuleTerm::Field(column.clone());
        let edge=comparison(op,field.clone(),clock());
        let edge=if table.columns.get(column).is_some_and(ColumnType::is_optional) {
            RuleExpr::Or(vec![RuleExpr::Eq(field,RuleTerm::Literal(Value::Null)),edge])
        } else {edge};
        facts.push(edge);
    }
    RuleExpr::And(facts)
}

pub(super) fn bind(catalog: &Catalog, info: &super::super::catalog::TableInfo, expr: &ast::Expr) -> Option<RuleExpr> {
    use ast::{Expr,Literal,TypeKind};
    fn term(info:&super::super::catalog::TableInfo,e:&Expr)->Option<RuleTerm>{match e {
        Expr::Name{name,..} if name=="now" => Some(clock()),
        Expr::Member{base,name,..} if matches!(base.as_ref(),Expr::Focal{..}) && info.columns.get(name).is_some_and(|t|t.kind==TypeKind::Time) => Some(RuleTerm::Field(name.clone())),
        Expr::Literal{value:Literal::Number(n),..}=>Some(RuleTerm::Literal(Value::Int(n.parse().ok()?))),
        Expr::Literal{value:Literal::Null,..}=>Some(RuleTerm::Literal(Value::Null)),
        _=>None,
    }}
    if let Expr::Binary{op,left,right,..}=expr {
        if op=="and"||op=="or" {
            let xs=vec![bind(catalog,info,left)?,bind(catalog,info,right)?];
            return Some(if op=="and"{RuleExpr::And(xs)}else{RuleExpr::Or(xs)});
        }
        let op=match op.as_str(){"="=>Op::Eq,"!="=>Op::Ne,"<"=>Op::Lt,"<="=>Op::Lte,">"=>Op::Gt,">="=>Op::Gte,_=>return None};
        if let (Some(a),Some(b))=(term(info,left),term(info,right)){return Some(comparison(op,a,b));}
    }
    if let Expr::Unary{op,value,..}=expr && op=="not" {return Some(RuleExpr::Not(Box::new(bind(catalog,info,value)?)));}
    let rule=ast::RuleDecl{effect:ast::Effect::Insert,bindings:Vec::new(),value:expr.clone(),site:expr.site().clone()};
    super::super::schema::bind_rule(catalog,info,&rule).ok()
}

// @ref LLP 3000.036.004#102-temporal-intent — no snapshot-only clock refutation.
use super::*;

pub(super) fn run(bound:&Bound,out:&mut Campaign,sites:Option<&BTreeSet<String>>){
    for inv in bound.invariants.iter().filter(|i|i.target=="read"&&i.column.is_none()&&i.policy.as_ref().is_some_and(super::super::temporal::has_clock)

        let policy=inv.policy.as_ref().unwrap();
        if policy.has_reference(){out.unsupported.insert(format!("{}: temporal reference policy needs authorized per-tick engine replay",inv.table));continue;}
        if !kernel::dependencies(policy).is_empty(){out.unsupported.insert(format!("{}: clock policy with raw-probe dependencies needs a live-snapshot evaluator",inv.table));continue;}
        let name="$security.temporal";
        let probe=program(name,ProgramKind::Query,vec![Stmt::Return(Expr::Get(Read{site:"temporal security".into(),table:inv.table.clone(),index:"byId".into(),
            key:vec![Expr::Literal(id(&inv.table))],provenance:KeyProvenance::Computed}))]);
        for variant in [0,4] {
            let rows=match snapshot_mode(bound,inv,variant,true){Ok(r)=>r,Err(e)=>{out.unsupported.insert(e);continue;}};
            for now in [NOW,NOW+999,NOW+1000,NOW+1001,NOW+1999,NOW+2000,NOW+2001] {
                // Recreate the store for each boundary; never sweep before the
                // read. Unswept expiry remains a logical absence by contract.
                let mut engine=match engine(bound,&rows,probe.clone()){Ok(e)=>e,Err(e)=>{out.unsupported.insert(e);continue;}};
                let actual=match readback(&engine){Ok(r)=>r,Err(e)=>{out.unsupported.insert(e);continue;}};
                let Some(row)=actual.get(&inv.table).and_then(|rs|rs.first())else{continue;};
                for viewer in [VIEWER,OTHER] {
                    out.attempted+=1;
                    let Ok(q)=engine.query(name,Context::new(viewer,BTreeMap::new()).at(now))else{continue;};
                    if q.unavailable||!q.complete||q.data==Value::Null{continue;}
                    // Scalar clock atoms are evaluated only after a real
                    // engine read returned this committed row. This extra
                    // field is proof-private and never enters the store.
                    let mut image=row.clone();
                    if let Value::Row(fields)=&mut image {fields.insert("$security:server-clock".into(),Value::Int(now));}
                    if matches!(rules::evaluate(policy,viewer,None,&image,false,&mut Snapshot{schema:&bound.schema,rows:&actual}),Ok(false)) {
                        out.admitted+=1;
                        out.violations.push(Counterexample {reachability:Reachability::SyntheticOperation,history:Vec::new(),observations:None,invariant_site:inv.site.to_string(),args:BTreeMap::new(),viewer:viewer.into(),operation:name.into(),
                            effect:"read".into(),row:row.clone(),old:None,supporting_rows:actual.clone(),rule_path:format!("server read at {now}, before any physical sweep; clock policy false"),
                            scope:"actual engine read over schema-valid committed seed ingress at the recorded server clock; schedules are not assumed to have run".into()});
                        break;
                    }
                }
            }
        }
    }
}

fn framed(headers:&str,body:&[u8])->Result<Vec<u8>,String>{
    let mut length=None;let mut transfer=false;
    let mut lines=headers.split("\r\n");
    let status=lines.next().ok_or("missing HTTP status line")?;
    if !(status.starts_with("HTTP/1.1 ")||status.starts_with("HTTP/1.0 "))||status.bytes().any(|b|b<32||b==127){return Err("malformed HTTP status line".into());}
    for line in lines{
        let (name,value)=line.split_once(':').ok_or("malformed HTTP header")?;
        if name.is_empty()||!name.bytes().all(|b|b.is_ascii_alphanumeric()||b"!#$%&'*+-.^_`|~".contains(&b))||value.bytes().any(|b|b<32&&b!=b'\t'||b==127){return Err("malformed HTTP header field".into());}
        if name.eq_ignore_ascii_case("content-length"){
            let value=value.trim_matches([' ','\t']);
            if length.is_some()||value.is_empty()||!value.bytes().all(|b|b.is_ascii_digit()){return Err("invalid or duplicate HTTP content length".into());}
            length=Some(value.parse::<usize>().map_err(|_|"invalid HTTP content length")?);
        }
        if name.eq_ignore_ascii_case("transfer-encoding"){
            if transfer||!value.trim_matches([' ','\t']).eq_ignore_ascii_case("chunked"){return Err("invalid or duplicate HTTP transfer encoding".into());}transfer=true;
        }
    }
    if transfer{
        if length.is_some(){return Err("conflicting HTTP body framing".into());}chunks(body)
    }else{
        if length!=Some(body.len()){return Err("HTTP body lacks complete declared content length".into());}
        Ok(body.to_vec())
    }
}
fn chunks(mut wire:&[u8])->Result<Vec<u8>,String>{
    let mut out=Vec::new();
    loop{
        let line=wire.windows(2).position(|b|b==b"\r\n").ok_or("incomplete HTTP chunk header")?;
        let size=std::str::from_utf8(&wire[..line]).map_err(|_|"invalid HTTP chunk header")?;
        if size.is_empty()||!size.bytes().all(|b|b.is_ascii_hexdigit()){return Err("invalid HTTP chunk size".into());}
        let count=usize::from_str_radix(size,16).map_err(|_|"invalid HTTP chunk size")?;
        wire=&wire[line+2..];
        if count==0{if wire!=b"\r\n"{return Err("unexpected HTTP chunk trailer".into());}return Ok(out);}
        let end=count.checked_add(2).ok_or("HTTP chunk size overflow")?;
        if wire.len()<end||&wire[count..end]!=b"\r\n"{return Err("incomplete HTTP chunk body".into());}
        out.extend_from_slice(&wire[..count]);wire=&wire[end..];
    }
}
fn rotation_successor<'a>(session:&serde_json::Value,rotated:&'a serde_json::Value)->Result<&'a str,String>{

}

// An actual credential history at the production admission boundary. A stale
// device's already copied bytes remain a separate, explicitly unproved path.
fn revoked_sessions(bound:&Bound,address:SocketAddr)->Result<usize,String>{
    if !bound.schema.auth.guests && !bound.schema.auth.password {
        println!("security not covered: ordinary session revocation HTTP requires declared guest or password identity");return Ok(0);
    }
    let (path,payload)=if bound.schema.auth.guests{("/auth/guest","{}")}
        else{("/auth/signup","{\"email\":\"security-campaign@example.test\",\"password\":\"Isolated-campaign-7842!\"}")};
    let (status,session)=exchange(address,"POST",path,"",payload)?;
    if status!=200{return Err(format!("private revocation campaign could not authenticate (HTTP {status}); no revocation claim"));}
    let token=session["session"]["token"].as_str().ok_or("private revocation campaign did not receive a session")?;
    let bearer=format!("Authorization: Bearer {token}\r\n");
    if exchange(address,"GET","/schema",&bearer,"")?.0!=200{return Err("fresh session failed schema admission before revocation".into());}
    let (status,rotated)=exchange(address,"POST","/auth/refresh",&bearer,"{}")?;
    if status!=200{return Err("private revocation campaign could not rotate its live session".into());}
    let successor=rotation_successor(&session,&rotated)?;
    let next=format!("Authorization: Bearer {successor}\r\n");
    if exchange(address,"GET","/schema",&next,"")?.0!=200{return Err("rotation successor failed admission before revocation".into());}
    let (status,retired)=exchange(address,"GET","/schema",&bearer,"")?;
    if status!=401||retired["denied"]["code"]!="E_AUTH"{return Err("rotation left the original credential admitted before logout-all".into());}
    let (status,ended)=exchange(address,"POST","/auth/logout-all",&next,"{}")?;
    if status!=200||ended["ok"]!=true||ended["revoked"].as_u64().unwrap_or(0)==0{return Err("private revocation campaign could not revoke its successor".into());}
    let mut attempted=0;
    for header in [&bearer,&next] {
        let mut paths=vec![("GET","/schema".to_owned()),("GET","/changes?since=0&wait=0".to_owned()),("POST","/sync".to_owned()),("POST","/probe".to_owned()),("POST","/auth/refresh".to_owned())];
        for p in &bound.programs{
            let prefix=match p.program.kind{snapback4_core::ir::ProgramKind::Query=>"q",snapback4_core::ir::ProgramKind::Mutation=>"m",_=>continue};
            paths.push(("POST",format!("/{prefix}/{}",p.program.name)));
        }
        for (method,path) in paths{
            let (status,body)=exchange(address,method,&path,header,"{\"id\":\"security-revoked\",\"args\":{}}")?;attempted+=1;
            if status!=401||body["denied"]["code"]!="E_AUTH"{return Err(format!("revoked credential admitted at {method} {path} (HTTP {status}); bearer omitted"));}
        }
    }
    println!("security live-session revocation HTTP: {attempted} attempts refused after actual refresh and logout-all; disconnected device storage is not covered");
    Ok(attempted)
}

pub(super) fn run(bound:&Bound,sources:&[(String,String)])->Result<usize,String>{

    // startup needs its app-owned artifacts; never pretend this schema-only
    // host qualifies those paths.

        || !bound.schema.effects.is_empty() || !bound.schema.action_specs.is_empty(){
        println!("security not covered: unauthenticated serve HTTP for native/action/effect applications needs its complete deployed artifacts");return Ok(0);
    }

    let root=std::env::temp_dir().join(format!("sb4-security-serve-{}-{stamp}",std::process::id()));
    fs::create_dir(&root).map_err(|e|e.to_string())?;let scratch=Scratch(root);
    fs::create_dir(scratch.0.join("snapback")).map_err(|e|e.to_string())?;
    for (name,text) in sources {
        let file=std::path::Path::new(name).file_name().ok_or("source needs a file name")?;
        fs::write(scratch.0.join("snapback").join(file),text).map_err(|e|e.to_string())?;
    }
    let executable=scratch.0.join("security-host");
    image::snapshot(&executable)?;
    let output=fs::File::create(scratch.0.join("host.log")).map_err(|e|e.to_string())?;
    let command=|verb:&str|->Result<Command,String>{
        let mut c=Command::new(&executable);c.arg(verb).current_dir(&scratch.0)
            .env("SNAPBACK4_SUPERVISOR_PID",std::process::id().to_string()).stdin(Stdio::null())
            .stdout(output.try_clone().map_err(|e|e.to_string())?).stderr(output.try_clone().map_err(|e|e.to_string())?);Ok(c)
    };
    let mut deploy=Process(command("deploy")?.args(["deployment"]).spawn().map_err(|e|e.to_string())?);
    wait(&mut deploy,Duration::from_secs(30))?;drop(deploy);
    let listener=TcpListener::bind((std::net::Ipv4Addr::LOCALHOST,0)).map_err(|e|e.to_string())?;
    let address=listener.local_addr().map_err(|e|e.to_string())?;drop(listener);

    let until=Instant::now()+Duration::from_secs(15);
    loop{
        if host.0.try_wait().map_err(|e|e.to_string())?.is_some(){return Err("private production serve exited during startup".into());}
        if TcpStream::connect_timeout(&address,Duration::from_millis(100)).is_ok(){break;}
        if Instant::now()>=until{return Err("private production serve did not listen within 15 seconds".into());}
        std::thread::sleep(Duration::from_millis(20));
    }
    let mut attempted=0;
    for p in &bound.programs {
        let prefix=match p.program.kind{snapback4_core::ir::ProgramKind::Query=>"q",snapback4_core::ir::ProgramKind::Mutation=>"m",_=>continue};
        for forged in [false,true]{
            let (status,body)=request(address,&format!("/{prefix}/{}",p.program.name),forged)?;attempted+=1;
            if status!=401||body["denied"]["code"]!="E_AUTH" {
                return Err(format!("unauthenticated serve HTTP {} (forged persona={forged}) returned {status}: {body}",p.program.name));
            }
        }
    }
    // Staging/provisioning belongs to STAGE. This host never opens its dev doors.
    for path in ["/seed","/dev/reset","/dev/clock/advance"] {
        let (status,_)=request(address,path,false)?;attempted+=1;
        if !matches!(status,401|403|404){return Err(format!("production development door {path} returned {status}"));}
    }
    let revoked=revoked_sessions(bound,address)?;
    drop(host);drop(scratch);
    println!("security unauthenticated serve HTTP: {attempted} attempts refused (including forged personas and dev doors)");
    Ok(attempted+revoked)
}

use std::{fs,path::Path};

pub(super) fn snapshot(destination:&Path)->Result<(),String>{
    #[cfg(target_os="linux")]
    {fs::copy("/proc/self/exe",destination).map(|_|()).map_err(|e|format!("private host image snapshot: {e}"))}
    #[cfg(target_os="macos")]

    {let _=destination;Err("private host image identity is unsupported on this platform; no HTTP qualification".into())}
}

#[cfg(target_os="macos")]
#[repr(C)]
struct RegionInfo {protection:[u32;4],offset:u64,counters:[u32;14],address:u64,size:u64}
#[cfg(target_os="macos")]
#[repr(C)]
struct RegionWithPath {region:RegionInfo,vnode:libc::vnode_info_path}

#[cfg(target_os="macos")]
fn from_path(source:&Path,destination:&Path)->Result<(),String>{
    use std::os::unix::fs::MetadataExt;
    let mut file=fs::File::open(source).map_err(|e|format!("private host image open: {e}"))?;
    let before=file.metadata().map_err(|e|e.to_string())?;
    // SDK sys/proc_info.h: PROC_PIDREGIONPATHINFO=8 returns the VM region's
    // backing vnode. A pathname may already name a replacement; its open fd
    // must match the vnode actually mapped as this process's Mach-O header.
    let header=unsafe{libc::_dyld_get_image_header(0)} as u64;
    if header==0{return Err("cannot locate the loaded private host image".into());}
    let mut loaded:RegionWithPath=unsafe{std::mem::zeroed()};
    let size=std::mem::size_of::<RegionWithPath>() as i32;
    let got=unsafe{libc::proc_pidinfo(std::process::id() as i32,8,header,&mut loaded as *mut _ as *mut _,size)};
    if got!=size||header<loaded.region.address||header-loaded.region.address>=loaded.region.size{
        return Err("cannot establish loaded private host vnode identity; retry after rebuild".into());
    }
    let stat=&loaded.vnode.vip_vi.vi_stat;
    if stat.vst_ino==0||stat.vst_ino!=before.ino()||stat.vst_dev as u64!=before.dev(){
        return Err("private host executable pathname was replaced; no HTTP qualification".into());
    }
    let mut out=fs::File::create(destination).map_err(|e|e.to_string())?;
    std::io::copy(&mut file,&mut out).map_err(|e|e.to_string())?;
    out.set_permissions(before.permissions()).map_err(|e|e.to_string())?;
    let after=file.metadata().map_err(|e|e.to_string())?;
    if (before.len(),before.mtime(),before.mtime_nsec(),before.ctime(),before.ctime_nsec())!=(after.len(),after.mtime(),after.mtime_nsec(),after.ctime(),after.ctime_nsec()){
        return Err("private host executable changed while snapshotting; no HTTP qualification".into());
    }
    Ok(())
}
