Quarry store testing (LLP 3000.035 §5.1): `SNAPBACK4_EVAL_POSTGRES` is an
explicit evaluation connection. The factory owns one physical schema per worker,
restores its rows and bookkeeping, installs the compiled fixture, then opens the
ordinary engine. Mutation attempts restore a seeded snapshot; shrinking reuses
that same factory. `Database::connect_fresh()` is an opt-in test mode. Fresh and
restored outcomes must serialize to identical bytes. The local wire observer
retains SQLSTATE, message, detail and SQL statement before the public query API
converts a driver error to a refusal; it never changes the traffic.

Reads sweep every public boundary. Mutations compare every discovered position
twice on SQLite, and compare up to eight seeded positions per dimension on
Postgres (including first/last), plus the case's original budget. Sampling
counters are in `store_stats`; each selected position runs prefetch on and off.
Physical prefetch counters are separate from the exact public outcome record.
The widened generator (`src/widen.rs`) emits prefetch-reachable reads: pages
projecting `tags[.tag]` and `tags[name = .label]` (a `Get` and a unique
`Lookup` whose keys vary across rows) and a loop reading `tags[row.tag]`, so
`store_stats` reports marked reads, transferred rows, cases with a transfer
and `prefetch_consumption_witness_probes` (fewer database calls with prefetch
on: cached answers were consumed). A planted cached-hit-to-miss fault is caught
by the random corpus (LLP 3000.035 §5.1; the closed
[coverage ticket](../issues/closed/20261007-quarry-store-oracle-prefetch-coverage-gap.md)).
Heap is charged identically on every store and the device (LLP 3000.007
§20.24.5); any disagreement is a ticket candidate, never normalized into a pass.
The cluster regression asserts it finds no signature and refuses any new one.

`run-stores --seconds N` stops each worker between cases after N seconds; a case
and any shrinking already underway finish. `cases` remains the requested count,
`generated` is actual completed generation, and `time_limited_workers` reports
the early stop. Slowest-case timing includes generation, comparisons, shrinking
and artifact saving. It does not silently claim the requested million. The scheduled
runner rejects incomplete reports; its own `--hours` option instead chooses a
case count from a 256-case calibration of both campaigns, with 20% headroom and
a million-case cap. This is a sizing estimate, not a hard deadline.

Generator widening (`src/widen.rs`, LLP 3000.035 §5.1): from a stream
independent of the base generator (`generate::base`; a seed it leaves alone is
the base case byte for byte), cases gain prefetch-reachable reads, mutation
blocks (lets, `require`, `if`, several writes to `key` and `k2`, reads after
writes), a prelude of mutations `prep0..` run in order on the same store before
`run` (`Case::steps`, sometimes as the other viewer; `observe` then reads both
keys), and expiry (`expire at .until`, a clock advancing from `seeded_at`
through each step to `clock`, sweeps, `until: now + ttl`). Every oracle runs the
prelude (`execute::world`) and compares its outcomes (`prelude-*` fields;
`store-postgres-prelude`); a device acquires at the seed clock and catches up by
one sync round after the server's prelude. The prelude is emitted first so no
rewrite moves its sites. `lean::generate` narrows half the cases outside the
model (projections, expiry) back into its fragment; the rest stay named
unsupported (`shape`, `loop`, `table-expiry`). The report's `coverage` counts
each new feature (`block/*`, `prelude/*`, `projection/*`, `expire/*`, `clock/*`).

Quarry device testing (`src/devices.rs`, `src/device_writes.rs`, LLP 3000.035
§5.1 oracle 4): each case runs on a server engine and on a device of each store
(native SQLite at a file path, and memory), both brought up through the client's
own path: the `/schema` backend as JSON text, then `local.ts::syncRound` (capture
`sync_state`, `/sync` snapshot pages built as `serve_sync.rs` builds them,
`observe_store`, `apply` through `call_text`, catch-up stream). Never seed a
device store directly. Reads the device publishes without the server (`complete`
with `unknown` false, or a known refusal) compare the whole outcome record
except `seq` (and server-only `delivery`); every other read counts under a named
reason (`online-only-*`). Low ceilings reach the device only through `call`'s
`spent` ledger (`default - n`), compared at the server's boundary positions.
Writes go through `admit`: a device refusal must equal the server's, a
predicted row must equal the committed one (less its `pending` marker), and

# llp-orient

<!-- @ref https://github.com/ccheever/llp/blob/v0.5.2/llp/0008-distributed-agent-skills.rfc.md#the-skills--core-five-plus-flags — skill contract -->
<!-- @ref https://github.com/ccheever/llp/blob/v0.5.2/llp/0000-linked-literate-programming.explainer.md#2-reference-syntax — the grammar this reads -->

Load the design rationale governing the area you're about to touch, before touching it. This is the consumption side of LLP — orienting first is what turns `@ref` from a possibility into a habit.

Invoke as `/llp-orient <path-or-task>` (file, directory, subsystem, or task description). With no argument, use the current change scope (`git diff --name-only`).

## Trigger

Start of a coding task that touches an area with documented design. The orient-first *rule* lives in the repo's always-loaded `AGENTS.md`; this skill is the detailed form that rule routes to for non-trivial work — don't rely on ambient description-match alone.

## Invariants

- MUST be read-only: never edit code or LLP documents.
- MUST scope to the task: pull the constraints that bind this change, not a corpus summary.
- MUST cite, not restate: reference policy as `LLP NNNN#anchor` rather than paraphrasing sections.
- MUST NOT invent constraints. If something isn't documented, say so.
- MUST NOT guess the rationale behind a broken `@ref` — report it and hand off to `llp-maintain`.

## Workflow

> **Recipe (advisory)** — corpus root = nearest `llp/` walking up from the path in scope (LLP 0001 §Unit of adoption); "no corpus" is an empty walk, not cwd-relative absence. Read `llp/foundation/` first (the kernel; the root LLP is there once `Active` — on a fresh adoption it is still `Draft` and sits in `current/`), then skim `llp/current/` (the declared working set); both hold relative links — symlinks, or small files containing the relative path — so `ls` answers and either form resolves. Then the root LLP's systems vocabulary. `Grep '@ref'` over the files in scope and `Read` each target — these are the highest-signal context. `Grep` the `**Systems:**` headers across `llp/` for LLPs governing the subsystems touched; read the governing ones (Spec, Decision, Principles, relevant RFCs). Follow `Related:` and nearby `@ref` targets one hop out; stop there unless something is clearly load-bearing. Stale-pin nudge (skip offline): read the installed tag from the skills receipt (or a `source:` pin), compare `git ls-remote --tags <origin>` — if upstream is newer, say so in one line ("skills at v0.3.0, upstream v0.5.2 — run /llp-adopt update") and move on; never update from here.

## Artifact

A context pack with these sections, faster to read than the documents it points at:

- **Scope** — files / subsystems queried
- **Governing LLPs** — numbered list, one-line gloss each; mark which are in `foundation/` and which are in `current/` (in-flight — its guidance may still move)
- **Active constraints** — bullets, each citing `LLP NNNN#anchor`
- **Relevant rationale** — the *why*, same citation form
- **Open questions / risks** for this area
- **Likely doc updates** if the change lands
- **Hand-off** — one of `none | llp-adopt | llp-create | llp-review | llp-maintain`

## Hand-offs

- No corpus (no `llp/` walking up from the path in scope) → `llp-adopt`.
- The task needs a decision no LLP covers → `llp-create` (or `llp-review` if proposal-shaped).
- An `@ref` target or anchor doesn't resolve → `llp-maintain`.

## 12. SEC3 day-two amendment

Implementer: SEC3, 2026-10-19. Commission: day-two fix list 3/4/5/8.
REL5 owns release transitions and compatibility; MIG owns backfills and staging
clock control. This amendment changes security analysis, not runtime authority.

### 12.1 Column read intent

`invariant table.column read only P` protects the value, computations over it,
value-dependent counts/existence/refusals, copied values, assets and delivery.
It does not forbid observing an otherwise public row's existence independently
of the protected value. Binding validates the column and preserves its identity
in every verdict and audit. Effective payload authority is row read AND any
owner-private field gate. Pure projections excluding the field may eliminate
that payload path; predicates, group/order keys, derived values and copied
fields remain observations. Unknown flow stays unproved. A synthetic whole-row
read cannot refute a projection-only column policy: column counterexamples
execute an authored observer in two schema-valid worlds differing only in that
column, with policy false in both. Outputs must differ reproducibly. Maintained
values are recomputed; column-sensitive counts/existence are included. Separate
obligations name unresolved raw-probe, wire, device and opaque flows. A direct
column theorem never silently clears those obligations. Per-column audit
reports effective audience plus operation/derived observers, not only its type.

### 12.2 Reproducible campaigns and reachability

Generated seed ingress contains only authored base rows/fields. Never re-seed
maintained targets or engine-recorded fields. Generated lifetime samples are
live at the campaign clock; principal fields vary independently. Rejected
snapshots are recorded as unsupported, not successful attempts. Existing
fixture histories instead fork the complete SQLite store and asset ledger into
owned isolated memory stores; captures, deadlines, maintained values, lifetimes
and actual media identities survive unchanged. No source store is modified.
Temporary asset directories belong to Store and disappear on drop.

Actors include all principal values in fixtures. Required/optional references
range over fixture rows, not only the first. Short histories visit first steps
breadth first before extending them under a reported work cap. Read and row
assertions are checked after each step. Write/operation assertions judge only
actual committed changes, correct insert/update/delete arms and pre-write
policy state; ambiguous multiple writes, implicit effects or unstable policy
need executed-effect tracing and remain unsupported. A finite trace is never
an induction proof for always or arbitrary histories.

Every counterexample has a machine-readable origin: authored trace from trusted
fixture, trusted-seed-only, or synthetic operation. Only the first establishes
application reachability from the recorded trusted starting state and fails
normal check/test. Seed/synthetic witnesses remain refutations of all-snapshot
claims, visible with --all and JSON, without failing acceptance. Unproved
reachability is never asserted unreachable as a mathematical theorem. Check
loads the same fixture base for reachable histories as test, without HTTP or
business-case execution. A stronger witness must replace a synthetic witness
for the same declaration. --all exposes all witnesses and never changes which
ones fail. No unreachable refutation may print pass/ok beside exit 1.

### 12.3 Actionable authority advice

N_PRIVILEGE_ESCALATION identifies authored caller operations that write role
or group grants trusted by later rules while the effective admission does not
establish independent authority to confer that particular grant. Include
self-signup roles and transitions where a caller can confer a role they lack.
A trusted service seat or an independently authorized administrator may appoint
other roles; holding an unrelated ordinary role does not establish delegation.
Advice names the operation, grant and gate and points to guide staging's
operator first-admin recipe. It is advice, never an implicit runtime refusal
or a proof of malicious intent. Legitimate open enrollment can be intentional.

N_GRANT_OUTLIVES_ROLE requires an actually mutable/revocable current-role
population and a retained principal/grant branch lacking that role recheck;
cover read AND write branches. Immutable/static role populations do not fire.
N_EXISTENCE_ORACLE excludes public populations and caller-owned role lookups;
only an absent/hidden distinction crossing a narrower private audience warrants
advice. Every security note has a real source location and contributes to the
reported note count. Rule printing preserves connective precedence. Identity
429 responses include a conservative retry delay covering the rate window;
the existing limits and authentication semantics are unchanged.

### 12.4 Evidence

Qualification uses read-only copies of all ten wave-17 high lanes and their
spec-authored invariant sets, plus all 150 earlier schemas. Report caught,
partial and not caught separately; all-snapshot witnesses alone do not count
as a reachable detection. Preserve bad/fixed controls, note counts and source
hashes. The open qualification-gap ticket remains open for unresolved whole
proof/device/opaque obligations. No zero-hole claim follows from finite tests.


### 12.5 SEC3 reduction details

The direct column theorem is `(row_read AND owner_private_gate) => P` in the
existing three-valued kernel; deny-delete is never an admission for column
read. Whole proof still requires every observer obligation. This increment
uses dynamic column-world observers, not an unimplemented static dataflow
claim: pure projections can avoid a refutation, but do not acquire a proof by
absence of finite counterexamples. Census is existing point/scan/view/filter/
count/sum/exists, mutation return/refusal/copy, asset, sync, raw/derived/opaque
paths. Unsupported field flow remains unproved. Audit's `column_audiences`
maps every visible column name to its effective row-and-private-field rule;
operations and derived edges remain separately enumerated.

Column worlds use the same ordinary viewer, server clock and row id; the named
column has two different schema-valid typed values, and policy is false on its
respective image in each committed world. Every non-native authored query and

### 12.6 Disclosure and clock clarifications

A column observer mutation is declined if it can change the protected image,
policy dependency or an unresolved implicit writer before disclosure. A
pre-operation false policy cannot refute an authorized post-transfer return.
Column observers also run after committed history steps, preserving the
trusted initial fixture and authored prefix. All reference and principal
arguments use the same bounded fixture Cartesian cases; truncation of read
observer cases at 32 is named. Clock-only whole-row probes exclude columns.
Column tick coverage beyond the recorded campaign clock remains named.

All security fixture loading, probes, writes, paired deletions and policy
judgments use the same explicit campaign clock. Business tests keep their own
existing clock and store; security reloads trusted fixture files independently.
Raw policy probes respect both not-before and expire-at bounds. Direct delete
assertions judge removed pre-images against the stable pre-write state, never
surviving rows alone; ambiguous implicit removals remain unsupported.

Fixture forks copy already activated engine state without re-adopting a schema.
They use fresh entropy/minter and private assets, never shared live connections.
Ephemeral-hub fixtures require a separate isolated snapshot and are declined.
Structural privilege advice combines dominating safe operation requirements
with the actual insert/update/upsert gate and applicable owned-field patch gate.
A mutable roster alone is not enough for lifetime advice: require independent
current-role intent or a retained recipient column tied to a role literal
(judge, inspector, host, contractor, engineer; ordinary author attribution alone
is not a current-role contract). Deletion revokes even an immutable role field.

### 12.7 Stable judgments and direct payload witnesses

Unknown bound policy dependencies never authorize a mutation observer: such
column mutations require disclosure-boundary tracing. Pre-write assertions use
a transitive closure of maintained and cascade/set-null writes; a policy
dependency or target that may change implicitly makes the assertion unsupported.
The same rule covers insert, update, upsert and delete. Looped/opaque net images
cannot stand in for executed write events. Effective inserted authority includes
a defaulted role even when omitted from the source write.

An authored complete query returning a compiler-typed Row/Table or Page/Table
containing the protected row id is a direct payload witness at that query's
snapshot. Nested typed row returns retain their source-table identity. This
avoids inventing an invalid absent world by deleting a referenced parent.
Projected scalar/aggregate/refusal observations still require validated paired
worlds; a matching untyped id or value alone cannot attribute an exposure.

Check prioritizes actual fixture histories and column observers before searching
remaining synthetic counterexamples. It does not repeat the test-only operation
exploration matrix, which judges no additional policy. That matrix shares an
8192-call budget across every operation (1–512 calls per operation), reports
truncation, and preserves enum/reference/principal alternatives within that cap.
Required image/file operation arguments are actual uploads owned by the acting
principal, with ledger/scratch custody in the isolated engine. Unsupported video
and uncoupled column-world media identities remain named.

For escalation advice, a role-protected appointer is an explicit delegation
boundary; conferring a different role is not by itself evidence of escalation.
Independent role-value intent may restrict that boundary (for example a producer
must not confer legal). Ordinary role casts make service-seat equality false,
including inside operation requirements. Fixed literals still undergo the privilege comparison; ordinary enrollment
whose rules add no role-specific authority is not advised. Analyze caller-chosen
roles, defaulted inserted authority and owner-field upgrades; respect the
argument's actual enum choices. A fixed bootstrap that can appoint further
roles remains an actionable first-admin risk. Notes remain advisory; absence
of independent intent is not proof that a delegation matches the specification.

### 12.8 Runtime intent and independent worlds

Reference-hop intent is judged by the engine's own authorized RuleProbe and
three-valued verdict on an isolated actual snapshot. Hidden/missing references
remain Unknown, never false; snapshot-only evaluators decline those terms.
Temporal reference policies require a per-tick authorized replay and remain
explicitly unsupported until that path runs. Referenced immutable-column worlds
use fresh stores with copied verified asset ledgers and all authored base rows,
then ordinary seed validation/recomputed maintenance. They do not require a
legal delete transition. Every non-protected base field, capture, row identity
and row population must match before comparing observations.

Implicit stability includes source and member writes to row-keyed views,
maintained owner columns, through-parent effects and transitive cascade/set-null.
Only an actual direct delete can refute delete authority; commit-end expiry is
not relabeled a deletion by the caller. Defaulted upsert roles are analyzed on
the insert arm only; omitted fields are preserved on update. Revocability advice

not an unrelated display-name update.

violation despite another changing conjunct. Replace unstable atoms (or an
entire unstable negation) by Allow, retaining And/Or composition; separately

same-named argument beside a literal assignment. An unconditional helper call

conditional/loop-local requirements do not become caller assumptions.

/// Whether a value is (or contains) the reserved system principal.
pub fn contains_system_principal(value: &Value) -> bool {
    match value {
        Value::Id(id) => id == crate::SYSTEM_PRINCIPAL,
        Value::Array(items) => items.iter().any(contains_system_principal),
        Value::Row(fields) | Value::Map(fields) => fields.values().any(contains_system_principal),
        _ => false,
    }
}

/// Missing optional columns read as null; missing required columns with a
/// literal default read that value. Contextual defaults belong to inserts.
pub fn materialize_optional_fields(row: &mut Value, table: &Table) {
    let fields = match row {
        Value::Row(fields) | Value::Map(fields) => fields,
        _ => return,
    };
    for (name, kind) in &table.columns {
        if !fields.contains_key(name) {
            if table.maintained.contains_key(name) {
                fields.insert(name.clone(), Value::Int(0));
            } else if kind.is_optional() {
                fields.insert(name.clone(), Value::Null);
            } else if let Some(ColumnDefault::Literal(value)) = table.defaults.get(name) {
                fields.insert(name.clone(), value.clone());
            }
        }
    }
}

/// Borrow complete images; materialize old images only when needed.
pub fn row_image<'a>(row: &'a Value, table: &Table) -> std::borrow::Cow<'a, Value> {
    if table.columns.keys().all(|column| row.field(column).is_ok()) { return std::borrow::Cow::Borrowed(row); }
    let mut image = row.clone();
    materialize_optional_fields(&mut image, table);
    std::borrow::Cow::Owned(image)
}

fn validate_image(schema: &Schema, table_name: &str, row: &Value, viewer: Option<&str>, before_slots: bool, cache: bool) -> Result<(), RuntimeError> {
    let table = schema.table(table_name).ok_or_else(|| RuntimeError::Schema(format!("missing table {table_name}")))?;
    let object = row.as_object()?;
    if !object.contains_key("id") {
        return Err(RuntimeError::Schema(format!("{table_name} row lacks id")));
    }
    if let Some(name) = object.keys().find(|name| !table.columns.contains_key(*name)) {
        return Err(RuntimeError::Input(format!("{table_name} row contains undeclared field {name}")));
    }
    for (name, kind) in &table.columns {
        if before_slots && crate::schema::timeline::is_slot(name) { continue; }
        if cache && matches!(name.as_str(), "value" | "recountPending") && !object.contains_key(name) { continue; }
        let value = object.get(name).or_else(|| table.maintained.contains_key(name).then_some(&Value::Int(0)));
        if value.is_none() && viewer.is_some_and(|viewer| table.written_by.get(name).is_some_and(|authority|
            !authority.audience && row.field(&authority.owner).ok() != Some(&Value::Id(viewer.into())))) { continue; }
        validate_column(table_name, name, kind, value)?;
    }
    for constraint in &table.constraints {
        if let Constraint::Text { field, min, format } = constraint
            && let Some(Value::String(text)) = object.get(field)
        {
            validate_text(&format!("{table_name}.{field}"), text, *min, *format).map_err(|error| RuntimeError::Constraint(error.to_string().trim_start_matches("E_INPUT: ").to_owned()))?;
        }
    }
    Ok(())
}

pub fn validate_column(table_name: &str, name: &str, kind: &ColumnType, value: Option<&Value>) -> Result<(), RuntimeError> {
    let label = format!("{table_name}.{name}");
    if let Some(value) = value {
        crate::value::validate_identities(value)?;
        if contains_system_principal(value) {
            return Err(RuntimeError::Input(format!("{label} cannot carry the reserved system principal")));
        }
    }
    if let Some(code_point) = disallowed_control(kind, value) {
        return Err(RuntimeError::Input(format!("{label} contains disallowed control character U+{code_point:04X}")));
    }
    validate_column_minimum(kind, value, &label)?;
    if !fits(kind, value) {
        return Err(RuntimeError::Input(match value {
            None | Some(Value::Null) => format!("{label} is required ({kind})"),
            Some(value) => format!("{label} must be {kind}, not {}", describe(value)),
        }));
    }
    Ok(())
}

// @ref LLP 3000.007#5.4 — nested/optional columns use the same minimum on server and device writes.
fn validate_column_minimum(kind: &ColumnType, value: Option<&Value>, label: &str) -> Result<(), RuntimeError> {
    match (kind, value) {
        (ColumnType::Optional(inner), Some(value)) => validate_column_minimum(inner, Some(value), label),
        (ColumnType::List { of, .. } | ColumnType::ListRange { of, .. }, Some(Value::Array(items))) => {
            if let ColumnType::ListRange { min, .. } = kind { validate_list_minimum(label, items.len(), *min)?; }
            for item in items { validate_column_minimum(of, Some(item), label)?; }
            Ok(())
        }
        _ => Ok(()),
    }
}

fn validate_list_minimum(label: &str, length: usize, min: u32) -> Result<(), RuntimeError> {
    if length < min as usize {
        return Err(RuntimeError::Input(format!("{label} needs at least {min} {}; got {length}", if min == 1 { "item" } else { "items" })));
    }
    Ok(())
}

fn describe(value: &Value) -> String {
    match value {
        Value::String(text) if text.chars().count() > 24 => format!("{} characters of text", text.chars().count()),
        Value::String(text) => format!("the text '{text}'"),
        Value::Id(id) => format!("the id '{id}'"),
        Value::Int(n) => format!("the number {n}"),
        Value::Bool(b) => format!("the boolean {b}"),
        Value::Null => "null".into(),
        Value::Bytes(b) => format!("{} bytes", b.len()),
        Value::Array(items) => format!("a list of {}", items.len()),
        Value::Row(_) | Value::Map(_) => "an object".into(),
    }
}

pub fn validate_text(label: &str, text: &str, min: u32, format: Option<TextFormat>) -> Result<(), RuntimeError> {
    // @ref LLP 3000.036.004#6-bakeoff-repairs — minimums measure evidence, while maxima still measure the complete value.
    let length = text.chars().filter(|c| !c.is_whitespace()).count();
    if length < min as usize {
        return Err(RuntimeError::Input(format!("{label} needs at least {min} non-whitespace characters; got {length}")));
    }
    if let Some(format) = format
        && !format.matches(text)
    {
        return Err(RuntimeError::Input(match format {
            TextFormat::Handle => format!("{label} must be a handle: lowercase letters, digits and underscores"),
            TextFormat::Url => format!("{label} must be an http or https URL"),
            TextFormat::Email => format!("{label} must be an ASCII email address with one @, a dot-safe local part, and valid domain labels"),
        }));
    }
    Ok(())
}

fn disallowed_control(kind: &ColumnType, value: Option<&Value>) -> Option<u32> {
    match (kind, value) {
        (ColumnType::Optional(inner), Some(value)) => disallowed_control(inner, Some(value)),
        (ColumnType::List { of, .. } | ColumnType::ListRange { of, .. }, Some(Value::Array(values))) => values.iter().find_map(|value| disallowed_control(of, Some(value))),
        (ColumnType::Text { .. }, Some(Value::String(text))) => disallowed_text_control(text),
        _ => None,
    }
}

/// Text forbids C0 controls except tab, LF and CR.
pub fn disallowed_text_control(text: &str) -> Option<u32> {
    text.chars().find(|c| c.is_control() && !matches!(c, '\t' | '\n' | '\r')).map(|c| c as u32)
}

pub(crate) fn fits(kind: &ColumnType, value: Option<&Value>) -> bool {
    match (kind, value) {
        (ColumnType::Optional(_), None | Some(Value::Null)) => true,
        (ColumnType::Optional(inner), Some(value)) => fits(inner, Some(value)),
        (ColumnType::List { of, max } | ColumnType::ListRange { of, max, .. }, Some(Value::Array(values))) => values.len() <= *max as usize && values.iter().all(|value| fits(of, Some(value))),
        // @ref LLP 3000#7-decisions-during-execution — typed references do not imply target existence
        (ColumnType::Id | ColumnType::Principal | ColumnType::Ref { .. }, Some(Value::Id(_))) => true,
        (ColumnType::Text { max }, Some(Value::String(text))) => text.chars().count() <= *max as usize,
        (ColumnType::Bytes { max }, Some(Value::Bytes(bytes))) => bytes.len() <= *max as usize,
        (ColumnType::Image { .. } | ColumnType::Video { .. } | ColumnType::File { .. }, Some(Value::Map(fields))) => fields.get("id").is_some_and(|id| matches!(id, Value::Id(_))),
        (ColumnType::Enum { variants }, Some(Value::String(value))) => variants.contains(value),
        (ColumnType::Int | ColumnType::Time | ColumnType::Decimal { .. } | ColumnType::Money { .. }, Some(Value::Int(value))) => (I53_MIN..=I53_MAX).contains(value),
        // @ref LLP 3000.040#14-where-the-bound-is-enforced — the slot's bound is part of its type: every stored write and argument meets it here.
        (ColumnType::IntRange { min, max }, Some(Value::Int(value))) => (I53_MIN..=I53_MAX).contains(value) && (*min..=*max).contains(value),
        (ColumnType::Bool, Some(Value::Bool(_))) => true,
        (ColumnType::Json { max_bytes }, Some(value)) => canonical_json(value).len() <= *max_bytes as usize,
        _ => false,
    }
}

fn validate_arguments(schema: &Schema, program: &Program, inputs: &mut BTreeMap<String, Value>) -> Result<(), RuntimeError> {
    for (name, kind) in &program.args {
        if !inputs.contains_key(name) && (kind.is_optional() || matches!(kind, ArgType::Cursor)) {
            inputs.insert(name.clone(), Value::Null);
        }
        let value = inputs.get(name).ok_or_else(|| RuntimeError::Input(format!("missing argument {name}")))?;
        validate_arg(schema, kind, value, name)?;
    }
    if let Some(extra) = inputs.keys().find(|name| !program.args.contains_key(*name)) {
        return Err(RuntimeError::Input(format!("{} takes no argument {extra}", program.name)));
    }
    Ok(())
}

pub fn validate_arg(schema: &Schema, kind: &ArgType, value: &Value, label: &str) -> Result<(), RuntimeError> {
    if !kind.bounds_valid() {
        return Err(RuntimeError::Input(format!("{label} has a minimum greater than its maximum")));
    }
    crate::value::validate_identities(value)?;
    if contains_system_principal(value) {
        return Err(RuntimeError::Input(format!("{label} cannot carry the reserved system principal")));
    }
    match kind {
        ArgType::Cursor => match value {
            Value::Null => Ok(()),
            Value::String(token) => crate::cursor::decode_cursor(schema, token).map(|_| ()).map_err(|error| RuntimeError::Input(format!("{label}: {error}"))),
            _ => Err(RuntimeError::Input(format!("{label} must be an opaque cursor string or null"))),
        },
        ArgType::Optional(_) if *value == Value::Null => Ok(()),
        ArgType::Optional(inner) => validate_arg(schema, inner, value, label),
        ArgType::Scalar => match value {
            Value::Row(_) | Value::Map(_) => Err(RuntimeError::Input(format!("{label} must be a scalar"))),
            _ => Ok(()),
        },
        ArgType::Text { max, min, format } => match value {
            Value::String(text) => {
                if let Some(code_point) = disallowed_text_control(text) {
                    return Err(RuntimeError::Input(format!("{label} contains disallowed control character U+{code_point:04X}")));
                }
                if text.chars().count() > *max as usize {
                    return Err(RuntimeError::Input(format!("{label} is longer than {max} characters")));
                }
                validate_text(label, text, *min, *format)
            }
            other => Err(RuntimeError::Input(format!("{label} must be text, not {}", describe(other)))),
        },
        ArgType::List { of, max } | ArgType::ListRange { of, max, .. } => match value {
            Value::Array(items) => {
                if let ArgType::ListRange { min, .. } = kind { validate_list_minimum(label, items.len(), *min)?; }
                if items.len() > *max as usize {
                    return Err(RuntimeError::Input(format!("{label} has more than {max} items")));
                }
                if let Some(of) = of {
                    for item in items {
                        validate_arg(schema, of, item, label)?;
                    }
                }
                Ok(())
            }
            other => Err(RuntimeError::Input(format!("{label} must be a list, not {}", describe(other)))),
        },
        other => {
            let column = crate::schema::arg_as_column(other).ok_or_else(|| RuntimeError::Input(format!("{label} has no column form")))?;
            if fits(&column, Some(value)) { Ok(()) } else { Err(RuntimeError::Input(format!("{label} must be {column}, not {}", describe(value)))) }
        }
    }
}

/// Missing optional columns read as null; missing required columns with a
/// literal default read that value. Contextual defaults belong to inserts.
pub fn materialize_optional_fields(row: &mut Value, table: &Table) {
    let fields = match row {
        Value::Row(fields) | Value::Map(fields) => fields,
        _ => return,
    };
    for (name, kind) in &table.columns {
        if !fields.contains_key(name) {
            if table.maintained.contains_key(name) {
                fields.insert(name.clone(), Value::Int(0));
            } else if kind.is_optional() {
                fields.insert(name.clone(), Value::Null);
            } else if let Some(ColumnDefault::Literal(value)) = table.defaults.get(name) {
                fields.insert(name.clone(), value.clone());
            }
        }
    }
}

pub struct Counterexample {pub reachability:Reachability,pub invariant_site:String,pub args:BTreeMap<String,Value>,pub viewer:String,pub operation:String,pub effect:String,pub row:Value,pub old:Option<Value>,pub supporting_rows:BTreeMap<String,Vec<Value>>,pub rule_path:String,pub scope:String, pub observations:Option<paired::Observations>,pub history:Vec<histories::Step>}
#[derive(Clone,Debug,Default,Serialize)]
pub struct Campaign {pub paired_observer_calls:usize,pub history_observer_calls:usize,pub column_observer_calls:usize,pub operations:BTreeMap<String,usize>,pub sequences:usize,pub attempted:usize,pub admitted:usize,pub refused:usize,pub violations:Vec<Counterexample>,pub boundary_failures:Vec<String>,pub unsupported:BTreeSet<String>}
fn id(table:&str)->Value {Value::Id(format!("security-{table}"))}
fn sample(kind:&C,variant:usize)->Option<Value>{Some(match kind{
    C::Optional(inner)=>if variant&4!=0{sample(inner,variant).unwrap_or(Value::Null)}else{Value::Null},C::Id|C::Principal=>Value::Id(if variant&1==0{VIEWER}else{OTHER}.into()),
    C::Ref{table}=>id(table),C::Text{max}=>Value::String("x".repeat((*max).min(20) as usize)),
    C::Enum{variants}=>Value::String(variants.get(variant%variants.len())?.clone()),
    C::Int|C::Decimal{..}|C::Money{..}=>Value::Int(1),C::IntRange{min,max}=>Value::Int(1i64.clamp(*min,*max)),
    C::Bool=>Value::Bool((variant>>2)&1==0),C::Time=>Value::Int(NOW-1000),C::Json{..}=>Value::Null,C::Bytes{..}=>Value::Bytes(Vec::new()),
    C::List{..}=>Value::Array(Vec::new()),C::ListRange{of,min,..}=>Value::Array((0..*min).map(|_|sample(of,variant)).collect::<Option<_>>()?),
    C::Image{..}=>Value::String("$security:image".into()),C::File{..}=>Value::String("$security:file".into()),C::Video{..}=>return None,
})}
fn needed(schema:&Schema,name:&str,out:&mut BTreeSet<String>){
    if !out.insert(name.into()){return;}let Some(t)=schema.table(name)else{return};
    for m in schema.maintains.iter().filter(|m|m.target==name){needed(schema,&m.source,out);}
    for k in t.columns.values(){if let C::Ref{table}=k.required(){needed(schema,table,out);}}
    for r in [&t.rules.read,&t.rules.insert,&t.rules.update,&t.rules.delete]{for dep in kernel::dependencies(r){needed(schema,&dep,out);}}
}
fn snapshot(bound:&Bound,inv:&Invariant,variant:usize)->Result<BTreeMap<String,Vec<Value>>,String>{
    snapshot_mode(bound,inv,variant,false)
}
fn snapshot_mode(bound:&Bound,inv:&Invariant,variant:usize,timed:bool)->Result<BTreeMap<String,Vec<Value>>,String>{
    let mut names=BTreeSet::new();needed(&bound.schema,&inv.table,&mut names);
    if let Some(policy)=&inv.policy{for dep in kernel::dependencies(policy){needed(&bound.schema,&dep,&mut names);}}
    if let Some(mut syntax)=inv.syntax.clone(){super::super::intent_walk::expression(&mut syntax,&mut |e| {
        if let ast::Expr::Read(r)|ast::Expr::Exists{read:r,..}=e {needed(&bound.schema,&r.table,&mut names);}
    });}
    if let Some(op)=&inv.operation && let Some(p)=bound.programs.iter().find(|p|&p.program.name==op){for kind in p.program.args.values(){if let ir::ArgType::Ref{table}=kind{needed(&bound.schema,table,&mut names);}}}
    let mut out=BTreeMap::new();
    let mut enum_case=variant;
    for name in names {
        let t=&bound.schema.tables[&name];
        if bound.schema.maintain_for(&name).is_some(){continue;}
        let mut fields=BTreeMap::new();fields.insert("id".into(),id(&name));
        let mut principal_index=0usize;
        for (n,k) in &t.columns{
            if n=="id"||t.engine_field(n)||t.maintained.contains_key(n){continue;}
            let sample_variant=if let C::Enum{variants}=k.required(){let n=enum_case % variants.len();enum_case/=variants.len();n}else if matches!(k.required(),C::Principal){let n=((variant>>((if name==inv.table{0}else{3})+principal_index.min(5)))&1)|(variant&4);principal_index+=1;n}else{variant};
            let value=sample(k,sample_variant)
                .ok_or_else(||format!("{name}.{n}: asset ledger/required sample is not available"))?;
            fields.insert(n.clone(),value);
        }
        if timed || t.read_lifetime_sensitive() {for (n,k) in &t.columns {if matches!(k.required(),C::Time)&&(!k.is_optional()||variant&4!=0) {
            fields.insert(n.clone(),Value::Int(NOW+if t.expire.as_ref()==Some(n){2000}else if timed{1000}else{-1000}));
        }}}
        for constraint in &t.constraints{if let Constraint::Text{field,min,..}=constraint
            && matches!(fields.get(field),Some(Value::String(_))) {fields.insert(field.clone(),Value::String("x".repeat((*min).max(1) as usize)));}}
        // Named primary keys used by role probes must select the challenged
        // viewer; changing the enum represents a current-role change while
        // derived assignment/membership rows remain present.
        if name!=inv.table {for (i,(n,k)) in t.columns.iter().filter(|(_,k)|matches!(k,C::Principal)).enumerate(){fields.insert(n.clone(),Value::Id(if variant & (1 << (i+3)) == 0 {VIEWER}else{OTHER}.into())); let _=k;}}
        out.insert(name,vec![Value::Row(fields.into())]);
    }
    Ok(out)
}
struct Snapshot<'a>{schema:&'a Schema,rows:&'a BTreeMap<String,Vec<Value>>}
impl Probe for Snapshot<'_>{
    fn exists(&mut self,table:&str,index:&str,key:&[Value],equalities:&[(String,Value)])->Result<bool,RuntimeError>{
        let t=&self.schema.tables[table];let Some(idx)=t.index(index)else{return Ok(false)};
        if idx.components.len()!=key.len(){return Ok(false);}
        if idx.unique&&idx.components.iter().any(|c|c.column().is_some_and(|n|t.columns.get(n).is_some_and(C::is_optional)))&&key.contains(&Value::Null){return Ok(false);}
        Ok(self.rows.get(table).into_iter().flatten().filter(|r|live(t,r)).any(|r|idx.components.iter().zip(key).all(|(c,v)|c.column().is_some_and(|n|r.field(n).ok()==Some(v)))&&equalities.iter().all(|(n,v)|r.field(n).ok()==Some(v))))
    }
    fn created(&mut self,_:&str,_:&str,_:&[Value])->bool{false}

}
fn live(t:&snapback4_core::schema::Table,row:&Value)->bool{
    !t.expired(row,NOW)&&t.not_before.as_ref().is_none_or(|c|match row.field(c){Ok(Value::Int(n))=>*n<=NOW,Ok(Value::Null)=>true,_=>false})
}
fn policy(bound:&Bound,inv:&Invariant,rows:&BTreeMap<String,Vec<Value>>,viewer:&str,old:Option<&Value>,row:&Value)->Result<bool,String>{

    let Some(p)=inv.policy.as_ref() else{return inv.syntax.as_ref().and_then(|e|super::concrete::evaluate(e,row,rows,&bound.schema,viewer)).ok_or_else(||"concrete policy expression is unknown/unsupported (including clock and typed literal coercions)".into());};

    let mut image=row.clone();if super::temporal::has_clock(p)&&let Value::Row(fields)=&mut image{fields.insert("$security:server-clock".into(),Value::Int(NOW));}
    if p.has_reference(){return Err("reference intent requires authorized engine policy replay".into());}
    rules::evaluate(p,viewer,old,&image,false,&mut Snapshot{schema:&bound.schema,rows}).map_err(|e|e.to_string())
}
fn policy_in(bound:&Bound,inv:&Invariant,rows:&BTreeMap<String,Vec<Value>>,viewer:&str,old:Option<&Value>,row:&Value,engine:&mut Engine)->Result<bool,String>{
    let Some(p)=&inv.policy else{return policy(bound,inv,rows,viewer,old,row);};
    if !p.has_reference(){return policy(bound,inv,rows,viewer,old,row);}
    let mut image=row.clone();if super::temporal::has_clock(p)&&let Value::Row(fields)=&mut image{fields.insert("$security:server-clock".into(),Value::Int(NOW));}
    match engine.fixture_policy(p,viewer,old,&image,NOW).map_err(|e|e.to_string())?{
        rules::Verdict::Readable=>Ok(true),rules::Verdict::Denied=>Ok(false),rules::Verdict::Unknown=>Err("policy reference/coverage judgment is unknown; never a refutation".into()),
    }
}
fn program(name:&str,kind:ProgramKind,body:Vec<Stmt>)->Program{Program{name:name.into(),kind,args:BTreeMap::new(),body,read_time_granularity_ms:None,returned_shapes:BTreeMap::new(),native:false}}
fn engine(bound:&Bound,rows:&BTreeMap<String,Vec<Value>>,probe:Program)->Result<Engine,String>{
    engine_with(bound,rows,vec![probe])
}
fn engine_with(bound:&Bound,rows:&BTreeMap<String,Vec<Value>>,probes:Vec<Program>)->Result<Engine,String>{
    engine_on_store(bound,rows,probes,Store::memory().map_err(|e|e.to_string())?)
}
fn engine_on_store(bound:&Bound,rows:&BTreeMap<String,Vec<Value>>,probes:Vec<Program>,store:Store)->Result<Engine,String>{
    let mut programs=bound.programs.iter().map(|p|p.program.clone()).collect::<Vec<_>>();programs.extend(probes);
    let mut engine=Engine::new_at(store,bound.schema.clone(),programs,NOW).map_err(|e|e.to_string())?;
    fn hydrate(engine:&mut Engine,kind:&C,value:&Value)->Result<Value,String>{
        match (kind,value) {
            (C::Optional(inner),v) if *v!=Value::Null=>hydrate(engine,inner,v),
            (C::List{of,..}|C::ListRange{of,..},Value::Array(xs))=>xs.iter().map(|v|hydrate(engine,of,v)).collect::<Result<Vec<_>,_>>().map(Value::Array),
            (C::Image{..},Value::String(marker)) if marker=="$security:image"=>engine.store_asset(VIEWER,&PNG,NOW).map(|a|a.column_value()).map_err(|e|format!("verified image fixture: {e}")),
            (C::File{types,..},Value::String(marker)) if marker=="$security:file"=>assets::file(engine,VIEWER,types),
            _=>Ok(value.clone()),
        }
    }
    let mut seeded=rows.iter().filter(|(name,_)|bound.schema.maintain_for(name).is_none()).map(|(name,rs)|{
        let t=&bound.schema.tables[name];
        let clean=rs.iter().map(|r|if let Value::Row(fields)=r {Value::Row(fields.iter().filter(|(c,_)|!t.engine_field(c)&&!t.recorded.contains_key(*c)&&!t.maintained.contains_key(*c)).map(|(c,v)|(c.clone(),v.clone())).collect())}else{r.clone()}).collect();
        (name.clone(),clean)
    }).collect::<BTreeMap<String,Vec<Value>>>();
    for (table,values) in &mut seeded {for row in values {for (column,kind) in &bound.schema.tables[table].columns {
        if let Ok(v)=row.field(column) {
            let value=hydrate(&mut engine,kind,v)?;
            if let Value::Row(fields)=row {fields.insert(column.clone(),value);}
        }
    }}}
    engine.seed_at(seeded.iter().flat_map(|(t,rs)|rs.iter().map(move|r|(t.clone(),r.clone()))).collect::<Vec<_>>(),NOW).map_err(|e|format!("generated snapshot rejected by schema: {e}"))?;
    let actual=readback(&engine)?;
    for (name,values) in &actual {for row in values {
        snapback4_core::engine::validate::validate_row(&bound.schema,name,row).map_err(|e|e.to_string())?;
        for c in &bound.schema.tables[name].constraints {if let Constraint::FinalExistsOnInsert{table,index,key}=c {
            let rule=RuleExpr::Exists{table:table.clone(),index:index.clone(),key:key.clone(),provenance:KeyProvenance::Computed,equalities:Vec::new()};
            if engine.fixture_policy(&rule,snapback4_core::SYSTEM_PRINCIPAL,None,row,NOW).map_err(|e|e.to_string())?!=rules::Verdict::Readable {return Err(format!("{name}: trusted seed did not establish final-exists constraint"));}
    use ir::ArgType as A;
    fn one(k:&A,v:usize)->Option<Value>{Some(match k{
        A::Ref{table}=>id(table),A::Principal=>Value::Id(if v&1==0{OTHER}else{VIEWER}.into()),A::Id=>Value::Id("security-argument".into()),A::Cursor|A::Optional(_)=>Value::Null,
        A::Text{min,max,..}=>Value::String("z".repeat((*min).max(1).min(*max) as usize)),A::Enum{variants}=>Value::String(variants.get(v%variants.len())?.clone()),A::Int|A::Decimal{..}|A::Money{..}=>Value::Int(1),A::IntRange{min,max}=>Value::Int(1i64.clamp(*min,*max)),A::Time=>Value::Int(NOW+86_400_000),A::Bool=>Value::Bool(v&2==0),A::List{..}=>Value::Array(Vec::new()),A::Json{..}=>Value::Null,A::Bytes{..}=>Value::Bytes(Vec::new()),A::Image{..}=>Value::String("$security:image".into()),A::File{..}=>Value::String("$security:file".into()),_=>return None,
    })}
    args.iter().map(|(n,k)|one(k,variant).map(|v|(n.clone(),v))).collect()
}

fn materialize_arguments(engine:&mut Engine,args:&BTreeMap<String,ir::ArgType>,values:&BTreeMap<String,Value>,viewer:&str)->Result<BTreeMap<String,Value>,String>{
    fn one(e:&mut Engine,k:&ir::ArgType,v:&Value,viewer:&str)->Result<Value,String>{Ok(match (k,v){
        (ir::ArgType::Optional(inner),v) if *v!=Value::Null=>one(e,inner,v,viewer)?,
        (ir::ArgType::List{of:Some(inner),..}|ir::ArgType::ListRange{of:Some(inner),..},Value::Array(xs))=>Value::Array(xs.iter().map(|v|one(e,inner,v,viewer)).collect::<Result<_,_>>()?),
        (ir::ArgType::Image{..},Value::String(marker)) if marker=="$security:image"=>e.store_asset(viewer,&PNG,NOW).map_err(|e|e.to_string())?.column_value(),
        (ir::ArgType::File{types,..},Value::String(marker)) if marker=="$security:file"=>assets::file(e,viewer,types)?,
        _=>v.clone(),
    })}
    values.iter().map(|(n,v)|one(engine,&args[n],v,viewer).map(|v|(n.clone(),v))).collect()
}

/// Exercise every authored query/mutation with cross-principal candidates.
/// This is conformance exploration, not a guessed spec oracle: only declared
/// policies and replayed violations can fail security acceptance.
pub fn fixture_observers(bound:&Bound,fixture:&Engine,campaign:&mut Campaign){
    column_reads::fixture(bound,fixture,campaign);
    histories::run(bound,fixture,campaign);
}
pub fn operations(bound:&Bound,fixture:&Engine,campaign:&mut Campaign){
    fixture_observers(bound,fixture,campaign);
    assets::run(bound,fixture,campaign);
    let fixtures=match readback(fixture){Ok(r)=>r,Err(e)=>{campaign.unsupported.insert(e);return;}};
    let has_fixture=fixtures.values().any(|r|!r.is_empty());
                    match engine.mutate(&p.program.name,None,Context::new(viewer,args.clone()).at(NOW)){Ok(result) if matches!(result.state,snapback4_core::WriteState::Failed{..})=>campaign.refused+=1,Err(e)=>{campaign.unsupported.insert(format!("{}: matrix engine error {e}",p.program.name));},_=>{},}
                }
            }
        }
    }
}

fn fork(_bound:&Bound,fixture:&Engine,probes:Vec<Program>)->Result<Engine,String>{
    if !probes.is_empty(){return Err("fixture probes must be authored operations".into());}
    fixture.fork_fixture().map_err(|e|e.to_string())
}
//! Paired logical observations, replayed independently in memory.
// @ref LLP 3000.036.004#101-separate-observer-obligations — two valid worlds and repeatable observations are required.
use super::*;

#[derive(Clone,Debug,Serialize)]
pub struct Observations {
    pub present: serde_json::Value,
    pub absent: serde_json::Value,
    pub absent_rows: BTreeMap<String,Vec<Value>>,
}

pub(super) fn observe(engine:&mut Engine,p:&Program,viewer:&str,args:BTreeMap<String,Value>)->Result<serde_json::Value,String>{
    let context=Context::new(viewer,args).at(NOW);
    if p.kind==ProgramKind::Query {
        match engine.query(&p.name,context) {
            Ok(q) if q.unavailable || !q.complete => Err("incomplete/metered query is outside logical payload comparison".into()),
            Ok(q)=>Ok(serde_json::json!({"data":q.data})),
            Err(e) if e.rule.is_some() && matches!(e.family.as_str(),"rule"|"constraint") => Ok(serde_json::json!({"refusal":{"code":e.code,"message":e.message}})),
            Err(e)=>Err(format!("query error is not an admitted observation: {e}")),
        }
    }else{
        match engine.mutate(&p.name,None,context).map_err(|e|e.to_string())?.state {
            snapback4_core::WriteState::Sent{result,..}=>Ok(serde_json::json!({"sent":result})),
            snapback4_core::WriteState::Failed{why,current}=>{
                // E_RULE can also mask authorization-budget exhaustion. Only
                // an authored require/constraint carries this rule marker;
                // bound/storage/schema/ambiguous engine refusals cannot be a
                // logical counterexample in our resource-excluding contract.
                if why.rule.is_none()||!matches!(why.family.as_str(),"rule"|"constraint") {
                    return Err(format!("resource/engine or ambiguous mutation refusal {} is outside paired logical comparison",why.code));
                }
                Ok(serde_json::json!({"refusal":{"code":why.code,"message":why.message},"current":current}))
            },
        }
    }
}

pub(super) fn run(bound:&Bound,out:&mut Campaign,sites:Option<&BTreeSet<String>>){
    for inv in bound.invariants.iter().filter(|i|i.target=="read"&&i.column.as_deref().is_none_or(|c|c=="id")&&sites.is_none_or(|s|s.contains(&i.site.to_string()))) {
        if inv.policy.is_none(){out.unsupported.insert(format!("{}: paired observation needs complete bound policy dependencies; unsupported policy AST is not dependency-free",inv.table));continue;}
        if out.violations.iter().any(|v|v.invariant_site==inv.site.to_string()){continue;}
        // Closed transitive observer set: include maintained targets, inherited
        // readers and every table whose rule probes an affected population.
        // An operation mentioning none of them has no logical input changed
        // by this pair. This prunes experiments, never proves an obligation.
        let mut observers=BTreeSet::from([inv.table.clone()]);
        loop {
            let before=observers.len();
            for m in &bound.schema.maintains {if observers.contains(&m.source){
                observers.insert(m.target.clone());
                if let Some(owner)=&m.private{observers.insert(owner.table.clone());}
            }}
            for (name,t) in &bound.schema.tables {
                if t.through.as_ref().is_some_and(|p|observers.contains(&p.parent))
                    || [&t.rules.read,&t.rules.insert,&t.rules.update,&t.rules.delete].iter().any(|r|kernel::dependencies(r).iter().any(|d|observers.contains(d))) {
                    observers.insert(name.clone());
                }
            }
            if observers.len()==before{break;}
        }
        // Removing an ordinary row must not manufacture an invalid reference
        // graph. More general paired deletions need a checked closure.
        if bound.schema.tables.values().any(|t|t.columns.values().any(|k|matches!(k.required(),C::Ref{table} if table==&inv.table))) {
            out.unsupported.insert(format!("{}: paired absence needs a referentially valid world closure",inv.table));continue;
        }
        for variant in 0..8 {
            let Ok(present)=snapshot(bound,inv,variant)else{continue;};
            if present.keys().any(|name|bound.schema.tables[name].columns.values().any(C::contains_asset)) {
                out.unsupported.insert(format!("{}: paired fixture asset identities are not coupled",inv.table));continue;
            }
            let Some(row)=present.get(&inv.table).and_then(|rs|rs.first()).cloned()else{continue;};
            let prepared=(||->Result<Value,String>{
                let e=engine(bound,&present,program("$security.pair.image",ProgramKind::Query,vec![Stmt::Return(Expr::Literal(Value::Null))]))?;
                let actual=readback(&e)?;
                actual.get(&inv.table).into_iter().flatten().find(|r|r.field("id").ok()==row.field("id").ok()).cloned().ok_or_else(||"protected paired row is absent after validation".into())
            })();
            let row=prepared.as_ref().unwrap_or(&row);
            let mut absent=present.clone();absent.remove(&inv.table);
            // Final-exists validation is a pure judgment of this fixed seeded
            // world, before operation/viewer admission. Retain its rejection
            // across observers, never cache execution/resource/policy results.
            let invalid=std::cell::RefCell::new([None::<String>,None]);
            for viewer in [VIEWER,OTHER,"account:security-no-role","service:security"] {
                for bp in &bound.programs {
                    let p=&bp.program;
                    if !matches!(p.kind,ProgramKind::Query|ProgramKind::Mutation)||p.native {continue;}
                    let writes=ir::write_tables(p);
                    let deps=inv.policy.as_ref().map(kernel::dependencies).unwrap_or_default();
                    if writes.iter().any(|(table,kind)|table==&inv.table||deps.contains(table)||*kind!="update")
                        || !writes.is_empty() && (!bound.schema.maintains.is_empty() || bound.schema.tables.values().any(|t|!t.sequences.is_empty()||!t.on_delete.is_empty())) {
                        out.unsupported.insert(format!("{}: paired mutation lacks stable policy/implicit-write and deterministic-id reduction",p.name));continue;
                    }
                    let json=serde_json::to_value(p).unwrap();
                    if !observers.iter().any(|table|super::super::audit::mentions(&json,table)){continue;}
                    // Fresh generated ids and opaque viewer/work contexts are
                    // not repeatable functions of these paired inputs.
                    fn opaque(v:&serde_json::Value)->bool {match v{
                        serde_json::Value::String(s)=>s=="NewId"||s=="JobAs",
                        serde_json::Value::Object(m)=>m.keys().any(|k|matches!(k.as_str(),"Emit"|"JobAs"|"JobQuery"))||m.values().any(opaque),
                        serde_json::Value::Array(xs)=>xs.iter().any(opaque),_=>false,
                    }}
                    if opaque(&json){out.unsupported.insert(format!("{}: generated-id/opaque effects excluded from paired determinism",p.name));continue;}
                    let cases=histories::fixture_cases(&p.args,&present,&[VIEWER.into(),OTHER.into()],out);
                    if cases.len()>32{out.unsupported.insert(format!("{}: paired observer arguments capped at 32; remaining combinations not covered",p.name));}
                    for args in cases.into_iter().take(32){
                    if out.paired_observer_calls+4>8192{out.unsupported.insert("paired observers capped at 8192 call reservations; remaining worlds not covered".into());return;}
                    out.paired_observer_calls+=4;
                    let execute=|seeds:&BTreeMap<String,Vec<Value>>|->Result<(serde_json::Value,BTreeMap<String,Vec<Value>>),String>{
                        if let Err(why)=&prepared{return Err(why.clone());}

                        let slot=usize::from(std::ptr::eq(seeds,&absent));
                        if let Some(why)=&invalid.borrow()[slot]{return Err(why.clone());}
                        let mut e=match engine(bound,seeds,program("$security.pair",ProgramKind::Query,vec![Stmt::Return(Expr::Literal(Value::Null))])){
                            Ok(e)=>e,Err(why)=>{
                                if why.ends_with(": trusted seed did not establish final-exists constraint"){invalid.borrow_mut()[slot]=Some(why.clone());}
                                return Err(why);
                            },
                        };
                        let actual=readback(&e)?;
                        // Judge the hypothetical protected row in each complete
                        // committed world, before any operation can change roles.
                        let focal=actual.get(&inv.table).into_iter().flatten().find(|r|r.field("id").ok()==row.field("id").ok()).cloned().unwrap_or_else(||row.clone());
                        if policy_in(bound,inv,&actual,viewer,None,&focal,&mut e)!=Ok(false){return Err("paired policy is not definitely false in both worlds".into());}
                        observe(&mut e,p,viewer,args.clone()).map(|value|(value,actual))
                    };
                    let ((a,rows),(b,absent_rows))=match (execute(&present),execute(&absent)) {
                        (Ok(a),Ok(b))=>(a,b),
                        (Err(e),_)|(_,Err(e))=>{
                            if !e.starts_with("paired policy is not definitely false") {out.unsupported.insert(format!("{}: {e}",p.name));}
                            continue;
                        },
                    };
                    out.attempted+=2;*out.operations.entry(p.name.clone()).or_default()+=2;
                    if a==b {continue;}
                    // The query order is engine-defined. Recreate both worlds
                    // to decline store-scoped cursors or unstable outputs.
                    if !matches!((execute(&present),execute(&absent)),(Ok((aa,_)),Ok((bb,_))) if aa==a&&bb==b){
                        out.unsupported.insert(format!("{}: paired observation is not repeatable",p.name));continue;
                    }
                    out.violations.push(Counterexample {reachability:Reachability::SyntheticOperation,history:Vec::new(),invariant_site:inv.site.to_string(),args:args.clone(),viewer:viewer.into(),
                        operation:p.name.clone(),effect:"read observation".into(),row:row.clone(),old:None,supporting_rows:rows,
                        rule_path:"paired present/absent engine executions differ while the declared privacy policy is false in both".into(),
                        scope:"schema-valid seed-ingress paired worlds; authenticated logical data/refusal only; no application reachability claim".into(),
                        observations:Some(Observations{present:a,absent:b,absent_rows})});

    let bounded=crate::schema::live::has_live(schema);
    let mut bulk_meter=Meter::new(if bounded {Ceilings::job()}else{Ceilings::unbounded()},Cut::Abort);
    let rows:Box<dyn Iterator<Item=(String,Value)> + '_>=if bounded {Box::new(live_bulk::collect(rows,&mut bulk_meter)?.into_iter())}else{Box::new(rows.into_iter())};
    let rows = through_activation::ancestor_order(schema, rows);
    let targets: std::collections::BTreeSet<_> = schema.tables.values().flat_map(|table| table.recorded.values().map(|field| field.table.as_str())).collect();
    let mut imports = BTreeMap::<(String, String), Value>::new();
    let rows: Box<dyn Iterator<Item = (String, Value)> + '_> = if targets.is_empty() { Box::new(rows.into_iter()) } else {
        let rows: Vec<_> = rows.into_iter().collect();
        // A capture sees the imported target's eventual image, including
        // fields retained by patches, defaults and assigned ordinals.
        // Preview every allocation in input order (counters cross tables),
        // then undo the preview; ordinary writes allocate in that same
        // transaction and still own all validation, events and rollback.
        tx.savepoint("seed_sequences")?;
        let mut staging = Runner::new(tx, schema, Context::system().at(now), bulk_meter, 0);
        for (name, row) in &rows {
            if bounded {staging.reserve_bulk_source(name)?;staging.meter.heap(crate::rows::disclosed::decode_reservation(&schema.tables[name]).saturating_mul(4))?;}
            schema.refuse_ephemeral_import(name)?;
            let table = schema.table(name).ok_or_else(|| RuntimeError::Schema(format!("missing table {name}")))?;
            sequences::refuse_fields(table, name, row)?;
            let id = row.field("id")?.as_str()?.to_owned();
            let old = match imports.get(&(name.clone(), id.clone())) { Some(row) => Some(row.clone()), None => tx.get(name, &id)? }.filter(|row| !table.expired(row, now));
            let mut fields = old.as_ref().map(|row| row.as_object().cloned()).transpose()?.unwrap_or_default();
            fields.extend(row.as_object()?.clone());
            if old.is_none() { for (field, default) in &table.defaults { fields.entry(field.clone()).or_insert_with(|| default.value(now, crate::SYSTEM_PRINCIPAL)); } }
            let mut image = Value::Row(fields.into());
            if old.is_none() {
                let (assigned, full) = staging.sequence_fields(name, image.import_input(&ImportInput(())))?;
                if full { return Err(sequences::exhausted()); }
                staging.commit_sequences(name, &assigned)?;
                image = assigned;
            }
            imports.insert((name.clone(), id), image);
        }
        bulk_meter=staging.meter.clone();
        drop(staging);
        tx.rollback_to("seed_sequences")?;
        Box::new(rows.into_iter())
    };
    let seq = tx.next_seq()?;
    let mut runner = Runner::new(tx, schema, Context::system().at(now), bulk_meter, seq);
    runner.import_targets = Some(&imports);
    let mut count = 0;
    for (table, row) in rows {
        if bounded {runner.reserve_bulk_source(&table)?;}
        schema.refuse_ephemeral_import(&table)?;
        timeline::check_import(schema, &table)?;
        runner.upsert(&table, &row.field("id")?.clone(), row.import_input(&ImportInput(())))?;
        count += 1;
    }
    // Seeds preserve ordinary expired images for a later sweep. A source of
    // a row-keyed view is the established exception: an already-expired
    // seeded image must not enter a committed count basis or revive after
    // a clock rollback. Route only those sources through the common retirement
    // path so reference actions and net maintenance still run transactionally.
    // @ref LLP 3000.039#6.5 — seeded expired row-view sources retire with actions; unrelated expired fixtures remain stored.
    let final_exists = runner.satisfied_final_exists()?;
    runner.retire_seeded_view_sources()?;
    // Seeds historically admit fixture rows whose obligations are not
    // meaningful under the system viewer. Retirement may not invalidate an
    // obligation that did hold immediately before its reference actions.
    runner.check_final_exists_witnesses(&final_exists)?;
    let events = runner.events.take();
    let tables: Vec<String> = runner.written_tables.iter().cloned().collect();
    drop(runner);
    if count > 0 {
        tx.record_commit(seq, now, "seed", crate::SYSTEM_PRINCIPAL, "seed", &tables, count)?;
        partition::append(tx, seq, &events)?;
