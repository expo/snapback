## 1. The mark

The binder considers only a **query** AST node that is a top-level `Return` of `Shape` whose base is `Read`, `Merge`, or `Name` (`program.rs` 141–143). After lowering, `returned_shapes::marks` (`returned_shapes.rs` 5–21) keeps that candidate only when the IR is `For` immediately followed by `Return` of the collector that the loop’s last statement `Push`es, and the loop domain is:

- `LoopDomain::Page(scan)` — inline scan, or
- `DerivedArray` of `Expr::Merge` — inline merge, or
- `DerivedArray` of a variable with **exactly one definition in the whole lowered body**, that definition a `Scan`/`Merge` (`reads`), and **exactly one use** (this domain).

Helpers are not `Query`, so they get an empty map (`feed_forms.rs` 169–172). Inlined helper `return` becomes assign + loop-local `Break` (`control.rs` 509), not a top-level `Return` of Shape.

A marked loop cannot return or alias its **base** page: lowering of `return <page> { … }` always allocates a fresh collector temp and returns that (`program.rs` 578–593); the census rejects a second use (`return page { id, raw: page }`, alias, ignored copy, reassignment — `feed_forms.rs` 150–153). An inline base has no variable.

`Plan.shapes` is filled only from `program.returned_shapes` (`pages.rs` 57–62). The following `Return` is overwritten to `ReturnedPage { page, shapes: {loop path} }` (63). Every other return keeps main’s `result_page` owner with an empty `shapes` set (53–54). The runner therefore trims only `page_plan.shapes.get(&site)` (270–283) and applies a shape-owned cursor only when `returned.shapes` is non-empty (371–379).

`pages.rs` origin analysis matches main: `Origin` is `Empty | Page | Record | Cursor`; the `if` join is equality-of-maps (262–266); a loop body is visited once (272–313). There is no `join_origin`, `Unknown`, lineage, payload probe, or origin fixpoint. The wrap program from recheck 4 (`shape_pages.rs` 681–690) is an ordinary loop assignment plus a unique sibling page; it compiles and plans. Main’s separate collector-liveness helper still has a **bounded** name-set loop (`page_collectors.rs` 67–81) that widens a growing field path to the whole variable; that is pre-existing, not this lane’s origin analysis.

Unmarked serialized IR does not grow a field: `returned_shapes` is `skip_serializing_if = "BTreeMap::is_empty"` (`ir.rs` 29–30). `feed_forms.rs` 166 asserts the key is absent. `lowering.rs` 41–45 hashes unmarked IR as-is against the historical golden and strips only this map for marked programs; ownership-on/off still compare the full marked bytes.
