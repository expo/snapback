## 1. The revision-11 finding

Revision 11 left the repost slot optional, so a missing value materializes as null (event absence), and `keeps_literal_default_images` stays true when that diff also adds a literal default. `adopt` then keeps every image and marks the generation acquired.

Revision 12 closes that in §2.1a. The post slot is a required bool with no default: false means filled and not live, and a missing field is not false. It is not a maintained column. The repost slot is an optional id: null means filled and no event. Any generation that adds either slot forces `keeps_literal_default_images` false, including beside a literal default. The fill still runs before `assess` and before row validation, and it does not log.

The new sentence is what covers a later diff that adds only the optional repost slot beside a literal default: today that returns true, because the function returns true once any required literal default was added and nothing else failed.
- `adopt` therefore deletes stored images and sets acquisition to empty, not to the new generation (`device.rs`). `require_acquired` fails. A repost of P does not run, so it does not treat a missing slot as absence and does not refuse `FEED_POST_NOT_FOUND`. The read is unavailable and the mutation is queued.

A missing required bool is not materialized: `materialize_optional_fields` fills an optional with null, a maintained field with integer 0, or a literal default, and nothing else. After publication, P is true, the reply is false, and the repost slot is the minted id. A null repost slot is "filled, no event," not an unfilled post.

## 2. Nothing new that would make an implementation wrong

The required bool is not the maintained arm. That arm classifies the add as additive and a missing field reads as integer 0 (`validate.rs` and `materialize_optional_fields`), which is the wrong type for a bool, and `birth_columns` would overwrite it on insert. The text excludes that arm. False has to be stored; a missing post slot stays missing, and the device never answers while acquisition is clear.
