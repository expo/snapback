`snapback4 witness web [dist]` serves an existing export on an allocated
loopback port, launches headless Chromium (SNAPBACK4_CHROMIUM overrides cache
and standard-path discovery), opens the real page with `?api=&witness=web`,
then uses its persona or sign-in UI (signup on the owned empty backend). It calls that app's authenticated SDK
client, using the first generated durable mutation or `--mutation` and `--args`, and
requires terminal `sent`; failed/pending/timeout are nonzero with a reason.

`registerWebWitness(app, api)` from `snapback4/witness-web`; starters include
this hook. It exists only under the explicit query flag, adds no authority,
and is callable by the page's own scripts already holding that client.
This proves exported client/auth/write integration, not the application's
composer UI or an arbitrary user journey. Missing registration refuses.

runs repeatable without changing the project's durable store. `--url` never
resets a caller-owned server; a deterministic id derived from principal,
operation selection and canonical arguments deduplicates repeated proof
writes under that store's receipt guarantees. Different arguments are new
intents. Credentials are supplied through a named environment variable,
never printed. Cleanup records the owned backend immediately at spawn, even before readiness;
its supervisor PID also stops it if the witness dies. It closes the browser/static
server and only the owned backend; long polls never require networkidle.

`upgrade [version]` detects npm/bun/pnpm by packageManager then lockfile,
refusing ambiguous locks. It resolves latest once, preflights core and installed
Expo adapter versions, installs that same exact pin through the manager,
preserves dependency sections and verifies resulting package pins. Native
rebuild and check/acceptance remain explicit. Package-manager failures return
nonzero; its ordinary lockfile/install recovery applies.

Dropping a null mutation id is a serialization amendment only: a request
without id remains a fresh, non-deduplicated write. Callers mint ids for retries.
No id is fabricated after execution. Omitted ids remain omitted on error paths.

   188	/// One module from a sign-in head and a screen body, each written as a whole
   189	/// file: their single-line named imports merge per module (packages before
   190	/// `../`, then `./`), then the head's code, then the body's.
   191	fn compose(head: &str, body: &str) -> String {
   192	    fn split(text: &str) -> (Vec<&str>, &str) {
   193	        let mut imports = Vec::new();
   194	        let mut rest = text;
   195	        while let Some(line) = rest.split_inclusive('\n').next().filter(|line| line.starts_with("import ")) {
   196	            imports.push(line.trim_end());
   197	            rest = &rest[line.len()..];
   198	        }

   200	    }
   201	    let (head_imports, head_code) = split(head);
   202	    let (body_imports, body_code) = split(body);
   203	    // (`import {` or `import type {`, module, names) in first-seen order.
   204	    let mut merged: Vec<(String, String, Vec<String>)> = Vec::new();
   205	    for line in head_imports.into_iter().chain(body_imports) {
   206	        let (Some(open), Some(close)) = (line.find('{'), line.find('}')) else { panic!("starter imports are `import {{ … }} from \"…\";`: {line}") };
   207	        let (kind, module) = (line[..open].trim().to_owned(), line[close + 1..].trim().to_owned());
   208	        let names = line[open + 1..close].split(',').map(|name| name.trim().to_owned()).filter(|name| !name.is_empty());
   209	        match merged.iter_mut().find(|(k, m, _)| *k == kind && *m == module) {
   210	            Some((_, _, existing)) => for name in names { if !existing.contains(&name) { existing.push(name); } },
   211	            None => merged.push((kind, module, names.collect())),
   212	        }
   213	    }
   214	    merged.sort_by_key(|(_, module, _)| if module.contains("\"../") { 1 } else if module.contains("\"./") { 2 } else { 0 });
   215	    let imports = merged.iter().map(|(kind, module, names)| format!("{kind} {{ {} }} {module}\n", names.join(", "))).collect::<String>();

#[derive(Clone, PartialEq, Eq, Debug)]
pub(super) enum Offline {
    /// The schema does not compile (yet), or there is none: no claim either way.
    Unknown,
    /// The tables that declare `sync`, and how many tables there are (views excluded).
    Tables { synced: Vec<String>, total: usize },

impl Offline {
    /// The README paragraph (it always starts with "Offline", which is how
    /// `init --adapt` finds it again), wrapped like the rest of the README.
    pub(super) fn paragraph(&self, platform: Platform) -> String {
        let lead = match platform { Platform::Web => "Offline:", Platform::Expo => "Offline, in device builds and on the web:" };
        let body = match self {
            Offline::Unknown => "tables that declare `sync` read and write offline and sync when the link returns; the others read from the server, and writes to them made offline are kept on this device and sent when the link returns (`npx snapback4 guide sync`).".to_owned(),
            Offline::Tables { synced, .. } if synced.is_empty() => format!("no table in `snapback/*.q` declares `sync`, so reads need the server. Writes made offline are kept {} and sent when the link returns. Add `sync` to a table to read it offline (`npx snapback4 guide sync`).", if platform == Platform::Web { "in this browser's principal journal" } else { "on this device" }),
            Offline::Tables { synced, total } if synced.len() >= *total => "every table declares `sync`, so the app reads and writes offline and syncs when the link returns.".to_owned(),
            Offline::Tables { synced, .. } => format!("the synced {} ({}) {} and {} offline and {} when the link returns; the other tables read from the server, and writes to them made offline are sent when the link returns (`npx snapback4 guide sync`).",
                if synced.len() == 1 { "table" } else { "tables" }, synced.iter().map(|name| format!("`{name}`")).collect::<Vec<_>>().join(", "),
                if synced.len() == 1 { "reads" } else { "read" }, if synced.len() == 1 { "writes" } else { "write" }, if synced.len() == 1 { "syncs" } else { "sync" }),
        };
        wrap(&format!("{lead} {body}"), 80)
    }

    /// init's one-line summary of the same fact, or nothing when unknown.
    pub(super) fn summary(&self) -> &'static str {
        match self {
            Offline::Unknown => "",
            Offline::Tables { synced, .. } if synced.is_empty() => ", online reads (no table declares `sync`; offline writes queue in the write journal)",
            Offline::Tables { .. } => ", offline-capable for its synced tables",
        }
    }
}

/// Wrap at `width`, never inside a `code span`.
fn wrap(text: &str, width: usize) -> String {
    let mut words: Vec<String> = Vec::new();
    for word in text.split(' ') {
        match words.last_mut() {
            Some(open) if open.matches('`').count() % 2 == 1 => { open.push(' '); open.push_str(word); }
            _ => words.push(word.to_owned()),
        }
    }
    let mut lines: Vec<String> = Vec::new();
    for word in &words {
        match lines.last_mut() {
            Some(line) if line.len() + 1 + word.len() <= width => { line.push(' '); line.push_str(word); }
            _ => lines.push(word.clone()),
        }
    }
    lines.join("\n")
}

pub(super) fn without_offline(text: &str) -> String {
    let legacy = [
        ("the Snapback 4 web starter. It works offline and syncs when the link returns.\n", "the Snapback 4 web starter.\n\nOFFLINE\n"),
        ("started from the Snapback 4 Expo starter. Development and production builds\nopen the native device and work offline; Expo Go uses the online client; web\nuses the wasm device.\n",

    ];
    let mut text = text.to_owned();
    for (old, new) in legacy { text = text.replacen(old, new, 1); }
    text.split("\n\n").map(|paragraph| if paragraph.starts_with("Offline") { "OFFLINE" } else { paragraph }).collect::<Vec<_>>().join("\n\n")
}
