Material concerns and minimal fixes:

1. **§2 seat-token lifecycle unstated (security).** A seat branch delegates membership authority — enroll anyone, retarget mutable memberships — strictly stronger than §20.6's read-only seat. "Operator mints a seat token" names no expiry, revocation, or rotation. Fix: require short-lived, revocable seat tokens with deploy-card rotation guidance, plus an acceptance test that an expired/revoked seat is refused.
2. **§2 unmintable names satisfy the guard.** `service_grant()` accepts any nonempty name, but `service_session` enforces `valid_name` (1–64 alnum/`_`/`-`). A rule naming an unmintable seat passes the guard and, via §3, counts as an LFP root for a table that can never bootstrap. Fix: binder note on unmintable service literals; exclude them from LFP roots.
3. **§2 bootstrap rewrite must replace, not append.** Appending `or viewer='service:X'` to an open self-join rule still refuses (Or needs every branch guarded). Fix: state the offered rewrite replaces the open branch (or conjoins the probe into it), and assert the offered text binds clean.
4. **§5 "compiled" is undefined.** A rewrite that binds but carries its own refusal repeats fix-list #15. Fix: define compiled as binding with no new errors (say whether new notes are tolerated) and assert error/note deltas in the extended golden test.
5. **§4 E_INPUT matching is too coarse.** Mapping signature/decoding/validation failures to one code lets a negative case pass via a different failure path than it exercises. Fix: when a case declares a phase, require the executed sub-cause to match; otherwise name the actual path in an informational note. (No-skip execution is already stated; keep it.)
6. **§4 declared-op scoping swallows typos.** Cases naming a renamed/misspelled op are out of scope everywhere and silently never run. Fix: an unknown-op authoring note when a case names an operation no checked schema declares.
7. **§5 `!=` guidance crosses the §4 authority boundary silently.** Moving a probe test to a program filter narrows observation to caller-readable rows. Fix: require the diagnostic to state the visibility change and to point at unique/cap/final constraints when a cross-hidden-row invariant is intended.
8. **§5 readable/hidden conflict split needs a decision-time pin.** Returning authored codes for "readable" conflicts is sound only if readability is evaluated under the caller's authority at write time, and loader detail stays on operator surfaces. Fix: one sentence pinning both, plus a test where readability differs between check and commit time.
