## Summary

Ephemeral typing works end to end on this tree. Five real two-wasm-client trials showed a peer the indicator 6.0–16.6 ms after the first keystroke of a 45-keystroke, 25 ms burst, and cleared it 3850–3900 ms after the last keystroke. Each burst sent 2 ephemeral requests and 45 durable-control requests. Mounting a typing watch aborts and reissues the held poll with `ephTables=typing`; expiry and hidden-row refresh do not call `/sync`.

Revision 3’s four gates are in the code and covered by tests that fail if the gate is absent: the conservative `renews` proof (an `old.n + 1` upsert is not a renewal), wake publication while the hub lock is still held, request-revision fencing before incarnation checks, and a 1 s refetch while an ephemeral answer is incomplete. A schema with no ephemeral table still matches the frozen schema and TypeScript bytes. A legacy `/changes` poll with none of the three ephemeral parameters still has the old JSON shape. `$deadline` is stripped from mutation results and query rows. Capacity uses declared size, so a private payload does not change another principal’s refusal. The renewal law refuses a removed member’s later upsert and does not bump the epoch.

Opening a store no longer creates `_sequences` until a sequence is allocated. That is a deliberate on-disk change so a published store is not rewritten on open. Existing sequence tests and the new lazy-table test passed. It is not a wire change.

## Findings

### F1 (Low) — the acceptance trial does not fail if typing vanishes mid-burst, and it does not assert coalescing

- Where: `snapback4/packages/snapback4/test/ephemeral-e2e.test.mjs:72-73`
- `ephemeralGoneAfterLastMs <= 4500` is true for a negative number. `gone` is latched on the first empty snapshot after the indicator was seen, including one that happens before the last of the 45 calls. `ephemeralRequests` (2 vs 45 here) is only a diagnostic. This run’s numbers were inside the real bounds. `ephemeral-watches.test.mjs` does enforce ephemeral-only appearance within 500 ms and expiry without `/sync`, and the sender tests enforce coalescing. Not a product defect.
- Proposed fix: assert `ephemeralGoneAfterLastMs >= 0` and `ephemeralRequests <= 4` (or similar) in that trial.
