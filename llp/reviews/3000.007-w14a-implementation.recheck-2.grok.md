## Question 1 — High closed

**`OP_Column` matches the report.** At `~/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/libsqlite3-sys-0.38.2/sqlite3/sqlite3.c:99667–99692`, the page-resident branch (`pC->szRow>=aOffset[p2+1]`) for `t>=12` (TEXT/BLOB) does `szMalloc < len+2` → `sqlite3VdbeMemGrow` → `memcpy` and never reads `pOp->p5`. The overflow `else` at `99693–99727` reads `pOp->p5 & OPFLAG_BYTELENARG` and skips loading when `OPFLAG_BYTELENARG` / `LENGTHARG` / `TYPEOFARG` apply. The opcode comment at `99443–99448` itself only promises that `OPFLAG_LENGTHARG` avoids *large* blobs.

**Once-per-read precharge is correct.** `scan_metered` (`store.rs:810–824`) charges range names, then `meter.once(HeapSite::SqliteColumns, 2 * self.page_size)?`, then runs the `octet_length`/`length` preflight, then the same actual-length allowance as before (`bytes.saturating_mul(2).saturating_add(count.saturating_mul(64))`) before payload SQL. `page_size` is `PRAGMA page_size` at `open` / `prepare` / `open_read_only` / `reader()` (`store.rs:76,215,260`) and copied onto every `Tx` (`227,236,246`; `activation.rs:87`). `Meter::once` (`meter.rs:208–217`) is a per-meter bit, set only after `heap()` succeeds; `mark`/`restore` carry `heap_once`. Engine sites construct a fresh `Meter::new` per query, so the bit cannot leak across reads or connections. Repeated `once` after admission is a no-op (unit test: 1,000 calls still `8192`; probe `279–282` next-fetch / next-read). `Ceilings::default` is unchanged (`meter.rs:21–24`: examined 8,192, heap 16 MiB).

**Probe.** `sqlite_resident_payload_is_prepaid_before_preflight` uses a 650-byte body (report: `json_bytes=720`, under a 4,096-byte page) and `sqlite_overflow_payload_is_prepaid_before_preflight` uses 4,000 bytes (`json_bytes=4070`). Both wrap SQLite malloc, disable lookaside, and at heap 500 assert `preflight_runs==0`, `native_allocated==0`, and no payload `Run`. After admitting `2 * page_size`, they assert `payload_allocated == rounded(json+2)` for resident and `0` for overflow, preflight `Run==1`, payload `Run` unchanged, then a successful fetch.
