Classes: **plan 58** (including **11** `refused→rewrite → plan`) · **maintained 2** as the admitted route (usage, people counts) · **refused with no preserving paste 3** (`searchOnline` AND-as-specified, `splitPerson` unnamed, `offlineSearch`/`syncPullTiers` counted as **product-change 2** plus search-AND) · **schedule 7** · **effect 14** · **product-change 2** as a coverage class (tier replica; more concessions in §7) · **`E_BOUND`/`E_FANOUT` risk 4** (trash 500, reconcile page, album add uncapped, memory invalidation).

The thirteen “hard operations” are not thirteen plans. Backup **begin**, field LWW, one-item derive **commit**, one-item partner apply, album stay writes, generation **pointer**, and quota **reads** close. Op 3 (tiered 100k replica + offline search), Op 8 bulk, Op 12 except the pointer, Op 2/13 I/O, AND-search, and link-resolve are **effects, schedules, or product changes**. A silent page-count of the owner’s own timeline as storage or “photos of Alice” is an **admitted wrong number** (§4).

### 2. Schema in v0

Sentinels: no `optional` → `0`/`''` = absent. Enums are `text({ max })`. `json` is opaque to rules and indexes (§2) and **[inferred]** to predicates — sets that rules or indexes must see are **exploded**. No `hlc`/`i64`/`bytes`/`geo`/`sha256` type: HLC is `(wallMs, counter)` `int()` (i53; packed 64-bit HLC would overflow). `syncLog` is **not a table**: v0’s trace is the invalidation/OCC/receipt (§6). `storageUsage` is **not a table**: it is `maintain`. Interval columns store history; **authorization uses `open: int()` 0|1**, flipped in the same write (K5 / ruling 11 — rules have no clock). `cap.by` as an array is **[inferred]** from `maintain.by`. `time({ commitTime: true })` is **[inferred]** from §4.3.

  deviceId: id(), localAssetId: text({ max: 128 }),
  contentHash: text({ max: 64 }), sizeBytes: int(), mimeType: text({ max: 64 }),
}, ({ db, ctx, args }) => {
  const dev = db.get(devices, args.deviceId)
  db.require(dev !== null && dev.userId === ctx.viewer && dev.revokedAt === 0, 'NO_DEVICE')
  const u = db.get(users, ctx.viewer)
  db.require(u !== null && u.state === 'active', 'GONE')

  if (existing !== null) {

### 6. Language delta

Ranked by how much of this app they unblock.

1. **Owner-partition structural reductions.** Ruling 8 admits prefix-pinned tautologous tallies, which is exactly photos’ meters. Smallest addition: `E_STRUCTURAL_COUNT` also when the result is returned/written as a **resource fact** (quota, person size, “is full”) even if the rule is tautologous — require `maintain` or `page.countCapped`. General. Amends §4.4 / §9.1.8.

2. **Tiered replica protocol** (compact projection, recent-first backfill, per-tier watermark, generation `reset` as one invalidation, 100k-row closure). Smallest addition: a schema `replica({ table, index, order, watermarkColumn, maxBytes })` whose certificate completeness is `replica` not `page`. General (volume axis). Amends §1 kinds / §5 / §6. Without it Op 3 is a product change.

3. **Host asset protocol** beyond “provisional slot”: content-hash identity, verify(size, hash), refcount seam, resumable URL. Smallest addition: specify `db.media.{begin,verify,forget}` as the only blob writer; mutations never insert `blobs`. General. Amends §4.2.

4. **Posting-list intersection** with a static examined bound (DAAT/`take` on **output**, not per list). Smallest addition: `db.intersect([scanA, scanB], { take })` whose `maxExamined` is declared, failing `E_BOUND` on common terms. General. Amends §4.2 / §4.4. Else search is rarest-term page.

5. **Partial unique / filtered `cap`.** `(ownerId, contentHash) WHERE purgedAt=0`; one **open** stay already handled by `exclusion`. Smallest addition: `unique(..., { where })`. General. Amends §2 constraints.

6. **Column-level read rules** (or required table-split diagnostic). `shareLocation` / `includeLocation` cannot hide two columns on an otherwise readable row. Smallest addition: `E_RULE` rewrite “split the secret columns.” General. Amends §3.

7. **Anonymous capability principal** (token holder) + constant-time miss. Rules see only `viewer`. Smallest addition: host maps token → ephemeral principal with a capability row; or keep resolve as **effect** (this app). Mostly app-specific. Amends §3 / §8.

8. **Crypto in the IR or a hash seam.** Token hash, content hash, perceptual Hamming. Smallest addition: host-only `hash`/`distance` not callable from client programs. General. Amends §4.1 (`E_OPAQUE`).

9. **`maintain.max` / argmax row** for edit head and “best cluster.” Workaround (CAS on two ints) works for head. Smallest addition: `maintain.max` keyed. General. Amends §2.

10. **Job/orchestrator kind** (generation-fenced pages, barrier, one pointer swap). Spec has `schedule` + `effect` only; 100k work is always an effect. Smallest addition: document `effect` paging named mutations as the bulk pattern (clarification, not syntax). General. Amends §1 / §7.

11. **Rate limit** (20/min/address on resolve). Smallest addition: host, not IR. App-specific. Amends nothing if resolve stays an effect.

12. **i64 / `hlc` type.** Packed 64-bit HLC overflows i53. Workaround: two `int`s (this schema). Smallest addition: `hlc()` as `(wall, counter)` compared lexicographically. General. Amends §2 types.

13. **Triggers on maintain 0** (blob purge when `blobRefs` hits 0). Workaround: purge page writes `blobs.state`. App-specific.

Not added: `syncLog` as a table (that would be a second query class — the thing §1 forbids). `Math.random`. Clocks in rules. Vector indexes. Hamming. Geo. `onInsert` notify.

### 8. Where the design is wrong

Not taste. Exposed by forcing v0 spelling.

1. **Invariant 20’s owner counts and Op 3’s completeness are specified as if a vis-filtered replica were a source of structural truth.** The owner’s read rule is tautologous. A timeline scan that omits trash/hidden, or a `hasMore=false` page, is an admitted program that still returns the wrong meter and a confident empty year. Confirming observation: trash 10 GB, read `usageMeter` via `sum` of `timelinePage` (live only, `take: 2000`); `check` emits a plan; the meter is short 10 GB and any year older than the page is “zero photos.”

2. **I2 / Op 1 unique hash vs 90-day tombstones, and no unique on open upload sessions.** `unique(ownerId, contentHash)` as written cannot coexist with tombstones that remain in the same table; `unique(..., purgedAt)` lets two lives after purge but refuses a live re-upload while `purgedAt≠0`. Two devices backing up a **new** hash each insert an `open` session: `reservedBytes` doubles. Confirming observation: empty-trash a photo, re-upload the same file the same day → unique refusal or a second live row; or two phones back up a new photo → usage jumps 2× until expiry.

3. **Promise 4/13 and T1 name split + prompt hide, Op 7 does not.** Merge is a pointer plus an enqueued job; split has no algorithm; `setHidden` does not invalidate memories in the triggering transaction (unlike trash, which does). Partner removals after split have no `personId → itemIds` posting list — the design already flags this, and v0 `E_FANOUT` makes it a hard miss of the “under one minute at 100k” SLA. Confirming observation: hide Alice; `memoriesFeed` still returns her until the job; split Alice; partner feed still lists the sister’s photos for >60 s with no in-tx closes.
