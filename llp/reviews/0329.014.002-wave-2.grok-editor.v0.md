### 2. Schema in v0

v0 has no `optional`, enum, `principal()`, `seq({by})`, `maintain.min`/`max`, or replica on `ctx`. Sentinels: `UNSET` id = `0`, `NEVER` time = `0`, empty text `''`. `tree`/`exclusion` unused: a character sequence is not a `maxDepth: 32` parent path; overlapping grants are allowed. `json` is opaque to rules and indexes — exploded columns below are mandatory. `interval` used on grants/links; rules still cannot read the clock (K5), so `status` is the authorization bit.

```ts
  db.get(docAccess.byDocPrincipal, [docId, viewer])

const hasGrant = (docId: ReturnType<typeof id>) => {
  const a = access(docId)
  return a !== null && a.status === 'active'
}
const canEdit = (docId: ReturnType<typeof id>) => {
  const a = access(docId)
  return a !== null && a.status === 'active' && (a.role === 'owner' || a.role === 'editor')
}
const canComment = (docId: ReturnType<typeof id>) => {
  const a = access(docId)
  return a !== null && a.status === 'active'
    && (a.role === 'owner' || a.role === 'editor' || a.role === 'commenter')
}
const isMember = (docId: ReturnType<typeof id>) => {
  const a = access(docId)
  return a !== null && a.status === 'active' && a.principalKind !== 'link'
}
```

### 3. Operations in v0

Grouped by the design’s §5. Helpers `hasGrant` / `canEdit` are inlined at `check`.

#### Op 1 — Open a document and subscribe

**First attempt** (agent): clock in the grant rule; unbounded log; snapshot+gap as one result.

```ts
export const openDocument = query({ documentId: id(documents), lastAckSeq: int() }, ({ db, args }) => {
  const g = db.get(grants.byDocPrincipalActive, [args.documentId, viewer, 'active'])
  if (!g || g.expiresAt < Date.now()) return null          // E_AMBIENT_TIME
  const snap = db.scan(snapshots.byDocSeq, [args.documentId], { order: 'desc' }) // E_UNBOUND_SCAN
  const opsAll = db.scan(ops.byDocAccepted, [args.documentId], { order: 'asc' }) // E_UNBOUND_SCAN
  return { snap, opsAll, head: opsAll.length }             // E_UNBOUND_COUNT
})
```

```
E_AMBIENT_TIME — Date.now in a query. rewrite: grants.status flipped by schedule; rule reads status.
E_UNBOUND_SCAN — take required. rewrite: snapshot take:1; ops take:256 + after cursor.
E_UNBOUND_COUNT — opsAll.length as head. rewrite: db.get(opCount, [documentId]).
```

### 6. Language delta

Ranked by what Tessera actually needed.

1. **Host sequence / CRDT type** (the `tree` analogue for this archetype). Identity items, `after`, `(lamport, replicaId)` siblings, retractable tombstones, range-move with cycle refuse, same-commit apply, bit-identical client evaluation. Smallest addition: `sequence({ after, lamport, replica, tombstone })` plus `db.seqInsert/Delete/Retract/Move`. **General.** Amends §2 (beside `tree`), §4.2, §6 (evaluator must run it). `tree(maxDepth:32)` and `recurse(D,F)` are compile-time polynomials; a sequence is depth-n. Raising `maxDepth` to 400k is not a fix (`E_BOUND` at check, not at data).

2. **Compose isolation, not OCC-reject, for declared commuting writes.** Smallest: table `merge: 'append' | 'lww({ by: ['lamport','replicaId'] })' | 'occ'` (default `occ`). **General.** Amends §6. Without this, P1/P2/I18 die on any in-place materialize even after (1).

3. **Corollary to §9.1.2–3: a completeness-sensitive log must be uniform-read.** Hidden rows consuming `take` make I1 and I16 irreconcilable on one table. Smallest addition: a `check` diagnostic `E_SEQUENCE_VISIBILITY` when a scan of an `appendOnly` log has a non-hoisted/non-tautologous rule and the result is used as “the document”. Do **not** add `hidden: 'skip-budget'` (leaks cardinality). **General.** Amends §9.1.

4. **`ctx.replica` (device principal) alongside `ctx.viewer`.** Bound at session; rules may name it; insert `op.replicaId === ctx.replica`. **General.** Amends §4.3, §3. Enforces I5.

5. **Channel invalidation.** Cut subscribers when the one probe’s durable row changes; don’t wait for ttl. Smallest: channels inherit §6 invalidation of `publish`/`subscribe` keys. **General.** Amends §8 (U5).

6. **`seq({ by: 'documentId' })` host dense counter** *or* strike density from the product. Like `commitTime`, provisional locally. **General.** Amends §2, §4.3. Anti-snipe-style `at` reschedule is not this app; dense seq is.

7. **`maintain.min` / `maintain.max`.** Prune horizon is `min(lastAck)` over a `cap`ped replica set; register winner can be maintained. Seal-then-reveal still must not use time-independent `readable` (auction). **General.** Amends §2.

8. **Schedule `if` / `args` / skip `at=NEVER`; `callable: 'system'`.** Expire grants, mention delivery, prune. Same hole as auction. **General.** Amends §7.

9. **D-D `maxOfflineAge` hard max 7d vs I20 30d.** Smallest: raise the hard max to a declared per-app bound, or keep 7d and force the product change. **General axis, app number.** Amends §10 D-D.

10. **Server vacuum below a proved horizon** (drop tombstones, rewrite `after`, preserve sort key). Not `deleteWhere` in a program. **Runtime, editor-shaped but GC-general.** Amends §6 / new engine job.

11. **Typed argument lists of structs with `max` (nested `text` loop domain is already in §4.2; nested lists of items are not spelled).** Clarify §4.3. **General.**

12. **Publish G.** Open/render/move/restore certificates are unclassifiable at 400k without it. **General.** Amends §5.

13. **`db.run(namedMutation)` with summed certificates** for reconnect 32-op pages and mention delivery. **General.** Amends §4.2.

14. **JSON in programs** (not rules/indexes): either exploded columns (used here) or a bounded `payload` accessor. Clarify §2. **General.**

**Do not add:** OT transforms as JS; `while`; locale; clock in rules; `tree` deep enough to encode a linked list; skip-hidden-take.

App-specific (do not add): RGA interleaving repair; sticky-format; 20 Hz coalescing.

### 8. Where the design is wrong

Not taste. Forced by v0 spelling.

1. **I1 and I16 cannot share one op log under §9.1.2–3.** Thread/comment/resolve as `ops.kind` means a guest scan of `ops.byDocAccepted` hides members-only rows **and those rows consume `take`**. The guest’s page is starved of `insert`s; the rendered document is missing characters, not just comments. Split tables fix visibility but contradict “every action is an ordinary operation on that sequence” (undo/history of comments). Confirming observation: 100 inserts interleaved with 200 members-only comment ops; guest `opsSince` take 256 returns ≪100 inserts, `hasMore` true, **no extent**; member and guest character counts differ.

2. **“The document” is treated as a value (move cycle, quote, restore, prune, I7) with no cardinality, while §6 quotes p99 400k chars / 2M ops.** v0 ceilings are compile-time. `recurse(D,F)` and `All` without `cap` are refused; with `cap` = p99 they are `E_BOUND`. I7 is then uncheckable: a cycle test over a prefix returns a **false negative**. Confirming observation: `moveRange` on a 400k-item doc either will not admit, or admits with `take: 2048` and fails to see `dest` inside the tail of a range that starts at item 0.

3. **Op 2 steps 4–5 contradict U3.** Dense `accepted_seq` plus same-tx materialize/split is a read-modify-write of `documents.head_seq` and of the split run. v0 OCC on that trace **rejects concurrent typing** (P1/P2). If the service assigns seq without the mutation reading it, local prediction of seq is `partial` and history numbers disagree until settle. The design wants commuting text **and** a total dense order **and** optimistic local apply. Those three are not one program. Confirming observation: two replicas insert after the same ItemId in one snapshot; if `check` emits a plan that updates a shared run or `headSeq`, one intent is `rejected`; if it only appends, `accepted_seq` is not the dense prefix I10 describes.

(The 30d vs 7d bound and replica-less undo are also under-specified, but they are D-D / `ctx` holes. The three above are the design’s own invariants colliding.)
