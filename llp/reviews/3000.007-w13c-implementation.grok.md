## Findings

### Low — server non-uniform hidden-vs-absent meters are not identical

- **Where:** `snapback4/crates/snapback4-sim/tests/lane_domains/mod.rs:80`
- **What:** §17’s method asked for byte-identical **meters** as well as pages. The server fixture examines **50 vs 100** rows when the extra rows are hidden rather than absent (`lane_domains/mod.rs:70–83`). Pages, `complete`, `cut` and `next` match. Hidden-vs-hidden meters match (`:86–102`). Both device stores, which do not acquire the other author’s rows, match including meters (`device/tests/lane_domains/mod.rs:50–67`).
- **Scenario:** A non-uniform range merge over `read <- .author = viewer` on the server; world A has 50 foreign rows, world B does not.
- **Why this is not a required change:** Ruling 28 also requires the non-uniform traversal to stay byte-for-byte. Equalizing meters would be a new disclosure repair (§20.12 N1 was descoped for that). Report 2 records this honestly.
- **Smallest correct change:** None for landing. If a later pass equalizes operator meters, it must do so for every non-uniform scan, not only range lanes.

### Low — “every store” key pin is SQLite/memory/browser, not Postgres

- **Where:** `snapback4/crates/snapback4-device/tests/index_key_bound.rs:63–91`
- **What:** Calendar key bytes are pinned across MemoryStore, `Store::memory()` (DeviceStore), and `MemoryRows`, using shared `index_key` / `CalendarKey::value` (`rows.rs:165–167`, `maintain.rs:17–18`). Postgres is not in that test.
- **Scenario:** A Postgres backend encoding `bucket(at, 2h, 30m)` differently would only show up in a store-specific path.
- **Smallest correct change:** None required if Postgres still calls `index_key` (it should). Optional: add the same scan comparison on the Postgres store in that pin.

No Critical / High / Medium defects. `engine/rules.rs` is edited (`scan_visibility` and `lazy_merge` use `component.column()` / `key_type` so calendar keys are not fake columns). That is required for ruling 29 once `Index::columns()` returns function names (`schema.rs:429–438`), not a copied uniformity checker and not a serialized-shape or ceiling change.

Verdict: READY
