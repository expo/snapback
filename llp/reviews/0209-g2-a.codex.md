1. Bounded root windows falsely claim exhaustion. [graph_evaluator.rs:593](/Users/ccheever/projects/snapback/.claude/worktrees/g2-lane/crates/snapback-engine/src/graph_evaluator.rs:593) computes `has_more`, but every bounded interval emits `hasMore:false` at [graph_evaluator.rs:621](/Users/ccheever/projects/snapback/.claude/worktrees/g2-lane/crates/snapback-engine/src/graph_evaluator.rs:621). Fix: emit `window` only when the named end was observed exhausted; otherwise select the closed `unknown` arm or materialize the applicable refusal.

2. To-many proof-arm selection fails on admissible per-parent mixtures. [graph_evaluator.rs:859](/Users/ccheever/projects/snapback/.claude/worktrees/g2-lane/crates/snapback-engine/src/graph_evaluator.rs:859) selects one global arm using `any_has_more`/`any_bounded`. Mixed bounded/unbounded parents select `window`, although unbounded and null-key ranges lack `interval`; [proof_entry at graph_evaluator.rs:477](/Users/ccheever/projects/snapback/.claude/worktrees/g2-lane/crates/snapback-engine/src/graph_evaluator.rs:477) then returns a host error. Fix: derive only wire-valid homogeneous arms; otherwise emit `unknown/parent-range-unproved`, and carry an interval for every window range.

3. `all` semi-joins do not bind the declared argument reliably. [graph_evaluator.rs:1063](/Users/ccheever/projects/snapback/.claude/worktrees/g2-lane/crates/snapback-engine/src/graph_evaluator.rs:1063) rewrites every `In` filter to the current argument, regardless of which argument or whether it was literal. Fix: admission must require the exact argument-bound predicate, and evaluation must rewrite only the matching `In Arg(argumentId)`.

4. Through semi-joins truncate an over-bound edge range without lookahead or refusal. ## MATERIAL findings

1. **Window accounting advances every lineage for one page publication.**  
   `next_ledgers` loops over every demand-paged node and increments `pages`, structural work, and whole-result charges for all of them ([graph_evaluator.rs:2038](/Users/ccheever/projects/snapback/.claude/worktrees/g2-lane/crates/snapback-engine/src/graph_evaluator.rs:2038)). LLP 0209 requires independent lineages and says a child page charges its own subtree/result ledger ([LLP 0209:1349](/Users/ccheever/projects/snapback/.claude/worktrees/g2-lane/llp/0209-live-graph-profile.spec.md:1349)). A child-only continuation therefore consumes the root and sibling page budgets and can refuse prematurely. The corpus only covers first-page vectors and a root overflow.  
   **Fix:** bind each request to the advanced `nodeId`; update only that ledger, carry all others unchanged, and add child-only plus sibling-only continuation cases.

2. **The required-edge refusal was re-frozen with an illegal projection proof class.**  
   Refusal construction assigns the projection `proofClass:"refusal"` ([graph_evaluator.rs:2144](/Users/ccheever/projects/snapback/.claude/worktrees/g2-lane/crates/snapback-engine/src/graph_evaluator.rs:2144)); the freezer copies that spelling ([freeze-graph-g0-corpus.mjs:1058](/Users/ccheever/projects/snapback/.claude/worktrees/g2-lane/demos/zerobugs/control/scripts/freeze-graph-g0-corpus.mjs:1058)). LLP 0209 requires every projection label, including `refused`, to use `projection-composition` ([LLP 0209:2350](/Users/ccheever/projects/snapback/.claude/worktrees/g2-lane/llp/0209-live-graph-profile.spec.md:2350)). The freezer’s adversarial checks run only on ordinary result construction, so the refusal path bypasses them before the global flags are accepted ([freeze-graph-g0-corpus.mjs:1046](/Users/ccheever/projects/snapback/.claude/worktrees/g2-lane/demos/zerobugs/control/scripts/freeze-graph-g0-corpus.mjs:1046), [freeze-graph-g0-corpus.mjs:2043](/Users/ccheever/projects/snapback/.claude/worktrees/g2-lane/demos/zerobugs/control/scripts/freeze-graph-g0-corpus.mjs:2043)).  
   **Fix:** use `ProjectionComposition`, re-freeze, and run proof-class/composition self-checks on every label, especially refusals.

3. **Class-2 validation rejects valid membership-only or role-only proofs.**  
   The closed policy-input enum permits `PermissionBacking`, `Membership`, and `Role` ([graph.rs:730](/Users/ccheever/projects/snapback/.claude/worktrees/g2-lane/crates/snapback-types/src/manifest/graph.rs:730)), but `class_two_context_is_complete` requires at least one permission backing for every class-2 data node ([graph_evaluator.rs:508](/Users/ccheever/projects/snapback/.claude/worktrees/g2-lane/crates/snapback-engine/src/graph_evaluator.rs:508)). Thus valid membership/role-only admitted plans always become `SNAPBACK_AUTH_STALE_RESULT`.  
   **Fix:** validate context completeness by each declared policy-input kind; require permission values only for permission-backing inputs.

4. **Absent optional arguments pass demand validation but then fail evaluation.**  
   The demand validator explicitly accepts an absent optional argument ([graph.rs:4757](/Users/ccheever/projects/snapback/.claude/worktrees/g2-lane/crates/snapback-types/src/manifest/graph.rs:4757)), matching §2.6’s zero cardinality, but `input_for` requires every declared argument ([graph_evaluator.rs:411](/Users/ccheever/projects/snapback/.claude/worktrees/g2-lane/crates/snapback-engine/src/graph_evaluator.rs:411)).  
   **Fix:** omit absent optional arguments from normalized handler input, preserving observed cardinality zero; add an executable optional-omission case.

5. **The legal `take:0` completeness arm is rejected and would panic if admitted.**  
   LLP 0209 defines `take:0` as `unknown/zero-take-unproved` unless exhaustion is independently known ([LLP 0209:2336](/Users/ccheever/projects/snapback/.claude/worktrees/g2-lane/llp/0209-live-graph-profile.spec.md:2336)). Demand validation rejects zero ([graph.rs:4896](/Users/ccheever/projects/snapback/.claude/worktrees/g2-lane/crates/snapback-types/src/manifest/graph.rs:4896)); if allowed through, root evaluation can obtain lookahead with no consumed row and hit `expect("lookahead implies a consumed root")` ([graph_evaluator.rs:841](/Users/ccheever/projects/snapback/.claude/worktrees/g2-lane/crates/snapback-engine/src/graph_evaluator.rs:841)).  
   **Fix:** admit zero, emit the specified unknown proof without a continuation, and cover root and child zero-take demands.

6. **An admitted search-membership node is not executable.**  
   Search membership is an admitted §2 node with complete/unknown/refused production rules ([LLP 0209:2339](/Users/ccheever/projects/snapback/.claude/worktrees/g2-lane/llp/0209-live-graph-profile.spec.md:2339)), but evaluation returns a host `SNAPBACK_QUERY_COST_EVIDENCE_REQUIRED` error unconditionally ([graph_evaluator.rs:2246](/Users/ccheever/projects/snapback/.claude/worktrees/g2-lane/crates/snapback-engine/src/graph_evaluator.rs:2246)).  
   **Fix:** consume the admitted provider certificate/membership input and emit the closed complete or unknown proof, or reject such plans at admission until that execution contract exists.

7. **Imported evaluation-time refusals escape as host errors instead of materialized results.**  
   LLP 0209 requires storage, authorization, and query-cost evaluation errors to become result outcomes, with canonical-node/owner-register precedence ([LLP 0209:1225](/Users/ccheever/projects/snapback/.claude/worktrees/g2-lane/llp/0209-live-graph-profile.spec.md:1225)).    **Fix:** translate every closed evaluation-register diagnostic into `GraphMaterializedRefusalReasonV1`, select by canonical node and owner-register order, and return complete per-node/projection/composition refusal evidence.
