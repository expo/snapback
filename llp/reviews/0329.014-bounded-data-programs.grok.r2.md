### 1. The strongest objection to each proposal

**Fable.** The product-breaker is the authoring cut plus the client substrate, not the certificate. Builder callbacks that cannot `if` on a row throw away the Convex prior that won Linear/Relay/Split: Clique inbox unread and Split’s payer branch are `for`/`if` in those transcripts. A technically correct rewrite to `when`/`countCapped`/`maintain` is the cardinality lecture that already loses B-scores. Separately, a TypeScript operator evaluator on the client against a Rust interpreter on the server is LLP 0320 in miniature — Hermes/JSC/V8 collation, NaN, and i64 versus the authoritative value model (0120 finding 7). The architecture (static shape, dynamic windows, prediction closures, one-hop hoist) survives; the spelling and the TS client do not survive this bakeoff unless replaced.

**Codex.** `AllOrRefuse<T,N>` as a peer of `Page`, used for Relay cards at `allOrRefuse(1_000)`, is LLP 0120 variant 2 as an availability trap. Seed boards pass; a live board seals; the agent raises `N` until `G` or the UI dies; Convex keeps serving. That is capability discovered at overflow — Fable’s P2 hybrid with the discovery point moved from codegen to growth. P4+ otherwise survives if `AllOrRefuse` is legal only on schema-capped collections (members ≤ 128) and growing collections are `Page` plus cursor. Two bytecode interpreters are a conformance risk, not the first product-breaker.

**Grok (r1, this panelist).** The load-bearing error is the Zero analogy. I treated a data-dependent `for` as “the client becomes a query engine.” A `for` over `Page<N>` whose every read is `get`/`scan(take)`/`exists` is not Zero: the client still cannot invent a query, the bound is still N×B, the closure is still the trace. Refusing that class loses unread and Split on first paste — the loss mode my own r1 §6 predicted. Opaque-verdict absolutism is the second error: Clique membership must not need them, but admin/ACL rules over hidden tables need a bound witness or they become `public`. Rank-1 “builder constructs AST” does not survive; the IR, cardinality types, ⊆ assertion, and query/effect split do.

**Orchestrator/P9.** The thesis “static analysis is an aid, not the gate” is false of the design that follows (the gate is `check` on shape+bound). Implement the sentence and you have Convex. The guarantee that actually breaks is prediction-closure-at-check. Pure computation may select a key the last trace did not contain:

```ts

  ...m,
  author: db.get(users, m.authorId),
  hits: handles(m.body).map(h => db.scan(users.byHandle, [h], { take: 1 })),
```

`handles` is admitted; `take` is bounded; loops are over a page. Offline `send` of the first `@bob` reads `users.byHandle[bob]` outside coverage → `partial`. Clique mention hydration is that program. Algebra refuses the UDF-driven nest or requires a `mentions` write; P9 admits it and finds incompleteness in the field. Helper inlining is load-bearing: an un-inlined helper is an opaque UDF (0320). Recant the thesis sentence, put `maxSteps` on the certificate, qualify prediction as “substitution-closed subset, else `partial`,” and P9 survives.

**P4 (0329.005).** Right skeleton, incomplete product. Treating capture as “cheap insurance” rather than the closure leaves the client without exact windows or a miss detector — shape-only is Snapback’s table-granular `reads:`. Combined with “no row-level if/for” as a semantic rule (necessary only for a build-time builder) and no `(view, transition)` prediction artifact, optimistic `send` of nested `users[author]` for a viewer who has never posted is `partial` after the fact — Fable’s whole difference. Cardinality without examined entries, steps, and write amplification is not a cost proof. Survives as the type system and operator list; not as v1.

### 2. The crux, re-litigated

All four answers are right about different operations. Adopt this as a shared fact.

A shipped trace T of P at `(S, args, V)` is a **snapshot closure**: index ranges including absences, rows that passed V’s row rules, stop-reasons (`limit` vs `empty`), and — only if a rule input failed V’s read rule — opaque verdicts. It supports (i) display of R and exact replay at the same `(S, args, V)` with no local writes; (ii) re-exec of P against T ⊕ Δ while every issued read is ⊆ T, else `partial`; (iii) precise invalidation/OCC on overlapping writes and rule-dep keys.

It does not support observing a remote revocation during partition (`stale`; reconnect re-runs inlined rules, ships absence, purges; queued intents re-authorized in the server transaction; T is never authority). No language can.

Boundary conditions:

- **Dependent reads on a not-yet-existing row.** Completeness known in advance holds iff the extra read is a function of (written fields, viewer, args). Clique `send` → `users[viewer()]` is this case: derive `PredictionClosure(view, transition)` by substitution or bounded symbolic execution, and hydrate at subscribe. It does not hold for keys computed from body text, hashes, or aggregates of the existing page plus the new row; those are `partial` unless the mutation writes a row the view already nests. A trace cannot know them. An algebra refuses some; an imperative program admits them. Honest `partial` is the same detector. Fable’s artifact is therefore derivable over P9/codex for the substitution-closed subset, and fails exactly on computed-key and page-aggregate-gated reads.
- **Rule reads over hidden rows.** T cannot ship those rows (0120 noninterference). A verdict bound to `{ruleHash, ruleSite, planHash, viewer, args, epoch, notAfter}` is a lease of a boolean. Viewer-readable rules (Clique membership) ship the row or an absence and recompute. Clique must not need verdicts. Verdicts are v1 for admin/ACL only, never write-authorization, never a query-authoring tool. For the common membership rule, compiler-proven equivalence of the hoisted read `exists` and the insert `exists` is enough; a separate write witness is required only when insert is a strictly stronger predicate (muted-from-sending).
- **Local delete of a held row.** A full `Page<N>` whose stop-reason is `limit` needs row N+1 *content* to stay complete and N+2’s *key* to keep `hasMore` exact. Without halo content: N−1 rows and `partial`. Static and dynamic agree. Empty-range evidence does not repair a truncated nonempty range. Halo content of 1 is worth it; halo 2 is not v1 (trace +1 row/page; invalidation fan-in is the same prefix — the next key was already the stop-reason).
- **Shipping T is safe only if authorization is a property of rows.** Under “function = authorization,” T is unshippable.

F3/P1 as stated is false of the last execution and true of the next local execution’s unknown reads. Turning a snapshot closure into a program closure *is* static analysis. They compose as type + value with a ⊆ assertion. What does not compose is P2 (JS queries + traced closures): `partial` in production after `predicted` in fixtures.

### 3. Static vs. dynamic — the actual trade

Once both have shape+bound at `check` and windows at run, an algebra still differs on:

| | Algebra | Bounded imperative |
|---|---|---|
| Examined bound | yes | yes, same calculus (exclusive `if` is max, not sum) |
| Closure / honest `partial` | yes | yes (the trace) |
| Noninterference | hidden → verdict | same if enforced |
| Prediction as a *check*-time set | every admitted nest | substitution-closed subset only |
| Reviewable predicate | `byConv[C]` | `byConv[*]` bound 51 if prefix computed |
| One-statement SQL | `LATERAL` / `WITH RECURSIVE` | program-near-DB |
| IVM of loops | possible for terms | `maintain` only |
| Work bound | implicit | **`maxSteps` required** (string-build, Map) |
| Semantic corners | tiny model | tiny *iff* one interpreter |
| Agent prior | new | Convex-shaped |

Codex/P9 are half right: pure computation cannot change the *examined-entry* bound if every read goes through the typed API with `take`. It *can* change static prefix pin, prediction-closure, work, SQL, and IVM. The program that breaks prediction is the mention scan in §1. The program that breaks work-without-`maxSteps` is a `Page` fold that concatenates bodies in a nested numeric loop — no extra reads, unbounded CPU.

Year one (SQLite-first, agent-native, private-offline, vs Convex): need bound, closure, noninterference, Clique-send prediction (substitution-closed in both), and the agent prior. Do not need one-statement SQL or algebraic IVM (rerun-and-diff ≤ G; `maintain` for exact unbounded). Do need `maxSteps` the moment Map/string is in. Do need `prefixTemplate: computed` printed so review sees the weaker predicate. The algebra’s remaining real purchase is forcing mention-style reads to a table write or a refusal rather than a field `partial`. That is a product choice. I take field-`partial` plus a rewrite, because refusing `if`/`for` is how we lose B-scores.

### 4. Your updated position

Admitting arbitrary pure computation and structured control flow between bounded typed reads is a threat to prediction-closure-as-a-check-time-set, reviewable closed predicates, one-statement SQL, algebraic IVM, and work-without-`maxSteps`. It is not a threat to examined-entry bound, trace closure, honest `partial`, or noninterference (hidden → verdict only). Year one still ships the TS-syntax language, because the fatal product axis is agent prior and Clique `send` is substitution-closed.

**Moved** from “rank-1 algebra, builder callbacks, JS `if`/`for` out of the data plane” to **“TS-syntax bounded data programs lowered to IR; algebraic operators as library; `if` on rows; `for` only over `Page<N>` (cost N×B); pure computation between typed reads with `maxSteps`.”** What moved me: a `for` over `Unbound` is a type error in both designs; I had identified control flow with Zero. Fable already called refusing `if`/`for` a spelling artifact. I did **not** move off the gates: named ops, row rules as only auth, derived artifacts, JS out of the authoritative path, query/effect, cardinality types, G, trace ⊆ shape, eight states, no authored `reads:`/`retainable`. P9’s “analysis is an aid” I reject; `check` remains the gate.

**Spelling.** TS subset; `tsc` against a `lib.d.ts` that omits `Date`/`Math.random`/`fetch`; library `db.get` / `db.scan(index, prefix, {order, take})` / `exists` / `recurse` / `maintain`; mutations `insert`/`update`/`delete`/`assert`/`alloc`. Helpers inlined. `take` required; N a literal or an arg with a declared max.

**Substrate.** One Rust IR interpreter, native on the server, WASM on the client. Same bytes, same value model (i64/f64, UTF-8 codepoint order; `localeCompare` refused). Effects: sandbox off the tx path; DK-5 shrinks to this. Fable’s TS client evaluator is rejected (Hermes ≠ V8 ≠ Rust). Codex’s two bytecode interpreters are the fallback if a wasm32 spike misses size/startup, with a cross-target corpus as a merge gate. QuickJS-in-WASM is prototype-only.

**Prediction.** Emit `PredictionClosure(view, transition)` for the substitution-closed subset; hydrate at subscribe. Computed-prefix and page-aggregate-gated reads are `predict: partial` in the certificate; rewrite: write a row the view already nests.

**Verdicts.** v1, narrow. Clique membership = row or absence. Binding = Codex’s tuple. Read-witness ≠ write-authorization. Common `memberOf` on insert is compiler-equal to the hoisted read `exists` — no second witness. Muted-from-sending is a different insert rule. Verdicts never authority.

**Halo.** Compiler-selected **content of 1** (row N+1) plus the N+2 **key** as `hasMore` sentinel. Not author-visible. Worth it for one chat delete. Halo 2 is not v1.

**Expiry.** Engine-owned `maxOfflineAge` is a required *mechanism* with a policy *value* (loud default 7 days), not a lease and not per-query. Partition semantics remain `stale` until reconnect; the fence bounds stolen-device / never-reconnect plaintext. Sign-out destroys the store key.

**AllOrRefuse.** Schema-capped domains only. Messages/cards/activity are `Page`. `allOrRefuse(1000)` on cards is a policy refusal.

**Certificate (minimal).** `planHash, schemaHash, evaluatorVersion, ruleHashes`; `indexedReadSites[{index, prefixTemplate: arg|viewer|const|computed, maxCalls, maxRows, hoist}]`; `writeSites`; `maintainedWriteAmplification`; `maxExamined, maxSteps, maxOutputBytes`; `completenessSemantics`; `predictionSites[{transition, reads, mode: hydrate|partial}]`. Cardinality is not a cost proof. Trace ⊈ certificate is a compiler bug.

### 5. Convergence candidates

**Sign today:** row rules are the only authorization; public is conspicuous and unlocks nothing; named ops, compile-time inlining, no client-invented queries; read/write sets, indexes, retention, prediction derived; effects are not queries; static certificate + dynamic trace, trace ⊆ shape; eight states; JS out of query/mutation; client = closure cache + interpreter + outbox; `Unbound` cannot execute or `count`; exact-over-unbounded is only `maintain`; one-hop equality-pinned membership hoists to cost 1; `for` over `Unbound` is a type error; G is a compile-time fact of the plan; revocation during partition is unobservable.

**Genuine (not spelling):**

1. **Prediction at `check` vs at re-exec for computed-key reads.** Experiment: hand-lower `thread` with `users[author]` *and* with `handles(body)`; offline `send` of a first mention; assert `predicted` vs `partial`. Product call: refuse computed-prefix or require a `mentions` write. One day.
2. **Whether helper inlining actually produces the bound.** P9’s spike plus a helper wrapping `scan`. If the bound misses, P9 is Convex. Same week.
3. **WASM size/startup vs two bytecode interpreters.** Compile the spike to wasm32; measure on RN Hermes and web V8. Miss → two interpreters + corpus, not app JS.
4. **`maintain` contention for unread fan-out ≤ 256 on SQLite.** Send to a 256-member conv, ±1 per member; p95 vs `countCapped`. 0120’s unmeasured expectation.
5. **Verdicts on the census.** Clique/Relay/Split with viewer-readable membership only. First rule that cannot be stated without a hidden table is the first verdict customer — do not introduce the object earlier.

### 6. Benchmark failure mode

The first Clique paste is a Convex `for` the subset almost accepts; `check` then refuses a `scan` without `take` or `Unbound.count` for inbox unread; the diagnostic lectures cardinality. The agent burns M2, copies the loop into an `effect` (not live, not retained), or widens `take` until `G` and ships a capped inbox. Convex’s win was “a query is code.” A closed language with a Metro/identity rebind still loses (0329.000 F-B, Diary 0114).
