## 1. Unordered NFC canary — FIXED

U+0307 is CCC **230**, U+0323 is CCC **220** (`UnicodeData.txt` 776, 804). Input `d U+0307 U+0323` is therefore unordered. NFC reorders to `d U+0323 U+0307`, composes `d`+U+0323 → U+1E0D, and leaves U+0307 (UAX #15 / `NormalizationTest.txt` 48 is the capital analog `0044 0307 0323` → `1E0C 0307`). Expected `U+1E0D U+0307` is that result.

A compose-without-reorder host composes `d`+U+0307 first → `U+1E0B U+0323`, which is not the expected NFC, so it now fails the constructor (`web.rs` 29–31).

The stub is not a constant for the full canary string. It replaces adjacent starter+mark pairs (`unicode.test.mjs` 37): `d\u0307` → `\u1E0B`, leaving `\u1E0B\u0323`. On the **old** ordered canary `d\u0323\u0307` the same stub yields `\u1E0D\u0307` and would pass; it still satisfies canaries 1, 3, and 4. That is the host the finding described.

The native oracle is table-bound, not literal-only: `input.nfc().collect()` and `words::fold` (`unicode_fold.rs` 14–16) both go through `unicode_normalization`. The same unordered pair is in the constructor, the JS matrix, and LLP 3000.002 line 414.

## 2. `since` captured before the server read — FIXED

`evaluateLocal` is the only composed-read builder. `query` and `observe`/`rerun` both call it (`local.ts` 1094–1106, 937–950). Capture is `const composedSince = lastSyncAt` at 893, immediately before `await server(...)` at 894, and that bound is what the composed return stamps at 907. There is no second composition site for watches.

Test ordering (`retained-history.test.mjs` 376–396, fetch wrapper 163 and 175):

1. `querySince = syncedAt` when `/q/both` is issued (163), which is during `server()` after 893.
2. Intercept runs **after** the HTTP fetch returns (175) and holds the reply from the client.
3. `await waiting` then `client.sync()`; `after = meta syncedAt` must be `> before` (387–389) — the later sync finished while the reply was still gated.
4. Release, then `result.since === before` (395).

Old code read `lastSyncAt` after `await server()`, so `result.since` would equal `after`, not `before`. The lane rebuilt `local.ts` from `7235fa6273` and that assertion failed on both wasm and process; that matches the control flow.

## 3. `unicode_normalization` in `--check-absent` — FIXED

Production matcher (`attribute-wasm.mjs` 130): `row.name.includes('unicode_normalization')` on the raw twiggy name. That hits `unicode_normalization::…`, hashed `unicode_normalization[hash]::…`, and generic owners such as `<unicode_normalization[…]::Recompositions<…> as …>`, at any mount. It is the same substring the S3-R0 census used. Fully inlined bodies with the crate name stripped remain the documented byte-budget backstop (125–126), unchanged.

The synthetic rows are passed to the exported `checkAbsent` (`wasm-absent.test.mjs` 3, 10–13), including `unicode_normalization::normalize::canonical_fully_decomposed` and a hashed `Recompositions` owner. Without the matcher change those `assert.throws` calls would not throw.
