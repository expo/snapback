# Paper archetype, wave 2: regulated health records against LLP 0329.014.000 v0.1

**Respondent:** Claude Fable 5 · **Design under test:** `design-health.md` (codex), fixed · **Target:** LLP 0329.014.000 v0.1 incl. §9.1 and §11 · **Prediction under test:** LLP 0329.014.002 #4.

Headline. Prediction 4 named three missing schema declarations, "all new". Two are not missing. Column-level visibility is the protection-class split the design's own §7 concedes, expressible in v0 today; row versioning and hold-fenced deletion are append-only rows plus a system `schedule`, with `versioned()` and `hold()` as K6 *bindings*, not enablers. The one genuinely new item is narrower than predicted: not "reads that write" (a `mutation` already reads, writes, and returns) but **live, retained reads that audit** — the `query` kind cannot satisfy invariant 12, so 16 of this app's 17 reads are mutations and forfeit liveness and offline retention until a table-level `audited` declaration exists (L2). The most valuable findings are two spec rules that return wrong answers here: **§9.1.2 (hidden rows consume `take`) makes page length and `hasMore` a cardinality oracle** — a nurse confirms an SSN guess through the lookup-token index — and **§9.1.8's uniformity proof admits a reduction under a hoisted-false rule**, so a nurse's retention-deadline `max` silently omits the identity and restricted chains and the sweep destroys early. L1–L9 refer to §6; ⓐ marks an audited read (§3).

### 2. Schema in v0

Protection classes are tables (`contact`, `directory`, `identity`, `identityMask`, `identityToken`, `coverage`, `clinical`, `codes`, `narrative`, `restricted`); a version is a row in one class's chain, and each class has its own head row. `ledger()` below abbreviates `delete: never` + `immutable(every column but state)` + `immutableExcept({ fields: ['state'], when: (o, n) => sys() || n.state === 'revoked' })` — an abbreviation of spec features, not a new one. Lines marked `// L…` are §6 deltas.

```ts
import { table, id, text, int, bool, time, ref, interval, json, unique, cap, appendOnly, immutable, immutableExcept, maintain, tokens, viewer, principal, never } from 'backend'

const sys     = () => principal.kind === 'system'
const cx      = () => db.get(activeContexts, viewer)                                                     // viewer-pinned → hoisted
const grantOk = orgId => db.exists(staffGrants.byActorOrgRoleState, [viewer, orgId, cx().roleCode, 'active'])   // key from a probed row: L9a
const adminOf = orgId => db.exists(staffGrants.byActorOrgRoleState, [viewer, orgId, 'securityAdmin', 'active'])
const careOk  = pid => db.exists(careRelationships.byPatientActorState, [pid, viewer, 'active'])
const glassOk = pid => db.exists(breakGlassEpisodes.byPatientActorState, [pid, viewer, 'active'])
const cell    = (cls, action) => db.get(policyCells.byCell, [cx().policyRevisionId, cls, cx().roleCode, cx().purposeCode, action])
// Deny-wins and priority are resolved when the policy is written; a rule reads one normalized cell.
const may = (r, cls, action) => grantOk(r.orgId) && (
     (cell(cls, action)?.effect === 'allow' && (cell(cls, action).basis === 'none' || careOk(r.patientId)
        || db.exists(consentEntitlements.byPatientClassGrantee, [r.patientId, cls, viewer])))
  || (action === 'read' && cell(cls, 'emergency')?.effect === 'allow' && glassOk(r.patientId)))     // emergency allow-list: never identity/coverage/restricted

export const organizations = table({ id: id(), name: text({ max: 200 }), jurisdictionCode: text({ max: 8 }) })
  .rules({ read: o => grantOk(o.id), insert: sys, update: never, delete: never })
export const devices = table({ id: id(), actorId: id(), publicKey: text({ max: 512 }) /* L9b: bytes() */, state: text({ max: 8 }), registeredAt: time() })
  .rules({ read: d => d.actorId === viewer, insert: d => d.actorId === viewer, update: (o, d) => o.actorId === viewer && d.state === 'revoked', delete: never })
export const activeContexts = table({ id: id() /* actor */, orgId: ref(organizations), roleCode: text({ max: 32 }), purposeCode: text({ max: 32 }),
    policyRevisionId: ref(policyRevisions), deviceId: ref(devices), setAt: time() })
  .rules({ read: c => c.id === viewer, insert: c => c.id === viewer && db.exists(staffGrants.byActorOrgRoleState, [viewer, c.orgId, c.roleCode, 'active'])
      && db.get(policyHeads, c.orgId).currentRevisionId === c.policyRevisionId, update: (o, c) => o.id === viewer && /* same */ true, delete: c => c.id === viewer })

export const policyRevisions = table({ id: id(), orgId: ref(organizations), effective: interval(), state: text({ max: 10 }), contentHash: text({ max: 64 }),
    firstApprover: id(), secondApprover: id(), recordedAt: time(), recordedBy: id(), supersedesId: id() }).ledger()
  .rules({ read: p => grantOk(p.orgId), insert: p => adminOf(p.orgId) && p.recordedBy === viewer && p.firstApprover !== p.secondApprover && p.secondApprover !== viewer })
export const policyHeads = table({ id: id() /* org */, currentRevisionId: ref(policyRevisions), revisionNo: int() })
  .rules({ read: h => grantOk(h.id), insert: sys, update: (o, h) => adminOf(o.id) && h.revisionNo === o.revisionNo + 1, delete: never })
export const policyCells = table({ id: id(), policyRevisionId: ref(policyRevisions), cls: text({ max: 16 }), roleCode: text({ max: 32 }), purposeCode: text({ max: 32 }),
    action: text({ max: 10 }) /* read|filter|write|export|emergency */, effect: text({ max: 5 }) /* allow|mask|deny */, basis: text({ max: 8 }) /* none|care|consent */ })
  .appendOnly().unique('byCell', ['policyRevisionId', 'cls', 'roleCode', 'purposeCode', 'action']).cap({ by: 'policyRevisionId', max: 2_000 })
  .rules({ read: c => grantOk(db.get(policyRevisions, c.policyRevisionId).orgId), insert: c => adminOf(db.get(policyRevisions, c.policyRevisionId).orgId), update: never, delete: never })

// Authority facts: revisions + a head row (the expected-revision fence). validity is [from, until); `state` is flipped by
// flipValidity schedules at both ends (K5) and instantly by revocation mutations.
export const staffGrants = table({ id: id(), grantId: id(), revisionNo: int(), actorId: id(), orgId: ref(organizations), facilityId: id(), patientId: id(),
    roleCode: text({ max: 32 }), validity: interval(), state: text({ max: 10 }), approvedBy: id(), recordedBy: id(), recordedAt: time(), supersedesId: id() }).ledger()
  .unique('byGrantRev', ['grantId', 'revisionNo']).index('byActorOrgRoleState', ['actorId', 'orgId', 'roleCode', 'state'])
  .rules({ read: g => g.actorId === viewer || adminOf(g.orgId),
           insert: g => adminOf(g.orgId) && g.recordedBy === viewer && g.actorId !== viewer && g.approvedBy !== viewer
                        && db.exists(privacyApprovals.byGrantRev, [g.grantId, g.revisionNo]) })
schedule(flipValidity, { at: g => g.validity.from, key: g => [g.id, 'start'], principal: 'system' })     // L9d: two schedules per row
schedule(flipValidity, { at: g => g.validity.to,   key: g => [g.id, 'end'],   principal: 'system' })

  .index('byPatientActorState', ['patientId', 'actorOrTeamId', 'state'])   // rules: read own-or-admin; insert adminOf(org); schedules as above
export const representativeAuthorities = table({ /* authorityId, revisionNo, patientId, representativeActorId, permittedActions: json, validity, state, evidenceHash … */ }).ledger()
  .index('byPatientRepState', ['patientId', 'representativeActorId', 'state'])

  .rules({ read: c => c.patientId === viewer || repOf(c.patientId) || privacyOfficer(c.patientId), insert: c => c.grantorActorId === viewer && (c.patientId === viewer || repOf(c.patientId)),
           update: (o, c) => c.revisionNo === o.revisionNo + 1 && (o.patientId === viewer || repOf(o.patientId) || privacyOfficer(o.patientId) || sys()), delete: never })
export const consentRevisions = table({ id: id(), consentId: ref(consentHeads), revisionNo: int(), granteeKey: text({ max: 80 }) /* actor:… | org:…:role */,
    purposeCode: text({ max: 32 }), authorization: interval(), record: interval(), state: text({ max: 12 }) /* pendingSignature|scheduled|active|expired|revoked */,
    revocationEffectiveAt: time({ commitTime: true }), artifactKey: text({ max: 200 }), artifactHash: text({ max: 64 }), recordedAt: time(), recordedBy: id(), supersedesId: id() }).ledger()

  .appendOnly().cap({ by: 'consentRevisionId', max: 64 })
export const consentEntitlements = table({ id: id(), patientId: id(), cls: text({ max: 16 }), granteeKey: text({ max: 80 }), consentRevisionId: id(), state: text({ max: 8 }) })

// Chart: item spine + one chain per protection class + one head per class. Full-snapshot rows spanning classes are the
// design's model and are refused by visibility (§3); a logical version is the union of chains ordered by recordedAt.
export const patients = table({ id: id(), orgId: ref(organizations), createdAt: time() }).rules({ read: p => may(p, 'directory', 'read'), insert: p => may(p, 'contact', 'write'), update: never, delete: never })
export const patientDirectory = table({ id: id() /* patient */, orgId: ref(organizations), patientId: id(), legalName: text({ max: 200 }), dob: time() })
  .index('byNameToken', tokens('legalName')).index('byOrgDob', ['orgId', 'dob']).partitioned()      // L1
  .rules({ read: d => may(d, 'directory', 'read'), insert: d => may(d, 'contact', 'write'), update: (o, d) => may(o, 'contact', 'write'), delete: never })
export const chartItems = table({ id: id(), patientId: ref(patients), orgId: ref(organizations), recordKind: text({ max: 16 }) /* demographics|note|restrictedNote|diagnosis|medication|allergy|lab|document */,
    createdAt: time(), createdBy: id(), sourceSystemId: id() })
  .index('byPatientKindCreated', ['patientId', 'recordKind', 'createdAt']).immutable(['patientId', 'orgId', 'recordKind']).partitioned()   // L1: kind in the prefix → hoisted
  .rules({ read: i => may(i, kindClass(i.recordKind), 'read'), insert: i => i.createdBy === viewer && may(i, kindClass(i.recordKind), 'write'), update: never, delete: sys })
// One chain per class. Shown once; identityParts, identityMasks, identityTokens, coverageParts, clinicalParts, codeParts,
// narrativeParts, restrictedParts repeat the shape with cls fixed and their own typed columns.
const versionCols = { id: id(), itemId: ref(chartItems), patientId: id(), orgId: id(), revisionNo: int(), parentVersionId: id(), changeKind: text({ max: 8 }),
    status: text({ max: 8 }), clinical: interval(), recordedAt: time(), recordedBy: id(), reason: text({ max: 500 }), commandId: id(), payloadHash: text({ max: 64 }) }

export const disclosureManifestEntries = table({ id: id(), jobId: ref(disclosureJobs), ordinal: int(), versionId: id(), cls: text({ max: 16 }), contentHash: text({ max: 64 }), state: text({ max: 10 }) })
  .unique('byJobOrdinal', ['jobId', 'ordinal']).cap({ by: 'jobId', max: 500 }).immutable(['jobId', 'ordinal', 'versionId', 'cls'])
export const disclosureEvents = table({ /* jobId, eventType queued|handoff_started|receipt|ambiguous|cancelled, occurredAt, detailHash */ }).appendOnly()
```
