## 2. Other family’s repairs (D1R1)

**A device cannot predict or read a complete aggregate, group, rank, or page the server would not produce.** Incomplete local folds can still materialize, marked `complete: false`; that is the unknown contract, not a false-complete answer.

**Zero-sum occupancy.** `aggregate_source_present` uses `count_prefix(..., 1)` on the selected contribution index (`engine/maintains.rs:127–142`). A local positive witness keeps the candidate. Absence on a device requires `aggregate_source_complete`: synced source, no horizon, not a public-subset inherit, target `byGroup` absence proved, and no left source group (`:145–154`). Otherwise prediction is `E_PREDICT` and queues with no row. Partial history vs a delivered witness vs whole sync is tested on both stores (`device/tests/maintains/review.rs:39–66`). Live scalar misses and empty pages call `aggregate_read_coverage` before returning (`engine/read.rs:85–94`, `:288`, `:537`), so a missing candidate is unknown rather than a complete zero.

**Bounded occupancy under prepayment.** `reserve_maintains` now prepays occupancy scratch (four source-row copies), contribution-index evaluations (6 vs 2), and does not exempt a source page (`write_target.rs:286–309`). Actual hidden work stays prepaid (`charge_maintain` is a no-op). The independent counter on the real SQLite `Rows` interface shows one occupancy lookup and ≤3 source rows with 9,000 excluded (`sim/tests/maintains_review.rs:83–99`). A fallback scan would fail that bound.

**Subset inheritance.** `maintain_subset_unknown` is public-readable source plus non-public audience (`maintain.rs:108–111`). Residency classifies that target `Server` first (`bind/residency.rs:75`). Local reads set `beyond_horizon`; mutations that read it do not predict. Raw-schema subset (Quarry `sync to .owner` still does not compile here) is incomplete for the viewer, another owner, and an unpinned page; server reads stay complete (`device/tests/maintains/review.rs:87–104`). Inheritance still requires every audience column as a bare `Expr::Name` key (`bind/schema.rs:25–29`). Online-only targets are still skipped on the device (`engine/maintains.rs:19`).

**Expiring value indexes.** Binder refuses `E_QUARRY_MAINTAIN_EXPIRE` (`bind/schema.rs:544`). Core `validate_maintain` refuses the same on every schema entry, including raw create and adopt (`schema.rs:899–901`). `Engine::new` / `adopt` / device open prepare contribution indexes then validate (`engine/mod.rs:198–201`, `:343–347`). Ranked expiring raw schemas fail create and leave generation unchanged (`device/tests/maintains/review.rs:170–184`). A successor cannot publish an index the schema cannot compile.

**Cursors.** Direct table and maintain pages encode `CursorScope { generation, prefix }` (`cursor.rs:31–36`; `engine/read.rs:481–485`, `:663`, `:688`). A token for another prefix or generation is `E_INPUT` / `CursorError::Scope`. Ordinary value changes and deletes keep the old token valid in the same generation (`device/tests/maintains/review.rs:191–212`). Query-issued tokens work in mutations and outbox replay because `Engine::mutate`, device query/predict, and replay all stamp `context.generation` (`engine/mod.rs:720`; `device.rs:564`, `:600`; `predictions.rs:51`). Merge/search tokens still omit scope: they may continue across an additive generation and are withheld on non-uniform reads, meter cuts, and word-limit cuts (`read.rs:783–796`, `:869–871`). That is a distinct contract, tested after this merge (`lang/tests/guide.rs:538–569`).

**Paired hidden/absent/filter worlds.** Filter-true vs filter-false match on the complete observation for hidden update and hidden delete, including tight ceilings. Present vs absent and admitted vs denied remain distinct delete outcomes (`NOT_FOUND` restores the mark; `E_RULE` does not). Overflow remains the named residual. Below reservation, those outcome distinctions are not inspected yet: every world is `E_BOUND`.

**Skip / duplicate / cross.** Direct pages cannot cross prefix or generation. Merge pages cannot emit a continuation that would skip an unfinished lane: `merge_can_continue() && has_more` (`read.rs:791–796`). Matching/`words` pages are merge-shaped and were explicitly left on that contract.
