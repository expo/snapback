Findings:

- **Low — indirect crate alias can hide `Deserialize` under a trusted name.** `wasm-codec-census.mjs:112` and `:128`. Concrete scenario:

  ```rust
  use serde as s;
  use s::Deserialize as Serialize;
  #[derive(Serialize)]
  #[serde(untagged)]
  enum E { A }
  ```

  This returned no census error. The same works through `extern crate serde as x`. It requires deliberate obfuscation, but it is a new gap versus the base’s unresolved-import refusal. Smallest fix: refuse aliases/re-exports of the serde crate itself, including `use serde as …`, `serde::{self as …}`, and `extern crate serde as …`; add a test that renames the resulting `Deserialize` to `Serialize`.

- **Low — split declarative macros evade the census.** `wasm-codec-census.mjs:153`. Concrete scenario:

  ```rust
  macro_rules! repr {
      ($item:item) => { #[serde(untagged)] $item };
  }
  repr! { #[derive(Deserialize)] enum E { A } }
  ```

  This and the reverse arrangement return green; nested split macros do too. Smallest fix: conservatively refuse macro bodies that apply either a buffered representation or a decoder/unknown derive to an item/token metavariable, with exact allowlisting for intentional cases.

- **Low — trait-only re-exports receive an inaccurate derive-policy refusal.** `wasm-codec-census.mjs:117` and `:220`. `pub(crate) use serde::de::Deserialize;` is a legitimate trait re-export and cannot re-export serde’s root derive macro, but the message says it violates the “serde derive import policy.” Limit import-policy rejection to the derive-bearing root paths `serde::Deserialize` and `serde::Serialize`; an aliased `serde::de::Deserialize` used as a derive would still be caught lexically on a representation-bearing item.

- **Low — harmless new derives produce a misleading refusal.** `wasm-codec-census.mjs:125` and `:252`. For example, `#[derive(Hash, Serialize)] #[serde(untagged)]` is rejected as “unresolvable derive Hash,” although `Hash` is a standard non-decoder derive and was accepted by the base implementation. Restore `Hash` and phrase future misses as “derive not approved by the census,” with an instruction for extending the reviewed list.

The live tree contains none of these newly refused forms.
