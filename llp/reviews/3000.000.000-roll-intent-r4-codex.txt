Those spellings are also legal nominal table names.

A concrete static counterexample is this predecessor:

```quarry

  owner: principal
  public
  online only
query echo(id: docs):
  return id
```

With current source:

```quarry

  owner: principal
  public
  online only
query echo(id: alias):
  return id
invariant alias.read only true
```

The adapter maps `alias → docs`. At the argument’s first type token, `arg_type` returns a start at `alias` and an end before its preceding whitespace. That reversed range reaches `replace_range` at [line 436](/home/ccheever/projects/snapback-sb4loop/snapback4/crates/snapback4-lang/src/release_bridge_current.rs:436), causing a panic instead of preparing the view or returning an authored-compatible-source refusal.
