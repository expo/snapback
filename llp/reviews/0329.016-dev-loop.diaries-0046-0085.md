## (b) Delight — what Snapback 2 must keep

1. **Codegen fails closed, writes nothing on error, names file:line and the fix.** 0057: "Codegen is the best part of the product. Deterministic, fails closed, writes nothing on error, stable diagnostic codes, and messages that name the function, the argument, the file and the line." 0056: "Every mistake I made was caught at generation with a file/line, not in the app." 0058-relay: "All three diagnostics named the failing concept and no stale artifacts were written." 0072: "27 first-try codegen/typecheck passes; every refusal named its rule (the PNG-CRC refusal quoting the exact failing chunk did it again)."
2. **Deterministic acceptance with injected seams (cron tick, clock, reset-install) that runs in seconds.** 0047-a6: "A 10-check operations suite that runs in five seconds changes what you bother to prove." 0056: "Acceptance testing is the best part of the platform ... I could *prove* the local-first claims rather than assert them." 0058-msg: "The headless acceptance harness caught every real bug before the UI ever ran."
3. **`snapback doctor --json` proves the install before any code.** 0057: "`npm i @expo/snapback-cli` pulled nine packages in 8 seconds, including a prebuilt server binary and Hermes runtime, and `snapback doctor --json` then ran a full vertical slice ... No Rust, no Hermes build, no `vendor/ibex`." 0075: same on 0.1.20.
4. **Serialized commits make the naive thing correct.** 0047-a6: "Six concurrent `createJob` calls ... allocated JOB-4..JOB-9 dense and duplicate-free with a three-line counter read-increment-write ... no advisory locks, no retry loops." 0046-a5: "Convex needed scheduled mutations for this shape in 0031; here it's read-check-write made correct by commit order."
5. **Stable `SNAPBACK_*` codes designed to be matched, not read.** 0057: "Diagnostics are designed to be matched on, not read." 0050: "Structured diagnostics were much better than PocketBase's generic API errors."
6. **Ephemeral presence as a primitive.** 0050: "Connection-keyed presence arrived in 39–43 ms and did not advance durable storage at all—materially better semantics than PocketBase's presence table." 0059: the Convex arm needed "a durable `typingIndicators` table, two indexes, a public mutation, an internal expiry mutation, one scheduled job per refresh, a nonce guard against stale jobs, a two-second client keepalive, and explicit cleanup." 0058-msg (LLP 0257): "the application no longer owns timeout generation fencing, connection-self filtering, heartbeat, reconnect, or room cleanup."
7. **Typed asset intent: policy in one declaration, TUS resume with 0 bytes re-sent, revocation at origin, GPS stripped.** 0048-clip: "Bytes re-transmitted after the drop: 0." 0048-face: "Snapback is the only arm where the served avatar provably lost its GPS location." 0049: "Snapback is the only arm where feed authority and byte authority are one system." 0051: "the app wrote no EXIF scrubber, content sniffer, hash verifier, thumbnail worker, or retry state."
8. **Retained queries + durable outbox + honesty facts.** 0046-fn: "It was the only arm that produced certified cold retained rows after a fresh client with the backend down, and it labeled them retained rather than current." 0056: "`freshness: 'retained'` never being relabeled `current`, `retention.code` naming *why* a query refuses to retain ... none of this is decoration." 0066: "Snapback's offline proof is categorically stronger".
9. **Declarative mutation IR replays offline.** 0056: "So liking works offline, queues durably, and replays in order. That is a genuinely strong result and I did not expect to get it."
10. **Generated branded IDs / exact references create correctness pressure.** 0050: "Generated branded IDs made my initial stringly UI fail typecheck at every incident-operation boundary." 0083: "Exact references made it hard to accidentally call an undeclared function."
11. **Transactional jobs with `delayMs` = dynamic per-entity deadline.** 0057: "`ctx.jobs.enqueue(action, args, { delayMs })` — transactional with the move that armed it, so a rolled-back move provably arms nothing". 0047-a6: "transactional enqueue with receipt facts is better than what I'd get from Convex".
12. **Trusted time/ids frozen per invocation, enforced at generation.** 0053: "The generator immediately refused ambient `Date.now()` with `BUNDLE_UNSUPPORTED_TIME`. `guide/backend/trusted-runtime-values.md` gave the exact repair ... productive friction."
13. **Structural auth: identity cannot come from the body.** 0057: "the request body may not mention identity at all — not even `"auth": null` ... The original `backend.yml` bug this spec calls out is not merely avoidable here, it is close to unexpressible."
14. **Guide architecture: intent-indexed, transcluded CI-verified snippets, capability index with GAP rows.** 0057: "the *documentation architecture* is the most agent-aware I have worked with". 0065-rematch: "the served capability index routed the agent to `useSnapbackPresence` ... and needed **no web searches**."
15. **Supervisor JSONL as evidence and the no-URL Expo screen.** 0063: "There is no backend URL, token carrier, session-mint call, or transport choice in `App.tsx`." 0063 G4: "register the Expo file store once, mount the generated app, and call `conversation.commands.send({ body, image })`."
16. **Instance forks per worktree.** 0054-fork: "The workflow removed the shared-database and fixed-port coordination entirely." 0062: "each lane's writes are invisible to the others and to the parent, proven per run rather than assumed."
17. **Familiar profile once running.** 0078: "Once it was running, the M2 feature loop felt remarkably close to Convex." M2 timing 594 vs 600 s.
18. **Declared roles on rooms.** 0058-msg: "the room declaration names the subset once with `allow.members(..., { roles })`; codegen supplies the role field and validates the closed vocabulary."
19. **Day-2 evolution.** 0073: Snapback B8 90 vs Convex 82 vs Supabase 74 — "declare, migrate, types flow through, data verifiably intact".
20. **Skill-in-scaffold routing.** 0066: "20% wall reduction, three traps that changed the design up front, the done-oracle prediction verbatim, and the routing that got lane 2 onto the paved retention path lane 1 never found."

## (c) Competitor mechanism comparisons

### Convex (0046-a5, 0047-a6, 0048-*, 0049, 0051, 0053, 0056, 0058-relay, 0059, 0060, 0065-rematch, 0066, 0068, 0069, 0072, 0073, 0078, 0085)
- **Better: one-command anonymous local dev, phone-reachable immediately.** 0058-relay: "It created the project and cloud dev deployment, wrote ignored Expo environment variables, generated types, added eleven indexes, and deployed all functions without a code correction." 0078: "Anonymous local development came up with one command and no account". 0065-rematch: "Anonymous local mode remains the standout (zero-auth, self-port-managing, wrote the client env var)."
- **Better: zero orientation cost — the model already knows the API.** 0065-rematch: "Convex's lane also spent almost nothing on orientation — prior model familiarity supplied the API shapes". 0072: "The "agents don't read docs on Convex" fact held 3/3 — zero doc fetches."
- **Better: `_storage` sha256 as queryable system data; `v.id("_storage")`.** 0048-clip: "size and sha256 come free as data" — flagged "worth stealing".
- **Worse: no resumable upload; suffix ranges 500.** 0048-clip: "Bytes re-transmitted after a mid-transfer drop: 59,768,832 — 100 % of what had already been sent."
- **Worse: bytes outlive membership.** 0049: "already-learned file URLs kept serving (200) after leaving ... Feed access and byte access are two different authority systems and only one of them hears about membership."
- **Worse: typing/presence rebuilt from durable primitives** (0058-relay, 0059, 0072 3/3, 0085: "typing is ephemeral product state but Convex's straightforward expression is a durable row plus a scheduled cleanup mutation").
- **Worse: no platform offline;** hand-rolled ~40–60-line cache every run, "not a real sync story" (0068), image bytes from browser HTTP cache (0065-rematch).
- **Worse: emoji field names refused at runtime** — "chat's most natural key" (0072, 3/3).
- **Worse: deploy is deployment-global** — "my push printed `Deleted table indexes: [-] ub_a_profiles.by_handle`, i.e. it dropped a concurrently-running Lane α arm's index" (0048-clip).
- **Worse: no built-in password auth** — scrypt in a Node action, sessions as hashed rows (0078, 0085); Node 26 rejected, `--local` deprecated, `CONVEX_AGENT_MODE=anonymous` dug out of CLI source (0072, 0085); local backend dies with the CLI process (0059, 0065-rematch).
- **Worse: OCC around app counters vs serialized commits** (0047-a6); secret-custody Stop-class defect in the frozen 0031 arm (0046-a5).

### Supabase (0048-*, 0049, 0050 mention, 0073, 0080)
- **Better: auth mostly just works; real Postgres constraints; pgvector/full-text ahead.** 0073: "the only lane where auth mostly just worked (B2 82)". 0046-a5: "Supabase's first-party pgvector/full-text remain ahead on retrieval capability".
- **Better: best non-Snapback privacy default** (private bucket + RLS → nothing anonymous, 0048-face).
- **Worse: diagnostics distance-from-cause.** 0049: "The RLS recursion trap cost the most wall-clock of the day ... surfaced not as Postgres's 42P17 but as the storage API's `DatabaseInvalidObjectDefinition` 503, three services away from the mistake."
- **Worse: three size ceilings, each discovered by failing; key vs `apikey` header** (0048-clip: "the documented client + current keys fail out of the box; nothing in the error says "use apikey"").
- **Worse: bytes served after revocation** (0049: "a byte fetch **served 200 immediately after membership removal**").
- **Worse: policy authored in SQL out-of-band; folder-name-equals-uid convention "load-bearing ... nothing enforces you got it right until a 403 at runtime"** (0048-face).
- **Worse (posture): hosted project without DDL authority blocked the entire Clique lane** (0080); hosted signup meter made the scale replay uncompletable (0073).
- 0047-a6: "Supabase would need pg_cron plus triggers plus RLS and none of it would fit in a five-second proof loop."

### PocketBase (0048-*, 0049, 0050, 0082)
- **Better: zero authored backend files; fastest to first byte; on-the-fly thumbs; file-as-field deletion truth; rules re-checked per SSE delivery; compact, direct SDK.** 0050: "PocketBase was easiest and fastest to work with overall." 0049: "For a single binary with zero infra, the realtime-authorization integration embarrassed two cloud arms."
- **Worse: public-by-URL + EXIF passthrough** (0048-face: "the default avatar flow lets an anonymous fetcher read the uploader's location"); no resumability, no digest (0048-clip).
- **Worse: migration is verbose and statically unsafe** — four runtime-only mistakes; `created`/`updated` not auto-added (0050, 0082 hit it again); fixed-ID error names no record; `pb_migrations/` replays into "fresh" instances (0049).
- **Worse: no type contract; presence is a durable table + cron; declarative rules "not a complete group-messaging authorization language"** (0050, 0082).

### InstantDB (0084)
- **Better: one broad client graph query feeds every screen; 0.3–0.6 s cross-client without subscription plumbing.**
- **Worse: no password auth → Node adapter with admin token and scrypt; membership/message authorization lives outside the client; `set: !liked` in a stale render repeated writes; typing expiry passed best-of-three.**

### Zero / Replicache (0046-fn, 0047-fleet)
- **Zero better on its home ground:** "Repeated filter combinations became local reads around one millisecond. That is a qualitatively different interaction model from Snapback's roughly 56–63 ms server round trip for every switch." Inspectable custody; pushed-down relations. **Worse:** "PostgreSQL logical replication, publications and slots, two app endpoints, `zero-cache`, client identities, and exact teardown"; disconnected mutation "easy to misread".
- **Replicache:** strongest conflict semantics, most protocol — "idempotence, cookies, mutation ordering, patch production, conflict policy, and poke/pull coordination belong to the application."
- **Snapback:** "needs the smallest local stack"; wins cold retained read; lacks speculative reconstruction after restart and a rebase/conflict hook.

### Firebase (0048-*, 0049)
- Emulator "genuinely good ... No competitor in this bakeoff matched that local-fidelity story (Snapback's local target is the same idea, and it is telling that these two are the ones with one)." Resumable uploads are in-process only (187 MB across two attempts); Blaze billing cliff before first byte.

## (d) Agent behavioral failure modes — and what in the tool induced or prevented them

1. **Guessed a spelling the tool has a near-synonym for.** `ctx.db.update` vs `patch` (0048-clip); raw `/assets/{id}/{variant}` vs `deliveryUrl()` (0048-face); `credential.session.userId` (0049); `useSnapbackEphemeral` vs `useSnapbackPresence` (0058-msg); raw IR `{ Arg: 'gameId' }` vs `arg()` (0057); raw `{ kind: 'delete' }` vs `del()`, `'text'` vs `lit('text')`, integer `seedVersion` (0058-relay); `mutationPlan()` vs plain array (0056); live handle as async iterator (0075); `.rows` on `StartedLiveQueryHandle` instead of `.current` after `.started()` (0058-relay); `{ args: {...} }` nesting (0069). **Induced by:** two spellings for one thing (raw IR alongside helpers; schema "ephemeral" vs React "presence"; `_generated` vs `generated`), and `ctx.db` accepting unknown members until runtime. **Prevented by:** codegen refusing at generation with file:line (every case above that went through codegen cost one edit); the runtime-only `ctx.db.update` case is the one that cost minutes.
2. **Hypothesis loop instead of observation.** 0056: five disproved hypotheses over hours before a 90-line wire tee answered the question in twenty minutes — "Five disproofs felt like progress and were mostly a substitute for looking." Twice concluded from one sample. **Induced by:** a bare code (`NOT_RQS_ELIGIBLE`) with no supporting facts; **fixed by** rendering five state facts next to the error — "it converted every subsequent screenshot into real evidence."
3. **Vacuous/silent passes written by the agent.** 0057 C02 "passed" on a transport refusal; 0056 headless click that hit empty space and synthetic MouseEvents Pressable ignores ("Both failures were **silent passes**, which is the worst shape for a test to fail in"); 0061 four gate-authoring defects "right about the product and wrong about observation mechanics"; 0081 seven typing mitigations against a red that was the choreography's clock. **Prevented by:** the harness's `expectedChecks`/"zero checks can never pass" rule (0056, 0057 praised it); ledger-ordinal comparison instead of sleeps (0067).
4. **Reached for familiar client state instead of the platform's reconciliation model.** 0053: local `+1` plus authoritative increment → double-count; then heart in component state; final fix used `useSnapbackMutation` optimistic projection with an `isAuthoritative` matcher. 0056: the recipe's own `projectRecordFields` spread a non-column into the row and the result contract refused it (platform caught it; agent "never clicked the button").
5. **Trusted a guide sentence that was wrong or ahead of the package.** 0057 (`source:` lane "for imported helpers"; `ctx.refuse`; `anonymous-public`), 0078/0079 (familiar profile only in source). **Induced by:** `maturity: shipped` pages without a version fence — "It cannot tell you what version of itself you are running."
6. **Reading package source / binary strings as the primary discovery method.** 0047-a6, 0057, 0069, 0081, 0085 (Convex too: `CONVEX_AGENT_MODE`). This is the agent adapting correctly; the tool induced it by leaving the verb set, custody recipes, and scan roots undocumented.
7. **Worked around a missing verb by writing infrastructure.** 60-line `serve.mjs` (0057), `scripts/dev-server.mjs` (0058-relay), `/__snapdrop` proxy (0051), ~80-line CORS relay (0065-rematch), `adoptAuthority` (0083), session broker (0059). Each is "a framework should own" work.
8. **Compromised authority to make progress.** 0081 migrated conversation/membership/message rows to public-read; 0057 hand-rolled `fetch` against `/query/` (guide-named anti-pattern); 0056 argument-keyed viewer scoping means "the *server does not enforce* that you only read your own likes." **Induced by:** owner-visibility on handler reads, a one-command membership model, and no anonymous-public custody in the published client.
9. **Over-broad initial build / improvisation.** 0078 Grok "built much of M1–M3 up front, generated far more narrated/tool traffic", added a polling fallback around familiar queries that "materially shaped the failure."
10. **Feedback loops the agent created.** 0078 typing per keystroke + receipt acknowledgement reactive loop; 0061 `useZerobugsQuery` re-derived objects → 86k renders/13 s and a starved CDP session. **Prevented by:** stable snapshot from `useSnapbackQuery` (the instability "was 100% ours").
11. **Process hygiene misses.** Edits reverted by a late writer/formatter and shipped a white screen (0056: "verify an edit *persisted* rather than that it *applied*"); stale subagent checkpoint read as a final report (0060); duplicate ticket filed without checking `issues/closed/` (0056); stale worktree merge base (0060).
12. **Delegation as a wash.** 0056: codex UI lane ran 10 min with no visible output, produced eight type errors; "The brief was the valuable artifact."
