**Concern — High: short-circuit probe counts disclose hidden state even when both verdicts deny**

W4 charges `PrefixProbe.count` on false verdicts. That count records probes actually executed, while `And` and `Or` short-circuit. Consequently, it depends on hidden probe answers. [read.rs:478](snapback4/crates/snapback4-core/src/engine/read.rs:478), [read.rs:764](snapback4/crates/snapback4-core/src/engine/read.rs:764), [rules.rs:153](snapback4/crates/snapback4-core/src/engine/rules.rs:153).

Concrete source-traced pair:

```quarry
-- Both tables have owner: principal and unique byOwner: owner.
-- permits is empty in both worlds.
read <- exists secrets[owner = viewer] and exists permits[owner = viewer]
```

Apply that read rule to `secrets`, with no expiry or sync. One world has no secrets; the other contains a secret owned by the caller. **Both verdicts are false**, so neither world exposes any secret row. The rule has no focal-field dependency and therefore qualifies as uniform for an empty-prefix page. [rules.rs:48](snapback4/crates/snapback4-core/src/engine/rules.rs:48).

Use the existing fixture’s fixed readable-work prelude, reduced to **8,191** point reads/probes, then bind `secrets[] first 1 by byId` and return a constant:

| World | Page verdict | Additional probes | Final outcome |
|---|---|---:|---|
| Empty | First conjunct is false | 1 | `sent` |
| Hidden-populated | First true, second false | 2 | `E_BOUND` |

The common page attempt brings examined work to 8,192 in both worlds. Probe charging then reaches 8,192 versus 8,193; only the latter aborts. No candidate is fetched in either world. [meter.rs:23](snapback4/crates/snapback4-core/src/meter.rs:23), [meter.rs:120](snapback4/crates/snapback4-core/src/meter.rs:120).

This particular **false/false** channel is introduced by W4: previously both false verdicts returned before charging their probe counts. With ample budget, W4 still exposes differing logical meters.

Adding `enabled = true` to the first probe gives a hidden-value variant: keep a secret present in both worlds, vary only `enabled`, and leave permits empty. The final denial remains identical, but the equality controls whether the second probe runs. Thus each individual equality probe remains one unit, yet composition discloses through cost.

**Resolution:** charge a state-independent, schema-derived probe allowance for the uniform page verdict, preserving the common attempt charge and verdict-before-candidate ordering. Merely reserving the maximum while retaining actual branch counts would leave meter differences and potentially later budget differences.

Add `w5_uniform_denied_short_circuit_pages_have_identical_complete_observations` through the shared helper, covering:

- Empty/hidden and hidden equality-match/mismatch pairs.
- Ample budget and exactly one remaining probe.
- `and` and corresponding `or` short-circuit forms.
- Both stores and every observation field.

The existing single-probe regression cannot detect this branch-count difference. [page_admission.rs:146](snapback4/crates/snapback4-sim/tests/page_admission.rs:146).
