## 1. Setup discovery

Round 2 cloned the reaching-definition `HashMap` at every `If` and `retain`ed through `assigns` (a full live-map walk × subtree scan). That is gone.

- One map, push on change, `restore(mark)` after each arm (`presence.rs` 346–357, 444–454). The other arm therefore starts from the incoming definitions, as a clone did.
- `Assignments::collect` writes each assignment **once** into a flat `names` vec and stores a `Range` per statement (`372–382`). An `If`/`For` range is the contiguous slice of its subtree, so nested statements share the list. `forget` invalidates only those names (`384–386`) instead of asking every live binding to search the subtree.
- `needed_setups` collects once, then `discover_setups` walks (`416–419`). Each statement is visited once. Sibling `If`s whose bodies only `emit` have an empty slice: forget is O(1) while N aliases stay in `values`. That is GPT’s Ω(N²) family, now O(N).
- Independent lets still `set(name, None)` (`428`). Reassignment still replaces the reaching statement (`433`). `$bool` short-circuit still records condition inputs from the *incoming* map, then the branch’s reaching def of the accumulator, then forgets the subtree and rebinds the `If` (`441–459`) — the same edges as round 2’s `yes`/`no` clones plus `short_target`.
- Loops still drop the binding and every name assigned in the body, before and after the walk (`461–465`). `Push` still drops the target (`467`).
- Still `#[cfg(not(target_arch = "wasm32"))]` and still not charged to the meter (`59–66`, `415–419`). `plan_guards` still clones proofs and still meters that (`240–243`, `274–278`).

Mark preservation: `assigns` (`230–237`) and `collect` recurse the same `Let`/`Assign`/`Const`/`Push`/`If`/`For` set (`ir.rs` 101–123). Forget-by-slice is the same name set as `retain(\|n\| !assigns(then) && !assigns(else))`. `$bool` rebind after forget matches insert-after-retain. I do not see a guard that round 2 would mark and this walk would miss, or the reverse.

The new `w15a5_setup_*` tests (`setups.rs` 5–16, 57–67) keep `a0 = connected[p] > 0` … `aN = a{N-1}` **live** across N `if flag` siblings, then `if not aN`.
