Historical withholding is unchanged.

**Acquisition.** Snapshot pages with `stage_snapshot` return before `ACQUIRED` (`device.rs:457-460`). Publication and the marker commit together on the last catch-up page (`521-526`). Interrupted snapshot/catch-up stays unacquired. `admit` maps `Prediction` to an unpredicted durable queue (`623-647`, `predictions.rs:47`). Literal-default widening keeps the marker only when table count is unchanged (`240-241`, `328-329`), matching “added tables need acquisition.” Reset without that path writes an empty marker. Queries do not invent empty complete pages.

**Browser persistence.** `web.ts` returns a reply only after `persist.save`; on failure it `free()`s the live device and later `restore()`s from load with no backend (`83-106`). Open/orphan failure releases the lock (`70-76`). `hold()` now awaits the Web Locks request (`200-217`). Wasm is compiled and export-checked before cache promotion; wasm-bindgen identity is bound to the initialized digest (`137-163`). Same content can retry; a different digest requires reload. Node durability tests plus `witness/idb.mjs` cover abort, lock release, orphan source removal after destination commit, and incompatible-byte retry.

**Release restore.** Serving rewrites `releases/N/.snapback4/store.sqlite` to relative `../../../store.sqlite` under the deployment lock, and refuses a regular file (`releases.rs:158-176`). Depth matches `project.rs` (`releases/N/.snapback4`). The restore test copies with `cp -a` after stop, reads through a fresh process device, and keeps the original deployment’s later rows out. Two-step unlink/symlink is not a power-loss claim.

**TCP_NODELAY.** Set on accepted TCP streams before wrap (`vendor/tiny_http/src/connection.rs:29-36`); Unix sockets unchanged. Framing, ceilings, and deadlines are untouched. The patch’s 20.25s vs 4.61s / 273-receipt write-up matches the stated Linux debug counterfactual and does not mint a gate.
