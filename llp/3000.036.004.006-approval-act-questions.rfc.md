## Approval questions

SEC11b item 2 extends the existing advisory campaign. An actual positive
receipt read together with a typed write establishes the modeled act, including
an insert into the approved parent. The operation's name does not determine
the act. Existing precise coupled-flag gates remain unchanged.

The checked resource argument must identify the actual parent write target.
A descendant observation must be the selected source write and an actual
false-to-true completion on its next association; cancellation, no-op and
retargeted old associations cannot supply this question.

A guarded parent stage can suggest a scoped prerequisite on a related child's
Boolean completion effect. This is a question about the exact descendant
operation, not a claim that every child effect shares the parent's business
meaning. Preserve the original branch condition and the unique typed reference
path. A current admitted write violating that scoped hypothesis supplies the
witness. An unresolved path supplies no witness.

When an insert copies a principal identity and caller ordinal, and that ordinal
selects a receipt requirement keyed by a prior parent, ask whether the ordinal
must come from the stored same-identity population. A separate question asks
whether the selected prior parent may be older than another same-identity row.
The supported whole-body receipt scan requires a sole top-level returned insert,
no prior exits/loops, no caller argument rebinding, and receipt applicability
expressed in actual arguments. Unresolved aliases stay uncovered.

The latter needs the actual invocation's selected reference, a strictly higher
stored ordinal, and the matching receipt. Equal ordinals do not establish a
newer row. Neither inferred meaning is a production obligation.

Private analysis metadata for latest-subject judgments is evaluated only by
the replay observer with actual arguments, typed stored rows and exact receipt
keys. It never becomes executable application IR. The complete ordinal, receipt and applicability semantics participate in the
canonical candidate, so a changed hypothesis renews its decision. Unknown
receipt evaluation remains unknown. Supporting dependencies and
actual old/new images join the existing redacted witness identity. Generated
initialization is labeled; it is not claimed reachable from an empty app.

All three questions remain advisory, use the existing bounded question campaign
and witness-addressed acknowledgment, and appear by default only with current
concrete replay evidence. No synthetic image, verb match, source cache or
exhausted search can create a gate. No deploy scheduling or latency work belongs
to this amendment.

The receipt-question campaign retains null as a valid optional-reference proposal
when its referenced population is empty. Missing required references supply no
invented placeholder row. For operations selected by these questions, at most
16 source-literal paths and 32 correlated argument tuples precede the existing
512-tuple cap. Literal equality and inclusive numeric boundaries suggest tuples;
every argument, lookup, authority check and branch still executes normally.
Focused continuation pairs include optional typed parent references and these
receipt-reading insertions, within the existing call/work bounds. None of
these proposal changes creates admission or extends the gate work budget.

Caller-history evidence is specifically an applicability bypass: an ordinal
already in the approval-requiring branch cannot witness this question merely
because another insertion has reused that ordinal. The full same-identity
population and actual stored caller ordinal remain in the replay evidence.

This bounded history lane accepts only a bare positive receipt `require` and a
positive, direct inclusive caller-ordinal comparison selecting its branch.
Short-circuit receipt alternatives, negated/composite threshold conditions,
unknown lexical aliases and early exits remain uncovered. An approval-requiring
else branch must not be mistaken for the bypass branch. These restrictions
preserve actual receipt evaluation and the polarity of applicability; future
broader forms need their own execution-path evidence.
The supported receipt's enclosing branch premises must depend solely on that
ordinal and literals. Independent feature flags or row-dependent exemptions
cannot be dropped when asking whether a caller bypasses approval; those shapes
remain uncovered by this narrow history lane.
